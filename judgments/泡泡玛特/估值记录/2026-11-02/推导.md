### ⚠️ 本估值的核心含义(必读)

这套输入描述的世界是:**2026 年是 LABUBU 退潮的谷底**——归母从 2025 年的 127.76 亿降到约 77 亿(−39.6%);**2027 年起新 IP 接棒**,利润每年回升 10%,2029 年回到约 103 亿,相当于 2025 年峰值的八成。

1. **买点不含**:LABUBU 二次爆发、海外重新放量、再出一个 THE MONSTERS 量级的爆款——这些都是免费期权。
2. **本估值容忍**:2026 年利润近四成的下滑(已在 P₁ 里);THE MONSTERS 继续萎缩,只要新 IP 补得上。
3. **失效边界**:2026 年报归母 < 65 亿;或 2027Q1 业务更新整体同比仍为负;或星星人收入同比转负(接棒主力熄火);或存货减值与递延所得税资产减记合计 > 5 亿——任一出现即作废重跑。
4. **与市场定价对照**:按 P₁=77.2 反推,2026-11-02 现价隐含 2026–2029 年每年 +14.2%、2029 年约 115 亿,比本估值的 +10% 更乐观——所以现价在买点之上。要让现价落到买点,股价需再跌约 10.7%(≈122 港元),或 2026 年归母做到 86.4 亿以上。

## 四、g 与 P₃ 推导

- **历史 CAGR 不可用**:2020–2025 年归母复合约 89%(5.24 → 127.76 亿,`利润表.csv`),是 LABUBU 脉冲,外推无意义。
- **LABUBU 例外的量级**(2026-11-02 测算):若 THE MONSTERS 保持 2023 年 5.84% 的营收占比(即与其他 IP 同步增长),2025 年营收约 244 亿、归母约 71–84 亿(只剔直接贡献);若连光环一起剔(其他 IP 只按 2023 年 +36.3% 增长),2025 年归母约 20–25 亿(`分部营收.csv`、`利润表.csv` 派生)。2026 年 THE MONSTERS 仍远在正常线以上:2026H1 44.54 亿,正常线约 7.9 亿(`分部营收-H1.csv` 派生)。
- **「新 IP 接棒」的证据与分量**:2026H1 THE MONSTERS −7.5%,其他 IP 合计 +40.4%;但其中星星人 3.89 → 26.50 亿(+580.6%),剔掉 THE MONSTERS 与星星人后,其余 IP 只 +16.1%(86.73 → 100.69 亿,`分部营收-H1.csv` 派生)。接棒目前主要押在星星人一个 IP 上,它同样受单 IP 周期约束。
- **workflow 建议 g ≈ −5%**:LABUBU 到 2029 年退回普通 IP 水平、其他 IP 每年约 +10%,2029 年归母约 66–79 亿,对应 g 约 −5%~0%。

## 八、估值状态与敏感性

- **状态:合理**(买点 1,413 ≤ 市值 1,582 < 卖点一 3,860)。市值 = 买点的 111.9%,股价需跌约 10.7%(≈121.9 港元)才到买点;市值只有卖点一的 41.0%。
- **汇率**:按 0.886 计,市值 1,610.71 亿 = 买点的 114.0%,结论不变。
- **P₁ 敏感**(g = 10%):P₁ = 65 → 买点 1,190 亿(102.7 港元),市值是它的 1.33 倍;P₁ = 90 → 买点 1,647 亿(142.2 港元),市值是它的 0.96 倍,转为便宜。**2026 年归母 ≥ 86.4 亿时现价即落入「便宜」**——门槛在 65–90 亿的估计区间之内,2026 年报是关键。
- **隐含 PE**:2025 年归母 12.4 倍;2026E 20.5 倍。
- **假设栈总评**:P₁ 取基准(不保守);g 取 +10%(高于 workflow 建议的 −5%,用户 override);PE 27.5 全库统一。保守性只来自五折买点一层。与 2026-07-17 轮相比,下行主要由 P₁ 下修吸收,买点随之降到 2026-07-17 轮的 50.4%。
