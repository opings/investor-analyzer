## 输入

| 符号 | 定义 | 值 | 来源 |
|---|---|---|---|
| **P₀** | 最近一个完整年度扣非归母(亿元) | | `财务数据/利润表.csv` |
| **P₁** | 当年预计扣非归母(**当下财年**预估值·面向未来) | | 用户输入 / CAGR 建议 override |
| **P₃** | 三年后预计扣非归母 | | 近 3-5 年 CAGR 外推·用户 override |
| **r** | 你能锁定的最低无风险利率(排除信用风险产品) | 3.6% | 大额存单/货基/逆回购最低那档 |

> **变量来源说明**:如果 P₁ / P₃ 用户 override 了 CAGR 建议,写明 override 原因(经营变数/一次性事件/增速拐点等)

## 公式(成长股估值法)

```
合理 PE = 1 / r = 1 / 3.6% = 27.5

合理估值 = P₃ × 27.5 = ___ 亿(三年后)
买点     = 合理估值 × 50% = ___ 亿

当年卖点三档(基于 P₁):
  第一档(卖 1/3)= P₁ × 50 = ___ 亿
  第二档(卖 2/3)= P₁ × 55 = ___ 亿
  第三档(清仓) = P₁ × 60 = ___ 亿
```
