# backtest-call

让大V的"嘴"接受数据检验。

## 何时激活

- "复盘 XX 2025-Q1 对地产的观点"
- "XX 去年喊的 600519 后来涨了吗"
- "过去一年 AA 的胜率怎么样"

## 工作流

1. **圈定范围**
   - 哪位大V？**先读 `knowledge/gurus/INDEX.md`** 把中文名/别名映射到 slug；查不到 → 未收录，不要臆造目录。若状态是 `⚪ 骨架`（无正文）→ 直接告知"该大V知识库尚未录入，无 call 可回测"
   - 哪个时间窗口？（如 2025-Q1 / 过去一年 / 自数据收录起）
   - 哪个标的或主题？

2. **抓出原观点**
   - 在 `knowledge/gurus/<昵称>/calls/` 和 `posts/` 里筛符合时间窗 + 标的的条目
   - 提取：观点日期、方向、目标位（若有）
   - **先查 `knowledge/gurus/<昵称>/coverage.md`**：时间窗落在空洞（✗）→ 直接说"该时段无 call 可回测"

3. **定验证窗口（随持仓周期，不写死）**
   - 读 `knowledge/gurus/<昵称>/current-view.md` 或 `style.md` 的"持仓周期"
   - **长线投资者（持有以年计，如老唐 3-5 年）→ 验证窗口至少 1 年，最好对齐其声称的持有期**，绝不要用 3 个月窗口判长线 call 的对错（会系统性误判）
   - 短线/波段大V → 可用周/月级窗口

4. **拿后续行情（优先实测，不要瞎估）**
   - **首选：跑行情脚本** `python3 scripts/quote.py <代码> <起> <止>`（详见下方「行情数据」节）
     - 返回区间首尾收盘价 + 涨跌幅，自动算 ✓/✗
   - 脚本拿不到（停牌/退市/网络/未装依赖）→ 退回：
     - (a) 用户提供后续行情数据（贴价格 / 截图）
     - (b) Claude 基于训练数据粗略评估，**必须标注"非实时、可能不准"**
   - 切忌瞎编具体涨跌幅

5. **输出**

```markdown
# 信号复盘：<大V> · <时间窗> · <标的/主题>

> 复盘日期：YYYY-MM-DD
> 数据基础：N 条 calls，行情数据来源 <用户提供 / 公开估算>

## 观点清单

| 发表日 | 标的 | 方向 | 论据 | 验证窗口 | 实际表现 | 准确 |
|--------|------|------|------|---------|---------|------|
| 2025-01-12 | 600519 | 看多 | 现金流强 | 3 个月 | +12% | ✓ |
| 2025-02-20 | 0700.HK | 看空 | 监管风险 | 3 个月 | +8% | ✗ |
| ... | ... | ... | ... | ... | ... | ... |

## 统计

- 总观点数：N
- 准确：X (X%)
- 错误：Y (Y%)
- 时间太短无法判断：Z

## 模式

- 在 <行业> 上准确率高，在 <行业> 上偏低
- 看多的胜率 > 看空 / 看空的胜率 > 看多
- 短期判断 vs 长期判断的差异

## 把复盘结论沉淀回 style.md

更新 `knowledge/gurus/<昵称>/style.md` 的"标志性判断"表格，让画像越来越准
```

## 行情数据（scripts/quote.py）

- 位置：项目内 `scripts/quote.py`，基于 AkShare（免费、无需 token，支持 A 股 / 港股 / 指数）
- 用法（单条命令，不要复合）：
  ```
  python3 scripts/quote.py 600519 2018-12-28 2021-12-31
  ```
  输出区间首尾收盘价 + 涨跌幅（前复权）。**A 股填 6 位**（`600519`），**港股填 5 位**（`00700`），**指数加前缀**（`sh000300` / `sz399006`）。
- 依赖装在项目 venv（`scripts/.venv`，已装好 akshare）。脚本会**自举**：用系统 `python3` 跑会自动切到 venv，无需手动激活。
- 重装依赖（如换机器）：`python3 -m venv scripts/.venv` 然后 `scripts/.venv/bin/pip install akshare`
- **数据源统一新浪首选**（A股/港股/指数），东财仅作 A 股兜底；输出会打印「数据源」一行
- ⚠️ **跨源不可比**：东财与新浪前复权锚点不同，同一标的两源涨幅会差很多（茅台曾 +260% vs +439%）。算**精确收益率**时只认输出里标注的那个源，别混用
- 偶发连接中断**重试一次**通常即可
- **脚本只取行情，不下判断**——✓/✗ 由 skill 结合方向 + 验证窗口判定

## 注意事项

- **不要编涨跌幅**：脚本拿不到、用户也没给 → 就说没有，别用印象编
- **"看多但没涨"≠"错"**：验证窗口必须匹配持仓周期（见工作流第 3 步），长线 call 别用短窗口枪毙
- **样本量要够**：3 条 calls 算不出胜率，至少 10 条
- **复盘后回写**：把结论写进 `style.md`「标志性判断」表 + `current-view.md`（若该判断改变了当前立场），闭环收敛
