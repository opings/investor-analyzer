# 估值法选择器（valuation-method）

> **一句话**：所有估值的本源都是 DCF（企业内在价值＝其余生所能产生现金流的折现总和）。不同"估值法"只是 DCF 在不同企业类型上的**不同简化**。本 skill 的职责＝**先判断企业属于哪一类 → 选对方法 → 套对公式**。
> 📐 **本 skill 是估值方法论 / 三大前提 / 三类估值公式的 canonical（唯一权威）源**。`caibao-analysis`、`finance/_模板/财报阅读规则.md`、`tangchao/playbook.md` 涉及估值公式时以本文件为准、不另行推导；它们各自的副本仅为本地检索方便，口径冲突时改它们而非改这里。
> 估值库根目录：`finance/`。配套：`caibao-analysis`（先提财报数据）、`tangchao`（老唐法溯源）。

## 何时激活

## 核心理念（所有估值的同一个地基）

> 巴菲特（1994 致股东信）："内在价值 ＝ 一家企业在其余下生涯中所能产生的现金流量的折现值。"
> 伊索寓言「二鸟在林不如一鸟在手」：林中的鸟值多少，取决于 ①有几只（现金流量级）②多久抓到（时间）③无风险利率（折现率）。

**三种方法 = 同一个 DCF 的三种简化：**

| 你的叫法 | 专业名 | 数学本质 |
|---------|--------|---------|
| 老唐成长股估值法 | **简化（两阶段）DCF / 收益资本化法** | DCF 的永续年金特例：合理 PE = 1/无风险利率 |
| 巴菲特现金流折现 | **DCF（Discounted Cash Flow）/ 所有者收益折现** | 完整多阶段折现 + 永续价值 |
| 周期股十年平均法 | **CAPE / 席勒市盈率（Cyclically Adjusted P/E）** | 用十年正常化盈利消除周期噪音后的 PE |

## Step 0：先过「双闸门」（值不值得估 → 能不能估）

估值之前先过两道前置闸门，顺序不能反：先问"**是不是好生意（值不值得估）**"，再问"**能不能估**"。

> 📐 **本 skill 是「生意质量四问 + 三大前提」双闸门的 canonical（唯一权威）源。** 其他 skill（`invest-report`、`caibao-analysis`、`tangchao/研究新公司-SOP.md`）涉及这两道闸门时以本文件为准、指针式引用，不另抄正文。

### Step 0a：生意质量四问（护城河自检 → 值不值得估）

估值是"给好生意定价"，不是"给烂生意找借口"。**先考虑买对，再考虑买贵**——下面四问全是"是 / 有"才算一门有护城河的好生意（通用，不限某位大V）：

1. **靠什么获利？**——它卖的是什么商品/服务，被持续需要吗？（商业模式）
2. **客户为什么选它？**——难替代吗、转换成本高吗？（客户黏性）
3. **资本逐利天性下，为何别人没提供更高性价比？**——现有护城河在哪？（现存壁垒）
4. **同行挟巨资能否抢走份额？**——护城河扛得住吗？（壁垒可持续性）

- 四问都站得住 → 好生意，进 Step 0b 看能不能估。
- **任一问存疑** → 生意质量打问号：要么估值取更保守的假设，要么直接归入"太难"。**好生意是估值的前提，便宜从来救不了烂生意。**

配套判据（任选其一交叉验证）：
- **优势赢平均三要素**：被需要 + 难替代 + **价格不受管制**（水电这类受管制只有浅护城河）。
- **护城河 5 来源**：无形资产（品牌/专利/牌照）/ 转换成本 / 成本优势 / 网络效应 / 有效规模。
- 出处溯源见 `tangchao/playbook.md` §2、第 55/60 章（老唐核心 4 问 + 福寿园范本）。

### Step 0b：三大前提闸门（决定能不能用公式）

任何 PE/净利类简化法，前提是 **净利润 ≈ 自由现金流**。老唐三大前提（缺一不可）：

1. **利润为真**？（经营现金流/净利 ≥ 1，看现金不看账面）
2. **利润可持续**？（生意模式稳定、可预测）
3. **维持当前盈利不需大量资本投入**？（资本开支占净利低，轻资产/印钞机）

- 两道闸门全过 → 净利可代表自由现金流，进 Step 1 选法。
- **任一条不过**（尤其②不可预测：爆款驱动/技术剧变/前景高度不确定）→ **不套公式，直接下结论「无法估值」**（归入巴菲特"太难"那一堆 / 能力圈外）。**不给买卖点、不强行造数字**；可定性说明"为什么不能估"+ 列跟踪变量，但这不是估值结论。
  - 这是老唐/巴菲特/段永平的本来纪律：**能力圈外直接 pass，不研究估值**。不做"情景区间"凑数——区间会给人"已经估过"的错觉。
  - 范例：泡泡玛特（爆款 IP Labubu 占 38%、三年后净利无法可靠预估）→ `finance/泡泡玛特/分析.md` 结论＝**无法估值**，不给买点。
  - **「无法估值」登记（两处齐才算归档）**：① 该公司 `分析.md` 投资决策块「可估值性=无法估值·评级=太难」 ② `finance/README.md` 状态表评级列标「太难」。现存太难池：美团 / 圣邦 / 泡泡玛特 / 五粮液（一眼可查全库有几家被判太难，便于能力圈扩大后重审）。

## Step 1：企业分类判据 → 给出「建议」（最终由用户拍板）

> 🚦 **决定权规则**：方法的最终选择权**在用户手里**。本 skill 只负责**按硬信号做出判断、列出依据、给出推荐**，然后**显式请用户确认或改选**，不自动套用某法就往下算。用户已指定方法时，直接用用户指定的。

按顺序做三道判断题，每道都**填可核对的硬信号**（不要凭感觉）：

### 判断①：能不能估？（确定性闸门）→ 套公式 vs 直接判「无法估值」

| 信号（任一命中 → 不套公式） | 例 |
|------|------|
| 利润高度依赖单一爆款/短周期项目（占比大且生命周期不确定） | 泡泡玛特 Labubu 占 38% |
| 赛道技术/政策剧变，三年后格局不可知 | 多数 AI/设备 |
| 能力圈外、说不清靠什么持续赚钱 | — |
| 经营历史太短（< 一个完整周期）看不出形态 | 次新股 |

→ 命中 → 结论 **「无法估值」（归"太难"/能力圈外）**，不给买卖点、不进下两题。

### 判断②：是不是强周期？→ 方法三 vs 方法一/二

**核心看十年利润序列「形态」+ 驱动因素：**

| 信号 | 强周期（→方法三） | 稳定成长（→判断③） |
|------|------------------|-------------------|
| A 利润振幅 | 十年内**出现过亏损**，或最高/最低净利 **>3 倍** | 单调或温和上升 |
| B 定价权 | 售价由**外部商品价/供需**定，自己是价格接受者 | 有提价权/品牌/需求刚性 |
| C 毛利率 | 随景气**大幅摆动**（>10pct） | 常年稳定或缓升 |
| D ROE | 大起大落、甚至为负 | 常年稳定 >15~20% |

→ 多数命中 → 建议方法三；否则进判断③。
🔸**弱周期 ≠ 强周期**：会不会亏损、有没有定价权、振幅几倍是分界。茅台 2025 转负但不亏损+有提价权+个位数振幅 → 仍方法一；分众广告位收入随宏观大摆动 → 方法三。

### 判断③：方法一 还是 方法二？（都属稳定成长）

- **默认建议方法一**（简化够用、变量少、纪律强）。
- **改荐方法二** 任一：①重资产、折旧摊销大致净利严重偏离自由现金流 ②增长明显分段（前高后低）③要内在价值**绝对数** ④想交叉验证。

> 方法一与方法二**同源**：老唐法是 DCF 的工程化简化；日常方法一即可，精细/交叉验证才上方法二。

### 输出建议的写法（务必带依据 + 交还决定权）

> 例："**建议方法二/三/…**——依据：①利润振幅 X 倍、②价格由 Y 决定、③毛利率摆动 Z…（逐条引数据）。**但最终用哪个由你定**：要按建议（方法 X）算，还是改用方法 ?，或要我并列跑两种对比？"

## 方法一：老唐估值法（简化 DCF / 收益资本化）

> 适用：**稳定成长的好生意**（茅台/腾讯/古井/农夫山泉/安踏…）。出处：唐《价值投资实战手册》#88/#89/#124（见 `tangchao` skill）。

### 使用前提（缺一不可，不满足就别用本法）

简化的代价＝苛刻的前提。本法成立必须同时满足：

1. **三大前提（让"净利 ≈ 自由现金流"成立，是 PE 类简化的命根）**——见 Step 0：
   - ① 利润为真（经营现金流/净利 ≥ 1）
   - ② 利润可持续
   - ③ 维持当前盈利不需大量资本投入（轻资产/印钞机）
2. **利润稳定可预测、非强周期**——这样"三年后净利 = E₀×(1+g)³"才算得出；强周期股用本法会在景气顶部把它估成"便宜"（→ 改用方法三 CAPE）。
3. **增长温和可持续（g 取 10~15% 合理）**——一年翻几倍、靠单一爆款的高不确定增长不适用（g 估不准 → 判「无法估值」）。
4. **在你的能力圈内**——你能看懂生意、敢对三年后净利下判断。

> ❌ 任一条不满足 → 不要套本法。范例：泡泡玛特（②③ 不过、g 不可预测）→ 结论「无法估值」，不给买卖点。

**公式：**
- **合理 PE = 1 / 个人能获得的无风险收益率**（本库 canonical 口径，单一真相）
  - r ＝ **个人能实际获得的无风险利率**（大额存单/货基/国债逆回购等可得档，非抽象 10 年国债中债收益率），**随利率变、定期复核**。
  - **当前（2026）全库统一取 r=3.6% → 合理 PE = 27.5**（茅台/腾讯/古井/汾酒/泸州等成长股一律按此，不再 25 / 27.5 并存）。
  - 对照：4%→25x、**3.6%→27.5x（当前采用）**、3%→33x、2%→50x。**r 变了 → 全库同步重算「当期」买卖点并各记一条 `观点变更.md`。**
  - ⚠️ **历史不追溯**：`历史买卖点记录` 里的旧快照按**当时**的无风险利率（如 2024-25 多在 4%/PE25）原样保留，**绝不 retroactively 改成现值**——它们是当时的正确判断、是事实。r 变只影响**当期新买点**，不动历史行。
- **合理估值 ＝ 三年后预计净利润 × 合理 PE(25~30)**
  - ⚠️「三年后净利」面向未来：以最近实际净利 ×(1+增速)³ 推算；有当年中报实数则 refine。增速对优质企业"理性外推"取 10~15%。
- **理想买点 ＝ 三年后合理估值 × 50%**（五折买；回归合理则约年化 26%）
- **卖点 ＝ 当年预计净利 × 50 / 55 / 60 倍**，分三批清空（或三年后合理估值 ×150%）
- 高杠杆/有息负债重的企业，买点再打七折。

**为什么是三年**：经验——市场恐惧/遗忘/贪婪大致 3~5 年完成一轮交替。

### 变量拆解（哪些要估、哪些写死）

**真正要估的变量只有 3 个：**

| 变量 | 符号 | 作用 | 取值习惯 |
|------|------|------|---------|
| ① 当年预计净利润（基数） | E₀ | 一切起点，**面向未来的预估**（非上年报实际值） | 最近实际 ×(1+g)，有中报用实数 refine |
| ② 三年净利增速 | g | 把基数外推到"三年后净利" | 优质企业"理性外推"取 10~15% |
| ③ 无风险收益率 | r | 决定合理 PE | **个人能获得的无风险利率（可变），当前 3.6% → PE 27.5** |

由 ③ 派生：**合理 PE = 1/r**（当前 r=3.6% → **27.5**；4%→25、3%→33，随利率变）。

**两阶段对应：** 阶段一＝`三年后净利 = E₀×(1+g)³`（变量①②）；阶段二＝`合理估值 = 三年后净利 ×(1/r)`（变量③，隐含永续增长 g₂≈0，三年后增长只当安全边际不计价）。

**固定参数（不是变量，是纪律）：** 预测期＝3 年（写死）；买点系数＝50%（五折，同时替代"折现回今天"）；卖点倍数＝50/55/60。

**对照标准两阶段 DCF——老唐砍掉/固定了哪些变量：**

| 标准 DCF 变量 | 老唐处理 |
|--------------|---------|
| FCF₀ 自由现金流 | ≈ 净利润（三大前提成立时，省去算 FCF） |
| n 高增长期长度 | 固定 = 3 年 |
| g₂ 永续增长率 | ≈ 0（合理 PE=1/r 即 g=0 的永续年金） |
| r 折现率 | = 无风险利率 |
| g₁ 高增长增速 | 保留（＝变量 ②） |

→ 标准 DCF 的 5 个变量塌缩成 **3 个要估 + 一组写死参数**。

**终极压缩（理性外推·#S18-04）：** 优质企业把 g 固定 10~15%、r 固定（当前 3.6% → PE 27.5）→ 合理 PE 也固定 → **唯一真正要判断的就是「净利润」**。故财报分析里"扣非/经调整净利 + 增速"是估值命门。

## 方法二：完整 DCF（自由现金流 / 所有者收益折现）

> 适用：**想要内在价值绝对值**（具体数字，非"PE×净利"相对值）、**增长分多段**（一个增速套不住）、**重资产但现金流稳定**（折旧大、净利失真需直接看现金流），或给方法一**交叉验证**。出处：巴菲特/格雷厄姆；老唐 #67《漫谈现金流折现法》。

### 使用前提（比方法一更苛刻）

1. **现金流高度可预测**——要显式建模未来很多年，不可预测＝"垃圾进垃圾出"。
2. **能区分维持性 vs 扩张性资本开支**——FCF 的命门，也最难拆。
3. **g < r**——否则永续公式发散、无意义。
4. **能力圈内 + 简单生意**——巴菲特把绝大多数公司扔进"太难"那堆，只算几个。

**两阶段公式：**

```
内在价值 = Σ[t=1..n]  FCFₜ / (1+r)ᵗ   +   永续价值 / (1+r)ⁿ
永续价值 = FCF(n+1) / (r − g)
```

- **FCF 自由现金流** ＝ 经营现金流净额 − 维持现有运转必需的资本投入
  - 毛估 ≈ 经营现金流净额 − 购建固定/无形/长期资产支付的现金（**仅低速/无扩张企业可这么近似；高速扩张企业不可**）。
- **所有者收益（Owner Earnings）** ＝ 净利润 + 折旧摊销 − 维持性资本支出（− 额外营运资金）。
- **r 折现率** ＝ 长期国债利率（＝机会成本，巴菲特**不加风险溢价**，靠"只投确定性高的"替代）。
- **g 永续增长率**：保守（通胀 2~3% 或更低）；g < r。

### 变量拆解（比方法一多一倍）

| 变量 | 含义 | 难点/取值 |
|------|------|---------|
| ① FCF₀ 基期自由现金流 | 经营现金流净额 − 维持性资本投入 | ＝owner earnings；维持性 capex 最难拆 |
| ② g₁ 高增长期增速 | 显式预测期年增速（可多段 g₁,g₂…） | 最主观、误差最大 |
| ③ n 高增长期长度 | 显式折现几年 | 通常 5~10 年 |
| ④ g 永续增长率 | 第 n 年后永远的增速 | 必须 g < r；保守取 ≤ 通胀 |
| ⑤ r 折现率 | 机会成本 | 长期国债利率，不加风险溢价 |

→ **5~6 个变量**（方法一只要 3 个）。

### 最关键纪律：终值敏感性

- **永续价值常占内在价值 60~80%**，而它由 g、r 决定；g 或 r 动 1 个百分点，估值可摆动 30%+。
- 故巴菲特要"**模糊的正确胜过精确的错误**"：**不拉精细 Excel**，只对确定性极高的简单生意毛估，算完再**打安全边际折扣**（＝按债券估值再打对折）。其余归"太难"。
- **这正是老唐简化成方法一的根本动机**：把 5~6 变量砍到 3 个（固定 n=3、g₂≈0、FCF≈净利），变量越少、误差越小、纪律越能执行。

## 方法三：CAPE 席勒市盈率法（周期调整市盈率）

> 适用：**强周期股**（利润随商品/景气大起大落，单年利润无意义）。专业名 CAPE（Cyclically Adjusted P/E，Robert Shiller 据格雷厄姆思想推广）；唐朝体系称"席勒法/十年正常利润法"。范例：陕煤、中海油、分众、胜狮货柜。

### 使用前提

1. **确属强周期**——利润随商品价/景气大起大落（钢铁/煤炭/航运/原油/水泥/面板/猪/化工/广告…）；若利润其实稳定，别用本法（→ 方法一）。
2. **生意能跨越周期存活**——公司不会在周期低谷破产（资产负债表扛得住），否则"十年均值"无意义。
3. **有足够长的盈利历史**——理想 ≥ 完整一轮周期（约 7~10 年）；太短不足以平滑噪音。
4. **周期属性稳定**——主业没发生结构性质变（否则历史均值不代表未来正常盈利）。

**核心**：用**十年正常化盈利**消除周期噪音，而非当年利润。

- **正常化盈利 ＝ 近十年扣非净利均值**（理想再做通胀调整；数据不足十年用尽可能长的全周期均值）。
- **唐朝版买卖点（均以「十年均值」为基数，PE 与系数只各算一次，勿重复计 PE）：**
  - 合理市值区间 ＝ 十年正常利润均值 × 合理 PE（25 / 30）
  - **买点 ＝ 十年均值 × PE 下限(25) × 0.7**（安全边际）
  - **卖点 ＝ 十年均值 × PE 上限(30) × 1.5**
  - 🔸**曾亏损/盈利格外不稳的周期股，对"十年均值"再加一层净利折扣**（如陕煤额外 ×0.7 → 买点＝均值×25×0.7×0.7）。这层折扣是个案保守裁量，非通用项。

### 变量拆解

| 变量 | 含义 | 难点/取值 |
|------|------|---------|
| ① 十年正常化盈利 E_norm | 近十年扣非净利均值（理想通胀调整） | **核心变量**；周期/口径选取最关键 |
| ② 合理 PE | = 1/无风险收益率 | 同方法一，取 25~30 |
| ③ 买点系数 | 0.7（PE 下限再打七折） | 固定纪律 |
| ④ 卖点系数 | 1.5（PE 上限再上浮） | 固定纪律 |
| （可选）净利折扣 | 对曾亏损/极不稳的周期股再 ×0.7 等 | 个案保守裁量（如陕煤），非通用 |
| （辅助判断）当前周期位置 | 现价/盈利处于周期顶/中/底 | 非公式变量，但决定买卖时机 |

→ 真正要估的就 ① 一个（E_norm）；②③④ 是固定参数。与方法一的差异**只在于"基数"——用十年均值代替"三年后单年净利"**。

### 最关键纪律：严禁用成长法

- 周期股**绝不能用方法一/单年 PE**——景气顶部单年利润最高、PE 反而最低，会把它估成"便宜"，这是最大的坑。
- **事实相反**：周期**顶部（高利润、低 PE）应卖**，**底部（巨亏/亏损、高 PE 或无 PE）反而可能是买点**。
- 判断**当前处于周期什么位置**比精确估值更重要（"准确估值是最不重要的"）。
