# ingest-guru

把用户给的原始材料结构化后落盘到 `knowledge/gurus/<昵称>/` 下。

## 何时激活

- 用户贴了一段长文 + 提到了某个大V昵称
- 用户贴了持仓表格/截图 + 提到大V
- 用户说"把这篇归档到 XX 名下"、"录入 XX 的最新持仓"

## 工作流

1. **确认大V身份**
   - 用户提到的昵称是否已在 `knowledge/gurus/` 下？
   - 若不存在：先 `cp -r knowledge/gurus/_template knowledge/gurus/<昵称>`，再问用户 profile 关键信息（平台 / 主页链接），但不卡住流程，先收数据
   - 若存在：直接进下一步

2. **判断材料类型**
   - **文章/帖子** → 归档到 `posts/YYYY-MM-DD-标题.md`，模板见下
   - **持仓表格** → 归档到 `holdings/YYYY-MM-DD.md`
   - **关键观点（明确看多看空某标的）** → 同时在 `calls/YYYY-MM-DD-<标的>.md` 立一条，方便后续复盘

3. **抽取元数据**（保存到归档文件顶部 frontmatter）
   - 发表日期（务必！没有就问用户）
   - 原文链接 / 来源
   - 提到的标的代码（中文名 + 代码都记，例：贵州茅台 600519）
   - 方向标签：看多 / 看空 / 中性 / 复盘

4. **更新 coverage.md**（每次都做，轻量）
   - 把这篇材料所属的年-月在 `coverage.md` 热力图标成 `◐`/`✓`
   - 新建 guru 时从 `_template/coverage.md` 复制

5. **可选：更新 style.md / current-view.md**
   - 若材料补充了风格画像（第一次发现用杠杆、风格转向）→ 追加到 `style.md`
   - 若材料**改变了当前立场**（如以前看多某股现在清仓）→ 同步刷新 `current-view.md`，把旧立场移进"已废弃/已演化"表

## 归档模板

### posts/YYYY-MM-DD-标题.md

```markdown
---
date: YYYY-MM-DD
source: 雪球 / 微博 / 公众号
url: <原文链接>
tickers: [600519, 0700.HK]
direction: 看多 / 看空 / 中性 / 复盘
topics: [白酒, 港股]
---

# <原标题>

## 核心观点（3 句话以内）

…

## 原文

<粘贴原文，不做改写>

## 我的笔记（可选）

<用户额外补充>
```

### holdings/YYYY-MM-DD.md

```markdown
---
date: YYYY-MM-DD
source: 雪球组合 / 财报披露 / 自报
---

| 代码 | 名称 | 仓位% | 较上次变动 | 备注 |
|------|------|-------|-----------|------|
| 600519 | 贵州茅台 | 25% | +5% | 加仓 |
| ... | ... | ... | ... | ... |

## 同比上一次的变化总结

- 加仓：…
- 减仓：…
- 清仓：…
- 新建：…
```

## 注意事项

- **日期必填**，没有日期的材料先问用户，别瞎填"今天"
- **不改写原文**，用户给什么粘什么；笔记/总结放在独立区块
- **标的统一带代码**：600519 而不只是"茅台"，方便 stocks/ 反查
- **一次只处理一份材料**：多份材料分多次归档，避免混淆日期/来源
