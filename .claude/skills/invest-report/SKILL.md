# invest-report · 综合投资参考报告

把三个维度拼成一份**投资参考**（不是投资建议——决定权在用户）：

```
① 财报数据 + 风险预警   (caibao-analysis)
② 估值与买卖点          (valuation-method)        ──► 一份《综合投资参考》
③ 多位大V视角           (guru-view / 专属 skill)
④ 现价对照              (scripts/quote.py)
```

> **本 skill 是编排器，不重抄任何公式/规则**。每一步委派给对应 skill，本文件只负责"按顺序串起来 + 综合成报告"。

## 何时激活

- "出一份 XX 的投资报告 / 综合估值 / 投资参考 / 投研"
- "XX 现在能不能买 / 值不值得买 / 贵不贵"
- "帮我综合评估 / 全面看看 XX"
- "老唐和段永平会怎么看 XX 该不该买"

> 只问其中一维时**别用本 skill**，直接用对应单 skill：只提财报→`caibao-analysis`；只问估值→`valuation-method`；只问大V视角→`guru-view`/专属 skill；只复盘历史判断→`backtest-call`。

---

## 前置：先确认输入齐不齐

1. **财报数据**：`finance/<公司>/` 是否已有数据？
   - 有 → 直接用库里的（`分析.md` + `.xlsx`）
   - 没有/不全 → 先走 `caibao-analysis` 提数（用户得先给财报；缺的标 `⏳待补`，**不编造**）
2. **大V视角选谁**：用户指定了就用指定的；没指定**默认 老唐 + 段永平**（已有专属 skill 的），并可纳入 `knowledge/gurus/` 下其它提过该标的/同行业的大V。
3. **现价**：能跑 `scripts/quote.py <代码>` 就取实时收盘；取不到则标"现价待用户提供"，不臆测。

## 编排工作流（严格按序，不跳步）

### Step 1 · 财报数据 + 风险预警 → 委派 `caibao-analysis`
- 产出：本期关键数据提取（扣非净利/营收增速/经营现金流/合同负债/应收/资本开支…）
- 产出：**三大前提复核**（✅/⚠️/❌）——这是"能不能估值"的闸门
- 产出：**分级风险预警**（🔴暴雷嫌疑 / 🟡需关注 / 🟢正常）= 通用红旗（对照 `knowledge/造假案例库/造假模式库.md` 这份随案例增长的活清单扫描）+ 该公司 `财报关注要点.md` 特有项

### Step 2 · 估值与买卖点 → 委派 `valuation-method`
- 先过三大前提闸门：**任一不过 / 爆款·技术剧变·能力圈外 → 直接「无法估值」**，不套公式、不给买卖点（归"太难"），报告照出但 Step 2 结论=无法估值。
- 能估 → 给方法建议 + 依据（成长=老唐法 / 绝对值=完整DCF / 周期=席勒法），**请用户拍板方法**（用户已指定则直接用）→ 合理估值 + 买点 + 卖点。

### Step 3 · 多位大V视角 → 委派 `guru-view`（多人模式）/ 专属 skill
- 对默认/指定的大V，逐人给：**该大V会怎么看这家公司**（风格契合度 + 用其估值标准套这家公司的隐含买卖点）。
- 有专属 skill 的（老唐→`tangchao`、段永平→`duanyongping`）走专属 skill 取更准的出处；其余走 `guru-view`。
- ⚠️ 只基于已蒸馏知识库，没有就说没有，带日期+出处。

### Step 4 · 现价对照 → `scripts/quote.py`
- 取现价 → 落在买/卖区间何处（便宜 / 合理 / 高估 / 已触卖点）。
- A股6位 / 港股5位 / 指数带前缀；取不到标"现价待补"。

## 调用纪律（继承各子 skill，不放松）

1. **先提数→再估值→再综合，不跳步**：没有财报数据不开估值；没过三大前提不给买卖点。
2. **不确定生意直接「无法估值」**：爆款/技术剧变/能力圈外不强造数字（继承 `valuation-method`）。报告照出，但 Step 5 = 无法估值 + 跟踪变量。
3. **大V视角只基于已蒸馏知识库**：没有就说没有，带日期+出处（继承 `guru-view`/专属 skill）。
4. **风险预警两层**：通用红旗（对照 `knowledge/造假案例库/造假模式库.md`，随真实造假案例增长的活清单）+ 公司特有（`<公司>/财报关注要点.md`），分 🔴/🟡/🟢，每条带数据依据。
5. **不编数据**：缺失标 `⏳待补`，现价取不到标"待补"，不臆测。
6. **这是参考不是建议**：方法选择权、买卖决定权都在用户；报告顶部固定免责声明。
7. **沉淀回库**：报告结论可回写 `finance/<公司>/分析.md`（走 caibao 的更新流程），形成闭环。
