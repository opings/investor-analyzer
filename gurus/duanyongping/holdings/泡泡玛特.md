## 🔴 头号口径警告：DI「长仓」≠ 实物持股

**媒体与本文件早期版本所载的 6.04% / 7.65% 都是 DI 长仓口径，不是他持有的实物股票比例。**

依 SFO 第XV部（SFC《第XV部的概要》2024-05-24 版）：
- **§2.4.1(ii)「你有责任购买相关股份」⇒ 卖出 put 计入「长仓」**
- **§2.4.2(ii)(b)「你有责任交付相关股份」⇒ 卖出 call 计入「淡仓」**
- **§2.6.3.1 长仓与淡仓不得互相抵销**，须分开申报
- **§2.6.7** 分母不因期权/权证/可换股债而变大 ⇒ 长仓分子含名义股，比例天然虚增

段惯用「卖 put 建仓 + 备兑卖 call 收租」（其自述"我投资的利润在普通年景里有很大一部分就是来自于 options"，2011-01-21），
**故他在本标的的每一个披露百分比都必须拆口径后才能引用**。2026-07-30 事件已完成一次拆解（见下）。

## 2026-07-30 事件拆解【推】

由上表披露值算术还原（五个百分比同锁总股本 ≈ **13.30 亿股**）：

```
事件前  实物持股      ~8,290.0 万股  (6.23%)  ─┐
        卖出 put       1,900.0 万股  (1.43%)  ─┴→ 长仓 10,190 万股 / 7.65%
        卖出 call      2,131.8 万股  (1.60%)  ───→ 淡仓 1.60%（备兑比例 25.7%）

07-30   put 到期失效  -1,900.0 万股  → 长仓 -1.43pp，**零股份成交**
        call 被行权     -893.28 万股  → 长仓 -0.67pp，**真实交出股份** @162.50
        call 价外作废   -768.02 万股  → 只减淡仓

事件后  实物持股      ~7,396.7 万股  (5.56%)  ≈ 披露后长仓 7,393 万股（差 3.72 万股 / 0.003pp）
```

**结论：实物持股实际只从 6.23% 降到 5.56%（-0.67pp）；披露口径的 -2.10pp 把变动放大 3.1x。**
事件后的 5.55% 反而是比过去 7.65% **更"干净"**的数字（长仓已不再掺 put 名义）。

**媒体「套现约 45 亿港元」为错算**：893.28 万×162.5 = 14.52 亿（真实现金）+ 1,900 万×162.5 = 30.88 亿（**从未成交**）= 45.39 亿，
即把整个 2.1pp 按市价折算，**68% 对应不存在的成交**，真实成交额被高估 3.1x。

**时点自证**：HKEX 月度股票期权到期日 = 到期月最后营业日之前一个营业日；2026 年 7 月最后营业日 07-31（五）⇒ 到期日 **07-30（四）**，与事件日精确吻合；
09992 股票期权已于 **2025-10-13** 在 HKEX 上市 ⇒ **"期权到期"这个解释不依赖任何当事人自述即可成立**。

## 结构与其自述方法的对照

段对这两条腿都有长期记载（出处见 `posts/投资逻辑篇.md` 六.金融衍生品套利 / `playbook.md` §5）：

- **"short put 的说法骨子里是不对的，因为卖 put 其实是 long。不懂不要乱用术语哈。"**（2011-04-11）
  ——与 SFO §2.4.1(ii) 把「有责任购买」归入**长仓**的逻辑一致；监管定义与其自述在此罕见对上
- "卖 covered call 和卖 put 在数学上是等值的（没区别）。"（2020-11-26）
- **"naked call 和做 short 都是属于不对的事情。"**（2011-10-04）
  ——**可验证**：淡仓 2,131.8 万股 < 实物 ~8,290 万股 ⇒ 确为**备兑**而非裸卖 ✓
- 卖 put 的前提："愿意以那个价格长期持有这家公司"，否则就是投机
- ⚠️ **"我一般想卖的股票会倾向于卖 call，除非是着急用钱或想跑的时候。我的网易就是用卖 call 的办法慢慢卖掉的……从 30 一直卖到了 50。"**（2010-08-12）
  ——按其自身定义，卖 call 是他"慢慢卖掉"一只股票的手法；事件前备兑比例 25.7%。
  **两条事实（07-23"10 年不卖"表态 / 25.7% 备兑）并列存档，不作言行一致性裁定**（铁律：不做大V回测/胜率复盘，见 `_schema/知识库结构规范.md` §3 L4 + [[discipline.md]]）

## 跟踪 / 待验证（⏳）

1. **🔴 5% 能见度悬崖**：现长仓 5.55%，距 5% 线缓冲 **742 万股 / 0.56pp**。剩余卖出 call 470.5 万股即便全被行权，也只降到 **5.20%**（仍在线上）；但**一旦跌破 5%，即退出 DI 披露义务，此后该股东完全不可追踪**。
2. **下一个机制性时点：2026-08-28**【推】（HKEX 8 月股票期权到期日 = 最后营业日 08-31 前一营业日）——每个月度到期日都可能再次机械改变披露数字。
3. **是否仍为第二大股东**：7.65% 时媒体称仅次于王宁；**5.55% 后是否仍居第二位未核【疑】**。
4. **DI 原件未取**：di.hkex.com.hk 于 2026-08-06 共 4 次访问均返回 temporarily unavailable。上表股数/淡仓/交割价均为**媒体转载的单链条二手来源**（算术互锁自证一致，但非原件核实）。原件可访问时优先核：**07-06 增持 1,059 万股的事件代码**（区分实物买入 vs 卖出 put）、07-30 存档日、行权价档位。
5. **权利金收入不可知**：DI 只披露股份权益，权利金不在披露范围 ⇒ 这套"期权收租"的实际收益与**真实有效成本**均无从计算，**不推测**（"估计均价约 150 港元"为媒体口径，且未计权利金）。
6. **验证窗口**：段为超长线投资者，以**年**计，勿用短窗口评判。
