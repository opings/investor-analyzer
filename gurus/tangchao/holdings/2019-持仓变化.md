## 三、关键持仓决策回顾

### 1. ★ 茅台: 38% → 42% (年内涨幅 +103.47%, 翻倍突破!)

- 2019 茅台股价从 590 元附近 → 突破 1188 元历史新高 (年内翻倍)
- 老唐持仓比例 38% → 42%, **市值大幅增长靠的是股价上涨, 不是加仓**
- 茅台连续创历史新高: 9-21 至 1160 元 / 9-28 至 1188.87 元
- "**感恩茅台. 年初持股 38% 的茅台实现翻倍, 茅台以外的其他持仓仅获得约 20% 收益, 确实如某些朋友批评的'去掉茅台就是垃圾'**"
- **关联 [[moutai-2019-pegged]]**: 茅台 2019 翻倍 = 老唐 2019 收益主力!

### 2. ★ 腾讯: 30% → 25% (比例下降但绝对值大幅加仓!)

- **2019-07 (本 PDF 缺失) 加仓 ~3% 港币 375.4** (来自 2019-09-07 文中追溯)
- 2019-10-19: 周一开盘买入腾讯 ~1% 仓位 (成交价 327 港币 / 来自三笔版税)
- **2019 年期间陆续从分红 + 新增资金加仓腾讯**
- 比例下降原因: 茅台涨幅 +103% 远超腾讯 +20%, 总账户膨胀拉低腾讯比例
- **重要分析: 老唐对腾讯的史诗承诺** (2019-11-15 #14 老唐实盘周记)

### 3. ★★ 洋河: 8% → 13% (大幅加仓 +5pp / 老唐 2019 主战场!)

- **2019-08 月 (本 PDF 缺失) 加仓** (基线显示 8% → 12%)
- **2019-10-19 加仓**: 周一开盘买入约 1% 仓位 (103.48 元)
- **2019-12-21 加仓**: 买入约 1.5% 仓位 (周四早 / 107.9 元)
- **关联 [[touring-2019-yanghe-加仓]]**: 老唐 2019 持仓最大变化 = 洋河大幅加仓

**洋河 Q3 反应** (2019-10-29):
- Q3 营收同比 -21% / 净利同比 -23% (出乎意料)
- "**这个三季报也出乎我的意料. 我没想到第三季度会这么糟糕, 本来对下半年还挺乐观的**"
- **老唐立场**: "**高端白酒存货和设备不贬值的特性没有改变, 洋河的核心竞争力也没有改变. 企业经营小有波动, 常有的事儿**"
- "**目前不到 1600 亿的市值, 对应一年八九十亿真金白银的获利能力依然相当超值, 对我有足够的吸引力**"

### 4. ★★ 分众: 11% → 10% (估值大调整!)

- 老唐对分众的重大估值调整 (2019-10-30《分众 Q3 估值调整》):
  - **2018 末 (#121) 2021 合理估值 2200 亿** → 2019-09 撤回 → **2019-10-30 改为 875 亿 (一年内合理估值)**
  - 交易区间: 高于 1400 亿拟出售 / 低于 600 亿拟增持 / 中间持股不动
- **老唐自陈风险提示** (2019-12-31): 分众实盘 17 个月平均成本 7.6 元 / **仍亏 18%**!
  - 最高买入价 10.38 元
  - 最低买入价 5.01 元
  - 平均买入成本 7.6 元
- **2019 期间分红 + 新增资金小幅加仓分众**

### 5. ★ 古井贡 B: 5% → 6% (年内 +86.98% 仅次于茅台)

- 2019-12-21 买入 5 万元古井 B 股 (本来计划换汇成功后买古井 B + 洋河各半, 但周四换汇失败, 只买了 5 万元古井 B + 全部洋河)
- 古井贡 B 年内表现极佳 (+86.98%), 仅次于茅台
- B 股开户细则在 12-21 周记中详述

### 6. 海康威视: 7% → 5% (比例被动下降)

- 2019-10 海康被美国列入实体清单 → 老唐影响轻微判断
- 2019-11 海康二股东及总经理被立案调查
- "**老唐挺看好现在的海康的**" (持仓不变)
- 比例下降原因: 茅台 + 古井 B 涨幅远超海康

## 四、2019 持仓哲学演化

### 1. ★★★ "对 2020 年, 我的看法没有变" (年终展望)

> "**对于 2020 年, 我的看法没有变. 虽然过去一年手中持股均有不小的涨幅, 但仍然没有任何个股进入高估区域, 所以仍然可以估计: '未来几年收益可能会不错, 而且什么也不需要做, 葛优瘫即可'**"

### 2. 2018 葛优瘫展望兑现 (2018-12-28 → 2019-12-31)

- 2018 末"葛优瘫"展望 → 2019 验证: **52% 收益 + 葛优瘫成功!**
- "**这种信心来自对投资本质规律的认识**"

### 3. ★★ 新增"年内卖点"披露 (2019-10-19 首次)

- 老唐首次在持仓表中加入"**年内卖点**"列 (≠ 三年后合理估值)
- 茅台 21000 亿 / 腾讯 50000 亿 / 洋河 4700 亿 / 古井 B 800 亿 / 海康 5000 亿 / 分众 (10-30 后) 1400 亿
- **"一年内达到该市值会考虑卖出, 否则就是持股呆坐"**
- 高能警告: "**老唐不是说一年内股票会涨到这个卖点, 也没说过三年后股票会涨到合理估值位!**"

### 4. ★ 老唐新增小额资金计划 (2019-12-31)

- 未来零碎小钱拟改投挂钩**恒生指数**的指数基金 (000071/000948)
- 不进入股票账户, 不计入老唐实盘

### 5. ★ 老唐医药指数基金 2 只 (2019 全年回顾)

- 广发全球医疗保健 (000369): +15.55%
- 国联安中证医药 100 指数 A (000059): +8.9%
- 总持有约 80 万 / 累计利润 5.82 万 / 老唐"完全是不动脑状态"
- 凑整 100 万后不再增加

## 五、年度业绩

- **2019 总收益率**: **+52%** (简单收益法 / 老唐选低披露)

|------|-----------|------|---------|
| 2014 | +62% | 1.62 | +51.7% |
