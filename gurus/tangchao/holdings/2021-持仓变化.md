# 唐朝 (老唐) · 2021 年持仓变化全记录 (完整一年)

> **一句话**: 2021 一改 2019/2020 连续两年"没卖过一股"的状态 —— **春节前茅台触卖点分三次卖出绝大部分 (均价 2366)、年内分六次买回 (均价 1730)**；腾讯全年大举加仓 (均价 553) 升为第一大重仓；海康清仓退出、陕煤新建仓。全年大量买卖, 但**核心动作是"把组合整体估值从 40.1 倍 PE 换到 31.2 倍, 顺带小赚七位数"**。

- **海康**: 三次清仓退出 (均价 61.48), 留 1000 股观察仓
- **陕煤**: 年内新建仓 (均价 10.69), 老唐周期股估值首次实战
- **过渡股全亏损离场**: 恒生 ETF / 博时转债 / 美的集团 (合计 -3.2%, 近十年单只亏损过万的全部记录)

## 四、关键持仓决策回顾

### 1. ★★★★★★ 茅台: 38% → 20% (卖出大半 + 年内买回)

- **春节前分三次卖出绝大部分仓位** (均价 2366, 仅保留 3% 准备涨跌不卖) —— 触及预设卖点 (茅台触 2.7-3 万亿)
- **年内分六次买回** (最低 1559.9 / 最高 1954.74 / 均价 **1730**); 买回数量为年初卖出量的 53%, 叠加剩余 3% 后年末持有约年初数量的 57%
- 小遗憾: 茅台跌到 1560 原计划仓位从 16% 提到 32% (最大买点), 但因腾讯洋河先到位资金用完, **只买到 18%** (穷病)
- **反"死了都不卖"**: ①巴神认错可乐 1998 没卖 ②"死了都不卖"是控股公司语境 ③巴神暗示六七十倍也会卖

### 2. ★★★★★★ 腾讯: 21% → 37% (大举加仓成第一重仓 / "后腿鹅")

- **全年大量买入** (最低 421.8 / 最高 633 / 均价 **553** 港币); 加仓时点贯穿全年 (562/535/514/490.6/471/421.8...)
- **全年跌 18.78% (港币口径叠加汇率 ≈ -21.5%), 几乎全程承受 → 收益率为负的核心因素**
- 五大利空集中轰炸 (教培/精神鸦片/反垄断/税收/共同富裕) → 触理想买点 3.6 万亿 / 450 港币 (#82)
- **承诺: 三五年内市值一定有比 2021/8/7 高 35-50% 的时候 = "近于 100% 确定"**
- 年末意外惊喜: 派京东股票中期股息 1277 亿港币 (创中国单次分红记录)

### 3. ★★★★★ 海康: 6% → 清仓 (留 1000 股观察仓)

- 年内分三次清仓 (均价 61.48); 企业仍是好企业, 只是当下估值无吸引力, 仅保持关注
- 海康被列美国实体清单 / 对美销售进一步受限

### 4. ★★★★★ 陕西煤业: 0% → 6% (新建仓 / 周期股估值首次实战)

- 5/22 首次建仓 11.78 → 年内多次加仓 (10.32/10.69/11.62/13.45), 均价 **10.69** (已扣分红 0.8 元/股)
- 老唐**首次对周期股估值**: 席勒市盈率法 = 十年扣非净利平均值 (约 65 亿) × 25 × 70% = 买点 1140
- 政府强力打压煤价 → 老唐: 煤企让利应该且必要; "煤价无法预测前提下这笔投资还做才下注"
- 年内 +42.45% (一度 +60%)

### 5. ★★★★ 洋河: 20% → 22% (增持 / 年内大跌 -29.30%)

- 年内增持 (最低 151.05 / 最高 193.43 / 均价 159.1)
- 去年领头羊 (2020 +120%), 今年下跌近 30% "略事休息"
- 洋河跌停史诗 (#58, 恒大信托 10.83 亿冲击) / 中银证券股价扭曲净利 (笋子)
- 接手云峰基金 10% 份额 + 民生信托 5.95% 股份 + 股权激励方案 (5100 人)

### 6. ★★★★ 分众: 10% → 9% (卖出 7% + 买回 / 中期分红回归)

- 春节前卖 7% (均价 11.8) → 7 月起买回 (7.25 买 3% + 零碎 1% 出头, 均价 7.6)
- 计划清仓的第三卖点 1980 亿未触及 (最高 2/18 对应 1936 亿, 差 2.3%)
- 半年报 4 大亮点 (现金流良性 + 客户结构 + 海外扩张 + 数禾科技) + 中期分红回归 A 股以来第一次
- 估值模式调整: 周期股法 → 当年预计净利润法

### 7. ★ 古井贡 B: 5% → 6% (增持)
- 年内均价 113.38 港币增持约 5 万美元等额

### 8. 观察仓
- **上海机场**: 年初 66.6 元买 1000 股 → 2/1 以 71.1 清仓 (补充协议变坏)
- **福寿园**: 因故小幅出入两次, 净相当于 6.8 港币买入 1 万股持有至今 (买点 5.75/5.70 触及但没钱买)
- **海康**: 清仓后留 1000 股观察仓
