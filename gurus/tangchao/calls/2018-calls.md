## 三、分众 2018 估值判断 (★★ 老唐最大判断失误)

### 3.1 分众建仓估值依据 (#44-46)

- 中国唯一覆盖几亿中产的媒体 (无可替代护城河)
- 与阿里巴巴深度合作潜力
- 2017 净利润 60 亿 / 2018 末市值 1190 亿 = P/E ~20
- 老唐预测 2021 利润可达 90 亿 (±10%)
- **2021 合理估值 = 2200 亿 ±10%**

### 3.2 实际验证 (2021)

- **2021 分众净利润 60 亿** (与 2018 持平, **未增长!**)
- **2021 实际市值 ~1100 亿** = 老唐预测的 **50%**
- **老唐判断失误根源**:
  - 新潮传媒等竞争对手抢占点位 → 价格战
  - 宏观经济下滑 → 客户预算紧缩
  - 阿里合作未带来实质提升
  - 老唐 2018 末已忽略风险 (内心没将股价波动视为风险)

### 3.3 老唐认错标准 (#121)

> "**老唐认错的标准是对企业经营情况的预判出了严重偏差, 它与股价腰斩还是翻倍没有关系**"

老唐 2018 末: "**截止此刻, 对于分众的分析, 老唐没有观点改变, 完全是死鸭子嘴硬的顽固分子 ??**"

→ 后续 2019/2020 老唐对分众观点逐步调整 (待 2019 年笔记)

## 六、宏观判断 (★★★ 反"正如我所料"自我打脸)

### 6.1 老唐 2018-01-13 预测 (反向自我打脸)

> "**这种市况下, 乐观情绪慢慢开始充斥市场. 不过呢, 在连续几年高收益之下, 开年九个交易日又涨这么多, 一般老司机都会本能地觉着今年日子可能不好过, 大概率在后面陷入长时间的调整状态, 对于很多介意市值回撤的朋友, 可能造成压力**" (#4 九连阳之下的冷思考)

### 6.2 实际验证

- 2018 沪深 300 -25.3% (大熊市) → 看似预测准!
- **但老唐 2018-12-28 自评 (#121 史诗反 SOP)**:
  > "**然而, 请注意: 上面这段纯属瞎蒙**"
  > 人脑有"神奇的特异功能": 自我欺骗 + 记正确观点 + 遗忘错误观点!
  > 大约 50% 看法会蒙对!

### 6.3 老唐反"宏观预测"立场 (#121 史诗 SOP)

> "**老唐的投资体系, 绝对不会以对未来宏观经济/股市大盘或者个股价格走势的看法为依据, 做出买或卖的决策. 即不会以别人的上述看法为依据, 也不会以自己的上述看法为依据**"

→ 以宏观为依据者: 0.001% 天才 + 一半幸运儿 + 一半傻蛋

## 八、老唐 2018 末打脸自评

### 8.1 2018 主要"打脸"

> 不同于 2017 年的"6 家公司打脸"自评 (#125), 2018 年老唐对自己投资体系**整体满意** (-18% 仍认为"令人满意"), 但承认:

1. **分众判断** — "**死鸭子嘴硬**", 不认错企业判断, 但对风险提示不足表达歉意
2. **2018-01-13 九连阳冷思考** — 自评"纯属瞎蒙"
3. **2017-11-24 茅台预测** — "顶多看到年内 480 元附近"实际涨到 800 → 老唐"超出我的想象"

### 8.2 老唐认错标准 (反复申明)

> "**老唐认错的标准是对企业经营情况的预判出了严重偏差, 它与股价腰斩还是翻倍没有关系**"
