## 1. 估值方法论

### 1.1 估值的唯一本源 = DCF

> "估值只有一条路，其它方法只是它的变形或者快捷应用"

**精确定义**：
> 如果这家企业生命周期里预计创造的自由现金流，折现至今天，**超过你付出的成本（包含投入及次优选项带来的回报）**，你就有投资意义上的盈利。
> **这笔投资盈利还是亏损，与这家企业股权目前在其他人之间以什么价格成交无关。**

### 1.2 两句话估值法（快捷应用）

> 出处：#3 聊聊估值 / #14 雅砻江系列

- **第一句**：三年后 15 PE 卖出能获利 100% → **现在就买**
  - 15 PE 锚定来自无风险收益率 6.67% 的倒数
- **第二句**：高杠杆企业打 7 折

**用法**：
```
判断步骤：
1. 预测三年后净利润 = ?
2. 三年后 15PE 估值 = 净利润 × 15
3. 三年后 15PE 估值 / 当前市值 ≥ 2 → 买入
4. 如果是高杠杆（如银行、地产），第 3 步阈值改为 ≥ 2/0.7 = 2.86
```

### 1.3 分类估值（同一公司不同资产用不同方法）

> 出处：#60B/C 国投估值实战

| 资产档次 | 估值方法 |
|---------|--------|
| 普通经营资产 | **净资产法**（折旧低于重建成本+政策壁垒+足额负债） |
| 优质有壁垒资产 | **重置成本/总投资倍数法** |
| 较差/破产边缘 | **破产清算法**（甚至取负值，承担连带负债） |
| 上市公司部分 | **历史最低价法** |

**反向校验法**：国投南阳火电厂 2016 卖掉的例子——投入 1020 万，评估 2880 万，**成交 9998 万**（接近 10 倍）→ 证明净资产法是足够保守的。

### 1.4 公式化估值（不给单一数字）

> 出处：#60C 国投 vs 川投选择

不要说 "国投合理估值 800 亿"，要说：

```
国投市值合理值 ≥ (44/40) × 川投市值 + 119 亿
                  ↑                    ↑
            水电对比公司          其他资产保守估值
```

**好处**：市值波动后可代入复算，公式仍然成立。**2 年后 2018-07-18 被市场验证**。

### 1.5 关于"成长"的态度

> **"拒绝为未来的成长出价。成长只能视为价值的安全边际。"**
> **"保证不成长的情况下，自己的出价也有利可图，否则不参与。"**

## 2. 选股标准

### 2.1 优势赢平均三要素

> 出处：#50 优势赢平均

一家公司能持续盈利超过平均，必须同时具备：

1. **被需要**（产品/服务有持续需求）
2. **难替代**（竞争对手做不出来）
3. **价格不受管制**（不是水/电/油等政府定价）

**公用事业类（如水电）只能有"浅护城河"**——因为价格受管制。

### 2.2 护城河 5 来源（来自晨星《投资的护城河》）

> 出处：#62 护城河书评

| 来源 | 典型 | 实质 |
|------|------|------|
| 无形资产 | 迪士尼、辉瑞 | 法律管制 + 专利 + 品牌心智 |
| 转换成本 | 苹果、黑石 | 用户转用代价高 |
| 成本优势 | 铁路、管理式医疗 | 成本结构低 |
| 网络效应 | 腾讯、达梭 | 每增用户都给老用户增值 |
| 有效规模 | 输油管道、机场 | 狭小市场再加竞争者全亏 |

### 2.3 行业护城河速查表

> 出处：#62 完整图谱

| 行业 | 主要护城河类型 |
|------|--------------|
| 饮料业 | **广泛分销品牌**（茅台/可口可乐适用） |
| 烟草业 | 品牌 + 转换成本（独特口味+成瘾性） |
| 银行业 | 转换成本 + 成本优势 |
| 制药业 | 无形资产 + 有效规模 |
| 受监管公用事业 | 有效规模 |
| 电力供应商 | 无形资产（进入壁垒）+ 成本优势 |
| 铁路 | 成本优势 + 有效规模 |
| 软件业 | 网络效应 + 转换成本 |
| 餐饮业 | **很难形成护城河** |
| 专业零售 | **很难形成护城河** |
| 油气钻探 | **很难形成护城河** |
| 货运水运 | **很难构成护城河** |
| 信息技术服务 | **很难构建护城河** |

### 2.4 能力圈底线

> **无法估算大致价值的企业，直接远离。因为你无法确认自己是否在出价的瞬间已经亏损。**

巴菲特原话："**我们不挑战恶龙，我们只是躲开它们**。"

## 3. "不赔钱"的真正定义

> 出处：#65 如何才能不赔钱

### 3.1 重新定义"亏损"

| 普通投资者认知 | 巴菲特/唐朝认知 |
|--------------|---------------|
| 市价 < 买入价 = 亏损 | **DCF 折现值 < 付出成本（含次优回报）= 亏损** |
| 与其他人成交价相关 | 与其他人成交价无关 |

**小饭馆比喻**：你家小饭馆是否盈利，**不是由隔壁饭馆的转让成交价决定**，而是由现金流决定。

### 3.2 巴菲特"也常浮亏"的三案例

| 案例 | 时间 | 浮亏情况 | 结局 |
|------|------|---------|------|
| 富国银行 | 1989-1993 | 70 美元买入后跌到 55，**浮亏 20%+ 持续 3 年** | 后翻倍，年化 20% |
| Tesco | 2012-2014 | **实亏 4.44 亿美元，亏损 20%** | 清仓认错 |
| 德克斯特鞋业 | 1993-2007 | **以伯克希尔股票支付，实际损失 35 亿美元（用 2200 亿的 1.6% 换垃圾）** | 巴菲特"最糟糕的决策" |

### 3.3 不赔钱三要点

1. **摆脱股价波动影响**：股市是"观察愚蠢行为的地方"
2. **关注未来产出**：只投能估算大致价值的企业
3. **错了认错**：发现持续竞争优势已消失 → 立即卖出，不管浮盈浮亏

### 3.4 最金句

> **盯着股价的，常被市场先生掏了腰包。盯着企业价值的，却常捡到市场先生的钱包。**

## 4. 卖出策略

### 4.1 卖出三原则

> 出处：#16 估值的误区

1. **价值高估**
2. **质地变坏**（持续竞争优势消失）
3. **有更好的新欢**（机会成本）

**核心区分**：**机会成本 ≠ 历史成本**。卖出哲学的精髓——是否换股不看"我当初多少钱买的"，看"现在这只 vs 候选标的，哪个未来回报更高"。

### 4.2 三步取利大法（针对慢牛股）

> 出处：#64 雅砻江系列 9 + 评论区"网名控世家卦"方案，唐朝认可

```
不轻易卖 → 分批卖 →
  ┌─ 一批足利卖：15 PE → 卖出 30%（年度目标到手）
  ├─ 二批高估卖：20 PE → 卖出 40%（累计 55% 盈利，三年目标达到）
  └─ 三批彻底坏：25 PE+ → 清仓或留底仓
```

**前提调整**：若行业景气度上升，一步取利可从 15 PE 上调到 20 PE——估值锚要动态调整。

### 4.3 享受泡沫 vs 估值回归就卖？均可

> **不要将大好时光浪费在"为什么我没有两头逮住"的懊悔上。这种懊悔相当于仰天长啸："为什么我不是上帝？"**

## 5. 仓位 & 现金管理

### 5.1 单股仓位上限

- **初始 4 成**（唐朝自述）
- 不允许单股满仓——必有百年一遇黑天鹅，要扛得过去

### 5.2 满仓 vs 择时

- **唐朝路线**：满仓不择时，全年陪跌
- **关键**：要满仓的前提是 7 只持仓有效分散在 5+ 个行业（白酒/银行/水电/医药/食品）

### 5.3 闲钱滚动管理（货基捡钱大法）

> 出处：#72 货基捡钱大法

```
闲钱分 2-3 部分循环：
  ├─ 有分级套利机会 → 做套利
  ├─ 有货基折价机会 → 511880/511990 折价买入、净值赎回（年化≥12%）
  ├─ 有逆回购机会 → 做逆回购
  └─ 啥都没有 → 收盘后转入券商理财（收益 ≈ 货基）
```

操作门槛：1 万元起，零费用券商 + 支持赎回券商。

### 5.4 拒绝的资产类别

- **P2P 理财**（"年化 13% 是大忽悠的目标人群"）
- **期货**（个人破产经历，"常规死路"）
- **小盘股/打新概念股**
- **杠杆/融资**

## 6. 风险评估方法论

### 6.1 风险预测 ≠ 风险评估

> 出处：#68A 利率风险

**预测利率/汇率方向超出投资者能力圈**。但"假设方向恶化、能造成多大伤害"难度低几倍——这才是投资者要做的。

**通用模板**：
```
1. 列出某变量历史区间（如利率 3%-8%）
2. 假设变量走到最坏极端
3. 量化每 1% 变动对净利润的影响
4. 用极端值代入 → 判断"能否承受"
```

### 6.2 风险分析的 7 大维度（电力股案例）

> 出处：#68 风险因素系列

1. **利率变动**
2. **下游需求**（GDP、用电量）
3. **价格管制**（上网电价）
4. **原料成本**（水/煤/气）
5. **税收政策**
6. **管理层乱投资 / 海外扩张**
7. **天气/天灾**

**通用框架（适用所有行业）**：
```
1. 行业 / 区域风险
2. 价格风险（产品+原料）
3. 需求风险
4. 政策风险
5. 管理层风险
6. 黑天鹅（不可控）
```

### 6.3 量化每个假设的影响

不要说 "利率上升会有影响"，要说：
- "雅砻江总负债 900 亿"
- "利率每变动 1% → 利息支出变 9 亿"
- "15% 所得税后净利润影响 7.65 亿"
- "对 462 亿市值的国投 → 利润下降 X% / 不会"

### 6.4 风险量化案例：加息反而是利好

> 出处：#68B 加息建模

**反直觉结论**：连续加息 6 次（2017-2020 每次 25bp），雅砻江利息支出**反而减少 2-5 亿**。

**原因**：
- 2/3 贷款（650 亿）锁定固定利率 5.73%
- 每年折旧 32 亿持续偿还本金
- 新加息只影响 1/3 浮动部分

**通用教训**：**不要凭直觉判断风险，建模代入实际数据**。

## 7. 股价波动的认知框架

### 7.1 股价变动三大动力源

> 出处：#73 股市获利的路径和逻辑

| 来源 | 整体盈亏 | 备注 |
|------|---------|------|
| ① 企业经营增值 | **盈利** | 长期约 = ROE 增速 |
| ② 融资增值（IPO/增发） | **盈利** | 前提：高于内在价值 |
| ③ 短期情绪波动 | **亏损** | 印花税+佣金的零和负游戏 |

**池塘水位隐喻**：
- 买①②就是站在水位上升的池塘里
- 智商平均 → 略高于 GDP
- 智商略高 → 超额收益
- 智商略低 → 仍正收益
- **只有智商大落后才会亏**
- 而追③需要超越平均才能保不亏 → **零容错**

### 7.2 高价融资 ≠ 对老股东有利

> 出处：#73B

**关键原则**：
- 高于**净资产**的融资 → 增加企业净资产
- 但只有高于**企业内在价值**的融资 → 增加老股东利益
- IPO 是极端高价融资形式，给原老股东带来巨大财富

**茅台 2013 反例**：100 元市价，每股净资产 40，若按 120 元增发 3 亿股 → 看似划算，4 年后新股东获利 900+ 亿，**实际让渡了 22.5% 公司所有权**。

### 7.3 A/B 类投资者博弈模型

> 出处：#73B 附件 2

- **A 类**：研究企业价值
- **B 类**：跟随价格趋势
- **结论**：
  - 即使没有新信息，股价也会在 A 类设定的区间内震荡
  - **A 类投资者是决定股价最终水平的力量**

## 8. 信息分析方法论

### 8.1 拿茅台练手

> 出处：#37 茅台分析（早期）

**步骤**：
1. 找出**财报核心数据**：营收、净利、ROE、现金流
2. **拆分业务**：高端/中端/低端各占多少
3. **查行业数据**：行业容量、竞争对手、上下游
4. **找管理层信号**：股东大会问答、提价信号
5. **历史 PE-PB 分位数**：当前在历史什么位置
6. **建估值区间**：保守/合理/乐观三档

### 8.2 数据来源（电力行业为例）

> 出处：#71 评论区

- **行业**：国家能源局、中国能源报、北极星电力网
- **企业**：年报、债券募集说明书、公告
- **股价**：万得股票（万德数据）
- **研报**：慧博
- **财报阅读**：iPad air + 福昕 PDF
- **读书**：Kindle 多看系统（划线笔记同步印象笔记）

### 8.3 阅读方法

- **整段阅读**（不是一行一字）
- 找喜欢的小说（如鹿鼎记）练习
- **写笔记 > 回看笔记**（整理过程系统化知识）
- 用 XMIND 电脑版做思维导图

## 9. 心态与纪律

### 9.1 戒盯盘绝招

> 出处：#63 评论区

> **早上起床问自己：今日若涨停，我会卖吗？今日若跌停，我会买吗？**
> - 答案 yes → 挂好涨停卖单或跌停买单，**闪人**
> - 答案 no → **直接闪人**
> - 答案"看情况" → 说明你大概率在糟蹷钱，**不如清仓花在老婆孩子身上**

### 9.2 跌停板判据

> "如果某股票跌不到 10% 就值得买了，说明它进入你的射程了，看盘就看呗！**如果跌停板也不足以吸引你买，你自然就不担心错过下跌机会了**。"

### 9.3 估值是动态的，不是静态的

> 出处：#64

经营环境、核心竞争力变化时，**估值假设必须重新校准**。例：
- 2015 年国投 14 元不觉贵（火电盈利好+新能源热潮）
- 2016 年国投 6 元不敢入场（火电环境恶化）
- → 不是哪个对，是**估值的假设条件变了**

### 9.4 一切短期波动如梦幻泡影

> **一切短期波动，如梦幻泡影，如露亦如电，应作如是观。**

## 10. "为什么不涨"的标准答案

> 出处：#73 附件 1

读者问：**"国投这么好，为什么不涨？"**

| 唐朝答 | 解读 |
|--------|------|
| 这个问题本身是错的 | 股价从来不和企业经营情况一一对应 |
| 没有任何因素和股价波动一一对应 | A 类投资者集体校准价值时才会涨 |
| 那你为什么买？ | **因为我确信它会涨** |

**等待**不是劣势，是天然本份。**"企业的经营增值，要靠生产销售人员一天一天、一单一单去积累，不可能一锄头挖个金元宝。"**

## 12. 投资 4 大核心问题（终极框架）

> 出处：#121《投资应该操心的核心问题》（2017-12-19）— 2017 末投资理念终极教科书

### 12.1 核心金句

> **"投资 4 大核心问题 = 彻底摆脱亏损"**
>
> **"4 大问题 = 核心 + forever 享受生活"**

### 12.2 4 大核心问题

1. **商品服务**：企业销售的是什么？被需要吗？
2. **客户选择**：客户为什么选它？难替代吗？
3. **资本天性**：资本逐利天性会带来什么？同行竞争如何？
4. **同行巨头竞争**：行业内大玩家的博弈格局？

### 12.3 重大金句

> **"首先考虑是否买对，其次才是考虑是否买贵"**
>
> 选择对错是生死问题，便宜贵贱却可以被时间治愈。

## 42. 15/25/50 三区交易系统升级版 (2019-10-05)

### 42.1 完整三区

| 区域 | 倍数 | 状态 | 行为 |
|------|------|------|------|
| **明显低估** | **15 倍 PE** | 低估 (买入区) | **买入 / 黄金雨机会** |
| 合理估值 | **25 倍 PE** | 合理 (持有区) | 持有 |
| **明显高估** | **50 倍 PE** | 高估 (卖出区) | **卖出** |

### 42.2 25 倍 PE 锚定原理

- 在大约 3%-4% 的无风险收益率条件下 (即现金的市盈率在 25-33 倍范围)
- 用企业未来增长的可能性 (包括潜在的真实价值增长 + 企业商品或服务价格对通货膨胀的抵御能力)
- 与现金资产近于 100% 确定性相抵消
- 则二者视为大致具有同等盈利能力的资产
- → **合理 PE = 25**

### 42.3 15 倍买入的合理性

- 未来三年哪怕企业只增长 5% → 三年后按 25 倍合理值考虑 → 大约翻倍
- 老唐判断: 自己选择的目标企业未来三年高于 5% 年增长 (三年累计增长 16%) 的确定性非常高
- 所以 15 倍线下被视为**黄金雨机会**, 是需要"想办法找钱"加仓的罕见时机

### 42.4 vs 2018 5 折/150% 系统

- 2018 末 (#121《老唐的 2018》): **5 折买入区 (合理估值 × 0.5) / 150% 卖出区 (合理估值 × 1.5)**
- 2019 升级为: **15 倍买 / 25 倍持 / 50 倍卖** (基于 PE 而非合理估值倍数)
- → 更直观, 易传播

### 42.5 数值可微调但二档划分必须有

> "**数值可以微调, 不是非常重要. 拥有这样一个数值很重要, 它有助于帮助你头脑清醒, 抗拒恐惧和贪婪, 赚到市场最肥美/最显而易见的利润**"

> 数据基础: 唐书院 (老唐第二个付费号·小圈子合集) 18 季 180 篇 (2023-08 起·主体为 2024 年内容 + 芒格维斯科股东大会经典陪读)。本节**只记唐书院相比文集 2016-2023 新出现的工具/口诀/反向案例/避雷清单**, 不复述已有框架 (老唐估值法/三区/三大前提等见前文)。引用格式 `#S<季>-<篇>`。
> 背景里程碑: **2024-11-09 老唐因"清朗行动"打击非法荐股、政策解释权不在己, 永久关闭公众号实盘 (#S15-09)**, 此后第 16-18 季转为"无实盘只闲聊"的价投经典陪读道场。

### A. 新增工具

- **🔑 "理性外推" (重要概念命名·#S18-04)**: 优质企业 (茅台这种天赋异禀的除外) 只要确认"导致历史优异表现的原因没有发生重大改变", 对未来三年净利润**毋须神神秘秘, 直接取利润增速 10%~15%即可**。命名以区别于格雷厄姆批判的"天真外推"(后者是分析师鼓吹动辄 50%、翻倍的成长股, 是程度问题非外推本身错)。**配套"对折买入大法"**: 该取值略有高估也不会有大问题, 企业实际增速偶尔更高还能对冲。**意义 = 把估值变量压缩到只有一个净利润, 是老唐投资体系的重大推进**。
- **🔑🔑 茅台五大护城河清单 (#S18-07·拷贝 2013/11/13 回复任俊杰旧文)**: 真正无法被金钱夺走的核心竞争力只有五个 —— ①**老酒** (6.5% 老酒比例·万吨级每年需 650 吨以上陈年老酒·15 年内无解) ②**勾兑师** (靠大师舌头·优秀勾兑师都与茅台签了同业禁止) ③**熟练工人** (熟练工年均产酒不过 3 吨多·万吨级需 3000 名多年经验工人) ④**大容量自动勾兑技术专利** (2007-2008 研发成功·人均年产 3.08→3.92 吨·盗用即侵权) ⑤**品牌**。**而土地/水/原料/制曲制酒/工艺流程反而是相对薄弱的"外围竞争力"** (有钱就能买到)。→ 直接修正"茅台护城河 = 地理 + 工艺"的常见误读。
- **🔑 "30 岁 10 万元增值路线图" (普通人致中产·#S16-07)**: 假设 30 岁本金 10 万, 30-40 岁每年追加 1 万 / 40-50 岁每年 2 万 / 50-60 岁每年 3 万。三档复利测算: **3% 理财 → 60 岁 119 万 (≈今 50 万退休·真·普通人)**; **8%±2% → 60 岁 209-483 万 (≈今 85-200 万·社会中产·只需"承认自己是普通人、只取市场平均收益")**; **日拱一卒学习提升至 15% → 60 岁 1500 万 (≈今 620 万)**。锚: 沪深 300 含股息 2004 底-2022 底 18 年 5.25 倍、年化 9.65%, "只要未来 30 年有过去 18 年的 2/3 好, 复利就够让你成中产"。
- **🔑 "普通人致富路径"算账 (#S18-01)**: 40 年投资生涯 15 万 → 9000 万 = 600 倍 = **年化 17.3%** (15 万→7200 万 = 年化 16.7%), "不容易但不高不可攀"。配套两句学习心法: "学习可以学习的、得到可以得到的"(起步晚不晚) + "取法乎上得乎其中"(向一流学·至少中等偏上·下有保底上不封顶)。
- **🔑 投资的"段位标尺"延伸·成为巴菲特不可能但可成为更好的自己 (#S18-01)**: 巴菲特不可复制 = 个人天赋 + 93 岁仍语速如闪电的**超长生理投资时长** + **整个投资生涯与美国崛起为世界头号强国完全重叠** (刘瑜"1913 年前美国是一个勉强的帝国")。但**投资体系清晰可复制**, 取得接近的长期收益率可能, 只是财富规模受限于基数/条件/时运。

### B. 新增口诀 / 金句

- **🔑🔑 "远离杠杆"四字真经强化 (#S18-08)**: 老唐"念叨最多"的一句, **写在著作扉页、排在估值三大前提之前**, 是真金白银换来的血的教训。论证链: 巴菲特"懂投资不用杠杆也会富, 不懂投资用杠杆只会万劫不复" + **2010 致股东信"任何序列的正数无论多大, 只要乘以一个零都会归零""几乎所有杠杆最终都通向零, 即便使用它的人非常聪明"** + 投资的"大概率赢"建立在"能承受小概率输取平均"上, 而**小量杠杆的小概率输 = 全盘皆输, 承担不起, 所以哪怕小量杠杆也远离**。
- **🔑 "成本 = 机会成本·市值与持有成本无关" (#S18-09)**: "成本八千和成本为零, 市值一分不少一分不多; **市值 = 此刻市价 × 持股数量, 和你的成本毫无关系**"。老唐说的"成本"是经济学的机会成本 (放弃机会中收入最高的一项·没有选择就没有成本), "历史成本"对当下股权投资没有任何影响。
- **🔑 无风险收益率"向上取整 3%" (#S18-09)**: 对无风险收益率一律向上取整 (2.1%~2.9% 均取 3%), 含义是"只要稍有耐心, 市场上存在回报率略高于国债、风险几乎一样的无风险产品"。**故即使 5 年期国债票面降到 2.5%, 也不会据此把茅台合理估值上沿调高到 40 倍 PE**。
- **🔑🔑 "巴菲特即投资圣经"·不需重新发明轮子 (#S18-10·全 18 季压轴)**: 巴菲特历年致股东信/股东大会问答/演讲 = 投资领域的『圣经』, 其他所有人 (含老唐自己) 的著作要么可直接忽视、要么只是对圣经的阐述讲解。操作含义 (GH/段永平): **"不需要再发明一遍轮子, 赶快把前人造好的这些轮子装到自己财富的三轮车上可劲蹬"** —— 复制巴菲特要"照猫画虎、一板一眼"学全套, 成大师后再谈创新。
- **🔑 "永远不要神话任何人" (#S18-06)**: 包括巴神芒神, 他们错误一点不少 (持续暴露在聚光灯下错误甚至更多)。**"我们要学的是思考方式、是逻辑、是持续学习和持续思考的能力, 而不是接受他们的结论。"** 配套: "躲开严重高估、抓住严重低估, 就已足够变富"(仅靠常识、不必精准抄底逃顶)。
- **🔑 "让身边老婆孩子崇拜才最难" (#S18-10)**: 让遥远信徒崇拜不难 (装神弄鬼者都能做到), 让身边好友、老婆孩子家人崇拜才是最难 —— 巴芒二老之间是相互崇拜。
- **🔑 "没动力改变主要是你还不够穷" (#S18-02)**: 穷时养成努力的习惯, 后来"积习难改"。
- **🔑 "降低预期是生活幸福的法宝·比高预期更糟的是不清楚自己的预期" (#S18-09)**。
- **🔑 "完美是卓越的敌人·垃圾输出也是输出" (#S16-07)**: 不能停止输出, 输出才能优化, 先从 0 到 1。
- **🔑 巴菲特投资业绩"最短三年"标尺已见 #82; 此处补 #S17-05 引"卵巢红利"等陪读金句来源。**

### C. 新增反向案例 (避坑实例)

- **🔑🔑 杠杆爆仓血泪三连 (#S18-09)**: ①**天行健** —— 月入四万多, 认为便宜就贷款买股、自信能快速还贷, 结果生活窘迫被动, 自评"失败失败"; ②**美团-财富俱乐部** —— 年收入 30 万却借钱投资陷入被动; ③**一锋一易** —— 33 岁宅家、一手好牌却因太贪杠杆搞惨。老唐结论: **"不要借钱投资。"**
- **🔑🔑 120% "小比例"杠杆代入算融创就爆仓 (#S18-08)**: 2020 年初 1 万股融创 (开盘 41.04 港元) 借 8.21 万买成 1.2 万股, 券商保证担保比例 130% (市值不得低于 10.67 万) → **融创跌到 8.88 元就触斩仓线 (8.88×1.2=10.66 万)**, 而 8.88 元一个半月前就已触及。结论: 不要小看 120% 的"小比例"杠杆, 当年格雷厄姆 1929 就吃了这个亏。
- **🔑 洪古 2024 差点融资买入 (#S18-08)**: 去年 8 月茅台 1525、腾讯破 300 时觉得"已经很低", 想"融资买入", 犹豫几天还是转回普通账户; 结果 11 月腾讯破 200、茅台 1333 又上一课 —— **"市场先生从不在乎你的'觉得', 它像病毒会自动寻找你身上的人性弱点。"**
- **🔑 追热点题材股 vs 着眼真赚钱 (#S18-09)**: 任何人都能为买入找理由, 区别在于是"基于买股票就是买公司、着眼真赚钱的盈利增长", 还是"追热点题材、摸对手口袋" —— 几十年后财富结果天差地别。
- **🔑 "神预测"祛魅 (#S18-06)**: 芒格 2008 "A 股完全疯狂只有暴跌一条路"看似神准, 但与他 **2007 年 5 月"4000 点已严重高估"(之后又涨 50% 到 6124 点才见顶)**摆一起 → "对股价的预测没有谁能说得准, 包括巴菲特和芒格"。巴菲特 2008 《Buy American》满仓后市场又跌了半年才见底 (SP500 呐喊后又跌 30%)。

### D. 新增避雷清单 (合规 / 风险)

- **🔑🔑 关闭实盘后的政策/合规风险 (#S15-09 里程碑 + 第 16-18 季)**: 老唐因"清朗行动"打击非法荐股、且**政策解释权不在自己手里**, 于 2024-11-09 永久关闭公众号实盘 (关闭时净值 8.08·年内 +21.07%)。此后**多篇周回顾被删后以"纯洁版"补发** (#S16-04/#S16-09/#S17-10) —— 警示: 公开荐股 (含晒持仓/买卖点) 在当下监管环境有现实合规风险, 价投内容宜聚焦企业分析与理念, 远离具体操作信号。
- **🔑 利空冲击应对不二法宝 (强化·见 #86)** 在唐书院反复被"远离杠杆"专题 (#S18-08) 与"成本=机会成本"(#S18-09) 夯实, 此处仅作交叉引用不复述。
- **🔑 恒大"财报造假后分红 = 不当得利"可被强制追讨 (#S18-09)**: 公司有限责任本不追溯股东, **但若用虚假手段做高利润再分红, 该分红可定义为"不当得利", 在分红限度内强制追讨有法律依据** (恒大向许家印等 7 名被告追收约 60 亿美元股息及酬金)。→ 排查"高分红"标的时需警惕利润真实性。
- **🔑 条款模糊比从严更可怕·博汇停产抗税案 (#S18-04)**: 博汇股份因"重芳烃/石脑油消费税"界定标准模棱两可被追缴 5 亿 (过去十年累计净利不足 4.5 亿) → 全面停产。**"不怕严就怕模糊, 条款模棱两可、想睡谁就睡谁怎么行"** —— 监管/税务口径不清晰本身即是经营风险。

## 《手把手教你读财报》新增 (财报方法论 / 逐科目排雷 SOP)

> 来源: 老唐出版著作《手把手教你读财报(财报是用来排除企业的·新准则升级版)》(中国经济出版社 2021·371 页·以贵州茅台 2013 年报为范本)。这是老唐投资体系的"**术**"(《价值投资实战手册》=纲·《巴芒演义》=道·本书=术)。本节沉淀书中可直接复用的财报阅读 SOP / 排雷信号清单 / 估值方法论。详见 `posts/手把手读财报-DRAFT.md`。

### F0. 核心理念 — "财报是用来排除企业的"

- 🔑🔑🔑**财报不是用来挖牛股的, 是用来排除企业的** (芒格"反过来想"): 排除①竞争力低下 ②数据可疑 ③不诚信管理层。读财报第一目的=把不合格的企业筛掉, 而非证明某家公司好。
- 三个造假故事打底 (白纸两沓扭亏 / 完美造假 60 倍牛股每笔有现金 / 任意调节盈利空壳转手) → **造假手法从 20 世纪到今天变化不大, 不过是收入、费用、现金流三个角度**。
- 🔑投资者 vs 执法者: **执法者需证据确凿、疑罪从无; 投资者却可以"有疑就杀"** (无须证明造假, 只要存在无法解释的疑点就排除)。

### F1. 三大表速读 SOP (拿到财报最快抓要点)

**资产负债表** (老唐"先找钱、后花钱": 先看负债+所有者权益, 再看资产):
1. 先看"负债和所有者权益总计"(家当) + "所有者权益合计"(自有 vs 借的)。
2. 🔑🔑负债率用 **有息负债÷总资产**(非教科书"负债÷总资产")·超 60% 算激进。无息负债(经营性负债)是产业链强势地位副产品无须担心。
3. 资产速读四比值 (结构/历史/同行三角度): ①生产资产÷总资产 ②应收÷总资产(超三成已严重) ③货币资金÷有息负债(应≥1) ④非主业资产÷总资产。
4. 🔑🔑🔑**轻资产优于重资产** (芒格"我恨第二种生意")·划分标准=**当年税前利润总额÷生产资产**显著高于社会平均资本回报率(≈银行贷款标准利率两倍≈12%)即轻公司·茅台 214÷125=171%。

**利润表** (四要点): ①营业收入(增长三途径=潜在需求增长 > 份额扩大 > 价格提升·可靠性递减) ②毛利率(🔑40% 以上有持续竞争优势·比同行高很多=强者或骗子) ③费用率(三费÷营业总收入·费用占毛利润 30% 内优秀、超 70% 关注价值不大) ④营业利润率(核心指标·看趋势+同行对比)。**最后一步: 经营现金流净额÷净利润持续>1 才算"挣到钱"**。

**现金流量表** (重心=经营活动现金流·关键两数字):
1. 🔑🔑🔑**经营活动现金流量净额五档分级**: <0 入不敷出 / =0 维持规模设备老化 / >0 但 <折旧摊销(不能更新) / =折旧摊销(只能维持现状) / **>折旧摊销(有潜在成长性=才值得关注)**。
2. 🔑**经营现金流净额÷净利润持续≥1=印钞机** (房地产行业不适用·卖期房大量预收款)。
3. 销售商品提供劳务收到的现金÷营业收入持续≥1=款项已收商业地位稳固。
4. 🔑投资活动现金净流量为负=扩张 / 为正=收缩或放缓。债务性筹资利率越高越危险(账上现金多却高息借款="首席骗子")。

**寻找优质企业 5 组数据** (数年持续, 越多越好): ①经营现金流净额>净利润>0 ②销售收现≥营业收入 ③投资流出>流入且用于扩张 ④现金及现金等价物净增加>0 ⑤期末现金≥有息负债。

### F2. 8 种现金流肖像 (三大活动正负号 → 企业类型)

经营现金流为正四型: **类型1 "+++"妖精型**(事反必妖·远离) / **类型2 "++-"老母鸡型**(收获期·低 PE 高股息值得拥有) / **类型3 "+-+"蛮牛型**(扩张·看项目前景+资金支持·川威集团"别做大别借钱") / **类型4 "+--"奶牛型**(🔑🔑茅台典型·靠经营现金流扩张+减债分红·关键看可持续性)。
经营现金流为负四型(都衰退期): 类型5 "---"大出血型(拒绝) / 类型6 "--+"赌徒型 / 类型7 "-+-"混吃等死型 / 类型8 "-++"骗吃骗喝型。
🔑勿仅看一份财报, 需数年数据才能认定企业秉性。

### F3. 老唐三分类法 + 金融资产"瘫笋粽" (科目归类工具)

- **老唐独特三分类法** (投资者视角·非会计准则): 生产类资产 / 经营类资产 / 投资类资产。
- 🔑🔑🔑**新金融准则三分类记忆法** (老唐原创·与 playbook 第 54 章"笋子/粽子/瘫子"一致): **瘫子**=以摊余成本计量(收息还本·中途转让收益记"以摊余成本计量金融资产终止确认收益") / **笋子**=以公允价值计量且变动计入当期损益(赚差价·公允价值变动进利润表) / **粽子**=以公允价值计量且变动计入其他综合收益(目的不清·持有变动进其他综合收益、处置转损益)。
- 🔑"其他权益工具投资"(=离别钩, 指定后公允价值变动与利润表永别·只分红进损益)≠"其他权益工具"(权益科目·本公司发行的优先股/永续债等)。

### F4. 资产负债表逐科目排雷清单

- **货币资金五大排雷信号**: ①余额<短债(穷病要命) ②存贷双高(虚构/挪用/被占用) ③定存大缺流动 ④其他货币资金巨大缺解释 ⑤利息收入异常低(资金只短暂停留报表日才回来)。
- **应收账款**: 大幅增长且增幅超同期收入 / 周转率低于同行且下降趋势 = 操纵嫌疑(放宽信用政策/提前确认/虚构收入)。收款优劣序: 现金>银票>商票>应收账款·先款后货=竞争优势。四川长虹 45 亿应收 37 亿坏账多年利润一次赔光。
- 🔑🔑**其他应收款**: 与销售无关却调动资金往来本就存疑·**越少越好(优秀公司其他应收款/其他应付款极小甚至为零)**·比应收账款更易操纵(无需发票仓单)·数额大可能资金被控股股东占用(建议先当坏人对待)。
- **存货**: 🔑🔑🔑**存货周转率明显下降却同时伴生毛利率显著上升=大概率造假**(警示信号)。存货会计魔术: 加大生产将固定成本转移到库存→降本期销售成本→虚增毛利率(50%→62.5%)。茅台存货周转率小不意味积压(产品需存放4-5年·自制半成品/在产品是"点石成金"·只要出厂价远高于成本存货越多越好)。
- **预付账款**: 财报造假重要资金出口·超一年挂账大概率有问题(金钱有时间价值·没人不急需提货却提前很久付款)。
- **生产类资产**: 在建工程不计折旧→🔑🔑**迟迟不转固定资产肯定有鬼**(虚构或为避免计提折旧)·在建工程=财报操纵者挚爱(总值高/进度造价难界定)·研发费用全费用化公司利润更可靠·🔑🔑商誉不摊销只减值、减值不可逆→商誉爆雷(收购方做高商誉减少折旧、需降利润时按需减值进可攻退可守)·长期待摊费用大增=不恰当费用资本化。
- **坏账准备**: 计提比例显著低于同行=操纵信号·已资不抵债欠款没计提 100% 减值=怀疑全部应收少计。

### F5. 利润表逐科目排雷清单

- 🔑🔑🔑**毛利率显著提升却伴随应收账款增加+应付账款减少=造假嫌疑**(正常逻辑: 竞争力提升→应收减少+应付增加)。虚构收入一般首选高毛利业务(一笔抵多笔)→扭曲产品销售结构改变毛利率。
- **营业收入确认**: 大部分造假涉及把不符合条件的收入确认为当期·最核心确认原则="已将商品所有权上的重要风险和报酬转移给买方"(与是否收款无关)·完工百分比法操作空间大。
- **其他业务收入/营业外收入**: 比主营更易操纵隐蔽·占比突然大增无合理解释=怀疑·利润主要来自偶然营业外收入=打扮报表(营业外收支净额大时用营业利润 75% 看待净利润)。
- **营业外支出/一次性费用**: 🔑"其他××"大额或罕见科目名称=警惕信号(藏匿不想被追究的支出)。
- **资产减值损失**: 大额=管理层自我抱脸承认决策失误·数字应很小·🔑🔑"洗大澡"(虚增费用·两动机=毁尸灭迹冲掉以前虚增利润[ZGGH盈亏交替规避ST堪称一绝] + 未来报表好看[管理层更替甩锅])·减值大增但利润波动不大=做低盈利基数。
- **三费**: 销售费用高=产品无"拉力"靠营销推力·管理费用="垃圾筐"·销售管理费用应与营收同向·某年大幅降且低于同行=操纵。

### F6. 估值方法论 (第五章重头戏)

- 🔑巴菲特: **投资只需学两门课 = 评估企业价值 + 看待股市波动**。塞斯·卡拉曼三估值法:
  1. 🔑🔑**现金流折现法 DCF** (巴菲特"企业价值=剩余存在期内自由现金流的折现值"): **自由现金流=经营现金流入净额-维持现有运转必需的投入**(毛估=经营现金流净额-购建固定无形长期资产支付现金)·**永续价值=自由现金流÷(折现率-永续增长率)**·🔑只能用于产品变化小/需求稳定/有持续竞争优势/现金流可预测的企业·假设细微变化结果差距巨大→无须精确·适当折扣买入。
  2. 清算价值法 (格雷厄姆): 有形资产账面净值=总资产-总负债-无形资产-商誉·投资市值远低于此的企业。
  3. 股市价值法: 可比公司市盈率/市净率/收入倍数。
- 🔑🔑**老唐估值法 = 对自由现金流折现法的一种简化处理** (详见《巴芒演义》《价值投资实战手册》·与 playbook 第 17/27/53/61 章呼应)。
- 🔑🔑**ROE = 衡量盈利能力最重要指标** (巴菲特选 >20%): 净资产指资产负债表所有者权益(与你买入价无关)。🔑🔑**经济商誉=仅靠金钱填不平的护城河, ROE 是寻找它的路标**: **G=(ROE÷N-1)×A** (N=无风险收益率·ROE越大经济商誉G越大·ROE<N时G为负)。
- 🔑🔑**杜邦分析**: ROE=净利率×总资产周转率×杠杆系数=茅台模式(产品净利率·最好"连傻蛋也能管理")/沃尔玛模式(周转率·"投资三标准都是人")/银行模式(杠杆·最差·"无数个100%增长抵不过一个100%亏损")。

### F7. 管理层分析 — 董事会报告是"最大宝藏"

- 🔑🔑**董事会报告 = 整份财报重要性仅次于财务会计报告** (管理层客串企业分析师·可靠性专业性高于券商研报且免费)。
- 🔑🔑🔑**"董事会关于公司未来发展的讨论与分析"=最大的一块宝藏** (易被当套话跳过): SWOT/波特五力·**认真读、把几年连起来读、把同行拿来对比读, 从中找分歧、找可信度、找真专家**。
- 案例: 白酒四巨头 2011 年报对比, **唯茅台危机感十足→ 2012-2014 一枝独秀**(茅台 2010 乐观 2011 转危机=真在转折点预见)。但反例: 四巨头 2014 年报**集体错判** 2015 复苏方向(预判中低速+大众消费, 实为高端供不应求高速增长·茅台五粮液涨 900%+ 而洋河仅 207%)→ 🔑**优秀商业模式有强大容错性**(差异化+提价增量+变化慢+存货不贬值, 即便管理层错判也有调整空间), 投资不能完全依赖管理层预测。
- 财报附注: 🔑🔑**信息量最丰富、不读不算合格阅读者** (占财务会计报告约 70% 篇幅)·最重要=合并报表项目解释+母公司项目解释(每个字都与钱包挂钩)·关联交易警惕显失公平·可通过少数股东权益反推子公司净资产。

### F8. 造假识别红旗清单 (汇总·牢记"事反必妖")

- **财报内**: 毛利率升却应收增+应付减 / 其他业务收入占比突增 / "其他××"大额科目 / 资产减值大增利润却平 / 存货周转率降但毛利率升 / 在建工程迟迟不转固 / 货币资金充足却高息借债 / 净利润远高于经营现金流。
- **财报外**: 无法按时发财报 / 更换会计师事务所(国资委定期更换例外·🔑其他改聘=财报有问题先兆) / 大股东持续大量减持 / 财务总监频繁更换 / 独董集体辞职 / 主要供应商客户可疑(执照没年审/注册地居民楼/税务资料缺失) / 跨行业玩收购且靠发股票支付。
- 🔑总纲: **无论突然出奇的好或突然出奇的坏, 都需探索背后的解释·没有可靠解释就从收入、费用、现金流角度考虑欺诈可能**·如此才能在市场长久避开陷阱。
