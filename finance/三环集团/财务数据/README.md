## 勾稽自洽校验

由 `_build_from_pdf.py`(待建)生成,**每年**验证:
- **损益**:营收 − 成本 = 毛利;+ 所得税 = 净利
- **资产负债**:总资产 = 总负债 + 权益
- **现金流**:经营 + 投资 + 融资 = 现金净变动;年初 + 净变动 + 汇率 = 年末

**当前状态**:核心指标(营收/归母/扣非/OCF/ROE/毛利率)已从年报 P6-9 主要会计数据提取,**逐行三表勾稽 ⏳ 待 `_build_from_pdf.py` 精解析**。
