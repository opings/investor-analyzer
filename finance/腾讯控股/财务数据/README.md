## 勾稽自洽校验(每年,校验不过不写出)

- **损益**:收入 − |成本| = 毛利;除税前 + 所得税 = 年度盈利;归母 + 非控 = 年度盈利
- **资产负债**:负债总额 + 权益总额 = 资产总额
- **现金流**:经营 + 投资 + 融资 = 净变动;年初 + 净变动 + 汇率 = 年末;CF 年末现金 = BS 现金
- **分部**:各年分部合计 ≈ 损益表收入(±0.2%)
- **跨年衔接**:t 年末现金 = t+1 年初现金(25 年全链无缝)

状态:**25 年全部通过**(2026-07-12 构建)。

## 口径注意(读数前必看)

1. **归母净利 2001–2006 为空**:该期间报表无归属拆分行(无重大少数股东权益),年度盈利即全额归母;`财务比率.csv` 的 ROE/分红率已按此处理。
2. **港股无扣非披露线**:利润表无扣非行;剔投资损益的近似口径可用「经营盈利」(2023 起)或公司披露的 Non-IFRS 归母(未入库,见各年年报)。
3. **capex 口径**:现金流「购建固定资产/在建工程/投资物业」主行;**购买无形资产单列**(腾讯无形 capex 体量大:媒体内容/游戏授权,2018 起 200-320 亿/年,算全口径 capex 需两行相加)。
4. **「其他收益净额」波动巨大**(2021 峰值 1,495 亿):含处置/视同处置投资收益——2021 京东实物分派确认处置收益约 780 亿、2022 美团视同处置约 1,066 亿,均为非现金一次性项,同比分析必剔。
5. **回购股份支付 2016/2017 空、2015/2020 为 0**:该年现金流量表无此行/印刷为零(2020 回购付款极小并入其他;非提取遗漏)。
6. **2012 BS 预付款项与定期存款**:2012 年报将定期存款拆「短期定期存款」且预付并入其他科目,CSV 已按原文归一,个别年份口径与相邻年略异。
