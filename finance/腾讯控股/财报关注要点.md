# 腾讯控股 财报关注要点

- **生意一句话**:微信/QQ 社交网络免费聚人,游戏+广告+金融科技及企业服务三引擎变现,另持大规模投资组合。
- **生意类型**:成长稳定(公司客观属性;IFRS 净利年度噪音大,利润趋势以毛利/经营盈利口径为准)

## 🅰 生意模式 / 护城河本质(读财报排雷相关的最小集)

- **先收钱后服务**:游戏充值/会员订阅先进递延收入再逐期确认——**递延收入是腾讯的"合同负债蓄水池"**,骤降 = 游戏/订阅需求转弱的先行指标(落点 → `财务数据/资产负债表.csv` 递延收入行、`财务比率.csv` 递延收入/营收)。
- **IFRS 净利被投资组合污染是常态**:处置/视同处置(京东/美团式实物分派)、公允变动、减值都进「其他收益净额/投资收益净额及其他」——**看利润必须三口径对照:毛利(最干净)→ 经营盈利(2023 起已剔投资项)→ Non-IFRS 归母(公司口径,剔 SBC/投资项)**。经营盈利跨 2022/2023 年报口径不可比(见 `财务数据/README.md` 重列表)。
- **「分占联营」也有反直觉噪音(2026Q2 实证)**:被投公司**估值上升**→其发行的可转换可赎回优先股(CRPS)按公允价值重估→腾讯分占**亏损**——方向与直觉相反、可单季百亿级摆动;Non-IFRS 已剔除(Non-IFRS 口径分占联营长期稳定)。读到"分占联营大亏/大赚"标题先回 `财务数据/中期财务-2026.csv` 拆口径。
- **商誉并在无形资产内披露**(与 A 股单列不同),无形资产异动要拆附注看商誉 vs 游戏授权/媒体内容。
- **VIE 结构**:境外主体合同控制境内运营实体,中概平台通用结构风险。

## 本公司独有红旗 / 易暴雷点

- 🟡⬆ **AI capex 失速风险(2026-08 状态更新)**:投入已量化到三张表(经营盈利拖累/单季 FCF 转负/预付款科目跳变,见 `中期财务-2026.csv` 与 `分析.md` 四)——**变量#1 已触线**;当前云/广告增速未掉队(广告增速居三引擎之首)故未升 🔴,若引擎增速回落而 capex 不减 = 升级。
- 🟡 **「其他收益净额」大起大落**:含一次性处置/减值,任何"净利大增/大降 X%"的标题都先回 `利润表.csv` 拆口径,勿被 IFRS 净利骗;**分占联营 CRPS 重估同理**(见 🅰)。
- 🟡→🟢 **SBC 摊薄(2026-08 缓解)**:2026H1 SBC 费用同比下降、加权股本因回购注销净缩(见 `中期财务-2026.csv`);继续跟踪股份奖励计划规模与回购注销的对冲净效果,再度大额一次性 SBC 则回 🟡。
- 🟡新 **收费增值服务订阅会员数连续下滑**:2026Q2 同比、环比双降(见 `中期财务-2026.csv` 单项事实段),当前靠道具销售/ARPU 补——连续第三期下滑或社交网络收入转负 = 社交增值基本盘预警。
- 🟡 **存贷双高表象**:大额现金+定期与大额票据并存是全球化资金管理常态,但**利息收入 ÷ 现金类均值**若显著低于市场利率(<2%)则升级核查资金真实性(康得新教训;当前 ~3.9% 匹配,🟢)。
- 🟡 **大股东减持节奏**:Prosus 长期减持 + 公司回购对冲,若回购停而减持继续 = 供给压力;创始人层面减持才是治理红旗(当前无)。
- ⚪ 泡泡玛特式爆款依赖**不适用**:游戏组合分散 + 长青款 10 年运营记录,单品风险低于 IP 玩具/单款爆款公司。

## 历史踩过的坑 / 管理层诚信记录

- 2021-2022 监管冲击(版号停发 8 个月/平台整改/教培广告消失):营收史上首次负增长,公司以降本+高质量增长应对,2023 起毛利率逐年回升——**管理层危机应对有实证记录**。
- 2021/2022 京东/美团实物分派:以股代息还股东,同时确认巨额账面处置收益——**动作对股东友好,但当年 IFRS 净利不可比**(读数教训,非诚信问题)。
- 回购全部注销(非库存再发)、审计 PwC 自上市未换、创始人零减持主导——诚信记录干净。
- 无造假指控/无监管财务处罚记录(区别于经营合规类罚款)。
