# 耐克（NIKE, Inc.·NYSE: NKE）财务数据（从一手 10-K 解析）

> 本目录 = 耐克的**一手财务数据库**：从一手申报解析的所有客观数字（三表 + 比率 + 分部 + 公司特有指标 + 分析派生指标）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/耐克/`（事实编年，分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/耐克/`（**FY1995–FY2026 共 32 份 10-K**）**逐行解析** + 勾稽自洽校验。
> **单位 / 符号**：金额一律 **百万美元（US$ mn）**；EPS 为美元/股、股数为百万股；利润表费用为正、现金流量表流出为负；空 = 该期财报无此科目（**不是零**）。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## ⚠️ 读这个库之前必须先知道的五件事

1. **财年截至 5 月 31 日**。FY2026 = 2025-06-01 ~ 2026-05-31。**"2026 年"在本库一律指财年**，与日历年差半年。跟中国同业（日历年）横比时要记住这半年错位。
2. **EPS / 股数不可跨年直接相减**。NIKE 在 EDGAR 可考期内拆股 **5 次**，各年 10-K 印的每股数据都按**该次申报时点**的股本基准追溯调整过。跨年比每股口径请用 `财务比率.csv` 的 **【复权】三行**。
3. **地区分部口径在 FY2018 断过一次**（6 区 → 4 区），更早在 FY2011 之前是另一套（美国/欧洲/亚太/美洲）。三代口径分列三张表，**不可拼接**。
4. **FY2026 净利里有一笔 9.86 亿美元的一次性关税退款收益**，记在营业成本里。见下「口径断点」第 6 条。
5. **美股无「扣非」法定口径**，本库不造扣非行。一次性项目（重组 / 商誉减值 / 无形减值 / 终止经营 / 会计变更累积影响 / 关税退款）各自单列或在事实编年里标注，需要时自行加回。

## 🔴 口径断点清单（跨年比较前必读）

| # | 财年 | 断点 | 影响 |
|---|---|---|---|
| 1 | FY1998 | 印刷单位由**千美元**改为**百万美元** | 解析按各表自陈单位换算；硬编码会让 FY1995-97 整体大 1000 倍 |
| 2 | FY2002 | 利润表版式由「营收 − 总成本及费用 = 税前」改为「营收 − 成本 = 毛利 − 费用 = 税前」 | **FY1993–FY2001 利润表没有「毛利」这一行**，`财务比率.csv` 的毛利为派生值（营收−成本） |
| 3 | FY2002–FY2005 | 存在「会计变更累积影响」税后项，净利 ≠ 税前−所得税 | **FY2003 净利 −29% 主要是 SFAS 142 商誉转型一次性计提 2.661 亿**，不是经营恶化：剔除后当年"会计变更前利润"同比 +10.7% |
| 4 | FY2012–FY2014 | Umbro（2012-11-30 售出）、Cole Haan（2013-02-01 售出）列作**终止经营** | 净利 = 持续经营净利 + 终止经营损益，两行单列 |
| 5 | FY2018 | 美国《减税与就业法案》令实际税率飙至 **55.3%** | **FY2018 净利 −54% 主要是税，不是经营**：当年 EBIT 仅 −11%（`财务比率.csv`） |
| 6 | **FY2026** | 🔴 **IEEPA 关税退款 9.86 亿美元确认在「营业成本」** | 其中北美 9.65 亿、Converse 0.21 亿。公司自陈"**大体抵消了同期确认的关税成本**"，故不是净增利；但 **6.84 亿关税应收款计入「应收账款净额」**，占当年应收增量 1,214 的 56% —— 算 DSO / 判"应收异常"时必须先剔 |
| 7 | FY2011 / FY2018 | 地区分部口径两次重划 | 见下「分部口径三代」 |
| 8 | FY2020 | 采用 ASC 842，首次出现使用权资产与租赁负债（约 31 亿 / 34 亿） | **资产负债率从 61.9% 跳到 74.3% 有相当部分是会计准则**，不是当年新增杠杆；`财务比率.csv` 同时给「含租赁」与「不含租赁」两个有息负债口径 |
| 9 | FY2019 | 采用 ASC 606，才开始披露批发 / DTC 渠道拆分 | 更早年份渠道行为空 = 未披露，不是零 |
| 10 | FY2013 | 该份 10-K 的**现金流量表印的是原始美元**（同一份申报里利润表和资产负债表却是百万美元） | 解析按各表自陈单位换算；不分表处理会差 10⁶ 倍 |

## 勾稽自洽校验

由 `_build_from_filings.py` 生成，**每个财年**验证（不过则不写出 CSV）：

- **必填项（C0）**：某年只要有该表任何数据，营收 / 税前 / 所得税 / 净利（利润表）、总资产 / 流动资产 / 流动负债 / 权益 / 现金 / 存货 / 应收（资产负债表）、经营 / 投资 / 融资 / 期末现金 / 资本开支（现金流量表）就**必须有值**。
  > 🔴 这条单独设，是因为其余勾稽都写成「锚科目存在才开查」——锚科目本身丢了，整张表的检查会**静默全过**。实证：解析器一度把 `Revenues` 误并进单位说明行，FY1993-1996 与 FY2002-2010 营收整段为空，而勾稽照报"全过"。
- **利润表**：营收−成本=毛利；税前−所得税=持续经营净利/会计变更前利润/净利（按当年版式选）；毛利−各项费用=税前（FY2002+）或 营收−总成本=税前且各项和=总成本（FY1995-2001）；持续+终止=净利；变更前−累积影响=净利；需求创造+运营管理=SG&A；**净利÷基本股数≈基本EPS（2% 容差）**。
- **资产负债表**：流动资产明细和=流动资产合计；资产分项和=总资产；流动负债明细和=流动负债合计；负债+权益=总资产；权益明细和=权益合计；两侧合计相等。
- **现金流量表**：经营+投资+融资+汇率(+FY1997-99 的子公司并表期间调整)=净变动；期初+净变动=期末；**CF 净利=IS 净利**；**期末现金=BS 货币资金**。
- **分部**：各地区+全球品牌部门=NIKE 品牌合计；NIKE 品牌+其他+总部=合计；批发+直营+其他=合计营收；鞋+服+装备(+其他)=合计营收/NIKE 品牌合计；各分部 EBIT 和=EBIT 合计；**分部合计营收=利润表营收（跨文件勾稽）**。
- **长期摘要**：FY1993+ 的重叠年份必须与三表对上（对 FY1988-1992 那批最老数据的独立验证）。

**当前状态：全部通过**（`_build_from_filings.py` 与 `_build_segments.py` 均报"勾稽全过"）。

## 拆股复权因子怎么来的（不是抄的）

`_build_ratios.py` 拿**相邻两份 10-K 里同一个财年的加权股数**相除，比值 ≈2 即判定其间发生一次 2-for-1 拆股。实测链条：

| 在哪两份 10-K 之间 | 用哪个财年对照 | 比值 |
|---|---|---|
| FY1995 → FY1996 | FY1995 股数 73.503 → 147.006 | ×2 |
| FY1996 → FY1997 | FY1996 股数 146.804 → 293.608 | ×2 |
| FY2006 → FY2007 | FY2006 股数 259.0 → 518.0 | ×2 |
| FY2012 → FY2013 | FY2012 股数 460.0 → 920.0 | ×2 |
| FY2015 → FY2016 | FY2015 股数 861.7 → 1,723.5 | ×2 |

由此得到相对 FY2026 的复权倍数：FY1988-1995 = ×32、FY1996 = ×16、FY1997-2006 = ×8、FY2007-2012 = ×4、FY2013-2015 = ×2、FY2016 起 = ×1。
**好处**：因子由本库自己的数字互证得出，记错拆股日期也污染不了数据。
