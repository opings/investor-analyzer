## 🅰 读耐克财报，与行业模板不同的三处

模板那一块是照着**港股/A 股的中国运动服饰公司**写的，耐克有三处结构性不同，读法要改：

| 模板假设 | 耐克实际 | 读法怎么改 |
|---|---|---|
| 「零售流水」是公司按季自愿披露的表外指标 | **耐克不披露零售流水**，但**披露同店销售（comparable store sales）与 NIKE Direct 收入** | 用「同店 + DTC 收入 + 公司对客流的自陈」三件替代流水；口径定义在 10-K 的 "Comparable Store Sales" 段 |
| 「渠道库存周转月数」由公司自愿披露 | **耐克不披露渠道库存月数** | 只能用**自家存货金额 vs 件数的自陈差异** + 折扣力度的 MD&A 措辞倒推，**精度显著低于中国同业**，判断时要留余量 |
| 分部利润看「经营溢利」 | 耐克分部只披露 **EBIT**，且**「全球品牌部门」与「公司总部」是净成本中心、常年为负** | 算分部利润率时分母用该分部营收、分子用该分部 EBIT；**不要把总部成本摊回去**再比 |

**另外两条耐克独有的结构**：

- **供应商融资计划（Supplier Finance Program）**：应付账款被第三方金融机构提前付给供应商、耐克到期再还。它**记在应付账款里、不计入有息负债**，是一条表外性质的融资通道。FY2023 起（ASU 2022-04）才强制披露，更早年份**没有数不等于没有这件事**。→ `财务数据/表外承诺与回购计划.csv`
- **代言与赛事合同**：这门生意真正的"维持性投入"走**需求创造费用**（损益表），不走资本开支。**看到 capex/营收只有 1%–2% 就说"轻资产、不用花钱"是误读**。

## 🅱 核心跟踪变量（5 个·按优先级）

### 1. 🔴 大中华营收与 EBIT —— 份额是不是还在丢

- **数据落点**：`财务数据/分部营收.csv`、`财务数据/分部经营利润.csv`、`财务数据/财务比率.csv`（大中华占比）
- **频率**：每季（8-K 业绩稿给分部营收，10-Q 给分部 EBIT）
- **警戒线**：**连续第三年双位数下滑**，或**占总营收比重跌破 10%**
- **触线动作**：立刻做同业对照——把安踏 / 李宁 / 特步 / 361度 同期中国区营收拉出来（各自 `财务数据/利润表.csv`）。**若同业仍在增长而耐克继续跌，则判为公司特有的份额流失，不是市场收缩**；若同业同步转跌，才是行业问题。
- **为什么排第一**：这是目前**库内数据能证伪**的那条"公司问题 vs 行业问题"命题（其余地区缺对照组）。

### 2. 🔴 应收账款增速 − 营收增速（先剔非经营性应收）

- **数据落点**：`财务数据/财务比率.csv`（「应收账款增速−营收增速(pp)」「应收账款周转天数 DSO」）
- **频率**：每季
- **警戒线**：**连续两期 >+10pp**，或 **DSO 连续两期上行且累计 >+8 天**
- **触线动作**：
  1. **先剔非经营性项**——FY2026 应收里有关税退款应收款，不是卖货形成的。每期先去 10-K/10-Q 附注确认「应收账款净额」里有没有这类夹带，剔干净再算。**不剔就会把政府应收当成渠道压货**。
  2. 剔完仍超线 → 去 MD&A 找是否有"延长账期 / 加大折扣 / 更高退货"的自陈；对照批发占比是否同步回升（`分产品与渠道营收.csv`）。
- **当前状态**：FY2025 +16.4pp、FY2026 +25.5pp（剔关税后约 +11pp），**已连续两期超线**。

### 3. 🔴 存货：金额之外必须看「件数」与折扣措辞

- **数据落点**：`财务数据/资产负债表.csv`（金额）、`财务数据/财务比率.csv`（存货周转天数 DIO、存货/营收）
- **频率**：每季
- **警戒线**：**DIO 连续两期 >105 天**，或**金额持平/下降而公司自陈"件数增加"**
- **触线动作**：金额与件数背离时，**以件数为准**——金额可以被产品结构（卖便宜货）和跌价准备掩盖。同时查 MD&A 的毛利率归因里有没有"更高折扣 / 更高存货跌价准备"。
- **为什么单列**：这是行业模板「存货周转天数抬升而毛利率不降 = 减值可能滞后（事反必妖）」那条的耐克版；耐克 FY2026 正好是"金额持平 + 件数增加 + 公司自陈"的组合。

### 4. 🟡 DTC 占比与同店销售 —— 渠道叙事还成不成立

- **数据落点**：`财务数据/财务比率.csv`（DTC 占比、批发占比）、`财务数据/分产品与渠道营收.csv`；同店销售只在 10-K/10-Q MD&A 里给，**本库未建序列** ⏳
- **频率**：每季
- **警戒线**：**DTC 占比连续第三年回落**，或**同店销售连续两期为负**
- **触线动作**：DTC 回落 + 批发回升同时出现时，注意**收入确认时点不同**会让同样的终端动销算出不同的报表收入——跨期比营收前先看渠道构成有没有变。
- **当前状态**：DTC 占比已连续两年回落，同店 FY2026 为 −4%。

### 5. 🟡 股东回报组合：回购是否重启、分红率是否失守

- **数据落点**：`财务数据/现金流量表.csv`（已付股息 / 回购股票）、`财务数据/财务比率.csv`（分红率、股东总回报率）、`财务数据/表外承诺与回购计划.csv`（授权与剩余额度）
- **频率**：每季（10-Q Item 2 给当季回购明细）+ 每年（10-K Item 5）
- **警戒线**：**分红率连续两年 >75%**，或**分红绝对额首次下调**
- **触线动作**：
  - **「回购授权」≠「已执行」**——授权额度挂着不代表会买。实际金额只看现金流量表那一行。
  - 分红率冲高时先分辨是**分子涨**（主动加派息）还是**分母塌**（利润下滑），两者含义相反。
  - 关注留存收益已为负这一结构：权益靠资本公积撑着，**这是长期回购冲减留存的算术结果，不是亏损累积**——别误读成资不抵债信号。

## 🅱 本公司独有红旗

| 级别 | 红旗 | 怎么看 / 数据落点 |
|---|---|---|
| 🔴 | **一次性项混入营业成本** | FY2026 的 9.86 亿关税退款收益记在**营业成本**里而非营业外。**凡看到毛利率反常改善，先去 MD&A "OTHER MATTERS" 与 Note 1 查有没有这类项**。→ `财务数据/README.md` 口径断点 6 |
| 🔴 | **Converse 分部 EBIT 继续向零或转负** | 该分部 FY2026 EBIT 已近乎清零，公司称在做"品牌与渠道重置"但**未给完成判据或时间表**。若下一年仍无拐点，需考虑它是否会从"拖累项"变成"减值项"（商誉与无形合计仅占总资产 1.3%，敞口有限）→ `财务数据/分部经营利润.csv` |
| 🟡 | **供应商融资计划余额骤降** | 余额下降意味着这条表外融资在收缩，会**一次性抽走经营现金流**且不体现在有息负债里。→ `财务数据/表外承诺与回购计划.csv` |
| 🟡 | **银行保函与信用证持续攀升** | FY2019→FY2026 增长约六倍，10-K 只给总额与用途类别、**未解释增长原因** ⏳。或有负债膨胀需要追问。→ 同上 |
| 🟡 | **「递延所得税及其他资产」占营收持续上行** | 已查实大头是净递延所得税资产 + 代言合同预付款 + 递延薪酬资产。**继续变厚就要追问是不是在往这里堆递延成本**。→ `财务数据/资产负债表.csv` |
| 🟡 | **地区分部口径再次重划** | 历史上已改过两次（FY2011、FY2018）。**口径一改，跨年序列即断**——每次年报先看分部定义段有没有变。→ `财务数据/README.md` 分部口径三代表 |
| 🟡 | **EPS/股数跨年直接比** | 这不是公司的红旗，是**读表的红旗**：耐克在可考期内拆股五次，各年 as-reported 每股数据基准不同。跨年比一律用 `财务数据/财务比率.csv` 的【复权】三行 |

## 持续监控节奏

| 频率 | 做什么 |
|---|---|
| **每季（业绩 8-K 当日）** | 分部营收（尤其大中华）、渠道拆分、同店与客流自陈、回购实际金额 |
| **每季（10-Q 发布后）** | 应收账款附注（有无非经营性夹带）、存货附注、分部 EBIT、供应商融资余额、重组计提 |
| **每年（10-K）** | 全部核心变量刷新 + **分部定义是否变更** + MD&A 毛利率桥逐项 + 表外承诺 + Item 5 回购进度 + 审计意见 |
| **事件触发** | 8-K Item 2.05（重组）、Item 5.02（高管变动）、Item 8.01（更正/其他）、关税与贸易政策裁决 |
