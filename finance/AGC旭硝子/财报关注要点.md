# AGC（旭硝子） 财报关注要点

> 行业块：**周期/资源 + 制造/重资产**（自 `_模板/财报关注要点-行业模板.md` 两块起步，按公司定制）。
> 本文件只写监控规格（指标/频率/警戒线/触线动作），**不嵌数字**——时间序列一律在 `财务数据/<csv>`。

- **生意一句话**：日本老牌材料集团——用**化学品与电子材料**赚主要利润，用**建筑玻璃与汽车玻璃**扛主要收入，另有一块仍在亏损的生命科学（CDMO）。
- **生意类型**：**强周期**（四条腿分别挂钩化工品价格、显示/半导体资本开支、汽车产销与年降、欧亚建筑景气；单年净利不可外推）。

## 🅰 生意模式 / 成本结构 / 护城河本质（读财报前先懂在哪赚钱）

- **别被名字骗**：公司名与历史都是玻璃，但**利润重心在化学品与电子**（分部营业利益占比见 `财务数据/分部营收.csv`）。用纯玻璃框架（对标福耀/耀皮）分析 AGC 会跑偏。
- **两条利润腿的性质不同**【判】：
  - **化学品**＝基础化工（氯碱/PVC/聚氨酯原料，价格接受者、随化工周期）＋ 高性能化学（氟系、碘系，技术门槛较高）。公司把 FY2025 减益直接归因于氯乙烯树脂售价下跌【源：FY2025 決算短信 P5】。
  - **電子**＝显示基板 + 半导体制程材料 + EUV 光罩基板。**FY2024-FY2025 分部利润率居六块之首，但 FY2022-FY2023 是化学品居首**——两块轮流领跑、并非固定座次（`财务数据/分部营收.csv`）；**挂钩客户资本开支周期**，出货与利润率波动大。
- **玻璃两块**：建筑玻璃随欧洲景气与亚洲售价波动；汽车玻璃面对整车厂年降，靠品种结构（隐私玻璃/天窗/HUD 前挡等）与价格政策对冲【源：FY2025 決算短信 P4】。
- **报表结构特性（最关键的一条）**：
  - **AGC 的「営業利益」不含减值等一次性项目**，减值/业务重组/资产处置走「その他収益・費用」，落在**营業利益 → 事業利益**之间。
  - 因此**头条营业利益长期平稳、净利却被反复击穿**。读 AGC 的利润表**必须先看「営業利益 − 事業利益」这道缝有多宽**，再谈增长（`财务数据/利润表.csv`）。
  - 重资产：折旧摊销规模常年与净利同量级，经营现金流长期高于净利——**现金流好看不等于盈利能力强**。

### 公司独有红旗 / 易暴雷点

- 🔴 **减值的重复性**：FY2022（俄乌后）与 FY2024（生物药 CDMO）两度把归母打成负数（`财务数据/利润表.csv`）。**把减值当"一次性"读是本公司最容易犯的错**——它在本库覆盖期内是重复模式。
- 🔴 **生命科学分部**：2016-2020 并购建成（德/丹麦·美/意）→ FY2024 集中减值 → FY2025 仍亏损且仍有资本开支（`分部营收.csv`、`knowledge/companies/AGC旭硝子/{2024,2025}.md`）。
- 🟡 **汇率放大器**：海外收入与资产占比高，日元贬值同时抬高**收入换算**与**权益（其他资本构成要素）**。公司自陈 FY2025 建筑/汽车玻璃增收含日元贬值贡献【源：FY2025 決算短信 P4】。**看增长必须剥汇率**。
- 🟡 **一次性收益美化净利**：FY2025 其他收益含东京江东区土地出售益（`knowledge/companies/AGC旭硝子/2025.md`）。**归母转正时先查其中多少来自卖资产**。
- 🟡 **组合持续做减法**：北美建筑玻璃（2021）→ 大连特种玻璃（2023，卖给上海耀皮）→ 俄罗斯（2024）→ 化学强化用特殊玻璃（2025 决定退出）。**减法本身中性**，但每次退出常伴随处置损失，须并入第 1 项缺口一起看。
- 🟢 **不存在存贷双高**：现金远小于有息负债、净负债经营（`财务数据/资产负债表.csv`）——不必按康得新/康美清单深查。
- ⏳ **待补**：市占率/行业集中度无一手口径；大株主（股东名册）章节未解析；监管处罚记录未逐年检索；のれん 明细与减值测试假设未逐年比对。

### 历史踩过的坑 / 管理层诚信记录

- **FY2010 是本库覆盖期的盈利高点**（日本基準口径 経常利益与净利、ROE 15.76%），FY2025 净利仍低于该水平而营收接近翻倍（`财务数据/长期业绩序列.csv`）——**长期看是"增收不增利"**。
- IFRS 期（FY2012 起）**归母 ROE 无一年到 10%**（同上）。
- 本库覆盖的 FY2013-FY2025 有価証券報告書均正常提交、未见更正或重述；三表跨源逐格一致（`财务数据/README.md`）。
- 分部口径 FY2022 由 4 改 6（ガラス→建築+オート，化学品拆出ライフサイエンス）——**做历史同比前必须确认用的是哪套口径**。

## 持续监控节奏

- **季度（決算短信·TDnet）**：营收/営業利益/事業利益 三者同看（尤其第 1 项缺口）、分部利润、经营现金流。
- **年度（有価証券報告書·3 月下旬提出）**：核心跟踪变量 5 项全查 + 分部资本开支与减值 + 折旧政策 + 分红与自由现金流匹配 + のれん。
- **事件触发**：分部重组/口径变更、业务退出与出售、大额减值公告、日元汇率急变、显示/半导体客户资本开支拐点、化工品价格拐点。
- **取数路径**（本库已跑通，见 `财务数据/README.md`）：有報 = `agc.com/ir/library/yu_report/pdf/rep{YYYY}_4.pdf`；最新年度有報 = EDINET 直连 `disclosure2dl.edinet-fsa.go.jp/searchdocument/pdf/{docID}.pdf`；決算短信 = `agc.com/news/pdf/{YYYYMMDD}_1.pdf` 或 TDnet 镜像。
