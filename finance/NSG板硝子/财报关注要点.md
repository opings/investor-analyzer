## 🅰 读这家财报必须先知道的事（排雷相关，非商业模式论述）

1. **两套准则、断点在 FY2012/3**：FY2011/3 及以前 JGAAP、FY2012/3 起 IFRS。**JGAAP 的経常利益与 IFRS 的税引前利益不是同一口径，不可连成一条曲线**。
2. **「営業活動による現金生成額」≠ 经营现金流**：前者是**付息付税前**的 cash generated from operations。NSG 的利息与税加起来能吃掉前者的四成以上——**用错口径会把这门生意的质量拔高一整档**。这是本公司财报的头号读数陷阱。
3. **「個別開示項目（exceptional items）」是常设科目不是偶发项**：重组/减值/处置常年从这里走。**连年出现的「一次性」不是一次性**——看营业利润必须同时看个别开示项目前/后两个口径。
4. **CF 的现金 ≠ BS 的现金**：现金流量表口径扣除银行透支、资产负债表按总额列示。**不要拿这两个数去对，也不要用它算净负债时混用。**
5. **公司自述的「净借入残高」与从三表算出的净有息负债有口径差**（FY2026/3 约差 ¥55 亿）。**引用时二选一并注明来源，不要混用。**
6. **亏损年份改的是科目名不是符号**（JGAAP 段亏损行甚至印无符号正数、盈亏各占一行）。人工核对老年报时极易把亏损读成等额盈利。
7. **2016-10-01 普通股 10 股并 1 股**：跨该点比较任何每股指标都必须先复权。
8. **FY2026/3 优先股全部转普通股，普通股数一年 +55.4%**：跨该点比较每股指标同样断裂。
9. 详细口径与踩坑清单见 `财务数据/README.md`「重要口径注记」16 条。

## 🅲 本公司独有红旗 / 易暴雷点

| 级别 | 红旗 | 判据 |
|---|---|---|
| 🔴 | **靠借新还旧维持资产** | 年度偿还与借入规模均达营收三成量级、自由现金流长期为负（`财务数据/现金流量表.csv`、`财务数据/财务比率.csv`） |
| 🔴 | **利润来自税项而非经营** | FY2026/3 税前接近零、净利靠英国递延所得税资产确认。**递延税资产的确认前提是「未来有足够应税所得」——对一家过去五年累计亏损的公司，这个判断本身是需要盯的科目** |
| 🔴 | **「一次性」项目常态化** | 個別開示項目 连年有量；FY2023/3 一次计提 ¥488 亿商誉与无形资产减值（即 2006 年收购皮尔金顿形成的欧洲汽车玻璃商誉与无形资产**全额**归零） |
| 🟡 | **应收账款证券化（債権流動化）规模未披露** | 会计方针载明应收售予金融机构后**终止确认**，但 有報 全文**未量化售出金额**【源：FY2026 有報 P111】。⇒ ① 表上应收是扣除未知规模已售应收后的**净额**；② 应收/营收比的「改善」**不能**当作回款质量变好的证据；③ 对一家自陈流动性受限的公司，**一条不计入有息负债、规模不明的融资渠道就是敞口**。明细见 `财务数据/应收明细.csv` |
| 🟡 | **公司自己的摘要页印错过数** | FY2002/3 投資CF/財務CF 的 5 年表值与同报告经审计现金流量表对不上，且错值在次年 5 年表被原样重复 → **一律以经审计三表与附注为准，摘要页只作互证** |
| 🟡 | **汇率与恶性通胀会计放大表观增长** | 公司自陈总资产/收入增长含日元贬值折算与阿根廷 IAS 29 调整。**看收入增长必须先剥汇率与通胀调整** |
| 🟡 | **利率是杠杆放大器** | FY2024/3 金融费用净额因市场利率上升单年跳升逾六成【源：FY2024 有報 P32】——**一次加息即可吃掉一整年的经营改善**（金额序列详见 `财务数据/利润表.csv`、`财务数据/现金流量表.csv`） |
| 🟢（就真实性而言） | **不是存贷双高** | 现金远小于负债，是真·高杠杆而非资金造假；利息支付额与负债规模匹配 |

## 🅳 历史踩过的坑 / 管理层诚信记录

- **2006-06 完全收购皮尔金顿（「蛇吞象」）**：这是理解此后二十年一切财务表现的起点。收购当年总资产翻一倍以上、自己资本比率腰斩、净有息负债跃升一个数量级（序列详见 `财务数据/长期业绩序列.csv`、`财务数据/财务比率.csv`）。
- **FY2023/3 全额减值该收购形成的欧洲汽车玻璃商誉与无形资产**【源：FY2023 有報 P32】——公司在账面上正式承认这笔交易没有创造价值（金额与年度断崖见 `财务数据/资产负债表.csv` 的「のれん」行）。
- **披露诚信：正面记录**。公司把「过去五年累计最终亏损约 ¥284 亿」「负债逾 ¥5,000 亿」「现状无复配前景」「逾 ¥1,000 亿到期借款若不做本交易连借新还旧都不容易」直接写进 有報 的「事業等のリスク」。**这种程度的自我披露在日企中不常见，属于加分项**——同时也意味着**不必怀疑其披露，该怀疑的是其偿债能力**。
- **股权结构本身是信号**：前三大股东为 DBJ 系与 JIS 纾困/重整型基金（且均为 A 种优先股原持有人）。**当第一大股东是救助资本，公司处境已经写在股东名册上了。**
- **四次遡及修正均为准则变更**（IAS19R / IFRIC14 英国年金资产上限 / IFRS15 / 持分法列报），**不是差错更正**，已逐条回溯到会计政策变更注记原文（`财务数据/README.md`）。

## 🅴 持续监控节奏

| 时点 | 动作 |
|---|---|
| **事件触发（最高优先级）** | Apollo 交易各节点：定时股东大会决议 → 各国竞争法/对内直接投资/FSR 许可 → 拟似DES → 第三者配发缴款 → 股份合并生效 → 退市。任一节点延迟或条件未满足即需重估 |
| **半年报（11 月前后）** | 净有息负债、利息覆盖、分部利润率、自己資本比率 |
| **年报 / 有報（5 月决算短信 · 6 月下旬 有報）** | 全套变量刷新；有報 独家含「事業等のリスク」「重要な契約等」「会計方針の変更」「主な販売先」——**这些只在 有報 里有，決算短信没有** |
| **年报后** | 重跑 `财务数据/_extract.py` → `_build_from_pdf.py` → `_build_segments.py` → `_build_ratios.py`，五重校验须全过才落盘 |
