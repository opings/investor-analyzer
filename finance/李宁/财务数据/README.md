## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**校验不通过则不写出 CSV**。当前状态：**261 条全部通过**。

| 类别 | 条目 |
|---|---|
| 损益① | 营业额 + 销售成本（负）= 毛利 |
| 损益②a/②b | 除税前 + 所得税 = **持续经营**溢利；持续经营 + **终止经营** = 年内溢利 |
| 损益③ | 母公司应占 + 非控股应占 = 年内溢利 |
| **损益④** | **经营溢利 + 财务收入净额 + 应占联营合营 = 除税前溢利** —— 这条是**毛额/净额混淆探测器**，见下 |
| 资负①②③ | 非流动+流动=资产总计；负债+权益=资产总计；流动+非流动负债=负债总额 |
| **资负⑤** | **权益分项之和 = 权益总额** —— 这条是**漏抓探测器**，见下 |
| 现流①② | 经营+投资+融资 = 现金净变动；期初 + 净变动 + 汇率 + 划归持作出售之现金 = 期末现金 |
| 跨表① | 现金流量表期末现金 = 资产负债表现金及现金等价物 |

> **为什么要单设「损益④」和「资负⑤」**：前面几条只对小计，对两类错**同时失效**——
> - **毛额当净额**：多数年份同时印 `Finance income` / `Finance expenses` / `Finance income – net` 三行，取首个会拿到毛额（2025 实测取到 296.7 而净额只有 33.1 百万元）。前三条勾稽不碰这一段，照样全平。
> - **整行漏抓**：某个权益分项整行没解析到，小计仍然自平。2006–2011 的保留溢利被拆成「– Proposed final dividend / – Others」两行且母行不带数字，就是这么漏的（2011 漏 2,730.2 百万元）。

## 口径断点（55 格差异的成因·均有一手附注佐证）

| 年 | 断点 | 一手出处与金额 |
|---|---|---|
| **2004** | 首次应用 **IFRS 2 股份支付**，追溯重述 2004 | AR2005 p82：「The adoption of IFRS 2 has resulted in a change in the accounting policy for share-based payments. Until 31 December 2004, the provision of share options … did not result in an expense … The 2004 comparatives have been amended」（译：采纳 IFRS 2 导致股份支付会计政策变更；2004 年比较数字已修订）。税前与净利同减 **11.025 百万元**，**所得税分文未动**——与不可抵扣的购股权费用相符 |
| **2005** | 员工成本由分销/行政**重分类至销售成本** | AR2006 附注 2.23：「Certain staff costs amounting to **RMB26,356,000** … reclassified from distribution costs and administrative expenses to cost of sales」（译：若干员工成本合计 26,356,000 元由分销费用及行政费用重分类至销售成本）。分销 7.377 + 行政 18.979 = **26.356**，分毫对上 |
| **2011** | 存货减值由行政开支**重分类至销售成本** | AR2012 p144：「(2011: **RMB72,427,000**) in respect of the write-down of inventories … reclassified as cost of sales」（译：2011 年存货减值 72,427,000 元已重分类为销售成本）。与实测 **72.427** 一致 |
| **2012**（并及 2009–2011） | 采纳 **IFRS 11**，合营企业由**比例合并改权益法** | AR2013 p9 脚注：「Upon adoption of IFRS 11, proportional consolidation of joint ventures is no longer allowed. Hence, the Group accounted for its investment in **Li-Ning Aigle Ventures Company Limited** using the equity method … figures for the years ended 31 December 2012, 2011, 2010 and 2009 have been restated」（译：采纳 IFRS 11 后合营不再允许比例合并，对李宁艾高合营公司改按权益法；2009–2012 数字已重述）。2012 营业额 −62.470、三表逐项联动 |
| **2014** | **红双喜列作终止经营**，比较数字重分类 | AR2015 p20/p96：「the disposal of 10% equity interest in **Shanghai Double Happiness** … Double Happiness has been treated as discontinued operation in 2015 … Comparative figures are also reclassified」（译：出售上海红双喜 10% 股权，红双喜于 2015 年作终止经营处理，比较数字亦已重分类）。2014 营业额 −680.406（6,727.6 → 6,047.2） |
| **2017** | 金融资产减值拨回由行政开支**单列** | AR2018 把 **10.985 百万元**从行政开支拆出成独立行；`−512.051 + 10.985 = −501.066`，经营溢利两版相同 |
| **2009→2010** | 「其他应收款及预付款项」拆出非流动/流动，且 2010 把原 `Other non-current assets` 改名并入 | 列报变更，非重述 |

> **对使用者的含义**：**2014→2015 营业额增速不可直接从本表两格相减**（2014 为含红双喜口径、2015 为持续经营口径）。同理 2011→2012 受 IFRS 11 影响。要 like-for-like 请回该年年报的比较列。

## 按恒等式补出的格（非报表原印）

IFRS 恒等式「权益总额 = 母公司拥有人应占权益 + 非控股权益」用于互补两代版式各自缺的那一行，**这是恒等式不是估算**：

| 行 | 哪些年是补出的 | 原因 |
|---|---|---|
| `母公司拥有人应占权益` | 2005–2025 | 该版式只印 `Total equity`，母公司应占小计以**无标签裸数字**印在权益段末（2008 实测 1,896,413，与补出值分毫相等） |
| `权益总额` | 2001–2004 | 旧版式只印 `Owners'/Shareholders' equity`（不含非控股）+ 单列 `Minority interests`，**没有 Total equity 行** |

### `分部营收.csv` 的覆盖率一栏必须看

「分产品合计÷营业额」是**口径覆盖率**，不是校验值：

- **15 个年份 = 100.0%**（2004–2010、2018–2025）：分产品和精确等于利润表营业额，三重勾稽通过。
- **7 个年份 < 100%**（2011 91.4% / 2012 87.9% / 2013 87.3% / 2014 88.2% / 2015 98.3% / 2016 98.9% / 2017 99.4%）：**这不是漏抓**——这些年年报按品牌分层披露（李宁 / 红双喜 / Lotto / 其他），**集团合计一栏没有拆产品**，能拆的只有李宁品牌。缺口 = 其他品牌收入。

> 曾想顺带记一行「李宁品牌收入」，但 MD&A 是两栏排版、左栏饼图标签会串进同一物理行，「第一个 Total 行」在 2006/2007/2009 分别取到 3,168 / 104 / 190 百万元——全是别的品牌块的合计。**定位不住就不记**：错的数比没有数更糟。品牌口径缺口已由覆盖率行如实反映。

## 为什么从年报解析、不用二手

二手 CSV 会错、与一手打架（农夫实证：`经营业务现金净额` 把税前 256 亿误标成净额，真值 211 亿）。本库李宁全部数字与一手同源。`derived.py` 报「未匹配科目」两项，均为**口径事实、非漏抓**：

- `扣非归母`：港股 IFRS **本无「扣非」这条线**，不存在可取的披露值（A 股才在「主要财务指标」披露）。要做需从「其他收入及收益净额」附注逐项判非经常性，属分析动作，未在本层估算。
- `预付`：李宁把预付款项并入「其他应收款及预付款项」列报，无独立行。
