# 李宁（02331.HK）财报关注要点

> 本文件 = **持续监控规格**（盯什么 · 频率 · 警戒线 · 触线动作）+ 公司独有红旗。
> 生意模式与护城河的完整论述在 `分析.md`，此处不复述。
> **不嵌数字时间序列**——指标的历史序列一律落 `财务数据/<csv>`；本文只写规格与阈值。
> 行业块底座：`_模板/财报关注要点-行业模板.md`「运动服饰 / 品牌服饰零售」。

- **生意一句话**：在中国内地做单一自有品牌运动鞋服，经「特许经销商批发 + 直营零售 + 电商」三通道卖给消费者，赚品牌溢价与周转的钱。
- **生意类型**：**不确定生意**（判据与同业对照见 `分析.md` 二、④ 与 五、5.3）。

## 🅰 这门生意靠什么赚钱（只保留读财报/排雷相关的部分）

- **收入确认时点因通道而异**：批发腿发货即确认（sell-in），直营与电商按终端成交确认（sell-through）。**渠道结构一变，同样的终端动销会算出不同的报表营收** → 跨期比营收增速前，先看三通道占比有没有动（年报 MD&A「REVENUE BY SALES CHANNEL」给的是**百分比**，不是金额）。
- **成本端没有稀缺原料**：鞋服原材料与代工产能都是可买到的，**成本不构成壁垒**；毛利率的真实驱动是**折扣率与产品结构**，而折扣率年报不列、只在业绩会口头给 → 属 ⏳ 长期待补项。
- **品牌溢价是租来的、不是买断的**：无合约锁定，随代言/赛事/设计/国潮情绪逐年重新定价。这是本公司的核心单点依赖【判·依据：成本端与渠道均可复制，品牌不可】。
- **海外不在报表内**：自 2024-10 起，李宁品牌**中国内地以外**业务归属一家 BVI 合营公司，上市公司只占 29%（见 🅱 独有红旗）。故「海外扩张」对本公司报表的贡献路径是**权益法投资收益**，不是营收。

## 🅱 核心跟踪变量（4 个·按重要性排序）

### ① 零售流水（retail sell-through）vs 报表营收 —— 头号表外温度计 🔴
- **为什么第一**：批发腿「发货即确认」，终端卖不动会先沉淀为经销商渠道库存（表外），报表可以毫无异样。**流水与营收背离，往往早于报表暴露压货。**
- **数据源**：季度《运营更新》自愿公告（每季度末后 2-4 周刊发，港交所披露易）。**报表里没有这个指标，必须单独抓。**
- **频率**：季度。**落点** → `财务数据/零售流水与POS.csv`（⏳ 待建）
- **警戒线**：流水同比转负、而同期报表营收仍正增长 → 🔴；连续两季背离 → 升级。
- **触线动作**：立即核对当期「贸易应收款项同比 vs 营业额同比」（`财务数据/财务比率.csv`）与渠道库存月数；两者同向恶化 = 压货确立。

### ② 渠道库存周转月数 + 线下新品流水占比 🔴
- **数据源**：同上季度运营公告 / 业绩公告「OPERATIONAL HIGHLIGHTS」。
- **频率**：半年度（业绩公告）+ 季度（若披露）。
- **警戒线**：库存周转**升破 5 个月**；或新品流水占比**跌破 80%**（占比下滑 = 在清老货）。
- **触线动作**：查存货周转天数与存货减值计提是否同步（`财务数据/财务比率.csv`、`资产负债表.csv`）；**天数升而毛利率不降 = 减值滞后嫌疑**（事反必妖）。

### ③ 销售点（POS）净增减 —— 拆直营 / 批发两腿 🟡
- **数据源**：季度《运营更新》。**必须拆两腿**：一腿净减一腿净增可能只是渠道结构调整，合计净减才是渠道收缩。
- **频率**：季度。**落点** → `财务数据/零售流水与POS.csv`（⏳ 待建）
- **警戒线**：合计连续两季净减；或直营单腿年内净减超过 100 家。
- **触线动作**：与使用权资产、租赁负债变动交叉（`财务数据/资产负债表.csv`）——关店应带来两者同步下降，若不同步须追因。

### ④ 资本去向：PPE + 投资物业 + 使用权资产 合计占总资产 🟡
- **为什么盯**：品牌商本应轻资产。本公司近年把大量自有现金投向不动产（见独有红旗②），**这类资产不产生品牌溢价、且折旧与减值会长期压利润**。
- **数据源**：年报资产负债表。**频率**：半年度。**落点** → `财务数据/资产负债表.csv`（已有）
- **警戒线**：三项合计占总资产比重连续两年抬升，而同期营收增速低于名义 GDP。
- **触线动作**：核对「投资物业」是否出现减值（本公司已有减值先例，见独有红旗②），并把减值额从当期利润中单列还原。

## 公司独有红旗

### ① 🔴 海外业务被装进「创始人持股 26%」的体外合营 —— 关联交易 + 利益分配结构
- **事实**：2024-10-22 关连交易公告。BVI 合营公司总股本 HK$200m，**上市公司间接全资子公司 LN Co 占 29%**，**执行董事兼联席行政总裁李宁先生全资的 Founder Co 占 26%**（上市规则第 14A 章项下关连人士），红杉系两主体合计 45.0%。合营取得李宁品牌**中国内地以外独家**经营权，公告自陈「seek opportunities for listings in the future」（寻求未来上市机会）。适用百分比率 <5%，**豁免股东批准**。
- **盯什么**：① 合营后续增资 / 股权变动是否进一步稀释上市公司；② 上市公司与合营之间的**持续关连交易年度上限**是否逐年抬升（2026-01-05 已设定、2026-09-17 已修订上限）；③ 合营若独立上市，海外品牌价值归谁。
- **频率**：事件触发（任何含「持续关连交易」「年度上限」「合营」字样的公告必读全文）。

### ② 🟡 大额不动产支出与随后的投资物业减值
- **事实**：2023-12-10 以 **HK$2,208,000,000** 全资收购一家目标公司（主要资产为香港物业，卖方为恒基兆业旗下独立第三方），资金来源为内部资源，公告自陈拟将部分用作集团香港总部。其后资产负债表出现「投资物业」科目。
- **盯什么**：投资物业账面值的逐年变动与**减值计提**；总部自用部分是否转入 PPE；租金收入是否在「其他收入及收益净额」中单列。
- **频率**：年度。

### ③ 🟡 新增「特许权使用费应付款」跳升 = 签了长约、先计负债后见收入
- **事实**：2026 年中期财务状况表首次出现非流动特许权使用费应付款（2025 年末该科目非流动部分为零），同期无形资产与非流动「其他资产」同步大幅增加。
- **盯什么**：对应的是什么 IP / 赛事 / 商标长约、年限与刚性付款额；未来数年现金流出节奏。
- **频率**：半年度（中报与年报附注）。

### ④ 🟡 净利增速与税前增速方向可能相反（有效税率口径）
- **事实**：2026 上半年归母净利同比为正、而**除税前溢利同比为负**，差异来自有效税率大幅下降。
- **盯什么**：**每期都要算一次有效税率**（所得税开支 ÷ 除税前溢利），并在引用「净利增速」时声明是税前还是税后口径。有效税率异动须回附注找原因（税收优惠到期/递延税资产确认/境外税率）。
- **频率**：每期。**这是口径纪律，不是预警指标**——但漏掉会把税率红利读成经营改善。

### ⑤ 🟡 股权分散、创始人持股低
- **事实**：截至 2025 年末，李宁先生权益占已发行股份 **14.44%**（个人 + Viva Goods Company Limited 合计），公众持股 85.56%。无控股股东。
- **盯什么**：大股东增减持、董事会构成变动、是否出现要约收购/一致行动安排。
- **频率**：事件触发（权益披露、月报表）。

## 持续监控节奏

| 频率 | 动作 |
|---|---|
| **季度**（季后 2-4 周） | 抓《运营更新》：零售流水同比（分线上/线下/直营/批发）、POS 数净增减两腿、渠道库存月数 → 与上一季对比，触线则按上文动作 |
| **半年度**（3 月下旬年报业绩 / 8 月中下旬中期业绩） | 三表刷新 → 跑 `python3 财务数据/_build_from_pdf.py`（勾稽不过不写出）；**必算有效税率**；核对新品流水占比与渠道库存 |
| **年度**（4 月下旬年报全文） | 读附注：投资物业减值、特许权使用费应付款条款、关连交易与年度上限、股权结构变动；刷新 `分析.md` 与本文件 |
| **事件触发** | 任何含「关连交易 / 年度上限 / 合营 / 须予披露交易 / 回购 / 权益披露」字样的公告，读全文而非标题 |
