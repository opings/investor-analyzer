# 上海耀皮玻璃 财报关注要点

> 行业块：**周期/资源 + 制造/重资产**（自 `_模板/财报关注要点-行业模板.md` 两块起步，按公司定制）。
> 本文件只写监控规格（指标/频率/警戒线/触线动作），**不嵌数字**——时间序列一律在 `财务数据/<csv>`。

- **生意一句话**：上海国资控股、日本板硝子（NSG）参股的老牌玻璃制造商——自产浮法原片，向下打通建筑加工玻璃与汽车加工玻璃两条产线，卖给地产幕墙链与整车厂。
- **生意类型**：**强周期**（利润随浮法玻璃价格与地产/汽车景气大起大落，单年净利不可外推）+ **长期缺乏稳定盈利**（扣非多数年份为负）——两项叠加，按本体系口径归入「太难」。

## 🅰 生意模式 / 成本结构 / 护城河本质（读财报前先懂在哪赚钱）

- **收入 = 三板块之和 − 内部抵销**：浮法玻璃（上游原片，标准品，价格随行业供需）/ 建筑加工玻璃（挂钩地产竣工链）/ 汽车加工玻璃（整车厂配套，有年降）。板块间互供原片，**看合计务必减内部抵销**（`财务数据/分部营收.csv` 设有该行；部分年份年报未单列，本库按恒等式倒推并在 `财务数据/README.md` 留痕）。
- **成本大头**：纯碱、乙烯焦油等原燃料 + 能源 + 折旧。公司多次把毛利率变动直接归因于原燃料采购价格【源：FY2025 年报 P15】——**这意味着毛利率主要由外部投入价格决定，不是自身定价权的结果**【推】。
- **护城河本质**【判】：**未找到可验证的护城河**。品牌/网络效应/转换成本/成本优势四项在披露中均无硬证据；分部毛利率长期显著低于同业（对照 `finance/福耀玻璃/财务数据/分部营收.csv`）。跟踪口径：若某板块毛利率能连续 3 年跑赢行业并稳住，再重估此结论。
- **报表结构特性**：
  - **重资产 + 刚性再投入**：浮法窑炉有强制冷修周期（窑龄到期必须停产大修），冷修年该线无产出且发生大额支出——**capex 不是可选项**，自由现金流比净利更真（`财务数据/财务比率.csv` capex 比、`现金流量表.csv`）。
  - **少数股东漏损大**：合并净利中相当比例归少数股东，**看合并数会高估上市公司股东所得**（`财务数据/财务比率.csv` 少数股东 leak 行）。
  - **非经常性损益主导报表利润**：读利润表**先看扣非、再看归母**，顺序反了会得出相反结论（`财务数据/利润表.csv` 扣非行）。

### 公司独有红旗 / 易暴雷点

- 🔴 **非经常性损益依赖**：20 年归母累计为正而扣非累计为负（`财务数据/利润表.csv`）。**每期必做**：把归母减扣非，看这一期的利润有多少来自资产处置/政府补助/动迁补偿等一次性来源；一次性来源占比高时，该期利润不具外推价值。
- 🟡 **少数股东损益占比**：占净利润比重已达约三分之一量级（`财务数据/财务比率.csv`）。**警戒**：若合并净利增长而归母不增，先查是不是利润长在了少数股东那一侧的子公司。
- 🟡 **披露质量瑕疵（历史记录）**：
  - FY2022 年报披露 3 个多月后发布「更新版」及更正补充公告（`knowledge/companies/上海耀皮/2023.md`）；
  - FY2025 年报内部口径打架——「股份变动情况表」称报告期内股本未变，资产负债表却已按扩股后列示实收资本（`knowledge/companies/上海耀皮/2026.md`）；
  - FY2007 年报利润表净利润为印刷错误（与同页两条恒等式及次年比较列均不符，`财务数据/README.md` 已留痕）。
  → **动作**：新一期年报出来后，用本库勾稽脚本先跑一遍再读文字；对"公司自述"的经营归因保持打折。
- 🟡 **股东行为双向**：控股股东（上海建材集团）2024 年起多次增持并公告"提质增效重回报"；第二大国有股东中国复合材料集团持续减持（`knowledge/companies/上海耀皮/{2024,2025,2026}.md`）。**盯**：减持是否延续、是否触及控制权结构。
- 🟡 **B 股结构**：公司存在 B 股（900918 耀皮B），流动性与定价机制与 A 股不同——涉及股本/每股指标时须确认口径覆盖 A+B 全部股份。
- 🟢 **不存在存贷双高**：货币资金长期低于有息负债（`财务数据/财务比率.csv` 净现金行），与康得新/康美式特征相反——此项**不必**按该清单深查，但净现金若转为大额正值且同时新增大额借款，需重新启动该项。
- ⏳ **待补**：市占率/行业集中度无可引用一手口径（本次建库未在年报找到）；关联方资金占用专项报告正文未逐份核；折旧政策逐年沿革基线未建（重资产公司折旧年限放宽=盈利质量信号）。

### 历史踩过的坑 / 管理层诚信记录

- **三度年度亏损**：2009、2015、2023 归母净利为负，2015 幅度最大（`财务数据/利润表.csv`）——**行业下行期未能守住盈利，是已被历史验证的脆弱性**。
- **扣非亏损是常态而非例外**：20 年中 11 年扣非为负（`财务数据/利润表.csv`）。
- 2023-01 公告核销部分应收账款和其他应收款坏账；2023-05 完成收购艾杰旭特种玻璃（大连）100% 股权；2024-02 变更会计师事务所（原众华）；2025-06 修订章程取消监事会（`knowledge/companies/上海耀皮/`）。
- 2025-04 公司专项公告"最近五年不存在被证券监管部门和证券交易所处罚或采取监管措施"（`knowledge/companies/上海耀皮/2025.md`）——**监管处罚记录清白，但披露质量瑕疵与之并不矛盾**。
- FY2013 因**同一控制下企业合并**被 FY2014 年报追溯重述（营收/资产/负债/现金流口径均变），本库 CSV 保留 as-reported 并在 `财务数据/README.md` 留痕——**做 2013 前后同比时须注意断点**。

## 持续监控节奏

- **月度**：玻璃期现价格与纯碱价格（行业景气温度计，外部数据源）；重大公告（如需日度监控须先登记 `knowledge/companies/_watchlist.md`）。
- **季报**：扣非归母绝对额与同比、经营现金流、应收周转天数。
- **中报/年报**：核心跟踪变量 5 项全查 + 分板块毛利率 + 浮法产销存 + capex 与在建转固 + 少数股东损益占比 + 非经常性损益明细表 + 分红方案 vs 融资动作。
- **事件触发**：浮法产线冷修/点火公告、募投项目进度与资金置换、股东增减持与权益变动、审计机构或关键财务人员变更、年报更正/补充公告（本公司有前科）。
