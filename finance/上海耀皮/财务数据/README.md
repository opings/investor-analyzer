## 勾稽自洽校验（`_build_from_pdf.py`，①③ 全过才写出 CSV）

**① 表内勾稽 + 完整性 + 跨年连续性**（每年 14 条恒等式）
- **损益**：营业利润 + 营业外收入 − 营业外支出 = 利润总额 · 利润总额 − 所得税 = 净利润 · 归母 + 少数股东损益 = 净利润 · 营业总收入 = 营业收入
- **资产负债**：流动 + 非流动 = 资产总计 · 流动负债 + 非流动负债 = 负债合计 · 归母权益 + 少数股东权益 = 所有者权益合计 · 负债 + 权益 = 负债和所有者权益总计 · 资产总计 = 负债和所有者权益总计
- **现金流**：三节「流入 − 流出 = 净额」· 三净额 + 汇率 = 净增加额 · 期初 + 净增 = 期末
- **跨年连续性**：期末现金[y] = 期初现金[y+1]（19 对，除 2013→2014 重述断点外全过）
- **完整性闸**：29 个核心行必须**每年**取到值——勾稽恒等式遇 None 会跳过而非报错，单个明细科目整列丢失能瞒过勾稽，故单设此闸（实战中它逮出了「固定资产」2012-2015、「所有者权益合计」2008、「购建长期资产支付的现金」2008 三处整列缺失）

**② 跨源互证**：年报 Y「上年列」 vs 本库 Y 年值，7 个关键行 × 18 年 → 现存 7 处差异，**全部集中在 FY2013**（见下「重要口径注记」）

**③ 锚点核验**：年报自家「主要会计数据」披露值 vs 本库三表取值，每年 5 项（营收/归母/CFO/归母净资产/总资产）→ **除 FY2007 两处年报内部不一致外全过**

**分部另验**（`_build_segments.py`）：分产品合计（减内部抵销）= 分地区合计，且主营业务收入与利润表营业收入偏离在 −2%~+20% 区间内。

## 重要口径注记

1. **【FY2007 净利润印刷错误·已 OVERRIDE】** 年报利润表印 122,187,403.66 元，但同页两条恒等式均指向 112,187,403.66 元（利润总额 − 所得税 = 112,187,403.66；归母 + 少数股东损益 = 112,187,403.66），FY2008 年报比较列亦作 112,187,403.66。判定为该年年报笔误，本库取自洽值，OVERRIDE 记录在 `_build_from_pdf.py` 顶部。
2. **【FY2007 摘要页 vs 审计报表内部打架·已留痕】** 年报「前三年主要会计数据」页列总资产 5,220,766,837.41 元、所有者权益(归母) 2,080,434,570.60 元，**均较审计后资产负债表高 38,760.20 元**。同一份年报内两处不一致，本库**以审计报表为准**。
3. **【FY2013 追溯重述·本库保留 as-reported】** FY2014 年报因**同一控制下企业合并**追溯重述 2013 比较数（FY2014 所有者权益变动表：上年期末余额 3,604,097,740.37 + 同一控制下企业合并 319,634,525.26），营收/归母/净利/资产/负债/CFO 口径均变；另含准则修订带来的递延收益单独列报、其他综合收益自资本公积拆出（**仅影响列报，不影响总资产/负债/净资产/净利润**）。本库 2013 列取 FY2013 自身年报 as-reported 值，重述后数字见 `_build_from_pdf.py` 校验输出。**做 2013 前后同比须注意断点**；2013→2014 现金连续性差额 100,899,949.87 元即被合并方期初现金并入所致。
4. **【2025 年末股本口径打架】** FY2025 年报「股份变动情况表」称报告期内股本未变（定增新股 2026-01-12 才完成登记托管），但同一份年报资产负债表 2025-12-31 实收资本已按 976,757,073.00 元列示（募集资金 2025-12-30 到账、当日验资）。本库 `资产负债表.csv` 采用**审计报表口径**；前十大股东持股比例%则为年报按登记口径（934,916,069 股）计算。定增明细：发行价 7.17 元/股、41,841,004 股、募资总额 299,999,998.68 元、净额 295,166,945.90 元【FY2025 年报 P62】。
5. **【分部内部抵销·部分年份为倒推值】** 板块间互供原片需抵销。抵销行各年叫法不一（内部抵销/合并抵消/减：内部抵销），且 2006-2017 多数年份年报未单列。本库对未单列年份按恒等式「分产品毛合计 − 抵销 = 分地区合计」倒推，**成本端无从倒推故留空**。倒推年份：2007、2008、2023。2006 年经核实**确无抵销**（分产品合计 = 分地区合计 = 主营业务收入，三者精确相等）。
6. **【分地区口径分三段】** 2006-2013 与 2023-2025 按「国内/国外」列示（2006-2009 出口行称「国际」）；**2014-2022 改按大区列示**（华北/华东/华南/华中/西南/西北/东北 + 国外）。本库对大区口径年份把各大区加总为「国内」行以保跨年可比，各大区原值同时保留。**FY2009 年报未见可解析的分地区表**（留空）。
7. **【分部单位分两段】** 2006-2009 该表用**元**、2010 起用**万元**，且表头跨页时可能丢失。本库按量级与利润表营收对表自动校正，全部归一为**万元**（校正年份：2006、2007、2015）。
8. **【分红率口径警告】** `财务比率.csv` 通用底的「当年分红率」分子取现金流量表「分配股利、利润或偿付利息支付的现金」，**该行含付息、且含子公司付给少数股东的股利**，对本公司（长期有息负债 8–25 亿元量级、少数股东占两成以上）**高估显著，不可直接当分红读**。本库另加「母公司现金分红(剔付息与少数股东·估算)」行，但**仅 2018 年起有值**（此前财务费用不拆分利息费用，缺项年份留空而非按 0 计，以免早年凭空多出上亿"分红"）。**精确派现以分红预案/权益分派实施公告为准**。
9. **【审计机构沿革】** 众华会计师事务所（特殊普通合伙）长期任审计机构；2024-02-01 公告**变更会计师事务所**；2025 年起为上会会计师事务所（特殊普通合伙）（定增验资、非经常性损益鉴证、年度审计均由上会出具）。
10. **【A+B 股】** 公司同时有 A 股(600819)与 B 股(900918 耀皮B)，每股指标口径覆盖 A+B 全部股份。
