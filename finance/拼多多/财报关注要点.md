# 拼多多 财报关注要点

> 监控规格(指标/频率/警戒线/触线动作)+ 排雷红旗。**数字一律落 `财务数据/<csv>`,本文件不嵌数字**。生意模式完整论述见 `分析.md`;通用红旗见 `财报阅读规则.md` Step 3 + `knowledge/fraud-cases/造假模式库.md`。

- **生意一句话**:向商家收费的电商平台——拼多多主站收在线营销费(广告)+ 交易服务费(佣金),Temu 收跨境交易服务费;消费者端免费、极致低价心智获客。
- **生意类型**:**不确定生意**(公司客观属性:主站现金牛特征明显,但整体盈利受管理层战略让利与境外关税/监管双重驱动、单年利润不可线性外推;分部不拆、Temu 盈亏不可见)——依据见 `分析.md` 速览。

## 🅰 生意模式 / 护城河本质(读财报视角)

- **收入两根柱**:在线营销服务(商家竞价广告·预充值·类现金池)+ 交易服务(佣金,Temu 全托管/半托管佣金计入此线,**按净额法确认**——营收远小于 GMV,毛利率口径与自营电商不可比)。数据落点 → `财务数据/分部营收.csv`。
- **浮存金模式**:商家应付款 + 商家保证金 + 客户预收 = 大额无息占款(先收消费者钱、后结商家款),是经营现金流长期 ≥ 净利的结构性原因 → `财务数据/财务比率.csv`「无息浮存」行。
- **极端轻资产**:履约(物流)外包,自持 PPE 占总资产 <1%,资本开支占净利个位数% → `财务比率.csv` capex 比。真实资产 = 巨额现金+债券投资组合(利息及投资收益已成利润表第二引擎,注意其与"主业利润"的区分)。
- **护城河判定要点**:低价心智 × 白牌/产地供应链 × 规模网络效应(买家聚单→商家低价→更多买家);**无自建物流/云等重资产壁垒**,护城河主要是运营效率与用户心智——验证方式是横比同业货币化率与费用率趋势,不能只听公司自述。

## 历史踩过的坑 / 管理层诚信记录

- **无财务造假处罚记录**【源:SEC 申报流 2018-2026 无 restatement/无非标意见;ICFR 历年有效】;做空指控(2018 年 Blue Orca 等)未获监管坐实【疑:未逐份核验做空报告,留档】。
- 2023-03 Google 以恶意软件为由下架主站 App(公司否认;Temu 不受影响)——软件行为合规是历史污点级事件【源:编年 2023】。
- 管理层沟通风格:不给指引、电话会一贯淡化利润(连续多年"预警利润下行")——**保守沟通但兑现**(2025 利润确实下滑),口径可信度较高【判:依据 2024-08 预警→2025 兑现的时序】。
- 会计口径:Non-GAAP 定义三年三变(剔除项从 SBC+FV+CB 利息 → 仅 SBC)——本库不采 Non-GAAP,以 GAAP 经营利润为锚【源:各季新闻稿脚注】。
