# 云铝股份 财务数据（从一手财报 PDF 解析）

> 本目录 = 云铝股份的**一手财务数据库**：从一手财报 PDF 解析的所有客观数字统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/云铝股份/事实编年`。

> **数据血缘**：所有 CSV 数字 = 从 `report/云铝股份/`（**上市至今全部年报**）**逐行解析** + 勾稽自洽校验。
> **单位**：元（人民币），与年报财务报表原始口径一致。负数 = 流出/减项。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**每年**验证：
- **损益**：营业收入 − 营业成本 − 期间费用 ± 其他 = 利润总额；利润总额 − 所得税 = 净利润
- **资产负债**：总资产 = 总负债 + 所有者权益
- **现金流**：经营 + 投资 + 融资 + 汇率影响 = 现金净变动；期初 + 净变动 = 期末

> 校验不通过则**不写出 CSV**（先回查 PDF）。
