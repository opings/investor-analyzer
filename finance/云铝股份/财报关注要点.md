# 云铝股份 财报关注要点

- **生意一句话**：云南水电炼铝全产业链（铝土矿→氧化铝→电解铝→铝加工），靠低电价成本优势在周期波动中赚价差
- **生意类型**：强周期（铝价驱动利润，单年净利不可外推）

## 🅰 生意模式 + 成本结构 + 竞争壁垒（闸门一·搞懂靠什么赚钱）

**靠什么赚钱**：卖的是大宗铝及铝加工产品，赚的是「铝价 − 电力成本 − 氧化铝成本」的价差。
- **电解铝**（营收~57%，毛利率~18%）：核心利润来源。铝价由 LME/SHFE 决定，公司是价格接受者。
- **铝加工**（营收~42%，毛利率~15%）：铸造铝合金锭、铝棒、铝焊材等，下游覆盖新能源车/光伏/3C/航空，加工费相对稳定。
- **产业链一体化**：铝土矿→氧化铝(140万吨/年)→电解铝(308万吨/年)→铝加工(161万吨/年)→炭素(80万吨/年)，上游自给降低原材料波动。

**成本结构（电解铝）**：
- **电力 = 头号成本变量**（通常占电解铝生产成本 30-40%）。云铝生产用电清洁能源占比约 87.5%（水电为主），碳排约为煤电铝的 20%。水电丰枯季影响产量（云南枯水期可能限电）。
- **氧化铝** = 第二大成本（约占 30-35%），公司自产 130 万吨但不够自用（电解铝 308 万吨产能需氧化铝约 600 万吨），外购依赖度高。氧化铝价格波动直接冲击成本。
- **阳极炭素** = 第三大成本，自产 80 万吨有部分自给。
- **人工** = 2025 年支付职工薪酬约 25.2 亿（占营收 ~4.2%），相对固定。

**竞争壁垒（周期股看的是"成本曲线位置"）**：
- **水电成本优势**：云南水电价格低于全国平均火电价格，使云铝位于中国电解铝成本曲线左侧。这是**区位性资源禀赋，非管理能力，也非永久**（水电价格市场化改革、跨省输电政策都可能改变比较优势）。
- **规模**：电解铝产能 308 万吨/年，占中国原铝产量约 7%，属头部梯队。
- **产业链一体化**：从矿到加工全覆盖，减少中间成本和供应风险。
- **中铝集团**（2018 年末加入）：央企平台带来资源获取、融资成本、集采议价优势。
- **"绿色铝"品牌**：碳足迹认证、碳排放配额等在"双碳"政策下有差异化溢价可能。

> **壁垒局限**：铝是标准化大宗商品，无品牌溢价/转换成本/网络效应；壁垒本质是成本优势（水电+规模+一体化），一旦电价比较优势缩小，壁垒随之削弱。

### 本公司独有红旗 / 易暴雷点

- 🟡 **云南枯水期限电风险**：历史上（2022-2023）云南因干旱限电导致电解铝减产。限电 = 产量下降 + 固定成本摊薄恶化。
- 🟡 **氧化铝外购依赖**：自产氧化铝仅覆盖电解铝需求的约 23%（130/~600），氧化铝价格暴涨时利润被侵蚀。
- 🟡 **中铝集团关联交易**：作为央企子公司，与中铝集团存在大量日常关联交易（原材料采购、产品销售、财务公司存贷款）。关注关联交易定价公允性、财务公司存款风险。
- 🟡 **固定资产减值**：固定资产 203 亿占总资产 46%，审计关键事项即"长期资产减值评估"。铝价长期低迷可能触发大额减值。
- 🟢 **商誉**：无商誉。
- 🟢 **有息负债**：极低（长期借款 18.1 亿，资产负债率仅 20%），财务风险很小。
