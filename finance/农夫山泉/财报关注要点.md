# 农夫山泉（9633.HK）财报关注要点

> 公司特有看点（风险预警第二层）。通用红旗见 `knowledge/造假案例库/造假模式库.md`；估值法/双闸门见 `valuation-method`。
> 行业：软饮料 / 包装水 + 即饮茶（非白酒，不套白酒批价倒挂雷达；但「渠道压货 sell-in」逻辑通用）。

---

## 一、生意模式（靠什么赚钱）

- **卖水 + 卖茶的快消平台**：包装饮用水（农夫山泉天然水）+ 即饮茶（东方树叶/茶π）双引擎，辅以功能饮料（尖叫/力量帝维他命水）、果汁（农夫果园/NFC）。
- **赚钱方式**：极低单价、极高频次、海量铺货 → 规模 + 周转。终端动销驱动，经销商**先款后货**（现金流好、几乎无应收坏账）。
- **成本结构**：水的原料成本极低（取水权 + PET 瓶 + 物流），毛利 60%+；核心开支是**销售费用**（冰柜/陈列/广告/经销商返利），故销售费用率是经营杠杆的关键变量。
- **从「水公司」到「饮料平台」**：2025 茶饮料（216 亿）首超包装水（187 亿）成第一大品类，平台化兑现。

## 二、护城河本质（为什么别人抢不走）

1. **水源地稀缺**：十大优质天然水源地（千岛湖/长白山/武陵山等），具排他取水权，是**不可复制的资源壁垒**——这是农夫区别于纯渠道品牌（如康师傅/统一）的根。
2. **品牌心智**：「农夫山泉有点甜」「大自然的搬运工」「我们不生产水，只是搬运工」——天然水定位 vs 纯净水，长期心智占领。
3. **渠道密度**：百万级终端网点 + 自建冰柜体系，铺货深度行业顶级，新品（东方树叶）能快速借渠道起量。
- **护城河排序**：水源地（最硬·资源型）> 品牌心智 > 渠道密度（最易被钱追赶，但有规模门槛）。

## 三、核心跟踪变量（每期财报盯这些）

| 变量 | 看什么 | 为什么 |
|------|--------|--------|
| 包装水收入增速 | 是否维持恢复（2024 -21%、2025 +17.3%） | 舆情冲击后基本盘修复的体温计 |
| 茶饮料增速 + 占比 | 东方树叶能否延续高增（2025 占 41%） | 第二曲线，决定平台天花板；增速放缓=成长逻辑松动 |
| 毛利率 | 是否守住 60%+（2025 60.5%） | PET/物流成本 + 产品结构 |
| 销售费用率 | 趋势（2025 降至 18.6%） | 经营杠杆核心；冰柜/促销战打响会反弹 |
| 经营现金流/净利 | 是否 ≥1 | 先款后货的快消应≥1，<1 要查存货/渠道压货 |
| ROE | 维持高位（2025 44%） | 轻资产+高周转的体现 |
| capex/净利 | 扩张性投入节奏 | 验证三前提③「维持利润不需大量资本投入」⏳待补 |

## 四、独有红旗（命中即降级排查）

- 🔴 **To C 舆情风险**：2024 年初一次舆情风波即令包装水当年 -21%。农夫是高曝光 To C 品牌，**单一舆情可重创单一品类动销**——这是它最大的非财务尾部风险，报表无法提前预警，需盯舆情面。
- 🟡 **渠道压货（sell-in ≠ sell-through）**：快消通用雷达。若收入增长但经营现金流/存货背离、经销商库存抬升，可能是向渠道压货而非终端真实动销。盯「收现 ÷ 确认营收」与存货周转。
- 🟡 **茶饮赛道竞争**：无糖茶（东方树叶）赛道涌入东鹏、三得利、康师傅等，2025 高增后需防增速回落 + 价格战侵蚀毛利。
- 🟡 **扩张性 capex**：新建水厂/产线属成长投入，节奏过快会压低自由现金流；需区分维持性 vs 扩张性 capex。
- 🟢 **应收/商誉**：先款后货 → 应收极低；无重大并购 → 无商誉减值风险。常态绿灯，但每期仍扫一眼。

## 五、持续监控规格（频率 + 触发动作）

> 第三节是「盯什么/为什么」，本节是「多久盯一次 + 触线怎么动」。**关键前提：农夫是港股，只出中报(~8月)+年报(~3月)、无季报**——基本面一年只更新 2 次，高频层只能盯价/舆情/公告。

### A. 高频层（daily-news 自动盯·每交易日）
| 指标 | 数据源 | 触发动作 |
|------|--------|---------|
| 现价 vs 买点 26.4 / 卖点 76.2·83.8·91.4 | 行情 | 跌到 26.4 → 进试仓区(≤5%)；触卖点阶梯 → 按 50/55/60PE 减 |
| 舆情/突发负面 | 新闻 | 命门（2024 一次舆情=水 -21%）；爆发 → 进编年，盯下期水分部 |
| 公告（回购/增减持/食安/管理层） | cninfo/港交所 | 重大事项 → 进编年 + 评估是否动逻辑 |

> 农夫**无白酒批价阶梯**（非渠道流通定价品），高频层就这三样。

### B. 半年层（中报/年报出时·走 caibao 重刷）—— 基本面唯一更新窗口
按重要性排序，触线即动作：
| 指标 | 警戒线 → 动作 |
|------|--------------|
| ① 茶饮分部增速（命门） | 掉到**个位数** → g 从 8% 再下调 / 质疑成长性 / 可能降评级 |
| ② 包装水分部增速 | 能否站稳并超 2023 峰值 202 亿（2025 才 187）；再走弱 → 基本盘存疑 |
| ③ 净利增速 vs 营收增速 | 背离=经营杠杆（2025 +30.9% vs +22.5%）；应向营收**收敛**，靠费用率硬撑则质量打折 |
| ④ 销售费用率 | **反弹**（2025 18.6%）→ 价格战信号、净利承压 |
| ⑤ 毛利率 | 跌破 60% → 成本/结构恶化 |
| ⑥ 经营现金流/净利 | <1 → 查存货/**渠道压货 sell-in** |
| ⑦ capex/净利 | ⏳ 当前空白（港股无 akshare CSV）；手录年报现金流量表验三前提③ |

> 每次中报/年报出，用 ①~⑦ 重算 2026E 净利与 g → 刷新买点（caibao skill）。

### C. 事件驱动（不定期）
- **无糖茶竞品动作**（三得利/东鹏/康师傅/统一新品、价格战）→ 影响 ① 判断；
- **水源地/取水权/食安事件** → 直接砸基本盘 + 舆情；
- **个人无风险利率变动** → PE 27.5 全库同步改（全库口径，不止农夫；见 valuation-method）。
