## 勾稽自洽校验：9 年全平 ✅

由 `_build_from_pdf.py` 内置 `verify()` 生成，**每年**验证：

- **损益（4 项）**：收益 + 销售成本 = 毛利；除税前 + 所得税 = 年内溢利；**母公司应占 + 非控股应占 = 年内溢利**；年内溢利 + OCI = 全面收益总额
- **资产负债（5 项）**：流动资产 − 流动负债 = 流动净额；非流动资产 + 流动净额 − 非流动负债 = 资产净额；总资产 = 总负债 + 权益；**股本 + 储备 = 母公司应占权益**；**母公司应占 + 非控股 = 权益总额**
- **现金流（3 项）**：经营所得现金 + 已付税 + 已收/付息 = 经营净额；经营 + 投资 + 融资 = 净变动；年初 + 净变动 + 汇率 = 年末
- **跨年连续性（8 项）**：年初/年末现金衔接，**含跨招股书→年报边界**：2019 年末现金 783,142 = 2020 年初现金 783,142（无缝衔接，实证招股书解析与年报同源）
- **分部交叉验证**：分部合计 = 损益表营收（百万取整）；5 品类相加 = 分部合计（±1 百万容差）
- **PPE 交叉验证**：7 项子科目相加 = PPE 合计 = 资产负债表「物业、厂房及设备」

> 校验不通过则**不写出 CSV**（先回查 PDF）。改数 / 补年份 → 改脚本 `_build_from_pdf.py` 重跑。
> **旁证**：computed 净利率 2017/2018/2019 = 19.4% / 17.6% / 20.6%，与招股书概要明文所述完全一致。

## 为什么从一手财报解析、不用东财二手

东财二手 CSV 会错且与一手打架——农夫实证（2025）：
- 二手「经营业务现金净额」标 **256.39 亿** → 实为年报「经营所得现金 Cash generated from operations」（**税前**）
- 真正的「经营活动所得现金流量净额」= 256.39 − 已付税 44.67 − 已付息 0.61 + 已收息 0.30 = **211.42 亿**（2025 年报 P120 一手数）

从一手财报解析则与一手同源，根除此类科目错位。**招股书**更是上市前 2017-2019 三年的唯一真源（二手/年报都没有）。
