## 勾稽自洽校验：6 年全平 ✅

由 `_build_from_pdf.py` 内置 `verify()` 函数生成，每年验证：

- **损益（3 项）**：收益 + 销售成本 = 毛利；除税前 + 所得税 = 年内溢利；年内溢利 + OCI = 全面收益总额
- **资产负债（4 项）**：流动资产 − 流动负债 = 流动净额；非流动资产 + 流动净额 − 非流动负债 = 资产净额；总资产 = 总负债 + 权益；股本 + 储备 = 权益
- **现金流（2 项）**：经营 + 投资 + 融资 = 现金净变动；年初 + 净变动 + 汇兑 = 年末
- **跨年（5 项）**：年初/年末现金连续性
- **分部交叉验证（12 项）**：分部合计 = 损益表营收（百万取整）；5 品类相加 = 分部合计（±1 百万舍入容差）

> 校验不通过则**不写出 CSV**（先回查 PDF）。改数 / 补年份 → 改脚本 `_build_from_pdf.py` 重跑。
> 这正是东财二手 CSV 做不到的——其「经营业务现金净额」**256 亿**实为**税前** Cash generated from operations，真净额 **211 亿**（2025 年报 P120），二手自身勾稽不平。

## 为什么从年报解析、不用东财二手

东财二手 CSV 会错且与一手打架——农夫实证（2025）：
- 二手「经营业务现金净额」标 **256.39 亿** → 实为年报「经营所得现金 Cash generated from operations」（**税前**）
- 真正的「经营活动所得现金流量净额」= 256.39 − 已付税 44.67 − 已付息 0.61 + 已收息 0.30 = **211.42 亿**（2025 年报 P120 一手数）

从年报解析则与一手同源，根除此类科目错位。
