## 🅰 读茅台财报必须先知道的四件事（生意模式中与排雷相关的部分）

1. **合并报表里有一家财务公司**（2013 年起并表）：吸收存款、发放贷款、存放央行与同业、拆出资金等六行计入经营活动现金流，单年摆动可达百亿级 ⇒ 判断「利润为真」用「现金含量(剔除财司科目)」，不用报表口径（`财务数据/财务比率.csv` 与 `中期财务.csv` 同名行）。
2. **营业总收入 ≠ 营业收入**：营业总收入含财务公司利息收入 ⇒ 增速、收现比、毛利率一律用营业收入（`财务数据/利润表.csv`）。
3. **存货以基酒为主，不等于积压**：基酒须陈放数年，存货周转天数 2008 年以来都在千日以上（`财务数据/财务比率.csv`）；已包装的「成品酒」库存另行盯（`财务数据/基酒产能.csv`）。
4. **2026 年起合同负债口径断裂**：公司自述销售模式改变、预收货款政策调整【公司自述·2026 中报】，叠加直销即时结算 ⇒ 合同负债不能再单独当「蓄水池」读，须与变量 1、2 联读。

### 茅台独有红旗 / 关注

- **财务公司放贷去向**：「发放贷款和垫款」若流向集团成员单位 = 关联占款风险（看年报关联方存贷款附注）；吸收集团存款骤变会大幅扭曲经营现金流（`中期财务.csv` 财司六行）。
- **集团营销公司配额**：集团全资子公司按与非关联经销商相同价格拿货【公司自述】，渠道价差归集团；占营收比例上升或定价表述改变 → 触发 `分析.md` 5.2 复核（`关联交易.csv`）。
- **商标使用费**：2024 年起跳升，费率 / 计费基数依据待核（`关联交易.csv` 表头 ⏳）。
- **成品酒库存**：2025 年大幅上升（`基酒产能.csv`），看 2026 年报是否回落。
- **应收账款**：2026 年三季度从近零跳升、三季报未解释（`中期财务.csv`），2026 年报看账龄与对象。
- **不走公告的经营动作**：自营店调价、i茅台投放规则、新品发布多不产生交易所公告（编年 2026-09、2026-10 已有实例）⇒ 依赖哨兵抓官微 / 权威财媒，证据等级低于公告。
- **治理**：总经理由董事代行、两年内董事长两度更替、2027–2029 市值管理方案待披露（编年 2024–2026）。
- **政策外部性**：消费税改革方向、公务与商务消费相关政策——不在报表里，事件触发时读董事会报告与业绩说明会。

### 历史踩过的坑（本库数据层·管理层诚信记录另见下）

- **分部营收**：曾用后一年同比反推、渠道两行整体左移一列（2026-09 订正）⇒ 分部只取当年年报当年数，三路勾稽必须全跑。
- **年度现金流量表 39 格抄录错误**（2026-10-30 订正）：财务公司三行未按「流出记负」翻号、小计抄进明细、数字串位；宽容差放过了分位级抄错 ⇒ 接新年报先跑生成器（明细和 / 净额勾稽 + 容差 0.005 元）。
- **prose 量级检查对茅台的「元」表静默失效**：`scripts/prose_audit.py` 以 `财务数据/README.md` 单位行判单位，该行同时写了「元」与「百万元」，工具取「百万」⇒ 三表量级漂移查不到（分部营收表不受影响）。待工具修复前，茅台 prose 数字须另用按表换算单位的脚本核。

### 管理层诚信记录（只记可核事实）

- 2022–2024 年报给出的下一年营收增速目标均达成；2025 年目标（增长 9% 左右）落空，2025 年报未再给 2026 年数字目标（`经营目标.csv`）。
- 2026 年中报对合同负债大降给出原因（销售模式改变）；三季报对合同负债与应收账款变动均未解释（编年 2026-10-31）。
- 业绩说明会上的渠道库存说法（存销比低于 1.0 等）为口头表态，口径与测算过程未公开（编年 2026-08-21）。

## 持续监控节奏

| 频率 | 看什么 |
|---|---|
| 日 / 周 | 批价（daily-news 哨兵写编年 → 月末入 `批价跟踪.csv`） |
| 季度（4 月底 / 10 月底季报 + 主要经营数据公告） | 渠道 / 产品 / 地区收入、经销商增减、合同负债、应收、剔财司现金含量、税金及附加 |
| 半年（8 月中报） | 存货明细（基酒 / 成品）、基酒产量、关联交易半年额、中期分红安排 |
| 年度（3–4 月年报） | 销量与吨价、成品酒库存、经营计划是否恢复数字目标、关联交易全年额、分红方案、在建产能进度 |
| 事件触发 | 出厂价 / 自营价调整、i茅台规则变化、管理层变动、市值管理方案、消费税等政策 |
