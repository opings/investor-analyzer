## 关键会计政策与准则变更

- **2003** 首次会计政策变更：折旧年限缩短（房屋 25-35→20 年 · 通用设备 15→10 年 · 运输设备 8→5 年），未追溯
- **2007** CAS 2006 首年：长期股权投资权益法→成本法 · 所得税应付法→资产负债表债务法 · 2006 数据经新准则重述（归母 +2.7%）
- **2013** 茅台集团财务公司并表：三表出现「利息收入 / 吸收存款 / 发放贷款 / 存放中央银行和同业 / 拆出资金」等银行科目——**它们进经营活动现金流，单年摆动可达 ±100-200 亿**（见 `财务比率.csv`「现金含量(剔除财司科目)」行）
- **2017** 首次单列研发费用 · **2018** 首次出现其他收益 · **2019** 新金融工具准则（公允价值变动收益 / 信用减值损失 / 拆出资金）· **2020** 新收入准则「预收款项」→「合同负债」（本 CSV 2016-2019 统一入「合同负债/预收款项」行）
- **2023** 解释 16 号追溯调整 2022/2021 递延所得税 · **2025** 首次出现库存股（回购注销 3,927,585 股）
- **2026** 执行解释 19 号 / 20 号（不追溯·公司公告临 2026-030）

## 勾稽自洽校验：28 年零残差 ✅（容差 0.005 元）

由 `_build_from_pdf.py` 内置 `verify()` 生成。**2026-10-30 起容差由 1000 / 10000 元收紧到 0.005 元**（半分钱，只留浮点余量）——宽容差曾放过一批 1 分到 30 元的抄错（见下方订正记录）。

**每年验证**：
- 损益：归母 + 少数 = 净利润 · 利润总额 − 所得税 = 净利润 · 利润总额 = 营业利润 + 营业外收支（旧准则另加投资收益/补贴收入）
- 资产负债：流动 + 非流动 = 资产总计 · 流动负债 + 非流动负债 = 负债合计 · 负债 + 权益 = 资产 · 归母 + 少数 = 权益
- 现金流：经营 + 投资 + 筹资 + 汇率 = 净增加 · 期初 + 净增加 = 期末 · **🆕 三段各自「明细和 = 小计」「流入小计 + 流出小计 = 净额」**
- 跨年：上年末现金 = 本年初（2007 起；更早为旧准则 / 准则切换点）
- 分部「三路」：分产品和 = 分渠道和 = 主营合计，合计 ≈ 营业收入（差额 = 其他业务收入，<1%）

**变异对照（2026-10-30）**：对 16 个格子注入错误（含 7 个 ±1 分钱、2 个本次修过的错型「财司行翻号」「小计抄进明细」），16/16 报错。
⚠️ **已知盲区**：小计被抄进**唯一非空**明细行时和式恰好配平（2013 投资段原错即如此，是回读年报时顺带发现的）；同年两行互换（和不变）也查不出。

## 为什么从年报解析、不用东财二手

农夫实证：东财二手「经营业务现金净额」2025 标 256 亿实为**税前**「经营所得现金」，真净额 211 亿（2025 年报 P120）——二手自身勾稽不平。茅台合并利润表有独特结构（营业总收入含财司利息收入、营业总成本含税金及附加/利息支出），二手往往把不同层级科目串错。从年报解析则与一手同源，根除此类错位。
