# 古井贡B（200596）投资分析

> 分析日期：2026-06-19（基准年口径修正 + 2025 年报 + 2026 Q1）
> 分析框架：唐朝价值投资体系（利润为真、维持利润不需大量资本投入、利润可持续）
> 估值法：老唐估值法（成长股）+ 净利润折扣 0.9 + B 股流动性折扣 0.8
> 口径：归母净利润（古井扣非≈归母，差 <2%）；古井贡 B 为深市 B 股，以港币计价
> 数据源：`古井贡B.xlsx` + 年报（2016-2025）+ 2026 Q1，目录 `report/古井贡酒/`

> ⚠️⚠️ **重大变化：2025 业绩断崖式下滑。** 归母净利 **35.49 亿（−35.67%）**、扣非 34.89 亿（−36.06%）、营收 188.32 亿（−20.13%）。**前高后低极端**：Q1 归母 23.30（占全年 66%）→ Q3 骤降至 2.99 → **Q4 亏损 −4.11**。2026 Q1 延续下滑（扣非 −30.86%）。白酒深度调整 + 安徽竞争白热化，古井是组合里跌得最重的之一。

## 二、选股三原则验证（2025 实数）

### 1. 利润为真 ⚠️（现金含量首次明显 <1）

- **经营现金流 19.47 亿 / 归母 35.49 = 0.55**，现金含量大幅低于 1（2024 为 0.86）。下行期回款放缓 + 主动控货，需持续盯。
- 合同负债 2026 Q1 逆势 +51.64%（蓄水），说明经销商仍打款、需求未崩，但发货确认放缓。
- 应收账款占比低，无赊销虚增。

**结论：利润真实性无虞，但现金含量 0.55 是调整期信号，重点跟踪。**

### 2. 维持利润不需要大量资本开支 ✅

- 白酒轻资产，维持产能资本开支占净利比例低（智能园等扩产为战略性，非维持性）。

**结论：轻资产模式不变。**

### 3. 利润可持续 ⚠️（区域龙头，但增长神话破裂）

- **徽酒龙头**：年份原浆（古 5/8/16/20、古 26）卡位次高端，省内品牌力强。
- ❗ **2025 营收 −20%、归母 −36%**，省外扩张受阻 + 次高端价格带（剑南春/汾酒/洋河/今世缘）竞争白热化 + 白酒深度调整。
- 黄鹤楼（2016 收购）省外贡献承压。

**结论：区域护城河仍在，但「次高端高增长」逻辑被证伪，须按弱周期 + 区域竞争重估。**

## 三、估值（老唐估值法 + 折扣 0.9 + B 股流动性 0.8）

> **基准年 = 当下年度（2026E）**，需独立预估（见 [[laotang-valuation-base-year]]）。

### 用 Q1 占比反推 2026E（数据见 xlsx `季度占比` sheet）

- 古井 **正常年 Q1 归母占比 ≈ 36%（2016-24 均值）**；但 2025 崩盘年（H2 仅 −1.1 亿）飙到 **65.7%**。
- **绝不能用正常 36% 反推**（→ 44.6 亿/+26%，下行期荒谬）。须用崩盘年高占比。
- 2026 Q1 归母 16.07。取 **Q1 占比 60%（H2 仍偏弱，但较 2025 极低基数略回升）→ 2026E 归母 = 26.80 亿（−24.5%）**。

| 假设 Q1 占比 | 2026E 归母 | 全年增速 |
|---|---|---|
| 50%（H2 明显回升） | 32.1 亿 | −9.4% |
| 55% | 29.2 亿 | −17.7% |
| **60%（采用·H2 仍偏弱）** | **26.8 亿** | **−24.5%** |
| 65.7%（同 2025 崩） | 24.5 亿 | −31.1% |

### 估值参数

| 项目 | 数值 |
|------|------|
| 2025 实际归母 | 35.49 亿 |
| **当年净利(2026E)** | **26.80 亿**（2026 增速 −24.5%，Q1 占比 60% 反推） |
| 前瞻增速（2027-29） | 3% |
| 净利润折扣 | 0.9 |
| 3 年后净利(2029) = 2026E×0.9×1.03³ | 26.35 亿 |

| 估计市值 = 26.35×25×0.8 | 527 亿 |
| 安全边际 | 50% |

> ⚠️ PE 取 25（古井沿用），茅台/腾讯用 27.5（无风险利率 3.6%）。口径不一致，可统一为 27.5（买点会升约 10%）——待定。

## 五、总结

古井贡 B **三原则仍成立，但 2025 是「增长拐点 + 业绩塌方」之年**：

1. **利润为真** ⚠️：真实，但现金含量降至 0.55，需盯回款
2. **资本开支** ✅：轻资产不变
3. **利润可持续** ⚠️：徽酒龙头护城河在，但 −36% 证伪高增长，次高端竞争 + 行业调整下须按弱周期重估

**核心跟踪变量：** ①季度营收/利润增速（2026 能否企稳）②合同负债（蓄水池，景气领先）③年份原浆动销 + 省外扩张 ④黄鹤楼商誉减值 ⑤次高端竞争格局。

**估值结论：** 基准年用 2026E。2025 崩盘致 Q1 占比异常（66%），取 60% 反推 **2026E 归母 26.80 亿（−24.5%）**，前瞻 3%。**买点 ≈ 49.8 港元（市值 264 亿）**，较上版（104）因业绩崩盘大幅下移。10 年 Q1 占比表见 xlsx `季度占比` sheet。
