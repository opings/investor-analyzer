# 批价跟踪 · 数据规范

> **本表 = 表外温度计**（skill 明确：白酒排雷主战场在三表之外·`财报关注要点.md` 🅱 渠道压货雷达 #1）。批价不在年报里，一手来源分散——本表是"骨架 + 已知一手数据点"，等 `daily-news` skill 每月抓取补齐。

## 为什么单独存

批价（终端流通价）不在任何一张财务报表里，是**表外雷达**。skill `财报关注要点.md`：
> 🔴 **批价 vs 出厂价（表外·头号温度计·决定下面一切怎么读）**：批价远高于出厂价=供不应求（安全垫）；批价逼近/跌破出厂价=倒挂 → 经销商压货亏损、被迫打款，合同负债是虚水位。

## 一手来源规范

**允许作为一手源的**（按可靠度排序）：
1. **今日酒价**（jinrijiujia.com·白酒批价专业媒体）
2. **同花顺 iFind / 万得 Wind**（付费）
3. **新浪财经/澎湃新闻/证券时报**关于批价的专项报道（需带具体调查方法/日期）
4. **企业官方公告**（提价/降价公告·首发上市公告）

**禁用作为一手源**：
- 未标注来源的雪球/知乎/微博/公众号帖子
- 大V个人转述（可作为二手对照·但需一手交叉验证）
- 电商随手截图（受促销/秒杀干扰，需带"稳态电商价"标注）

## 抓取节奏

- **月度**：daily-news skill 每月首日抓一次核心 SKU（普五 8 代 / 1618 / 39 度低度）批价快照
- **事件触发**：公司提价/降价公告、渠道调整、经销商大会次日抓一次
- **紧急触发**：批价倒挂 >10% 或环比骤降 >15% → 立即抓 + 记入事实编年

## CSV 字段说明

| 字段 | 含义 | 备注 |
|---|---|---|
| 日期 | 批价快照的日期 | 精确到日；月度快照标 `YYYY-MM-XX`（等日期确认后补） |
| SKU | 具体产品 | 第八代普五 / 1618 / 39 度普五 / 经典五粮液 等 |
| 出厂价 | 经销商打款价 | 出厂价=经销商向公司打款的价格 |
| 开票价 | 发票开价 | 出厂价 - 补贴 = 开票价；2026 起五粮液直降 119 元/瓶"补贴" |
| 批价 | 一批商→二批商的成交价 | 一批批价（若有多档、取中位）|
| 电商价 | 天猫/京东官方旗舰店稳态价 | 剔除大促/秒杀·稳态挂牌价 |
| vs出厂偏离 | (批价-出厂)/出厂 × 100% | **>0 = 供不应求**（安全垫）· **<0 = 倒挂**（压货信号） |
| 一手来源 | 具体链接或媒体名 | 允许标注日期后从事实编年查找 |
| 备注 | 上下文 | 提价/降价/新品上市/大促等 |

## 警戒线（对应 `财报关注要点.md`）

- 批价 > 出厂 5% 以上：🟢 **安全垫**
- 倒挂 <10%：🟡 **需关注**（叠加合同负债+终端动销判断）
- 倒挂 >10%：🔴 **压货信号**
- 倒挂 >15%：🔴 **严重压货·合同负债是虚水位** (**2026-06 实证 18%**)

## 分析用法

1. **与合同负债+预收/营收比配对看**：批价倒挂 + 合同负债水位反升 = 经销商被逼大额打款、货压在渠道
2. **与销售收现/营收比配对看**：批价倒挂 + 收现比骤升 = sell-in 压货兑现的先行指标
3. **与消费税/营收比配对看**：批价倒挂但消费税率保持 14-15%（发货量未减）= 产品高端结构未变·纯压货
4. **同业横比**：同期茅台批价 vs 出厂价、泸州老窖 vs 五粮液批价——判断是行业深度调整还是五粮液独有的品牌力压力
