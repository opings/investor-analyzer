## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**每年**验证 7 条：
- **损益**：营业利润 + 营业外收入 − 营业外支出 = 利润总额 ✓
- **损益**：利润总额 − 所得税 = 净利润 ✓
- **损益**：归母净利 + 少数股东损益 = 净利润 ✓
- **资产负债**：总资产 = 总负债 + 权益 ✓
- **资产负债**：归母权益 + 少数股东权益 = 所有者权益合计 ✓
- **现金流**：经营 + 投资 + 筹资 + 汇率变动 = 现金净增加 ✓
- **现金流**：期初 + 净增加 = 期末 ✓

**校验状态**：20/20 年全部通过（2006-2025），细节见脚本运行输出。校验不通过则**不写出 CSV**（回查 PDF）。

- **2016-2017 五粮液低谷**（销售费用率 19%、存货周转 462 天、净利率 28.75%）—— 李曙光 2017 年 8 月上任前的"改革参照系"

## 为什么从年报解析、不用东财二手

skill 铁律：一手财报 PDF 是唯一真源，东财二手 CSV 会错（如农夫 2026-06 实证：现金流量表 CSV 「经营业务现金净额」把税前 256 亿误标成净额，真净额 211 亿）。本目录严格从一手年报 PDF 逐行解析 + 勾稽自洽校验，杜绝二手错位。
