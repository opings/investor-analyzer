# 五粮液 财报关注要点

- **生意一句话**：浓香白酒龙头，普五卡位高端/次高端，靠品牌力 + 经销网络先款后货赚钱。
- **护城河本质**：浓香老窖池（明初古窖）+ 五谷配方（高粱/大米/糯米/小麦/玉米）；包装（水晶瓶）成本占比高。壁垒在，但当前账目可信度问题盖过生意本身（见无法估值；生意模式/成本结构详见行业模板白酒块 🅰）。
- **估值法**：⚠️ 当前**无法估值（太难）**——利润为真存疑（sell-in 压货 + 会计差错更正）；待干净 sell-through 口径财报积累数年后，才谈成长股老唐法。
- **核心跟踪变量（最该盯的）**：
  1. **收现 ÷ 当期确认营收**（头号探针）：2025 达 **2.26x**（正常含税 ~1.1）；回归 ~1.1 才说明压货出清、口径理顺。
  2. **批价 vs 出厂价 + 终端动销**（表外）：普五批价是否守住/倒挂——决定合同负债是真安全垫还是被逼出来的虚水位。
  3. **是否出干净可比的历史重述**（含 2024 及以前）：能否重建连续 sell-through 口径序列（决定能否重新估值）。
  4. **监管动向 + 审计意见**：深交所问询 / 证监会立案 / 审计是否被追责。
  5. **合同负债 + 其他流动负债**（收钱未确认收入的"壳"）变化。
