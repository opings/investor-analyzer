# 华致酒行 财报关注要点

- **生意一句话**：酒类精品流通分销商——不酿酒、不拥有品牌，靠从茅台/五粮液等上游采购、通过连锁门店/KA/团购/电商分销赚差价
- **生意类型**：不确定生意（分销商天然薄利、无定价权、高度依赖上游品牌授权和行业景气度；2021→2025 利润从 6.76 亿跌至 -3.69 亿 = 利润不可持续预测）

---

## 🅰 生意模式 / 护城河本质

**靠什么赚钱**：赚"买卖差价"——从酒厂以出厂价/协议价采购中高端酒品，通过自有渠道网络加价销售给终端（详见 `财务数据/利润表.csv`，毛利率长期仅 6–21%）。
- **渠道网络**：连锁酒行门店（华致酒行/华致酒库）+ 零售网点 + KA 卖场 + 团购 + 电商【源·招股书 p197-200】
- **上游关系**：核心供应商 = 贵州茅台 + 宜宾五粮液 + 其他名酒企，采购集中度高【源·招股书释义页】
- **保真定位**：以"保真"为核心卖点，建立了信息化供应链管理体系——这是分销商主要的差异化壁垒【公司自述·招股书 p2】

**护城河评估**：
- **无品牌定价权**【判】：不拥有酒类品牌，无法像茅台/五粮液那样靠品牌溢价获得高毛利
- **无产地/窖池壁垒**【判】：纯贸易型公司，物理资产极轻（固定资产仅 2.25 亿 vs 总资产 48 亿）
- **渠道壁垒有限**【推】：酒类分销行业参与者众多、集中度低（招股书 p2 自述"市场集中度不高"），其他分销商/电商/直营均可竞争
- **上游授权依赖**【判】：核心竞争力取决于能否持续获得茅台/五粮液等名酒的分销授权，这不掌握在自己手中

### 公司独有红旗

- 🔴 **存货减值是命门**：2025 年资产减值损失 3.05 亿，直接导致从微利转巨亏（归母净利从 +0.44 亿→-3.69 亿）。存货占总资产近半，酒价下行周期中减值压力持续
- 🔴 **分销商无定价权的致命弱点**：上游出厂价刚性、下游零售价随市场波动→毛利空间被双向挤压。2025 毛利率仅 6.19%（历史最低），行业景气好时能赚钱、差时立刻亏钱
- 🟡 **预付款项大额波动**：2021 年预付从 7.47 亿暴涨至 19.51 亿（向上游锁货），2025 回落至 6.86 亿（需求萎缩）。大额预付 = 看多市场的对赌敞口
- 🟡 **经营现金流与利润方向经常背离**：利润高峰年（2021 净利 6.76 亿、2022 净利 3.66 亿）经营现金流反而是大负（-3.73 亿、-3.30 亿）——利润增长靠预付锁货/存货膨胀推动，现金不支持
- 🟡 **实控人吴向东通过多层架构控制**：云南融睿 47.80% + 西藏融睿 14.52% + 华泽集团 7.64%，均为吴向东控制，合计约 70%——高度集中，无制衡

### 历史教训

- 2018 年经营现金流 -2.41 亿（IPO 年大额预付锁货）
- 2021-2022 连续两年经营现金流大负（-3.73/-3.30 亿），同期利润分别为 6.76/3.66 亿——利润与现金严重脱节
- 2025 年首次巨亏，且不分红
