## 勾稽自洽校验

由 `_build_from_pdf.py` 执行，已通过：
- 资产 = 负债 + 权益（2015/2021/2024/2025 四年验证）
- 经营 + 投资 + 筹资 + 汇率 = 现金净变动（2025 年验证）
- 期初 + 净变动 = 期末现金（2025 年验证）
- 营收 - 营业成本 = 毛利（2025 年验证）
