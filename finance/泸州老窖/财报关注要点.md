# 泸州老窖 · 财报关注要点（泸州老窖特有）

> 估值法：成长股估值法——2024-2025 进入行业下行周期，基准年取数勿线性外推。
> 高端浓香龙头·四川泸州。000568。核心：国窖 1573（千元高端）+ 特曲/窖龄（中端）+ 头曲/二曲（低端）。
> **护城河本质**：**1573 国宝窖池连续使用 450+ 年**（浓香第一·窖龄即酒质·新窖池数十年才成熟·不可复制）；护城河硬，但高端高度依赖单一大单品国窖（详见行业模板白酒块 🅰）。

## 一、⚠️ 行业级压货雷达（先过这关，见行业模板白酒块）

> 泸州老窖同为"经销商先款后货 + 发货确认收入"，行业级 sell-in 压货风险结构性存在。实测：泸州老窖**收现/营收 ~1.0-1.28、无五粮液式 2.26x 断裂**，2025 诚实下滑入表——**未发现 sell-in 现金掩盖**。但仍须每期扫：

| 雷达 | 泸州老窖怎么看 | 级别 |
|---|---|---|
| **国窖 1573 批价 vs 出厂价（报表外·头号温度计）** | 千元价格带是否守住、是否倒挂；高端动销是估值基准年的决定项 | 🔴 倒挂即高警惕 |
| **现金含量（经营现金流/归母）** | 历史 boom 期（2020-2023）跑 0.80-0.97=渠道建库；累计 0.94。盯是否回到 ~1 | 🟡 |
| **应收款项融资（银行承兑）** | **泸州老窖特有偏高项**：2019-2023 达 24-59 亿（票据结算/变相授信，收现质量打折），2024-2025 降至 15-18 亿。再抬升=放货压库信号 | 🟡 |
| 收现/确认营收 | ~1.0，正常；远超才警惕 | 🟢 |
| 合同负债 | 体量偏小（占营收 ~13%，小于茅台/五粮液的安全垫），波动看动销 | 🟡 |
| 收入确认口径/会计差错更正 | 警惕未来出现五粮液式口径切换 | 🔴 若现 |

## 二、经营质量（泸州老窖独有结构）

- **双品牌/价格带结构**：国窖 1573（核心利润与高端话语权，对标飞天/普五）/ 特曲·窖龄（次高端-中端基本盘）/ 头曲·二曲（光瓶低端）。**看国窖占比与批价**=高端壁垒；中端放量=以价换量信号。
- **毛利率**：87% 左右、行业第一梯队，结构升级（国窖占比）驱动；毛利率回落=结构下移/降价预警。
- **销售费用率**：泸州老窖营销投入大（"双品牌+品牌专营公司"模式），费用率波动看竞争烈度。
- **存货**：基酒/老酒是浓香的"宝"，但下行期成品酒+渠道累库要分开看（2025 存货/营收升至 60%）。

## 三、股东回报 / 泸州老窖特有排雷

- **分红**：现金分红比例与持续性（高端白酒现金奶牛，关注派现政策）。
- **货币资金极充裕 + 无有息负债** → 无存贷双高（🟢）；关注大额理财/资金去向、集团关联交易（泸州市国资控股）。
- **品牌专营公司模式**：国窖等通过品牌专营公司运作，关注关联交易公允性与渠道利益分配。
- **下行期估值风险**：增速转负时基准年取数勿外推；估值已落到买点区间附近，但需 2026 动销企稳确认（详见 `分析.md`）。

## 关键跟踪变量（每期财报后回答）

1. **国窖 1573 批价**（报表外·头号温度计）——守价还是倒挂？高端动销冷暖。
2. **2026 营收/归母增速**——能否止跌企稳？官方次年经营计划。
3. **现金含量**是否回 ~1 + **应收款项融资（银票）**是否再抬升。
4. **国窖占比 / 中端放量结构** + 毛利率是否守住 87%。
5. 存货/渠道库存去化；分红政策；无风险利率（定合理 PE）。
