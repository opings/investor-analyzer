## ⚠️ 口径提醒（分析前必看）

泸州老窖 2025 年营收/利润下滑是**真实经营下滑**（营收 -17.5%、归母 -19.6%），**不是**五粮液式的 sell-in→sell-through 会计差错更正（无追溯重述、审计口径连续）。但历史上有两处会计口径变化，本库已按「重述口径」统一处理，保证 2006-2025 可比：

- **2006**：《企业会计制度》(老准则) 末年。本库 2006 采用 **2007 年报追溯重述的 CAS2006 口径**（营收 19.26 亿），与 2007+ 可比；老准则原始披露值（营收 18.69 亿）留档于 `_extract_json/lzlj_extract_2006.json`。
- **2016**：2016-05 全面**营改增**。本库 2016 采用 **2017 年报按新口径重述的值**（营收 86.27 亿），与 2017+ 可比；2016 年报原始披露值（营收 83.04 亿）留档于 `_extract_json/lzlj_extract_2016.json`。

## 勾稽自洽校验

`_build_from_pdf.py` 每年验证 6-7 条：
- **损益**：营业利润 + 营业外收入 − 营业外支出 = 利润总额；利润总额 − 所得税 = 净利润；归母 + 少数股东损益 = 净利润
- **资产负债**：总资产 = 总负债 + 权益；归母权益 + 少数股东权益 = 权益合计
- **现金流**：经营 + 投资 + 筹资 + 汇率 = 净增加额；期初 + 净增加 = 期末

**校验状态**：20/20 年全部通过。校验不通过则不写出 CSV。

## 关键脉络速览（截至 2025-12-31 · 详见各 CSV）

- **营收脉络**（20 年，详见 `利润表.csv`）：黄金期高点 2012 → 2014 深度调整谷底(营收较 2012 腰斩) → 2020-2023 高增长 → 2024 增速急刹 → 2025 下滑。
- **毛利率**（详见 `财务比率.csv`）：由 2006 的 56% 持续升至 2023 的 88%（高端化：国窖 1573 占比提升），2025 微降。
- **ROE**：2012 高点约 45% → 2014 谷底约 9% → 2023 约 32% → 2025 约 22%。
- **存货两层**（详见 `产销量.csv`）：成品酒库存 2025 创六年峰值(+29.76%，需求走弱信号)；半成品(基酒)持续扩产(浓香升值资产、常态)。**财报「存货」周转天数高企主因是基酒，须与成品积压分开读。**
- **回款质量**：应收账款/营收常年 ≈ 0（白酒龙头本色）；但 2025 经营现金流大幅回落（详见 `财务比率.csv` 现金含量）。
