### ⚠️ 为什么起点是 2019 而不是「上市前 3 年」

模板默认「招股书含 IPO 前 3 年财务数据」。**Coinbase 是例外**：上市时属新兴成长公司（EGC），424B4 只列 **FY2019 / FY2020 两年**经审计财务，无 FY2018 三表。

**已穷尽三条路验证 FY2018 不可得**（非「只探一条路」）：
1. 424B4 全文 —— 无 FY2018 损益/财务状况/现金流表，正文仅 4 处提及 2018 年（均为业务指标：平台资产 $7B、市占 4.5%、验证用户 32M）；
2. 10-K FY2021 三年比较列 —— 最早列到 FY2019；
3. XBRL companyfacts 全量扫描 —— FY2018 仅 **3 个期初余额点**（现金 1,987,139 / 股东权益 500,071 / 未确认税务利益 6,605），系 FY2019 现金流量表与权益变动表的期初数。

→ 结论：FY2018 三表**实证不可得**，已登记在 `重述与口径变更.csv` 断点 F。**不构造 FY2018 列。**

## 🚨 四处口径断点（本库最重要的一张表）

Coinbase 七年内有 **4 处**使「同一科目跨年直接相减」失效的口径变更。三表 CSV 取 **各年 as-reported（当年自身申报原始披露值）**，断点全部登记在 **`重述与口径变更.csv`**（24 行）。

| 断点 | 内容 | 破坏力 |
|---|---|---|
| **A** SAB 121 → SAB 122 | 2022/2023 曾把「保管客户加密资产/负债」总额计入表内（2023 达 192,583,060 千美元）；FY2024 10-K 追溯剔除 | **2023 总资产 $206.98B → $14.75B**，naive 总资产序列完全失真 |
| **B** 客户托管资金流 经营↔融资 | FY2021 10-K 把客户托管资金负债变动列**经营**；FY2022 起改列**融资**并重述 | **2021 经营现金流 10,730,031 → 4,038,172**；现金含量 2.96x → 1.11x，直接改变「利润为真」判定 |
| **C** 支付稳定币改记现金等价物 | FY2025 自愿变更：USDC/EURC/PYUSD 由 ASC 310 应收改列现金等价物，**追溯**适用 | 2023/2024 现金、贷款、三大活动现金流全部重列（2024 经营现金流 2,556,844 → 3,103,935） |
| **D** ASU 2023-08 | 2024-01-01 采用（累积影响法·**非追溯**）：自持加密资产由「成本减减值」改按**公允价值** | 利润表加密资产损益行 2023 及以前与 2024 起**不可比**；期初留存收益 +561,489 |

另有 **断点 E：关键业务指标定义被改过 3 项**（MTU / Adjusted EBITDA / Trading Volume），且公司自陈「非重大口径修订一般不回溯更新已披露指标」—— 详见下节。

**跨年比较请用 `财务比率.csv` 里 `【可比】` 开头的行**（已消解 A/B/C）。

## 勾稽自洽校验

由 `_build_from_filings.py` 生成（转录固化 + 校验），**每年**验证；**校验不通过则不写出 CSV**：

- **利润表**：净收入+其他收入=总收入；经营费用**分项和**=总经营费用；总收入+总经营费用=经营利润；经营利润+线下各项=税前；税前+所得税=净利；净利+折算调整=综合收益
- **资产负债表**：流动资产**分项和**=流动资产合计；流动+非流动=总资产；流动负债分项和=流动负债合计；流动+非流动=总负债；**总负债+夹层(可转优先股)+权益=总资产**；权益分项和=权益合计；印刷「负债+夹层+权益合计」=总资产
- **现金流量表**：三活动+汇率=现金净变动；期初+净变动+汇率=期末；**经营段/投资段/融资段各自分项和=该段净额**；现金流净利=利润表净利；**期末现金=附注对账表（现金+受限现金+客户托管现金）三项和**
- **分部**：交易收入分项和=交易收入合计；订阅服务分项和=订阅服务合计；交易+订阅=净收入合计；其他收入分项和=其他收入合计；净收入+其他=总收入；**分部总收入=利润表总收入**；地区拆分和=总收入

> 本次构建：**全部勾稽通过**（7 年 × 上述全部条目）。

## 为什么从一手申报转录、不用第三方聚合

Coinbase 的四处口径断点使第三方数据源**极易给出混口径序列**：任何按「最新重述值」单值化的数据库都会让 2023 总资产显示 $14.75B（抹掉 SAB 121 时期的真实披露），而按「当年披露」的会让 2021 经营现金流显示 $10.7B（含 67 亿客户的钱）。两种单值化都会误导。本库同时保留 **as-reported（三表）+ 重述登记册 + 可比派生行**三层，才能既看到「当时报了什么」也能做「跨年可比」。
