### 为什么从 XBRL 解析、不用第三方聚合（东财/雅虎式）

XBRL（机读财报标签标准） companyfacts（SEC 机读接口·返主体全部历史标准标签） = **申报人自己**报给 SEC 的机读标签版，与印刷 10-K（美股年报） 同源，**非第三方 re-key**——根除聚合商的科目错位。且免 PDF 逐行转录误差（2007+ 机器精确）。

⚠️ **但 XBRL 有两个结构性盲区（2026-10-22 实证）**：① companyfacts **只收 us-gaap/dei 标准标签**，公司自定义标签（`goog:`）的行整行拿不到（2014–2022 折旧/摊销、2018–2019 欧盟罚款）；② 一行配多个候选标签时，**不同年份可能落到口径不同的标签上**（长期债务一行曾混三种口径），而这类行**不在任何勾稽等式里，错了勾稽照样全过**。对策：逐行列出「每年实际用了哪个标签」，标签切换处回原表核（见复核记录）。

## ⚠️ 口径决策（建库时查实并据实处理；6–11 为 2026-10-22 刷新新增）

1. **TAC（流量获取成本） 毛/净收入列示 → 序列 1999 起统一毛口径**：**只有首版 S-1（2004-04-29·`_ipo登记与增发档/招股说明书.htm`）**按净收入列示 2002–2003（扣 TAC：$347,848K / $961,874K）；S-1/A 修订、**定稿 424B4（2004-08-19）**与 FY2004 起 10-K 均为**毛收入**（TAC 计入销售成本：$439,508K / $1,465,934K），净利不变。**1999–2001 两种列示下收入完全相同**（$220K / $19,108K / $86,426K），不存在口径问题。
   🔴 本条旧版写「1999–2001 仅 S-1 净口径可得、不并入序列」——**只查了首版 S-1 一条路的误判**（定稿 424B4 与 FY2004 10-K 五年表都有这三年），2026-10-22 订正并入序列。
2. **SBC（股权薪酬） 列示变更**：早年原表把股权激励单列一行、FY2006 起摊入各费用项。费用分项统一取 incl-SBC 口径（2002+ 取 FY2006 10-K 口径；2000–2001 按 FY2004 10-K 五年表脚注分摊额并入：2000 年销售成本 167 / 研发 1,573 / 销售营销 514 / 行政 252 千美元，2001 年 876 / 4,440 / 1,667 / 5,400；1999 年为零），与 2007+ 一致。
3. **Motorola 终止经营 2012–2014**：Google 持有 Motorola 期间的终止经营净利单列（`利润表.csv`），使「除税前+税+终止经营=净利」勾稽成立。
4. **2026 起「净利」被股权重估严重污染 → 派生「核心口径」并列**（`中期财务-2026.csv` 派生段）：Q2 2026 OI&E（其他收入支出净额） 占除税前利润 **70.6%**（去年同期 7.8%），主体是 SpaceX + 一家未具名私营公司的**未实现**公允价值收益（美国 GAAP（美国公认会计准则） 下股权证券公允价值变动直接进净利、不走 OCI（其他综合收益·不进净利直接进权益））；**Q3 2026 方向反转**——股权证券净损失使 OI&E 为负、报告净利同比下降而经营利润同比上升。因此中期表同时给出：
   - **报告稀释 EPS（每股收益）**（10-Q（美股季报） 申报值）
   - **核心稀释 EPS（估）** = (经营利润 ×(1−有效税率) − 优先股股息) ÷ 稀释股数（Note 12）—— 剔除 OI&E 股权重估，标 `【推】非申报口径`，仅供跨期同口径比较；另列「按去年同季税率」敏感性行（未实现损益按法定税率计提递延税，会把当期有效税率抬高〔Q2〕或压低〔Q3〕）。
5. **净现金两口径并列**（同上 CSV）：`(现金+有价证券)−长期债务` 会把**受限的 SpaceX 股份**当成可动用现金，造成"净现金反而变厚"的错觉。故另列 **剔除上市股权证券后的可动用净现金**（上市股权证券取 Note 3 公允价值表）。两口径 2026-06-30 为 $144.3B 与 $57.2B，2026-09-30 为 $140.0B 与 $49.6B——引用时必须指明口径。SpaceX 限售股：6/30 为短期 $80.0B + 限售至 2027Q3 的 $14.1B（后者在其他非流动资产）；9/30 只披露短期限售 $75.2B，长期段脚注不再出现，持仓总额 10-Q 未给。
6. **利润表一次性行单列**（各年自家 10-K 利润表原文·旧版漏收、费用分项和校验抓出）：2004 雅虎和解非经常性部分 $201,000K、2005 Google 基金会捐赠 $90,000K、2011 司法部调查和解 $500M、2017–2019 欧盟委员会罚款（$2,736M / $5,071M / $1,697M）——均为经营费用行；**2008 股权投资减值 $1,094,757K 为营业外**（经营利润之下）。
7. **2012–2013 营业成本含 Motorola Mobile 一行**：FY2012/FY2013 10-K 利润表把营业成本分两行（Google / Motorola Mobile·$3,458M / $3,865M），XBRL 的 `CostOfRevenue` 只取到 Google 那行，而营收含 Motorola。旧版因此把 **2012/2013 毛利率分别高估 6.9 / 6.5 个百分点**；现单列一行，`财务比率.csv` 毛利率按两行合计算。
8. **长期债务 = 资产负债表原表那一行**：2012–2024 原表「Long-term debt」含融资租赁（`LongTermDebtAndCapitalLeaseObligations`），2010–2011 / 2025 为 `LongTermDebtNoncurrent`。旧版首选纯票据标签、兜底含一年内到期的总额标签，一行混三种口径（2013/2014/2017–2019 少计融资租赁、2020–2022 误含一年内到期部分）。⚠️ **FY2024 10-K 把 2023 年末长期债务从 $13,253M 改列为 $11,870M**，本序列取当年原表 $13,253M。FY2024 10-K 对此只有一句泛述、未说明是哪一项：
   > "Certain amounts in prior periods have been reclassified to conform with current period presentation."
   >
   > 译：「部分前期金额已重分类，以与本期列报一致。」
9. **折旧拆两行（FY2023 10-K 口径断点）**：原表那一行口径随年份变——2012–2013「折旧及摊销」/ 2014「折旧及处置损失」/ 2015–2022「折旧**及减值**」/ 2023 起「**纯折旧**」。FY2023 10-K 把 PP&E 减值与无形资产摊销并入「Other」，并把 2021–2022 回溯重列为纯折旧（$11,555M→$10,273M、$15,287M→$13,475M；三行合计两版相等，已核）。故 `现金流量表.csv` 设「折旧（原表口径）」与「折旧（纯折旧·FY2023 起口径）」两行，2021–2022 重叠供跨断点衔接；**跨 2022/2023 比较折旧增速必须用后一行**。无形资产摊销 2023 起原表不再单列。
10. **非上市证券投资 = 原表那一行**（行名三代：Non-marketable equity securities → equity investments → investments → securities，2008–2025 全部 = `OtherLongTermInvestments`，逐年对原表一致）。旧版行名误作「非流动有价证券」、候选标签取到附注小项（如 2024 仅 $266M，原表 $37,982M）。
11. **2015 EPS 分类别**：Class C 获 $522M 调整款，三类股 EPS 不同；XBRL 只有按类别维度值、companyfacts 不收。本序列取 Class A/B（基本 $23.11 / 摊薄 $22.84），Class C 为 $24.63 / $24.34。
12. **🆕 采购承诺计量口径断点（2026Q3 10-Q）**：FY2025 10-K 与 2026Q2 10-Q 均写「对可变条款协议，不超出最低数量和/或价格估计不可撤销义务」；2026Q3 10-Q Note 10 改写为部分长期供应协议「按合同上限价格与数量列示」，MD&A 删去「最低」一句。原文：
    > "The amounts disclosed above reflect pricing and volumes at the maximum contractual limits of the current contracts."
    >
    > 译：「上述金额反映的是现行合同上限的价格与数量。」

    10-Q 未量化口径变化的影响 → **6/30 → 9/30 的承诺增量不可全部视为新签**；Note 10 多年期承诺 6/30 的 $707.0B 是「固定或保证」口径、9/30 的 $802.1B 是上限口径（且含 $4.5B 备用信用证），两者不同口径（`表外承诺与储备.csv` 表头）。
13. **🆕 Note 3 股权证券损益分项跨期不可相加**：附注定义「已实现收益 = 售价 − 期初账面（或买入日）」，9M 与 Q3 的「期初」不同，同一笔出售在两种期间口径下的已实现 / 未实现拆分不同 → 只有**合计行**满足 9M = H1 + Q3（脚本只对合计做跨期勾稽），分项须按各期原表引用。
14. **🆕 稀释 EPS 的分子随期间变**：强制可转优先股按假设转换法，**只在有稀释作用时**加回优先股股息、把转换股计入分母——Q2'26、H1'26、9M'26 有稀释作用（分子 = 净利），Q3'26 反稀释（分子 = 归属普通股净利）。Note 12 逐期列出加回额与转换股数，脚本按此复算 EPS（两位小数完全相等）。

### 中期数据的已知边界

- **不并入年度序列**：`利润表.csv` 等年度 CSV 仍止于 2025；中期只在 `中期财务-2026.csv` / `分部营收-中期2026.csv`。年化推算属分析层动作、须标【推】。
