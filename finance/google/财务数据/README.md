### 为什么从 XBRL 解析、不用第三方聚合（东财/雅虎式）

XBRL companyfacts = **申报人自己**报给 SEC 的机读标签版，与印刷 10-K 同源，**非第三方 re-key**——根除聚合商的科目错位。且免 PDF 逐行转录误差（2007+ 机器精确）。仅 XBRL 够不着的 2002–2006 才手工转录，并逐年勾稽校验。

## ⚠️ 三个口径决策（建库时查实并据实处理）

1. **TAC 毛/净收入重述 → 序列起点 2002**：S-1(2004) 按**净收入**列示（扣流量获取成本 TAC）；FY2004 起 10-K 改**毛收入**（TAC 计入销售成本）。如 2003 收入 净 $961,874K vs 毛 $1,465,934K，净利不变。**本序列统一用毛口径（2002+）**。**1999–2001 仅 S-1 净口径可得，不并入序列**（避免混口径），净利留档：1999 −$6,076K / 2000 −$14,690K / 2001 $6,985K。
2. **SBC 列示变更**：FY2004 单列股权薪酬、FY2006 起摊入各费用项。费用分项统一取 FY2006 起的 incl-SBC 口径，与 2007+ 一致。
3. **Motorola 终止经营 2012–2014**：Google 持有 Motorola 期间的终止经营净利单列（`利润表.csv`），使「除税前+税+终止经营=净利」勾稽成立。

## 勾稽自洽校验（`_build_from_xbrl.py` 内置·2002–2025 逐年）

- **损益**：收益 + 总成本及开支(负) = 经营利润；除税前 + 所得税 + 终止经营 = 净利 —— **24 年全 OK**
- **资产负债**：资产 = 负债 + 权益 —— **24 年全 tie（残差 0）**
- **现金流**：经营 + 投资 + 融资 + 汇率 = 现金净变动 —— **24 年全 OK**
- **分部**：收入分项合计 = 总收入、广告三项 = 广告合计、分部经营利润合计 = 总经营利润 —— 全 tie，且与利润表交叉核对一致
> 校验不通过则不写出 CSV。改数/补年份 → 改脚本重跑。

## 已知细节缺口（非勾稽项·不影响三表自洽）

- EPS **未做拆股还原**（as-reported）：2014 C 类拆股、2022 20:1 拆股致断点；EPS 序列有台阶（`利润表.csv` 已注）。
- 折旧/摊销分项 2014–2020 XBRL 标签差异，部分年份空（补充项·非勾稽项）。
- 2007「其他收入净额」、2015 EPS 单元格因标签差异空缺（可由勾稽反推）。
- 股息 2024 前为空 = 真实无派息（Alphabet 2024 才首派）；回购 2008 前空 = 当时无回购。
