### 为什么从 XBRL 解析、不用第三方聚合（东财/雅虎式）

XBRL（机读财报标签标准） companyfacts（SEC 机读接口·返主体全部历史标准标签） = **申报人自己**报给 SEC 的机读标签版，与印刷 10-K（美股年报） 同源，**非第三方 re-key**——根除聚合商的科目错位。且免 PDF 逐行转录误差（2007+ 机器精确）。仅 XBRL 够不着的 2002–2006 才手工转录，并逐年勾稽校验。

## ⚠️ 三个口径决策（建库时查实并据实处理）

1. **TAC（流量获取成本） 毛/净收入重述 → 序列起点 2002**：S-1(2004) 按**净收入**列示（扣流量获取成本 TAC）；FY2004 起 10-K（美股年报） 改**毛收入**（TAC 计入销售成本）。如 2003 收入 净 $961,874K vs 毛 $1,465,934K，净利不变。**本序列统一用毛口径（2002+）**。**1999–2001 仅 S-1 净口径可得，不并入序列**（避免混口径），净利留档：1999 −$6,076K / 2000 −$14,690K / 2001 $6,985K。
2. **SBC（股权薪酬） 列示变更**：FY2004 单列股权薪酬、FY2006 起摊入各费用项。费用分项统一取 FY2006 起的 incl-SBC 口径，与 2007+ 一致。
3. **Motorola 终止经营 2012–2014**：Google 持有 Motorola 期间的终止经营净利单列（`利润表.csv`），使「除税前+税+终止经营=净利」勾稽成立。
4. **2026 起「净利」被股权重估严重污染 → 派生「核心口径」并列**（`中期财务-2026.csv` 派生段）：Q2 2026 OI&E（其他收入支出净额） 占除税前利润 **70.6%**（去年同期 7.8%），主体是 SpaceX + 一家未具名私营公司的**未实现**公允价值收益（美国 GAAP（美国公认会计准则） 下股权证券公允价值变动直接进净利、不走 OCI（其他综合收益·不进净利直接进权益））。因此中期表同时给出：
   - **报告稀释 EPS（每股收益）**（10-Q（美股季报） 申报值）
   - **核心稀释 EPS（估）** = 经营利润 ×(1−有效税率) ÷ 稀释股数 —— 剔除 OI&E 股权重估，标 `【推】非申报口径`，仅供跨期同口径比较。
5. **净现金两口径并列**（同上 CSV）：`(现金+有价证券)−长期债务` 会把**受限的 SpaceX 股份**（$80.0B 短期限售 + $14.1B 限售至 2027Q3）当成可动用现金，造成"净现金反而变厚"的错觉。故另列 **剔除上市股权证券后的可动用净现金**。两口径 2026-06-30 分别为 $144.3B 与 $57.2B，**方向相反**（前者升、后者降）——引用时必须指明口径。

## 勾稽自洽校验（`_build_from_xbrl.py` 内置·2002–2025 逐年）

- **损益**：收益 + 总成本及开支(负) = 经营利润；除税前 + 所得税 + 终止经营 = 净利 —— **24 年全 OK**
- **资产负债**：资产 = 负债 + 权益 —— **24 年全 tie（残差 0）**
- **现金流**：经营 + 投资 + 融资 + 汇率 = 现金净变动 —— **24 年全 OK**
- **分部**：收入分项合计 = 总收入、广告三项 = 广告合计、分部经营利润合计 = 总经营利润 —— 全 tie，且与利润表交叉核对一致
> 校验不通过则不写出 CSV。改数/补年份 → 改脚本重跑。

## 已知细节缺口（非勾稽项·不影响三表自洽）

- EPS（每股收益） **未做拆股还原**（as-reported）：2014 C 类拆股、2022 20:1 拆股致断点；EPS 序列有台阶（`利润表.csv` 已注）。
- 折旧/摊销分项 2014–2020 XBRL（机读财报标签标准） 标签差异，部分年份空（补充项·非勾稽项）。
- 2007「其他收入净额」、2015 EPS 单元格因标签差异空缺（可由勾稽反推）。
- 股息 2024 前为空 = 真实无派息（Alphabet 2024 才首派）；回购 2008 前空 = 当时无回购。

### 中期数据的已知边界

- **不并入年度序列**：`利润表.csv` 等年度 CSV 仍止于 2025；中期只在 `中期财务-2026.csv` / `分部营收-中期2026.csv`。年化推算属分析层动作、须标【推】。
- **Q2 单季经营现金流用 MD&A（管理层讨论与分析） 披露值 $39.1B**（10-Q（美股季报） 现金流表只给半年数），故 Q2 单季 FCF（−$5.8B）含一位小数舍入，标注在派生行算法里。
- **存货口径变更**：FY2025 10-K（美股年报） 述"主要为成品"；Q2 10-Q 改述"主要为**对企业客户销售的 TPU（张量处理单元·Google 自研 AI 芯片） 系统硬件**及 Pixel 设备"，并含原材料/在制品/成品 —— 口径与业务实质同时变，横比 2025 前需注意。
- **收入储备口径变更**：2026Q1 起纳入原始期限 ≤1 年的合同，$242.8B→$519.5B **含口径效应**，不可当纯增长读（`表外承诺与储备.csv` 表头已注）。
