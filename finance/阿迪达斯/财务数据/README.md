# 阿迪达斯（adidas AG · XETRA: ADS · ISIN DE000A1EWWW0）财务数据（从一手年报 PDF 解析）

> 本目录 = 阿迪达斯的**一手财务数据库**：从一手年报解析的所有客观数字（三表 + 比率 + 分部 + 重述台账）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/阿迪达斯/`（事实编年，分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/阿迪达斯/`（**1996–2000、2002–2025 共 29 份英文年报全本**）**逐年解析** + 勾稽自洽校验。
> **单位 / 符号**：金额一律 **€ 百万**；EPS 为 €/股；利润表费用记正数、现金流量表流出记负数；空 = 该期财报无此科目（**不是零**）。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## ⚠️ 读这个库之前必须先知道的七件事

1. **这是本库第一家欧陆股**。adidas 不在美国上市（美国只有非保荐 ADR `ADDYY`，**无 SEC 申报**），
   也不在巨潮/港交所。**一手源 = 公司 IR 官网自己挂的年报 PDF**（`adidas-group.com/en/investors/financial-reports`），
   1996–2002 的老年报官网已下架，取自 Internet Archive 存档的 `adidas-salomon.com` 旧站。
2. **1994–1999 年报以德国马克（DM）列报**，2000 年起改欧元。本库统一折成 € 百万，
   按欧元不可撤销固定汇率 **1 EUR = 1.95583 DM**。这不是估算：adidas 自己在 2000 年报把 1999 年
   折成欧元后印的数与本库换算**逐格一致**（1999 营收 DM 10,471,414 千 ÷ 1.95583 = € 5,353.9 百万，
   2000 年报印 € 5,353,949 千），构建器里有这条独立校验，不过则不写出。
3. **营收口径被三次业务剥离收窄，as-reported 序列不可直接连比**：
   2005 出售 Salomon（2004 营收 6,478→5,860）、2016-17 剥离 TaylorMade/CCM 等（2016 营收 19,291→18,483）、
   2021-22 出售 Reebok（2020 营收 19,844→18,435）。本库存 as-reported，重述值记在 `重述与口径变更.csv`。
4. **2019 首次适用 IFRS 16**，前期未重述。总资产一年内从 15,612 跳到 20,680（+32.5%），
   其中使用权资产 2,931、租赁负债 3,132 —— **资产负债率跳升有相当部分是会计准则，不是当年新增杠杆**。
   `财务比率.csv` 同时给「含租赁」与「不含租赁」两个有息负债口径。
5. **2018 已付利息由经营活动改列融资活动**，前期未重述 → **经营现金流跨 2017/2018 不可直接比**。
6. **2006-06-06 股票 1 拆 4**。2005 及以前的 EPS 是拆股前口径（2005 基本 EPS 8.19 ≈ 拆股后 2.05），
   跨年比每股数据请用 `财务比率.csv` 的 **【复权】两行**。
7. **分部口径六代、不可跨代拼接**（公司每次重划且不提供回溯序列），见 `分部营收.csv` 的「口径代」列。

## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**每年**验证（不过则**不写出 CSV**）：

- **必填项（C0）**：某年只要有该表任何数据，营收 / 营业成本 / 毛利 / 税前利润 / 所得税 / 归母净利（利润表）、
  资产总计 / 流动资产合计 / 流动负债合计 / 归母权益 / 货币资金 / 存货（资产负债表）、
  经营 / 投资 / 融资 / 期初现金 / 期末现金 / capex（现金流量表）就**必须有值**。
  > 🔴 这条单列，是因为其余勾稽都写成「锚科目存在才开查」——锚本身丢了，整张表会**静默全过**（本库耐克建库的实证教训）。
- **损益**：营收 − 成本 = 毛利；毛利 −(SG&A+折旧) 或 +特许权+其他收益−其他费用−商誉减值 = 经营利润（两代版式各一条链）；
  经营利润 →（±商誉摊销/财务损益/非经常）= 税前利润；税前 − 所得税 = (持续经营)净利润；
  持续 + 终止 = 合并净利润；合并 − 少数股东 = 归母。
- **资产负债**：资产总计 = 负债及权益总计；流动 + 非流动 = 总计；流动负债 + 非流动负债 + 权益 = 总计；股本+储备+留存 = 归母权益。
- **现金流**：经营 + 投资 + 融资 + 恶性通胀 + 汇率 = 现金净变动；期初 + 净变动 = 期末。
- **跨表**：利润表税前利润 = 现金流量表税前利润；资产负债表货币资金 = 现金流量表期末现金；
  上年期末现金 = 本年期初现金（**折算成同一单位后再比** —— 直接比印刷值会造出三条假断点，本库自查实证）。
- **DM→EUR 换算独立验证**：1999 营收按 1.95583 折算后必须等于 2000 年报印的欧元值（见上「七件事」第 2 条）。
- **分部三重勾稽**（`_build_segments.py`）：分地区合计、分产品合计**两路各自**对上利润表营收（差异 <3%）。
  > ⚠️ 只对一路 = 没跑（本库茅台实证：分产品那路全过、分渠道那路整体左移一列却从没被发现）。

**当前状态**：三表 32 年勾稽**全过**；分部两路 28 年勾稽**全过**（最大差 0.5%，为总部/未分摊）。
唯一保留提示：2002 期末现金 €76.0mn ≠ 2003 期初现金 €67.5mn —— 这是**真实重述**（2003 年报把 8.5 从现金拆入短期金融资产），已入 `重述与口径变更.csv`。

## 解析踩过的坑（换公司也会遇到，记下来）

1. **🔴 挑列陷阱（机械右对齐必错）**
   - **1998 年报三表各印三列**：①1998 adidas-Salomon 合并 ②1998 adidas「comparable」**备考**（剔 Salomon）③1997 restated。
     取最右列会拿到 1997 年数，取第二列会拿到一个**从未存在过的备考主体**。本库取 ①。
   - **2006 年报利润表在 Change 列右侧另印「2006 excl. Reebok」备考列**：取最右数字会把 2006 营收读成 7,548（真值 10,084）。
   - **2012 / 2018 年报资产负债表有第 4 列「Jan. 1 重述期初」**，不是本年数。
2. **连字符（ligature）吃掉整年数据**：2005–2008 年报文本层用 `ﬁ`/`ﬂ` 合字，
   `financing`/`profit` 正则**全部匹配不上** → 定位器一度判这四年「无现金流量表」。必须先做连字归一。
3. **行首混入页码**：2013 年报 `Total assets` 那行印成 `186        Total assets ...`，
   `^\s*Total assets` 匹配失败 → 整张资产负债表被判缺失。必须先剥行首孤立页码。
4. **「倒锁链挑表」**：`Consolidated Income Statement` 在一份年报里出现 6–22 次（目录/页眉/附注/重述对照表/十年概览）。
   靠标题打分会挑中**IAS 8 重述对照表**（2012 就中过）。判据要三条叠加：
   锚科目聚集 + 带准则与币种的正式表头 + **取「合并财务报表」章节里最靠前的那一组**（重述表永远在附注里、靠后）。
5. **十年概览表宽到被 pdftotext 拆成 4 段**，且行标签换行后与数字错位 —— 只可当交叉核对用，**不可当取数源**。
