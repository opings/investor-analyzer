## 🅰 读 adidas 财报特有的知识（排雷相关，非模式复述）

### 1. 🔴 行业模板里的三个核心雷达，adidas **不披露**

行业模板对中国同业（李宁/安踏/特步）列的三件表外武器，在 adidas 这里**要么不存在、要么口径不同**：

| 行业模板指标 | 中国同业 | adidas | 替代读法 |
|---|---|---|---|
| 零售流水（retail sell-through） | 季度运营公告按品牌披露 | **不披露** | 用 **DTC 汇率中性增速** 当 sell-out 代理（季度业绩稿给） |
| 渠道库存周转月数 | 部分公司自愿披露 | **不披露** | 无直接替代；只能看**自家存货 + 营运资本/营收**，**渠道那一段是黑箱** |
| 销售点（POS）净增减 | 季度披露 | **不披露** | 无 |

> **结论**：**adidas 的表外压货风险比中国同业更难被外部观察**。
> 本库能拿到的最接近的一组是「**DTC 增速 vs 批发增速的背离**」——见下方核心变量 ①。

### 2. 「汇率中性」与「欧元口径」是两个数

adidas 所有增长指引与 MD&A 主叙述用**汇率中性（currency-neutral）**，但三表是**欧元口径**。
两者可以差很多（2026 上半年：汇率中性 +14%、欧元口径 +10%，差约 4 亿欧元）。
**比增速前必须先声明用哪个口径**；本库 `财务数据/` 全部是欧元口径 as-reported。

### 3. 无「扣非」口径，一次性项目要逐项手工辨认

德国/IFRS 无法定扣非线。历史上大额一次性项包括：
在研研发一次性费用化（1998）、商誉减值（2012–2015 连续四年）、
终止经营损益（2005 / 2014-17 / 2021-22 三轮剥离）、美国关税退款（2026 起）。
**跨年比净利前必须先查这几类**，否则会把一次性当经营趋势。

### 4. 分部口径六代、不可跨代拼接

见 `财务数据/分部营收.csv` 的「口径代」列与 `重述与口径变更.csv`。
**每次重划都发生在业绩转折点附近**（2015、2018、2021、2024），
拿跨代序列算增速是本公司最容易踩的错。

## 🅱 核心跟踪变量（5 个）

### ① 🔴 DTC 增速 − 批发增速的缺口（本公司最重要的压货代理指标）

- **数据落点**：`财务数据/分部营收.csv`（渠道维度，年度）；季度值见公司业绩稿。
- **频率**：季度（Q1/H1/Q3/FY 业绩稿）。
- **怎么读**：
  - **DTC 增速 > 批发增速** = sell-out 快于 sell-in = 渠道在去库存或公司在主动控货 → 健康。
  - **批发增速 > DTC 增速** = 向渠道压货 → 🔴 **这是本行业的头号结构性风险**。
  - **两者同时高增** = 需与自家存货交叉验证（见变量 ②）。
- **警戒线**：**批发增速连续两个季度高于 DTC 增速 5pp 以上** → 🟡；**连续三季** → 🔴。
- **触线动作**：回查该期存货增速与毛利率；若存货同步膨胀且毛利率未降 → 按「事反必妖」升级为 🔴，
  并在 `knowledge/companies/阿迪达斯/` 记事实。

### ② 🔴 存货增速 vs 营收增速；存货周转天数

- **数据落点**：`财务数据/资产负债表.csv`（存货）、`财务数据/财务比率.csv`（存货周转天数 DIO）。
- **频率**：季度（业绩稿给存货余额）、年度（年报给完整口径）。
- **警戒线**：
  - **存货增速 − 营收增速 > 8pp** → 🟡；**> 15pp 或连续两年为正** → 🔴。
  - **DIO 较前三年均值抬升 > 15 天** → 🟡。
- **触线动作**：查存货减值计提是否同步（**抬升而毛利率不降 = 减值滞后**）；
  查公司对增长的归因是否可被 DTC 数据佐证。
- **历史刻度**：2022 那轮以「经营现金流为负 + 次年利润归零」收场；2025–2026 又在同一模式里，**尚未见分晓**。

### ③ 🔴 经营现金流 ÷ 合并净利（现金含量）

- **数据落点**：`财务数据/财务比率.csv`（现金含量两行，分别以合并净利与归母净利为分母）。
- **频率**：半年 + 年度。
- **警戒线**：**单年 < 0.8** → 🟡；**连续两年 < 0.8 或任一年为负** → 🔴。
- **触线动作**：拆到营运资本三项（存货 / 应收 / 应付）看差额堰塞在哪；
  **⚠️ 分母接近零时该比率会失真**（2023 年读数 −187.9 无意义），此时改用「经营现金流 ÷ 营收」。

### ④ 🟡 毛利率 与 营销及销售点费用率 的组合

- **数据落点**：`财务数据/财务比率.csv`（毛利率、营销及销售点费用率、经营利润率）。
- **频率**：季度。
- **怎么读**：**这门生意的利润率 = 毛利率 − 费用率**，而**费用率是公司自己选的**。
  毛利率上升但经营利润率下降 → 说明增长是买来的（2026 Q2 即如此）。
- **警戒线**：**营销费用率同比 +1.5pp 以上而经营利润率同比为负** → 🟡，记入事实编年并跟踪是否延续。

### ⑤ 🟡 分市场增速（尤其大中华与北美）+ 鞋类增速

- **数据落点**：`财务数据/分部营收.csv`（地区维度、产品维度）。
- **频率**：季度。
- **警戒线**：
  - **大中华连续两季汇率中性负增长** → 🟡（本库已建的同业——耐克 / 安踏 / 李宁 / 特步 / 361 度——都在这个市场正面竞争，
    是**横比信息最齐全的一段**，触线时可直接跨公司对照）。
  - **鞋类（占营收约六成）连续两季汇率中性增速 < 3%** → 🟡：最大品类停滞而总营收靠服装单腿撑。
- **触线动作**：查公司给的归因；⚠️ **归因只能靠外部信息验证**——
  一家公司的财报里结构性不含对手与终端的信息，别拿 adidas 自己的报表去证实「是不是竞争问题」。

## 🅲 本公司独有红旗

| 级别 | 红旗 | 判据与数据落点 |
|---|---|---|
| 🔴 | **单一合作方/单一 IP 的收入集中** | Yeezy 已实证：2022 年贡献 >12 亿欧元营收、终止后两年才消化完。**年报不按合作方披露收入** → 无法从报表证伪，只能靠事实编年跟踪新签的大额合作 |
| 🔴 | **存货增速持续快于营收且毛利率不降** | 见核心变量 ②；本公司 2022 与 2025–2026 两次落入该模式 |
| 🟡 | **商誉与无形资产减值** | 2012–2015 连续四年计提商誉减值（`财务数据/利润表.csv`）——**这家公司的减值是会真发生的**，不是纸面风险。盯商誉/归母权益占比（`财务比率.csv`） |
| 🟡 | **分部口径重划** | 每次重划都在业绩转折点附近（2015/2018/2021/2024）。**重划本身不是造假，但它让跨期比较失效**——发现重划就要回 `重述与口径变更.csv` 登记 |
| 🟡 | **递延所得税资产（DTA）规模与走向** | 常年 10 亿欧元级、占总资产约 5%。**2023 亏损年 DTA 反而升到 13.6 亿**（`资产负债表.csv`）——DTA 可回收性依赖未来盈利，利润塌陷年做大 DTA 须追问依据 |
| 🟡 | **美国关税与退款的确认时点** | 2026 年公司称另有 2.5–3.0 亿美元潜在可收回退款、**未计入指引**。退款计入毛利会美化毛利率 → 出现时须单独剔除再比 |
| 🟡 | **汇率**（欧元口径 vs 汇率中性） | 欧元升值年份，欧元口径营收会显著低于汇率中性口径（2026 H1 差近 4 亿欧元）。**比增速先对齐口径** |
| 🟢→🟡 | **高管更替密度** | 2023 换 CEO、2026 年底换 CFO（前任在职近 30 年）。单次不是红旗；**若与业绩口径变更同期发生**则升级 |

## 🅳 历史踩过的坑 / 管理层记录

- **2006 收购 Reebok**：商誉 + 无形资产一度占归母权益 113%，随后经历 2012–2015 连续减值与 2021-22 剥离，
  到 2025 年降至 28%（`财务数据/资产负债表.csv` 派生）。**大并购 → 减值 → 剥离，是这家公司已完成过一轮的完整剧本。**
- **2022-10 终止 Yeezy 合作**：随后启动仲裁；剩余库存分批售出、部分收益捐出（2023 年报 Note 20）。
- **审计意见**：2025 年报为**无保留**意见【源·2025 年报审计报告】。
- **未入库项（⏳待补）**：关联方交易明细、应收账龄与坏账计提、高管薪酬考核指标与股权激励行权条件。

|---|---|
| **季度**（Q1 约 4 月底 / H1 约 7 月底 / Q3 约 10 月底 / FY 约次年 3 月初） | 抓业绩稿：DTC vs 批发增速、分市场与分产品汇率中性增速、存货余额、毛利率与营销费用率、指引变化 |
| **年度**（次年 3 月初年报） | 跑 `_build_from_pdf.py` + `_build_ratios.py` + `_build_segments.py` 补新一年；**先查年报脚注有无重述**，有则登记 `重述与口径变更.csv` |
