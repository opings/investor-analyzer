# 财报关注要点 · 行业模板

> **用途**：新增一家公司时，从下面挑**最接近的行业块**复制到 `finance/<公司>/财报关注要点.md`，再按该公司微调（删不适用项、补公司独有项）。
> 这是「风险预警第二层（公司/行业特有）」的起点——通用红旗在 `财报阅读规则.md` Step 3，本文件解决"每个公司指标各不相同"。
> 每条特有指标同样按 🔴/🟡/🟢 分级，带数据依据，纳入风险预警表。

## 通用骨架（每个公司都填）

```markdown
# <公司> 财报关注要点

- **估值法**：<成长(老唐)/周期(席勒)/无法估值>
- **核心跟踪变量（3-5 个，最该盯的）**：…
- **本公司独有红旗 / 易暴雷点**：…
- **历史踩过的坑 / 管理层诚信记录**：…
```

## 白酒 / 高端消费品（茅台·古井·洋河·农夫·安踏）
- **合同负债（预收款）**：环比/同比——经销商打款意愿的"蓄水池"，**骤降是需求转弱预警**（🟡，连续降→🔴）。
- **吨价 / 产品结构**：高端占比、提价落地——驱动毛利率。
- **应收账款**：白酒龙头本应极低（先款后货）；**应收异常上升=放货压库**（🔴）。
- **存货**：基酒/老酒是"宝"，但成品酒积压+周转下降要警惕。
- **销售费用率 / 预收 vs 营收节奏**：渠道压货 or 真实动销。
- **分红与回购**：现金如何还股东（老唐/段都看重）。

## 银行 / 金融
- **不良率 + 关注类贷款迁徙率**：资产质量，**跳升是核心雷**（🔴）。
- **拨备覆盖率 / 拨贷比**：安全垫，过低🔴、过高可能藏利润。
- **净息差(NIM)**：盈利能力主引擎，趋势下行🟡。
- **核心一级资本充足率**：扩张/分红空间。
- **房地产/城投/表外敞口**：集中度风险。
- ⚠️ 银行用 PB / 股息率框架，**老唐三大前提/PE 法不直接适用**——单独处理。

## 周期 / 资源（陕煤·中海油·胜狮·分众）
- **产能利用率 / 开工率**：景气位置。
- **产品价格（煤/油/运价/广告刊例）**：自己是价格接受者，**价格趋势决定一切**。
- **库存周期**：补库/去库阶段。
- **单位成本 / 完全成本**：周期底部能否不亏（决定能否扛过周期）。
- **资本开支节奏**：顺周期扩产=见顶信号。
- ⚠️ 用席勒法（十年均值），**严禁单年 PE**；当前周期位置比精确估值更重要。

## 互联网 / 平台（腾讯·拼多多·泡泡玛特）
- **递延收入 / 合同负债**：预付的订阅/充值，先行指标。
- **获客成本 / 销售费用 vs 用户增长**：增长是否"买来的"。
- **经营杠杆 / 分部盈利**：哪块真赚钱、哪块烧钱。
- **股权激励(SBC)占比**：稀释，看 Non-GAAP 也要看摊薄。
- **回购**：腾讯式回购=帮股东买入。
- ⚠️ **爆款/IP 集中度**（泡泡玛特 Labubu 占比、游戏单品依赖）——过高且生命周期不定→可能**无法估值**（能力圈外）。

## 医药 / 创新药
- **研发费用资本化比例**：资本化越多、利润越"虚"（🔴 若激进）。
- **集采 / 医保谈判敞口**：核心品种降价风险。
- **单品种依赖度**：大单品占比过高=政策/专利悬崖风险。
- **商誉（License-in 并购）**：减值风险。
- ⚠️ 老唐/段永平明确"不碰制药"——能力圈外可直接归"太难"。

## 制造 / 重资产（赛力斯·海康·胜狮）
- **资本开支 / 折旧 vs 净利**：是否"碎钞机"——重资产用**完整 DCF 看自由现金流**比净利更真。
- **存货 + 应收双升**：需求转弱或压货。
- **产能扩张 vs 订单**：过度扩张风险。
- **客户集中度 / 大客户应收**：单一客户依赖。
- **毛利率 vs 同业**：成本/定价权。

---

> 没有完全匹配的行业 → 选最近的 + 通用骨架，逐项问"这门生意靠什么赚钱、最容易在哪暴雷"，把答案变成 3-5 个跟踪变量。
