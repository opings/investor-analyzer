# 财报阅读规则（价值投资体系 · 通用 SOP）

> **用途**：拿到任何一家公司的财报（年报 / 季报）后，**先按本规则逐项提取关键数据，再得出总结**——不要凭印象直接下结论。
> **原则**：
> - 「财报是用来排除企业的，不是用来证明企业优秀的。」有疑点就排除，不需要证明它造假。
> - **本项目只做公司客观分析**——不出现"我懂不懂 / 我出多少价 / 我押多少 / 我现在买不买"等主观决策；估值/买卖点不进 `finance/`。
> - **数字一律落 `财务数据/<csv>`**——`财务数据/` 是公司所有数字的**唯一真源**（三表 + 比率 + 分部 + 公司/行业特有指标 + 分析过程派生指标），其他 `.md` 文件**不复制数字**只引用。
> **配套**：通用规则在此；每家公司的特有看点见各自目录下的 `财报关注要点.md`。

---

## Step −1（前置·硬门槛）：先建事实底座，没有就先下载，再分析

> **铁律**：分析任何公司前，下面**三样必须先到位**；缺任一样就**先补齐，再往下走**——**绝不允许在残缺底座上出分析结论**。
>
> **🚨 硬 gate（不许口头带过·不许"6 份年报 = 全集"的隐性简化）**：进入 Step 0 之前，**必须显式输出「底座盘点表」并逐格打钩**；表内任一 ❌ 立即停下补，绝不进 Step 0。**曾在实盘中发生**：分析泡泡玛特时把"6 份年报"当作"一手财报 PDF 全集"直接放行，招股书 + 中报 + 季报全部隐性跳过——就是 gate 缺失导致的隐性妥协。

### 底座盘点表（必填·任一 ❌ 硬停）

| 类别 | 应有内容 | 命名规范 | 实际状态（`ls report/<公司>/` 等自证） | 打钩 |
|---|---|---|---|---|
| ① 三表 CSV | 覆盖上市至今全部年份 | `finance/<公司>/财务数据/{利润表,资产负债表,现金流量表,财务比率,分部营收}.csv` | | ✅/❌ |
| ② 事实编年 | 近 3 年 | `knowledge/companies/<公司>/YYYY-MM.md` | | ✅/❌ |
| ③a **招股说明书** | IPO 发行文件（独家含上市前 3 年经审计数据） | `report/<公司>/招股说明书.pdf`（补充 → `-YYYY-MM补充.pdf`） | | ✅/❌ |
| ③b **上市至今全部年报** | 一份都不能少 | `report/<公司>/YYYY.pdf`（每年一份） | | ✅/❌ |
| ③c **中报** | 上市至今每年一份 | `report/<公司>/YYYY-H1.pdf` | | ✅/❌ |
| ③d **季报**（A 股必备/港股按披露） | 上市至今每期一份 | `report/<公司>/YYYY-Q1.pdf` `YYYY-Q3.pdf` | | ✅/❌ |

> **打钩纪律**：
> - **"这就是全部可得" ≠ ✅**：需先跑 `scripts/notices.py` 或港交所披露易/巨潮**实证不可得**，才能给 ✅ 并备注"实证不可得"；未查证 = ❌。
> - **任一 ❌ → 硬停**：不允许"结论大概率不变"这类效率理由跳过。skill 的价值就在于防止这种隐性妥协。

### 三样详情

1. **上市至今三表 CSV（从 ③ 一手财报 PDF 解析）** —— canonical 落在 `finance/<公司>/财务数据/{利润表,资产负债表,现金流量表}.csv`，**逐行解析自 ③ 的财报 PDF（一手财报是唯一真源）**，单位按财报原始口径。
   - **起点 = 招股书披露的上市前最早年份**（招股书含 IPO 前 3 年财务数据，直接采纳）；**终点 = 最新一份定期报告**（年报 / 中报 / 季报，谁最新用谁）。年份序列 = 招股书补齐的上市前 + 上市至今全部年报；如需季度粒度，另建 `财务数据/利润表-季度.csv` 等 `-季度` 版按季存中报/季报数字。
   - 解析后**必做三表勾稽自洽校验**（损益:收益−成本=毛利、+所得税=净利；资产=负债+权益；现金流:经营+投资+融资=净变动、年初+净变+汇率=年末）——勾不平 = 解析错，回查 PDF。建议写数据脚本（如 `财务数据/_build_from_pdf.py`）固化数据 + 自动校验，**校验不过不写出**。
   - **不用东财二手**（`fetch_fundamentals.py`/`_raw_akshare/` 已弃用）——二手会错（农夫「经营业务现金净额」256 亿实为税前、真 211 亿），有一手后再用会错的二手对账无意义。**三表 + 衍生比率唯一来源 = 一手财报解析**；ROE/现金含量/capex 比/毛利率等比率从一手三表算（年报不直接给比率，见 `财务数据/财务比率.csv`）。
2. **近 3 年事实编年** —— 落在 `knowledge/companies/<公司>/YYYY-MM.md`（只记客观事实+一手来源）。
   - 没有就先补（巨潮公告 / 业绩 / 分红 / 监管 / 高管变动等），再分析。
3. **一手财报 PDF 全集** —— 起点 = 招股书，终点 = 最新一份定期报告；覆盖 **招股书 + 上市至今全部年报 + 中报 + 季报**（一份都不能少·上表 ③a-③d 每格都得打勾），落在 `report/<公司>/`：
   - 下载法（A股/港股均走巨潮 cninfo）：`python3 scripts/notices.py <发布窗口起> <止> <代码>` 探到目标披露的 announcementId（招股说明书=上市当年发行文件；年度报告次年 3–4 月；一季报 4 月底；中报 8 月；三季报 10 月），再按直链 `http://static.cninfo.com.cn/finalpage/{公告日期}/{id}.PDF` 用 `curl -fsSL` 下载。
   - 下载后**必验**：`file` 为 PDF + 大小 MB 级（错误页是几 KB 的 HTML）+ 抽读首页确认公司/年份/期间无串号。
   - **为什么每一类都必须有**：CSV 是东财**二手**、会错（农夫 2026-06 实证：现金流量表 CSV「经营业务现金净额」把税前 256 亿误标成净额，真净额 211 亿，靠一手年报才仲裁清）；一手财报是**二手数据的仲裁源**，且独家含董事会报告/附注（CSV/编年都没有）；**招股书**独家含上市前 3 年经审计数据（是上市早期年份的唯一真源），**中报/季报**是最新经营动向的唯一一手来源（年报有 3–6 个月滞后，只用年报 = 用过期底座估当下）。

> 底座不全 = 地基没打就盖楼。**三样缺一就停下来补，绝不在残缺数据上分析。**

### `财务数据/` 是数字的唯一真源（不限于三表）

> 公司所有数字都落 `财务数据/`，不只是三表。`分析.md` / `财报关注要点.md` **不复制数字**，只引用。

| 数据类型 | 落点 | 来源 |
|---|---|---|
| 三表（利润/资产负债/现金流） | `财务数据/{利润表,资产负债表,现金流量表}.csv` | 从一手财报 PDF（招股书 + 年报 + 中报 + 季报）解析 |
| 衍生比率（ROE/毛利率/现金含量/capex 比…） | `财务数据/财务比率.csv` | 从三表派生（年报不直接给） |
| 分部 / 区域 / 产品收入 | `财务数据/分部营收.csv` | 从年报 MD&A 解析 |
| 公司/行业特有数据（基酒/产能/批价/经销商/不良率/土储/产能利用率…） | `财务数据/<主题>.csv` | 从年报董事会报告/附注解析；非年报来源（如批价）单独标注 |
| 分析过程派生指标（销售收现÷营收、批价÷出厂价、应收增速÷营收增速…） | `财务数据/<指标>.csv` 或并入相关 csv 加列 | 分析中算出，**回写**到 `财务数据/` |

> **双向流动**：PDF 解析 → `财务数据/`（入）；分析中派生 → `财务数据/`（回流）。最终结果：单一公司的所有数字都在 `财务数据/` 一处可查。
> 每个 `财务数据/` 目录配一份 `README.md`（套模板 `_模板/财务数据-README模板.md`），标注数据血缘 + 文件清单（PDF 解析 / 分析派生 两类）+ 勾稽校验状态。

## Step 0：判断生意类型（公司客观属性）

> 生意类型是**公司客观属性**（看生意特征），定下来后进 `分析.md`「公司分析速览」的「生意类型」字段。

| 类型 | 客观特征 | 提取重点（数字落 `财务数据/`） |
|------|---------|--------------------|
| **成长稳定** | 利润稳定增长的好生意（茅台/腾讯/古井/农夫） | 扣非净利序列 + 增速 + 次年经营计划 |
| **强周期** | 利润随商品价格/景气大起大落（陕煤/中海油/分众/胜狮） | 近十年扣非净利序列 + 周期位置；单年净利不可外推（客观属性） |
| **不确定生意** | 爆款依赖 / IP 周期短 / 技术路线未定 / 缺乏稳定盈利（部分互联网/创新药） | 归"太难" |

## Step 2：三大前提验证数据

### ① 利润为真？（看现金，不看账面）

| 数据 | 出处 | 看什么 |
|------|------|--------|
| 经营活动现金流净额 | 现金流量表 | 与净利润比，**现金含量是否 ≥1** |
| 销售商品/提供劳务收到的现金 | 现金流量表 | 是否 ≥ 营业收入 |
| **合同负债（预收款）** | 资产负债表 | 余额及环比——先款后货型企业的「蓄水池」，骤降是预警 |
| 应收账款 | 资产负债表 | 增速 vs 营收增速；应收涨得快于营收 = 放宽信用催肥利润 |

### ② 维持利润需要大量资本开支吗？

| 数据 | 出处 | 看什么 |
|------|------|--------|
| 购建固定资产/无形资产支付的现金（资本开支） | 现金流量表 | **占净利润比例**——个位数=印钞机，过半=碎钞机 |
| 在建工程 | 资产负债表 | 规模、是否长期挂账不转固（藏雷点） |

### ③ 利润可持续吗？

| 数据 | 出处 | 看什么 |
|------|------|--------|
| 毛利率 | 利润表 | 趋势是否稳定/提升；异常波动要追因 |
| ROE | 财报/计算 | 长期水平与趋势 |
| 三费率（销售/管理/研发/财务） | 利润表 | 费用率趋势 |
| 商业模式定性 | 董事会报告 | 刚需？提价权？抗通胀？护城河有无变化 |

### ④ 三表勾稽补充取数（供 Step 3.0 勾稽用，非新增关注点）

> 下列均为**所有公司通用**的标准报表行项，提取它们只为喂饱 Step 3.0 的跨表勾稽——不是公司特有关注点（那些在 `<公司>/财报关注要点.md`）。

| 数据 | 出处 | 喂哪条勾稽 |
|------|------|-----------|
| 货币资金 | 资产负债表 | 货币资金 ↔ 有息负债/利息（存贷双高） |
| 净资产（归母所有者权益） | 资产负债表 | 累计净利 ↔ 净资产增长 |
| 利息收入 | 利润表/财务费用附注 | 货币资金真实性——**仅在存贷双高/货币资金存疑时深挖**，平时只提数 |
| 预付款项 / 其他应收款 / 其他流动资产 | 资产负债表 | 利润 ↔ "垃圾筐"科目（假利润常藏处） |

## Step 3：风险预警（两层 + 分级，逐科目扫一遍，有疑点就排除）

> **风险预警 = 两层**：
> ① **通用红旗层** —— 与行业无关、所有公司通用的财报结构性造假/暴雷信号。**canonical 源是会随真实案例增长的 `knowledge/造假案例库/造假模式库.md`**（下表为速查种子，完整、最新、带来源案例的版本以该库为准）；新案例通过 `ingest-fraud-case` 蒸馏进去。
> ② **公司/行业特有层** —— 各公司指标不同（白酒看合同负债、银行看不良率、周期看产能利用率…），写在 `<公司>/财报关注要点.md`，新公司可从 `_模板/财报关注要点-行业模板.md` 套最近行业起步。
>
> **分级**：🔴 暴雷嫌疑（出现即高度警惕，可能直接排除）/ 🟡 需关注（异常，追因后定性）/ 🟢 正常或已解释。
> **严重度看公司语境**：同一信号在不同公司权重不同（如高商誉对连续并购者是常态→🟡，对从不并购者→🔴）。每条结论必须带**数据依据**。

### 3.0 三表勾稽自查表（先做这个，再走红旗清单）

> **底层逻辑**：利润表可以编故事，但**编出来的假利润必须在资产负债表里找个壳装着**——要么变成虚增的货币资金、收不回的应收、盘不清的存货，要么藏进在建工程 / 商誉 / 预付款 / 其他应收款。勾稽就是顺着「**利润 → 现金 → 资产**」这条链找断点：哪里对不上，假利润大概率就堰塞在那个鼓起来的科目里。
> **它和红旗清单的分工**：勾稽**动态找方向**（定位哪个科目鼓包），红旗清单**静态查实**（对着鼓包的科目逐项深挖）。所以勾稽放在前面。
> **与 Step 2① 的分工**：Step 2① 的「现金含量」是**「利润为真」前提**（利润有无现金支撑/含金量）；这里同一条「现金 vs 利润」是**排雷**（差额跑哪去了、是不是假的）。视角不同，不重复。
>
> **🚨 硬 gate（`分析.md` 五、5.0 表 6 行不许留空）**：6 条必须**全部有判定（🔴/🟡/🟢/⏳）+ 数据依据**；判定缺任一行 = 违反"先勾稽后写小结"的执行顺序，"六、小结"必须在 6 条全填后再写。

| 必查矛盾 | 怎么对 | 命中含义 | 顺藤摸瓜查哪个科目 | 默认级别 |
|---|---|---|---|---|
| **利润 ↔ 经营现金流** | 净利润 vs 经营活动现金流净额，现金含量长期 <1 | 利润没收到真金白银 | 差额是否被应收账款 / 存货增量吃掉 | 🟡（连续多期 →🔴） |
| **营收 ↔ 收现 ↔ 应收** | 营收增长，但「销售商品收到的现金」没同步、应收账款大增 | 收入可能是赊出来 / 虚构的 | 应收增速 vs 营收增速、账龄、坏账计提 | 🟡 |
| **货币资金 ↔ 有息负债 / 利息** | 账上巨额货币资金 + 同时大额有息负债；或货币资金巨大但利息收入极低 | 钱可能是假的 / 受限（存贷双高） | 货币资金真实性、是否质押冻结、利息收入是否匹配 | 🔴 |
| **累计净利 ↔ 净资产增长** | 多年赚大钱，但净资产没同步涨、也没大额分红 | 赚的钱没变成家底 = 利润存疑或被占用 | 分红去向、其他应收款 / 关联方占款 | 🟡 |
| **资产扩张 ↔ 现金来源** | 固定资产 / 在建工程 / 商誉大增，经营现金流撑不起 | 靠融资堆资产，或在建工程虚增藏费用 | 在建工程是否长期挂账不转固、商誉减值 | 🟡 |
| **利润 ↔ "垃圾筐"科目** | 预付款 / 其他应收 / 其他流动资产异常膨胀 | 利润找不到现金归宿时常藏在这里 | 这些科目的交易对手、是否关联方 | 🟡 |

> 任一矛盾命中 → 先**定位鼓包科目**，再去下方红旗清单对该科目深挖；能合理解释则降级 🟢，否则保留进跟踪变量。多条矛盾同时命中、且都指向同一科目 → 升级。

### 通用红旗清单（全公司适用）

| 默认级别 | 红旗 | 含义 / 怎么看 |
|------|------|------|
| 🔴 | **存贷双高** | 大额货币资金 + 大额有息负债并存 = 钱可能是假的（康得新/康美式） |
| 🔴 | 毛利率升 + 应收增 + 应付减 | 典型造假嫌疑（事反必妖） |
| 🔴 | 存货周转率降 + 毛利率升 | 大概率造假 |
| 🔴 | 审计意见非标准无保留 | 直接高度警惕 |
| 🔴 | 货币资金充裕却借高息债 / 大额理财 | 资金真实性存疑 |
| 🟡 | 商誉占净资产比例高 | 并购后遗症，关注减值测试与业绩承诺到期 |
| 🟡 | 其他应收款 / 关联方占款大 | 资金被占用/向大股东输送 |
| 🟡 | 在建工程长期挂账不转固 | 藏费用 / 虚增资产 / 推迟折旧 |
