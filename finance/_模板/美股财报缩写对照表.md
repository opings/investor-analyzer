# 美股财报缩写对照表（canonical·通用）

> 分析美股公司时反复出现的英文缩写与术语。**本表是单一真相**——各公司 `分析.md` / `财报关注要点.md` 只放"本文用到的精简版"并链回此处。
> 首次沉淀于 google（Alphabet）建库（2026-07），后续美股公司通用。A 股/港股专有口径见 `财报阅读规则.md`「跨市场口径约定」。

## 一、SEC 申报文件与系统

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **SEC** | U.S. Securities and Exchange Commission | 美国证券交易委员会 | 美股监管机构，一手申报的接收方 |
| **EDGAR** | Electronic Data Gathering, Analysis, and Retrieval | SEC 电子申报检索系统 | 一手文件下载处（对应 A 股/港股的巨潮 cninfo） |
| **10-K** | Annual Report | 美股**年报** | 含完整三表 + 全部附注 + 风险因素 + 审计意见。**年度定性的唯一一手全貌** |
| **10-Q** | Quarterly Report | 美股**季报** | 含中期三表 + 中期附注（OI&E 拆解、限售条款、表外承诺、存货口径只在这里）。**季度定性必须等它** |
| **8-K** | Current Report | 美股**临时报告** | 重大事项即时披露，业绩新闻稿走这个。**只是摘要，不含附注——不足以下定性结论** |
| **S-1** | Registration Statement | 美股**招股书** | IPO 注册说明书，独家含上市前若干年经审计数据 |
| **S-8** | — | 员工股权计划证券注册 | 为员工股权激励注册可发行股份 |
| **Form 4** | — | 内部人持股变动报告 | 董监高买卖本公司股票的申报 |
| **accession (number)** | — | SEC 申报流水号 | 形如 `0001652044-26-000071`，定位某一份具体申报 |
| **CIK** | Central Index Key | SEC 申报主体编号 | 公司在 SEC 的唯一 ID。**注意主体重组会产生新旧双 CIK** |
| **XBRL** | eXtensible Business Reporting Language | 机读财报标签标准 | 公司自报的结构化财报数据 |
| **iXBRL** | inline XBRL | 标签内嵌进网页的申报格式 | 现行申报格式，一份 HTML 同时给人看和给机器读 |
| **companyfacts** | — | SEC 机读接口 | 返回某主体全部历史标准标签数据，**是一手非第三方聚合** |
| **MD&A** | Management's Discussion and Analysis | 管理层讨论与分析 | 财报中公司自述经营情况的章节。**含公司自己的归因，属【公司自述】须打折** |

## 二、会计科目与财务指标

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **OI&E** | Other Income (Expense), net | **其他收入（支出）净额** | 利润表上经营利润下方的一整行，装**主业之外**的全部损益：利息收支、汇兑、债券损益、**股权投资公允价值变动**、权益法损益等。**这行大了，报告净利就不能当经营成绩读** |
| **EPS** | Earnings Per Share | 每股收益 | 基本 EPS / 稀释 EPS（含潜在摊薄股份） |
| **FCF** | Free Cash Flow | 自由现金流 | = 经营活动现金流 − 资本开支。衡量"赚的钱扣掉必须再投入后还剩多少" |
| **OCF** | Operating Cash Flow | 经营活动现金流净额 | 主业实际收到的现金 |
| **capex** | capital expenditures | 资本开支 | 购建固定资产/无形资产支付的现金 |
| **SBC** | Stock-Based Compensation | 股权薪酬 | 以股票支付的员工报酬，非现金费用但**真实摊薄股东** |
| **APIC** | Additional Paid-In Capital | 资本公积 | 发行价超出面值的部分 |
| **OCI** | Other Comprehensive Income | 其他综合收益 | **不进净利、直接进权益**的损益（如部分汇兑、可供出售债券公允价值变动） |
| **AOCI** | Accumulated OCI | 累计其他综合收益 | OCI 的资产负债表累计数 |
| **PP&E / PPE** | Property, Plant and Equipment | 固定资产 | 房产、厂房及设备 |
| **AR** | Accounts Receivable | 应收账款 | |
| **ROE** | Return on Equity | 净资产收益率 | |
| **YoY** | Year over Year | 同比（与去年同期比） | |
| **FY / H1 / Q1–Q4** | Fiscal Year / First Half / Quarter | 财政年度 / 上半年 / 第一至四季度 | |
| **GAAP** | Generally Accepted Accounting Principles | （美国）公认会计准则 | ⚠️ 其下**股权证券公允价值变动直接进净利、不走 OCI** —— 持大额股权投资的公司净利会被浮盈浮亏主导 |
| **IFRS** | International Financial Reporting Standards | 国际财务报告准则 | 港股/欧股常用 |
| **Level 1 / 2 / 3** | fair value hierarchy | 公允价值三层级 | 1 = 活跃市场报价（最可靠）；2 = 可观察输入值（如同类交易价）；3 = 不可观察输入值（模型估，最软） |
| **measurement alternative** | — | 计量替代法 | 无公开报价的私营公司股权，平时按成本记，**仅在出现可观察交易时重估** |
| **take-or-pay** | — | 照付不议合同 | 不管用不用都得付钱，属**硬性表外承诺** |
| **capped call** | — | 上限看涨期权交易 | 公司买入，用于对冲可转换证券转股时的摊薄 |
| **ATM (Program)** | At-The-Market offering | 随行就市增发计划 | 可择时按市价零散卖新股的常备额度。**不是自动柜员机**——是持续性摊薄水龙头 |
| **revenue backlog / RPO** | remaining performance obligations | 收入储备 / 剩余履约义务 | 已签约未确认收入。⚠️**口径可能变更**（如是否纳入短期合同），跨期相减前先核 |

## 三、监管与机构

| 缩写 | 英文全称 | 中文 | 说明 |
|---|---|---|---|
| **EC** | European Commission | 欧洲委员会 | 欧盟执行机构，反垄断执法主体 |
| **DMA** | Digital Markets Act | 欧盟《数字市场法》 | 针对"看门人"平台的事前监管，可要求开放数据/互操作，**不止罚款** |
| **DOJ** | Department of Justice | 美国司法部 | 联邦反垄断执法 |
| **AAG** | Assistant Attorney General | 助理总检察长 | 此处指 DOJ 反垄断部门主管 |
| **FTC** | Federal Trade Commission | 美国联邦贸易委员会 | 另一反垄断执法机构 |
| **COSO** | Committee of Sponsoring Organizations | 美国内控评价框架 | 管理层评价内控有效性所依据的标准 |
