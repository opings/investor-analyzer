## 勾稽自洽校验

由 `_build_from_pdf.py`（LLM 提取 + 校验固化）生成，**每年**验证：
- **损益**：收益 − 成本 = 毛利；除税前 + 所得税 = 净利
- **资产负债**：总资产 = 总负债 + 权益；股本 + 储备 = 权益
- **现金流**：经营 + 投资 + 融资 = 现金净变动；年初 + 净变动 + 汇率 = 年末
- **分部**：各年分部合计 ≈ 损益表营收（百万取整）

> 校验不通过则**不写出 CSV**（先回查 PDF）。改数 / 补年份 → 改脚本重跑。

## 为什么从年报解析、不用东财二手

东财二手 CSV 会错、与一手打架。农夫实证：`_raw_akshare/现金流量表.csv`「经营业务现金净额」2025 标 **256 亿**，实为年报税前的「经营所得现金」；真正的「经营活动所得现金流量净额」是 **211 亿**（2025 年报 P120）。从年报解析则与一手同源，根除此类科目错位。**`_raw_akshare/` 已弃用删除**（用会错的二手对账一手无意义——不一致仍只信一手）。
