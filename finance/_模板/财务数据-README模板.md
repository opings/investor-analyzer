> 本目录 = <公司名>的**一手财务数据库**：从一手财报 PDF 解析的所有客观数字（三表 + 比率 + 分部 + 公司/行业特有指标 + 分析派生指标）统一落点。

> **数据血缘**：所有 CSV 数字 = 从 `report/<公司>/`（**招股说明书 + 上市至今全部年报 + 中报 + 季报**）**逐行解析** + 勾稽自洽校验（一手财报 PDF 是唯一真源）。
> **单位 / 符号**：每个 CSV 头部备注；通用约定——三表为公司财报原始口径（如 RMB '000 或亿元），负数 = 流出/减项，空 = 该期财报无此科目。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## 覆盖范围

**年度序列**（`利润表.csv` / `资产负债表.csv` / `现金流量表.csv`）：**起点 = 招股书补齐的上市前最早年份，终点 = 最新已披露年报**。

|---|---|---|
| 上市前 3 年（YYYY-3 ~ YYYY-1） | `report/<公司>/招股说明书.pdf` | 损益 P___ · 财务状况 P___ · 现金流 P___ |
| YYYY / YYYY+1 / …（历年）      | `report/<公司>/YYYY.pdf`（年报）| 损益 P___ · 财务状况 P___ · 现金流 P___ |
| … | … | … |

**季度序列（可选·若有月度/季度监控需求）**：另开 `财务数据/*-季度.csv`（如 `利润表-季度.csv`），期间列 `YYYY-Q1 / YYYY-H1 / YYYY-Q3 / YYYY`，来源列点回 `YYYY-Q1.pdf` / `YYYY-H1.pdf` / `YYYY-Q3.pdf` / `YYYY.pdf`。中报/季报**只披露主要科目**，明细以年报为准。

> 上市未满 3 年 → 招股书之前的年份缺失可接受；招股书本身必须解析。
> 科目按全部年份/期间**并集**对齐；分类变动 / 一次性项目仅在出现的期间有值，其余留空。

## 勾稽自洽校验

由 `_build_from_pdf.py`（LLM 提取 + 校验固化）生成，**每年**验证：
- **损益**：收益 − 成本 = 毛利；除税前 + 所得税 = 净利
- **资产负债**：总资产 = 总负债 + 权益；股本 + 储备 = 权益
- **现金流**：经营 + 投资 + 融资 = 现金净变动；年初 + 净变动 + 汇率 = 年末
- **分部**：各年分部合计 ≈ 损益表营收（百万取整）

> 校验不通过则**不写出 CSV**（先回查 PDF）。改数 / 补年份 → 改脚本重跑。

## 为什么从年报解析、不用东财二手

东财二手 CSV 会错、与一手打架。农夫实证：`_raw_akshare/现金流量表.csv`「经营业务现金净额」2025 标 **256 亿**，实为年报税前的「经营所得现金」；真正的「经营活动所得现金流量净额」是 **211 亿**（2025 年报 P120）。从年报解析则与一手同源，根除此类科目错位。**`_raw_akshare/` 已弃用删除**（用会错的二手对账一手无意义——不一致仍只信一手）。
