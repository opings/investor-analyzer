# 标准模板说明

> **本项目只做公司客观分析**——`finance/<公司>/` 下不出现任何主观决策内容（能力圈 / 估值 / 买卖点 / 仓位 / 操作 / 决策变更历史）。需要估值时调 `valuation-method` skill 现算，结果不沉淀。

## 新增公司

在 `finance/` 下建 `<公司名>/` 目录，放入：

| 文件 / 子目录 | 来源 | 内容 |
|---|---|---|
| `财务数据/` | 新建（按 `_模板/财务数据-README模板.md` 起一份 README.md） | 公司所有数字的**唯一真源**：三表 / 比率 / 分部 / 公司特有指标 / 分析派生指标 |
| `分析.md` | 复制 `分析模板.md` | 公司分析（财务数据指针式引用 + 商业模式 + 三前提验证 + 排雷与风险） |
| `财报关注要点.md` | 套 `财报关注要点-行业模板.md` 最近行业 | 持续监控规格（指标 / 频率 / 警戒线 / 触线动作 / 红旗） |

并完成：

1. **下载一手年报 PDF** → `report/<公司>/YYYY.pdf`（A股/港股均走巨潮 cninfo，详见 `财报阅读规则.md` Step −1）
2. **解析三表到 `财务数据/`** → 写 `_build_from_pdf.py`，从年报 PDF 逐行解析三表 + 派生比率，勾稽自洽校验通过才写出
3. **补 3 年事实编年** → `knowledge/companies/<公司>/YYYY-MM.md`（零判断 + 一手来源）
4. **登记花名册** → `knowledge/companies/INDEX.md`（唯一花名册）

## 结构总览

```
finance/<公司>/
├── 财务数据/                ← 数字真源·唯一存数字处
│   ├── 利润表.csv / 资产负债表.csv / 现金流量表.csv
│   ├── 财务比率.csv         (派生)
│   ├── 分部营收.csv         (通用结构)
│   ├── <主题>.csv           (公司/行业特有,如 基酒产能.csv / 不良率.csv)
│   ├── _build_from_pdf.py   (解析+校验脚本)
│   └── README.md            (数据血缘 + 文件清单 + 勾稽校验状态)
├── 分析.md                  ← 商业模式 / 三大前提 / 排雷与风险 / 生意质量定性
└── 财报关注要点.md          ← 监控规格(指标/警戒线/触线动作 + 公司特有红旗)
```

## 数据流（双向）

```
①一手年报PDF (report/<公司>/YYYY.pdf · 真源)
    ↓ 解析
②财务数据/<csv> (公司所有数字唯一真源)
    ↑              ↓ 引用
分析中派生回流    分析.md / 财报关注要点.md
```

- **入**：PDF → `财务数据/`（逐行解析 + 勾稽自洽）
- **出**：`分析.md` / `财报关注要点.md` 引用 `财务数据/<csv>`，**不复制数字**
- **派生回流**：分析中算出的新指标（如批价÷出厂价、应收增速÷营收增速）回写到 `财务数据/`

## 数据真源原则

- **唯一真源 = 一手年报 PDF**（在 `report/<公司>/`）
- **三表 + 衍生比率 = 从 PDF 解析 + 校验，落 `财务数据/`**
- **东财二手已弃用**（`fetch_fundamentals.py` / `_raw_akshare/` 已删除）——二手会错（农夫「经营业务现金净额」256 亿实为税前、真 211 亿），有一手后再用会错的二手对账无意义
