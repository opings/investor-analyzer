# 标准模板说明

新增公司时：在 `finance/` 下建 `<公司名>/` 目录，放入 `<公司名>.xlsx`、`分析.md`(复制 `分析模板.md`)、`我的决策.md`(复制 `我的决策模板.md`)、`观点变更.md`、`财报关注要点.md`(套 `财报关注要点-行业模板.md`)，并跑 `python3 scripts/fetch_fundamentals.py <代码> <公司名>` 下载 `_raw_akshare/` 三表 CSV（原始底座·文本入库）。**新公司须同步登记 `companies/INDEX.md`(唯一花名册)**。

## 公司分析 / 我的决策 / 决策历史 三分（重要）

每家公司的 markdown 分三份，**职责严格分开**：

| 文件 | 装什么 | 性质 |
|---|---|---|
| `分析.md`（套 `分析模板.md`） | 公司是什么样：财务数据 / 商业模式·生意质量 / 三前提验证 / 排雷与风险。**换个人分析结论应大致相同** | 对公司的判断 |
| `我的决策.md`（套 `我的决策模板.md`） | 我怎么看：能力圈 / 估值假设+买卖点 / 最高仓位 / 操作 / 现价位置 / 论点 / 跟踪变量。**取决于我的能力圈/要求回报/风险偏好** | 主观·当前快照 |
| `观点变更.md` | 上面这些决策**怎么变的**历史 | 主观·只增不改 |

> 三轴落地：**评级/生意质量**(公司好不好·`分析.md`) × **能力圈**(我懂不懂·`我的决策.md`) × **估值**(我出多少价·`我的决策.md`)。
> ⚠️ 任何"能力圈 / 可估值性 / 买卖点 / 仓位 / 操作"都**不进 `分析.md`**——那是 `我的决策.md` 的事。

## xlsx 标准 sheet schema

### 1. 估值（必备）

左侧——净利润历史（按年倒序）：

| 列 | 含义 |
|----|------|
| 年份 | 倒序，覆盖近 10~11 年 |
| 扣非净利润（亿） | 周期股 / 美元计价公司注明币种 |
| 增速 | 同比，成长股填，周期股可省 |

右侧——估值参数块（按估值法二选一或并存）：

- **成长法**：当年净利润、预估增速、净利润折扣、3年后净利润、合理PE(=1/个人无风险利率·当前27.5)、估计市值、安全边际(0.5)、买点、卖点(当年净利×50/55/60PE 三档)
- **席勒法（周期股）**：十年平均净利润、合理PE下限(25)/上限(30)、净利润折扣、估计市值(下/上)、安全边际下限(0.7)/上限(1.5)、买点、卖点

最右——买卖点历史：日期 | 股本(亿) | 买点(亿)/价格 | 卖点一/二/三(亿)/价格

### 2. 季度（可选，有季报跟踪需求时）

年份 | 季度 | 分部收入… | 总收入 | 分部毛利… | 毛利率

### 2b. 季度占比（成长股估值基准年反推·必备）

年份 | Q1占比 | Q2 | Q3 | Q4。用于**当年净利(基准年)= 当期季报实数 ÷ 历史同期占比**反推面向未来的预估值；**下行/崩盘年须用崩盘年高占比、不可用正常年均值**（否则下行期反出荒谬高增长）。茅台/古井贡均依赖此 sheet。

### 3. 营收 / 分部（可选）

按业务线 / 产品 / 主营非主营拆解收入与占比。

## 估值法选择

- **成长法**：消费白马、平台型——增长稳定、可预测（茅台/腾讯/古井贡/农夫/洋河）。
- **席勒法**：强周期——利润随商品价格 / 行业景气大起大落，用十年均值熨平（陕煤/中海油/分众/胜狮）。

详见根目录 `README.md`。
