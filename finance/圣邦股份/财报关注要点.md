# 圣邦股份 财报关注要点

- **生意一句话**：模拟芯片设计（fabless），做电源管理 + 信号链两大类模拟 IC，**34 大类、5,900 余款料号（2024 年报）**，下游覆盖消费电子/工业/汽车/通信/医疗。靠"料号广度 + 客户粘性 + 国产替代"赚钱，无晶圆厂、研发驱动。
  - **产品结构（主营构成数据）**：电源管理 ~61%（毛利 46%）/ 信号链 ~38%（毛利 58%）。**信号链占比 2020→2025 从 29% 升到 38%——往高毛利、高壁垒升级。**
- **估值法**：⚠️ **无法可靠估值（太难/能力圈外）**。强周期成长股——利润随半导体景气大起大落（2022 扣非 8.47 亿 → 2023 腰斩 2.12 亿）。经更新版 `valuation-method` 双闸门重判：**成长股估值法不适用（②不可持续）；CAPE 也不可靠**（周期叠加技术迭代+国产替代结构性变化，十年均值锚不住正常盈利）→ **归"太难"，不给买卖点**。CAPE 仅作"价值重力"参照（均值 3.27 亿 → 参照买点 ~57 亿/9.2 元，非操作依据）。
- **核心跟踪变量（最该盯的 5 个）**：
  1. **半导体景气周期位置**：行业去库存/补库存阶段，决定单年利润，比公司本身更主导短期业绩。
  2. **毛利率**：模拟芯片定价权与产品结构的晴雨表（2022 高点 58.98% → 2023 跌到 49.6%，价格战伤口）。
  3. **存货**：从 2.6 亿（2020）涨到 14.48 亿（2025），周转天数 257 天，**跌价风险是最大隐患**。
  4. **研发费用率**：2025 高达 26.8%（10.45 亿），是护城河也是吞金兽——投入能否转化为新料号放量。
  5. **应收账款增速 vs 营收**：2025 应收 +55% 远快于营收 +16%，回款质量要盯。

- **本公司独有红旗 / 易暴雷点**：
  - 🟡 **存货高企 + 周转极慢**（周转率 0.35，257 天）——芯片有迭代/跌价风险，下行周期易计提存货跌价。
  - 🟡 **应收增速 ≫ 营收增速**（2025：+55% vs +16%）——景气复苏期放货还是信用宽松，待追。
  - 🟡 **研发费用率 27%**——一旦行业价格战 + 研发刚性，利润弹性向下被放大。
  - 🟡 **2025 商誉骤增** 0.79 亿 → 3.01 亿（占净资产 5.7%）——年内有并购，关注标的、业绩承诺、后续减值。
  - 🟡 **货币资金 12.26 亿 + 交易性金融资产(理财) 13.40 亿，却新增短期借款 3.01 亿**（2024 才首次有借款）——非典型存贷双高（借款规模小），但"持大额理财又借短债"记一笔，看是否与并购/补流有关。
  - 强周期：**严禁用单年 PE 估值**，景气顶部会把它算成"便宜"。

- **历史踩过的坑 / 管理层诚信记录**：
  - 创业板 300661，2017-06 上市。实控人/董事长张世龙（模拟芯片技术出身）。
  - 暂未见监管处罚/财务造假记录（⏳ 审计意见、减持记录待补核）。
  - 2023 业绩"暴雷"系行业周期 + 价格战所致，非财务造假，但说明其**利润不可预测**。

- **竞争格局与产业链地位（已多源核实，2026-06-24）**：
  - 处产业链**设计环节**（最轻资产、最高毛利的一环）。上游=代工厂（台积电/中芯，议价弱）+ 封测；下游=模组厂/方案商/终端品牌。
  - **全球格局：TI 第一 ~19%、ADI ~9%、前五 ~52%，海外巨头主导。** 圣邦是国内模拟设计龙头之一，但全球份额仍 <1%（估算）。TI 为 IDM（自有产线 + ~8 万料号），护城河"宽且深"，圣邦尚不在同一量级。
  - **国产替代空间（实数）**：2024 中国模拟市场破 3000 亿，**国产自给率仅 16%**；车规级 <5%；家电领域已达 65%。圣邦高精度 ADC 打破国际垄断、已过 AEC-Q100 车规认证。
  - **议价力**：对上游代工偏弱（小客户、价格接受者）；对下游消费类无定价权（2023 价格战毛利率 59%→49.6% 为证），工业/汽车类靠认证粘性较强。**产业链地位：位置好（设计），但座次靠后、不强势。**

> 行业归类：最接近 `_模板` 的「制造/重资产」+「半导体设计」自定义。fabless 名义轻资产，但资本开支占净利约 60%（2025）+ 研发费用率 27%，"维持盈利不需大量资本投入"这条前提存疑。
> 数据来源：圣邦 2024 年报（cninfo/同花顺）、akshare 主营构成、芯智讯/新浪财经引行业份额、证券时报国产化率数据。料号/份额已核，全球份额为估算。
