# Nvidia（NVIDIA Corporation·NASDAQ: NVDA·CIK 1045810）财务数据（从一手申报解析）

> 本目录 = NVIDIA 的**一手财务数据库**：从一手申报解析的所有客观数字（三表 + 比率 + 分部 + 公司特有指标 + 分析派生指标）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/Nvidia/`（事实编年，分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/Nvidia/`（**1999-01-21 定稿招股书 424B4 + 1998-03-06 首版 S-1 + FY1999–FY2026 共 28 份年报（10-K405 / 10-K）+ FY2006 重述 10-K/A + 本财年两份 10-Q**）**逐行解析** + 勾稽自洽校验；`附注自陈数.csv` 另按锚句取自期后 8-K、2025-07-31 SEC 意见函回函（CORRESP）、**无 8-K 的公司新闻稿 10 份**与**对手方 Meta 定价招股书 424B5**；源档柜另存事实编年引用的新闻稿 / 官方博客（2026-11-09 补扫·清单见 `report/Nvidia/_下载清单.tsv`，57 份三验全过）。
> **单位 / 符号**：金额一律 **百万美元（US$ mn）**；EPS 为美元/股、股数为百万股；利润表费用为正、营业外按印刷符号；现金流量表流出为负；空 = 该期申报无此科目（**不是零**；印刷「—」的格记 0）。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## ⚠️ 读这个库之前必须先知道的八件事

1. **财年截至 1 月最后一个周日（52/53 周）**：FY2026 = 2025-01-27 ~ 2026-01-25，**主要落在日历 2025 年**。「2026 年」在本库一律指财年。
2. **没有 FY1998**：1993–1997 财年 = 日历年（截至 12-31；FY1993 自 1993-04-05 成立起）；**1998 年 1 月单独一个月过渡期**，之后才改成 1 月财年。过渡月单列 `过渡期-1998年1月.csv`，年度三表里 FY1997 之后直接是 FY1999（`scripts/derived.py` 按位置读列，非年份列会让整行左移，故不进年度表）。FY1999 的「期初」余额实为 1998-01-31，派生比率的年均值用了 FY1997 年末（差一个月）。
3. **EPS / 股数不可跨年直接相除**：拆股 6 次、累计 ×480（2000-06 二拆一·2001-09 二拆一·2006-04 二拆一·2007-09 三拆二·2021-07 四拆一·2024-06 十拆一）。跨年比每股口径只用 `财务比率.csv` 的 **🔴【复权】行**——倍数由数据自证（下节），不是抄的。
4. **地区营收两种口径不可拼接**：FY2025 及以前按**客户开票地**、FY2026 第三季度起改按**客户总部所在地**并重列前期（`地区营收.csv` 行名前缀【开票地口径】/【总部口径】）。
5. **分部三代不可拼接**：G1 GPU/PSB/CPB（FY2012 及以前）→ G2 GPU/Tegra Processor（FY2013–2020）→ G3 Compute & Networking/Graphics（FY2021 起）。分部营业利润不含股权激励等未分配项（All Other）。
6. **美股无「扣非」法定口径**，本库不造扣非行。一次性项目各自单列：收购终止费用（FY2023·Arm）、诉讼和解、重组、期权置换、在研技术、H20 / H200 对华减记（`附注自陈数.csv`）。**FY2026 起报告净利含可观的股权投资公允价值收益**（`财务比率.csv`「投资收益/税前利润」行）——看经营增速用营业利润。
7. **三次重述 / 改列都保留 as-reported**：① 1998-03 首版 S-1 → 1999-01 定稿招股书重述 CY1997（期权补偿）；② FY2002 10-K 重述 FY2000–2001（SEC 问询后审计委员会复核）；③ 2006-11 10-K/A 重述 FY2004–2006（期权授予计量日）。差异全部在 `重述与口径变更.csv`。**跨年比「其他资产」先查台账**：FY2026 10-K 把非上市权益证券从其他资产移出单列，FY2025 原报 6,425 → 重列 3,038（`重述与口径变更.csv` R2026 行）——拿原报值和 FY2026 比会把增幅低估成约三成（实为约 2.7 倍）。
8. **FY2026 起「有价证券」含上市权益证券**：10-K 资产负债表把有价债券与上市权益证券合在「Marketable securities」一行（FY2026 = 51,951），10-Q 起才拆成两行；上市权益证券多为锁定期内的战略持股（`附注自陈数.csv` 锁定期 4 行）。`财务比率.csv` 的「净现金」照年报一行算、**含**这部分股权；剔除口径见 `中期财务-FY2027.csv` 末两行派生。

## 勾稽自洽校验（不过则不写出 CSV）

**三表**（`_build_from_filings.py`，最近一次运行**执行 638 条、全过**；默认容差 0）：
- **必填项（C0）**：有数据的年份核心科目必须有值（完整报表年份另加成本 / 毛利 / 费用 / EPS / 股数 / 应收 / 存货 / 固定资产 / 应付 / 折旧 / 资本开支）——防「锚科目丢了、整张表静默全过」。
- **利润表**：营收−成本=毛利；产品+授权费=营收（FY1995–2001）；费用明细和=营业费用合计；毛利−费用=营业利润；营业利润+营业外=税前；营业外明细和=营业外合计（FY2016 起）；税前−所得税(=会计原则变更前利润)+累积影响=净利；净利÷基本股数≈基本 EPS（单位与拆股基准的守门人）。
- **资产负债表**：流动资产明细和=合计；流动+非流动=总资产；流动负债明细和=合计；流动+非流动负债=负债合计（FY2016 起印刷）；负债+夹层权益+权益=总资产；权益明细和=权益合计；负债及权益合计=总资产。
- **现金流量表**：经营+投资+融资=净变动；期初+净变动=期末；现金流量表净利=利润表净利；期末现金=资产负债表现金；**F0：原始行（不经概念映射）分段求和 = 印刷段小计**（证明「未单列项合计」那一行真是其余各行之和）。

**闸门对照组（全格变异·`--mutate`）**：对每个 as-reported 金额格加一个印刷单位（千美元来源 +0.001、百万来源 +1）重跑全部勾稽：**1,996 格中被捕获 1,520（76.2%）**。未覆盖 476 格（几乎都是现金流明细——被「未单列项合计」吸收，解析层另有 F0 兜底）中 **432 格有另一份申报印出同值**；**既无勾稽又无第二处印刷 44 格**：25 格为 FY2026（尚无下一份 10-K 比较列，其中 18 项现金流明细已由 XBRL 独立核确认），其余为后续申报做过重分类的老年份（差异在 `重述与口径变更.csv`）。

**跨源**：
- **跨申报同值确认**：利润表 1,322 格、资产负债表 776 格、现金流量表 1,233 格（另一份申报比较列 / 五年摘要 / 首版 S-1 印出同值；精度不同的两次印刷按较粗一方比）；不同值 345 处全部进 `重述与口径变更.csv`。
- **XBRL 独立核**（`_xcheck_xbrl.py`，SEC companyfacts API，与 R 文件、HTML 印刷件均为不同通道；**按「该财年自家 10-K 的 accession」取事实**——companyfacts 把 FY2014 那份 10-K 的事实标成 fy=2013，按 fy 选会同时制造假缺失与假不一致）：FY2010–2026 三表核心科目 + 现金流明细 **一致 507 格 / 不一致 0 格**；另 5 格为 **XBRL 事实与印刷件等绝对值反号**（FY2010/2011 应收与存货变动、FY2013 已付所得税），已回 10-K 印刷件仲裁、CSV = 印刷。

**附注层**（`_build_notes.py`，81 条全过）：分部营收和=合并营收、分部利润和（含 All Other）=合并营业利润；市场平台和=营收、Compute+Networking=Data Center；地区和=营收（两种口径各自成立）；存货构成和=存货合计；FY2022–2025 采购义务到期表合计≈两类义务之和（正文为十亿一位小数·容差 1 亿）；非上市权益滚动表期初+变动=期末；MUST 探针（主分部营收 / 利润、合并营收、存货合计必须取到）。
**中期**（`_build_interim_fy2027.py`）：利润链、负债+权益=总资产、流动资产明细和、三段=净变动；跨申报 Q1+Q2=H1（±1·两份 10-Q 各自取整）；**跨文件**：10-Q 对比列 2026-01-25 的「有价债券 + 上市权益证券」= FY2026 10-K「Marketable securities」、现金同值（只读上游 `资产负债表.csv`；+1 变异对照已验能拦）。
**附注自陈数**（`_build_selfreported.py`）：46 条锚句全部命中才写出；新闻稿首句前无句号的条目用 `exact`（锚句 = 正则完整命中句，不按句号回溯，免得把页头截进来）。
**比率层**（`_build_ratios.py`）：上游 CSV 探针行 + MUST 必需格；拆股链自证 = 自陈逐次对账。

## 拆股复权因子怎么来的（不是抄的）

`_build_ratios.py` 拿「后一份 10-K 比较列印的同一财年基本股数 ÷ 该财年 as-reported 基本股数」，比值落在 1.5 / 2 / 4 / 10 附近即判定倍数，再与公司自陈逐次对账（多一次、少一次都失败）：

| 在哪两份申报之间 | 推得倍数 | 公司自陈 |
|---|---|---|
| FY2000 10-K → FY2001 10-K | ×2 | 2000-06 二拆一 |
| FY2001 10-K → FY2002 10-K | ×2 | 2001-09 二拆一 |
| FY2006 10-K → FY2007 10-K | ×2 | 2006-04 二拆一 |
| FY2007 10-K → FY2008 10-K | ×1.5 | 2007-09 三拆二 |
| FY2021 10-K → FY2022 10-K | ×4 | 2021-07 四拆一 |
| FY2024 10-K → FY2025 10-K | ×10 | 2024-06 十拆一 |

相对 FY2026 股本基准：FY1993–2000 = ×480、FY2001 = ×240、FY2002–2006 = ×120、FY2007 = ×60、FY2008–2021 = ×40、FY2022–2024 = ×10、FY2025 起 = ×1。
