> 本目录 = 安踏体育的**一手财务数据库**：从一手财报 PDF 解析的所有客观数字（三表 + 比率 + 分部）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/安踏体育/` 事实编年（分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/安踏体育/`（**招股说明书 + 上市至今全部年报**）**逐行解析** + 勾稽自洽校验。
> **单位 / 符号**：统一换算为 **人民币百万元**（2004-2019 年报原单位为千元，已 ÷1000；2020 起原单位即百万元）。负数 = 流出/减项，空 = 该期财报无此科目。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**校验不通过则不写出 CSV**。当前状态：**230 条全部通过**。

| 类别 | 条目 |
|---|---|
| 损益 | 营收 − \|成本\| = 毛利；除税前 + 税项（+ 非持续经营）= 年内溢利；股东应占 + 非控股 = 年内溢利 |
| 资产负债 | 负债总值 + 资产净值 = 资产总值；非流动 + 流动 = 资产总值；股本 + 储备 = 股东应占权益；股东权益 + 非控股 = 资产净值 |
| 现金流 | 经营 + 投资 + 融资 = 现金净变动；期初 + 净变动 + 汇率 = 期末 |
| **分区构成** | 流动/非流动资产的**已抓明细之和 ≤ 小计，且残差 < 2%**（防某个分项被静默漏抓） |
| 分部 | 分部**收入**合计 = 利润表「营业额」、分部**毛利**合计 = 「毛利」（均须分毫吻合，对不上则该年不采）；分部**业绩**合计 = 「经营溢利」允许 ≤5% 残差（两者之间夹有分部对账项，如 2020 年的「處置合營公司部分權益之利得」），**残差逐年打印留痕**：2019 差 54 · 2020 差 14 · 2022 差 97 · 2023 差 166（百万元） |
| 跨年交叉核 | 1,230 格：AR(Y) 本年列 vs AR(Y+1) 上年比较列。**不一致 17 格，全部已逐条回一手判读**（见下） |

### 已判读的口径断点（17 格跨年差异）

差异 ≠ 解析错，也可能是公司真的重列。以下均已回一手核实并有算术佐证：

| 年 | 断点 | 实质 |
|---|---|---|
| 2007 | **全表重列**（损益 9 项 + 现金流 4 项） | 2008 年报把**上海锋线**（2008 年出售）改列为「非持續經營業務」，2007 比较列上方明印「**重列**」。营收差 193.7 = 上海锋线当年收入。现金流另叠一层列报变更：2007 年报把 −106.3 百万「滙兌差異調整」放在**经营活动内**，2008 年报改列到表底「滙率變動之影響」 |
| 2014 | 其他收益 / 其他净损益合并 | 2015 起并为「其他淨收入」一行（97.3 + (−11.3) = 86.0 ✓） |
| 2017 | 应收 / 应付**拆行** | 2018 起「應收貿易賬款及其他應收款項」拆为「應收貿易賬款」+「其他應收款項」（3,732.7 = 2,088.7 + 1,644.0 ✓）；应付侧同理（3,977.7 = 1,446.7 + 2,531.0 ✓） |
| 2018 | 土地使用权预付款项 | 2019 采用 IFRS 16，租赁类资产重分类 |
| 2019 | 借贷口径 | 2020 起「借貸」= 銀行貸款 + 應付票據款項(融資性質)（1,358.9 + 1,200.0 = 2,558.9 ✓） |

> **口径断点的处理原则**：**分两行存，不合并成一条时间序列**（合并会凭空制造一次 −44% 的假跳水）。
> 派生比率需要连续序列时，在 `_build_from_pdf.py` 里显式拼接并注明（见「应收合并口径」）。

### 恒等式推导（7 处·非报表印出行）

2004–2008 年安踏**没有非控股权益**，当年报表体例下这两行根本不印，故按同表内恒等关系补：

- `股东应占溢利 = 年内溢利`（2004-2008：损益表无「溢利分配為」段）
- `资产净值 = 股东应占权益`（2007-2008：资负表无「資產淨值」行）

> 仅在**非控股权益整行不存在**时套用；2009 年起出现非控股权益后立即停用、只取报表印出数。

### `财务比率.csv` 的安踏定制层

| 指标 | 定义 |
|---|---|
| 经营溢利率 | 经营溢利 ÷ 营业额 |
| **经调整股东应占溢利（率）** | 股东应占溢利 − 分占联营 − 分占合营 − Amer 上市/配售权益摊薄利得 − 可换股债券购回利得。对齐公司 2026 中期报告注(9) 自陈口径，本库按同一定义**回算历年**。港股无「扣非」线，此项替代之 |
| 有息负债/总资产 | (借贷-流动 + 借贷-非流动) ÷ 资产总值 |
| 净现金 / 净现金占比 | 现金 + 各类定期存款 + 已抵押存款 − 借贷总额 |

### 口径注意（引用前必读）

- **应收/应付为「合并口径」**：2018 年拆行、2020 年「其他應收款項」更名「其他流動資產」。比率表按「贸易 + 其他」拼成连续序列，故 `应收账款周转天数` 全期可比；若要**纯贸易应收**，直接读 `资产负债表.csv` 的「应收贸易账款」行（2018 起）。
- **分红率分母是「已付股东股息」**（现金流量表·年内实际支付），与「宣派」口径存在**跨年时间差**；分红爆发/骤变年份会明显误读，需与公告宣派额交叉核。
- **2019 年起资产负债表结构性变化**：IFRS 16 使用权资产入表、Amer Sports 合营/联营投资入表，总资产由 244 亿跳至 412 亿，`资产负债率`/`PPE占比` 等结构指标在 2019 前后不可直接比。
- **分部披露起点**：按品牌分部（安踏/FILA/所有其他）自 2019 年才有；2012 年报明载「董事認為呈列 Fila 中國業務分部資料對本年度財務報表不具意義」，即更早年份公司**主动不披露**，非本库缺采。
- **2007 年及以前为「重列前」口径**（见上表），与 2008 年起的序列不完全可比。
