## 🚨 报告主体口径警告（读任何一张表之前必须先读这段）

SpaceX 的合并报表 **不是**历史上那家独立火箭公司的经营记录，而是 **SpaceX + xAI + X 三者的追溯合并重述结果**：

| 时间 | 事件 | 会计处理 |
|---|---|---|
| 2022-10 | Elon Musk 个人收购 Twitter, Inc. | （彼时与 SpaceX 无隶属关系） |
| 2023-03 | X.AI Corp. 开始运营 | —— |
| 2025-03-28 | xAI 收购 X Holdings Corp.（"X Merger"） | 同一控制下重组 |
| 2026-02-02 | **SpaceX 收购 X.AI Holdings Corp.（"xAI Merger"）** | 同一控制下重组 |
| 2026-07-06 / 08-14 | 收购 Mesh Optical / **Cursor（Anysphere）** | **购买法**（自交割日起并表，确认商誉与无形资产） |

因 Musk 对三方均持有控股表决权，两笔合并均按 **ASC 805-50 同一控制下重组**处理：
**按历史账面价值追溯合并所有列报期间，不确认新商誉或无形资产**，招股书原文明示
「**This presentation constitutes a change in reporting entity**」（424B4 F-11 附注 1）。

**后果（用数时必须记住）**：
1. `利润表.csv` / `现金流量表.csv` 的 **2023 / 2024 列，不是任何一家实体当年实际披露过的报表**——是 IPO 时倒推构造的。
2. 2023 年的 $3,775M 减值、$11,418M 商誉，都来自 **X/Twitter**，与火箭/卫星业务无关。该减值**不是商誉减值**——424B4 明示 2023–2025 年度商誉测试均未识别减值；2026 前三季商誉变动只有企业合并与汇兑（Q3 10-Q Note 6）。
3. **想看"火箭公司"本体，只能用分部表的 Space + Connectivity 两个分部**；AI 分部 = xAI + X（2026Q3 起更名 **SI**，并含 Mesh Optical 与 Cursor）。
4. 招股书明示 **xAI 与 X 不单独提供财务报表**，故无法从公开文件还原三者各自的独立历史。
5. **2026Q3 起 SI 分部增速含收购贡献**：Cursor 交割日至 09-30 贡献收入 $608M（Q3 10-Q Note 20），读 SI 增速前先扣。

## 勾稽自洽校验

由 `_build_from_sec.py` 固化，**校验不通过不写出 CSV**。当前**执行 457 条、因空值跳过 0 条，全部通过**。

**闸门本身的对照组（2026-10-24）**：把脚本副本里 4 个已知数各改 +1（季度表 SI 产品线、前三季经营现金流、Q3 Falcon 发射数、09-30 商誉）——
**旧默认容差 1 时 4 处全部放过**；默认容差改为 0 后 7 条报错、0 个 CSV 写出。新增分部商誉行后再加第 5 个变异（06-30 AI 分部商誉 +1）：10 条报错、0 个 CSV 写出。现仅三处显式容差（均为源表四舍五入）：
跨申报的 2025 年分部数（±2）、入轨质量分项（±2）、派生 2025Q3 capex（13,846 − 6,965 = 6,881 vs 分部表 6,880，±1）。

**年度（每年各一遍）**
- 利润表：五项费用加总 = 总成本及开支；营收 − 总成本 = 经营利润；经营利润 + 利息 + 其他 = 税前；税前 + 所得税 = 净利
- 资产负债表：五项流动资产加总 = 流动资产合计；八项加总 = 资产总计；四项流动负债 = 流动负债合计；四段 = 负债合计；**负债 + 可赎回优先股 + 权益 = 资产总计**
- 现金流量表：经营 + 投资 + 融资 + 汇率 = 净变动；期初 + 净变动 = 期末；**上年期末 = 次年期初**（跨年衔接）
- 三表衔接：利润表净利 = 现金流量表起点净利

**分部**
- 年度 + H1：Space + Connectivity + AI = 合计（收入/经营利润/资本开支/折旧摊销/股权激励）；六条产品线加总 = 三分部收入；分部合计 = 利润表与现金流量表
- 季度（`分部营收-季度.csv`）：三分部加总、产品线加总、**分部调整后 EBITDA 调节**（经营利润 + 折旧摊销 + 股权激励 + 收购相关股权激励 + 收购费用 + 重组 + 减值）；**2026Q1 + Q2 + Q3 = 前三季**；季度表合计 = 中期利润表

**中期（两份 10-Q）**
- 七个期间列各自的利润表自洽 + **调整后 EBITDA 调节**；折旧 + 摊销 = D&A
- **H1（Q2 10-Q）+ Q3（Q3 10-Q）= 前三季（Q3 10-Q）**——逐行跨申报衔接
- 现金流 H1 与前三季：三段 + 汇率 = 净变动；期初 + 净变动 = 期末
- 三个时点资产负债表恒等式（流动资产、资产总计、流动负债、负债合计、资产 = 负债 + 优先股 + 权益）；**货币资金 + 受限现金 = 现金流量表期末口径**；**Connectivity + SI 分部商誉 = 商誉**（三个时点）；**商誉变动表（年初 + 企业合并 + 汇兑）= 09-30 资产负债表**

## 为什么不用二手源

本公司 2026-06 才上市，二手数据库（东财/akshare 等）对其**历史期间的覆盖必然来自同一份招股书**，
且极易丢失本页顶部的「追溯合并重述」口径警告——把 2023-2025 当成 SpaceX 本体的历史读，
是本公司**最容易犯且后果最严重**的错误。故一律从 SEC 一手申报解析。
