# 特步国际 财务数据（从一手财报 PDF 解析）

> 本目录 = 特步国际（01368.HK）的**一手财务数据库**：从一手财报 PDF 解析的所有客观数字（三表 + 比率 + 分部 + 分析派生指标）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/特步国际/`（分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/特步国际/`（**招股说明书 + 上市至今全部年报**）**逐行解析** + 勾稽自洽校验（一手财报 PDF 是唯一真源）。
> **单位 / 符号**：**本目录所有金额一律人民币百万元**（三表、分部、其他收益构成、应收账款质量；原始披露口径 RMB'000，解析时 ÷1000）；每股盈利为**人民币分**（不缩放）；比率为小数；`门店数.csv` 单位为**家**；负数 = 流出/减项；空 = 该期财报无此科目。
> 🔴 **一个目录只用一个金额单位**，不是洁癖：`scripts/prose_audit.py` 的单位探测**先读本 README 这一行、再退回 CSV 首行注释**，也就是目录内所有 CSV 共用这里声明的单位。附注层 CSV 若留在千元，它会把 316（千元）当成 316 百万 = 3.16 亿去比 —— 既造假阳性，也会让真的量级漂移被错误基准掩盖（2026-09-22 实测到过一次）。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## 一手源为什么走港交所披露易，而不是巨潮

**巨潮（cninfo）的港股镜像对本公司不全**，实证（2026-09-20）：

- 2008 整年无任何记录 → **招股说明书在巨潮上不存在**；
- FY2008 / 2009 / 2010 / 2011 / 2019 只有「年度业绩公布」，**没有年报全文**。

故全部一手件取自**港交所披露易 HKEXnews**（stockId `23896`，代码 01368）。两处取数坑已固化进脚本注释：

| 坑 | 症状 | 处理 |
|---|---|---|
| `t2Gcode` / `t2code` 须 = `-2` | 填 `-1` 恒返伪零结果 | 已固定为 `-2` |
| 日期参数名是 `fromDate` / `toDate` | 填 `from` / `to` 被**静默忽略**，返回「最新 N 条」——看起来成功其实是错的 | 已改用 `fromDate`/`toDate`，并以「2008 年应有 IPO 文件」作对照组验证过滤真的生效 |

**招股说明书与 FY2009 / FY2010 年报在披露易上是 `.htm` 索引页 + 分章 PDF**（招股书 34 章 E101–E134），需抓索引→下全部分章→`pypdf` 合并。合并件三验：`%PDF` 头 + MB 级 + 首页抽文（招股书 417 页，首页为 "IMPORTANT If you are in any doubt about this prospectus…"）。

## 🔴 口径断点表（跨这些年份比单科目前必查）

> 由「跨年交叉核」自动发现：拿**本年年报的本年列** vs **次年年报的比较列**逐格对，不一致即落此表。
> 2026-09-20 首次建库共发现 **24 处**不一致，逐条回源裁定后**无一是解析错**，全部为下列 6 类重述/重分类。

| # | 断点 | 影响 | 处理 |
|---|---|---|---|
| 1 | **招股书(2005-07) vs FY2008 年报** | FY2008 把「其他经营开支」并入「行政开支」；约 2.3 百万自「其他收益」移入「净融资收入」 | 除税前溢利两版一致；跨 2007/2008 比费用率须知此事 |
| 2 | **FY2012 → FY2013** | 37.421 百万自经营活动重分类至投资活动（2012 比较列） | 经营现金流 2012 as-reported 偏高约 37 百万 |
| 3 | **FY2019 → FY2020** | 分部披露由「单一可呈报分部」改为三分部 | 2019 及以前**无**品牌分部数据，非遗漏（FY2019 年报原文自陈单一分部） |
| 4 | **FY2022 → FY2023** | 权益列报拆行：「库存股」「可换股债券权益部分」自「储备」中单列 | **权益总值不变**（2022 两版均 8306.702）；单看「储备」跨 2022/2023 会凭空差 285.4 |
| 5 | **FY2023 → FY2024** | K-Swiss 可换股债券由非流动重分类为流动（期初 2022 影响 419.537、2023 年末 41.633） | 流动/非流动负债合计、流动资产净值三项随之移动 |
| 6 | 🔴 **FY2024 KP Global 处置（最要命）** | K-Swiss + Palladium（= Athleisure 分部）2024-11-30 出售，列为**终止经营**；FY2023 比较列重述为**持续经营**口径：营收 14345.5 → 12742.9（差 **1602.6**）。资产负债表因此出现**第三栏**「1 January 2023 (Restated)」 | **2024/2025 的营收与利润是持续经营口径，与 2023 及以前的 as-reported 不可直接比**。商誉 842.2→3.8、无形资产 723.3→16.5 同步归零 |

**取数原则（因上表而定）**：主值**只取当年年报的当年列**（2005-2007 取招股书），**不拿别年年报的比较列兜底**——比较列可能是重述后口径，拿它补空会把 as-reported 序列与 restated 序列缝成一个嵌合体，**勾稽照样能平却是两套口径**。比较列一律降级为交叉核证据。

其他非断点但影响读数的列报变化：

- **IFRS 16 于 2019 落地** → 「使用权资产」「租赁负债」自 2019 起出现。
- **非控股权益仅 2011–2023 存在**，2024 年起为零（随 KP Global 处置消失）；2010 及以前财报不印「应占」拆分行。故 `财务比率.csv` 的「归母」在这两段用「年内溢利 − 非控股权益应占溢利」补全。
- **特步资产负债表不印「资产总值」行** → `财务比率.csv` 的总资产 = 非流动资产合计 + 流动资产合计。

## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**每年**验证（不通过则**不写出 CSV**）：

- **损益**：营业额 − |销售成本| = 毛利；除税前溢利 + 税项 = 持续经营业务溢利（无拆分年则 = 年内溢利）；持续经营 + 非持续经营 = 年内溢利
- **资产负债**：非流动资产合计 + 流动资产合计 − 流动负债合计 − 非流动负债合计 = 资产净值 = 权益总值；股本 + 库存股 + 可换股债券权益部分 + 储备 + 非控股权益 = 权益总值
- **现金流**：经营 + 投资 + 融资 = 现金净变动；期初 + 净变动 + 汇率 = 期末
- **跨年交叉核**：本年年报本年列 vs 次年年报比较列逐格对（差异落上方口径断点表）

分部另由 `_build_segments.py` 跑**四路勾稽**：分产品和 = 分品牌分部和 = 利润表营业额（各自差异 <3%），外加**分部经营溢利和 + 未分配开支 == 利润表经营溢利**（这一路是恒等式，不是近似）。
⚠️ **每一路都要跑**——只对其中一路等于没跑（本库贵州茅台实证：分产品那路全过、分渠道那路整体左移一列且连续 6 年「渠道和 = 下一年营收」，因为从没对过）。
⚠️ **列序要逐路独立判**：FY2023 的营收行是「大众 / 专业 / Athleisure」，而同一张表的 Segment results 行印成「大众 / Athleisure / 专业」。照搬营收行列序会把专业运动 2023 年经营溢利读成 −1.84 亿（实为 +0.08 亿，可用 FY2024 年报的 2023 比较列独立验证）。

附注层由 `_build_extras.py` 另跑三条校验：其他收益分项和 == 利润表「其他收益」；应收总额 − 拨备 == 资产负债表应收净额、且账龄各档之和 == 应收净额；门店数逐条回原文校验该数字确实印在所引页上。

**当前状态（2026-09-22）**：三表勾稽 ✅ 全部通过（21 年 × 7 条）；分部四路勾稽 ✅ 全部通过；附注层三条校验 ✅ 全部通过。

## 解析层踩过的坑（改脚本前先读）

| # | 坑 | 后果（不处理的话） |
|---|---|---|
| 1 | **表标题跨行印** —— 2015-2019 把 `CONSOLIDATED STATEMENT OF` 与 `FINANCIAL POSITION` 印成两行 | 整张资产负债表漏配 |
| 2 | **装饰字体编码偏移** —— 2011/2012 的表标题在文本层是 `$0/40-*%"5&%*/$0.&`，每可见字节 **+31** 才是 `CONSOLIDATEDINCOME`；**数据行本身完全正常** | 这两年整表丢失 |
| 3 | **页眉插进跨行标题** —— 2012 印成 `Consolidated  ANNUAL REPORT 2012 / 86` 换行 `Income Statement` | 标题匹配落空 |
| 4 | **「行数最多者胜」会挑错表** —— 招股书**摘要节**的 Summary Consolidated Income Statements 行数更多 | 把摘要节当成附錄一会计师报告正表（数值虽同源，结构不同、`Revenue` 行被产品拆分行顶替）。改为**标题须整行自成一句 + 正表骨架覆盖度优先**（同 Disney「倒锁链挑表」坑） |
| 5 | **同名科目跨节互相覆盖** —— 计息银行借贷 / 租赁负债 / 定期存款 / 可换股债券 在流动与非流动两节**同名** | 后者吞掉前者。解析器须跟踪节区（非流动资产/流动资产/流动负债/非流动负债/权益） |
| 6 | **两只可换股债券并存**（特步 CB / K-Swiss CB）、**FVOCI 与 FVTPL 两行同节** | 归一到同名后互相覆盖，跨年交叉核表现为「两值对调」。已拆成独立科目 |
| 7 | **三栏资产负债表** —— FY2024 表头是「31 December 2024 \| 31 December 2023 \| 1 January 2023」，**2023 出现两次** | 「年份互不相同」的守卫会把整张表拒掉。改为读年份行上方日期行，`1 January YYYY` 归到 `YYYY-1` |

| 9 | **折行标签 + 破折号占位** —— 长科目名折到第二行且数值印在第二行；招股书配饰 2005 年印「—」 | 前者令科目名残缺；后者令整行**左移一列**（2006 配饰曾取到 2007 的 18,177，分产品和 500.7 vs 营业额 483.6）。破折号必须当**占位 token** 一起捕 |
