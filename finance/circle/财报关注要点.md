# circle (Circle Internet Group / CRCL) 财报关注要点

> 持续监控规格（盯什么·频率·警戒线·触线动作）+ 排雷红旗。生意模式完整论述归 `分析.md`；指标时间序列一律落 `财务数据/<csv>`，本文件不嵌数字。
> 行业块：**稳定币 / 浮存金**（无现成模板块——按「银行/金融」的挤兑-利差雷达 + 「互联网平台」的 SBC/渠道雷达自建；本块可供未来 Tether 类/交易所类公司复用）。

- **生意一句话**：发行 1:1 全储备美元稳定币 USDC，独享储备利息（法定不付给持币人）、与分销渠道分成——「链上货币基金浮存生意」。
- **生意类型**：不确定生意（叠加强周期属性：利润 = 流通量 × 利率 − 渠道分成，前两个乘数外生）。

## 🅰 生意模式 / 收入结构 / 护城河本质（读财报前先记住）

- **收入 ≈ 短端利率的函数**：储备限「银行现金 + 贝莱德 Circle Reserve Fund（政府货基·USDXX·持仓每日公开）」，储备收益率贴着 SOFR/3M 美债走——**看营收先看 Fed，别把利率红利读成经营 alpha**（序列见 `财务数据/USDC运营.csv` 季度收益率块）。
- **分销成本是「渠道税」不是可变营销费**：Coinbase 按其平台上 USDC 余额拿走对应储备收入 + 平台外分成一半（Collaboration Agreement + Stablecoin Ecosystem Agreement），Binance 等新渠道再叠加——**USDC 往交易所平台集中 = Circle 自留率被动下降**。真实盈利线看 **RLDC（收入减分销成本）**，不看毛收入（`财务数据/季度经营.csv`）。
- **护城河 = 合规执照集 + 储备透明度**（OCC 联邦信托银行 + 州牌照 + MiCA + GENIUS PPSI 路径），防小玩家有效；**防不了两头**——离岸 Tether（监管/税负套利）与 GENIUS 生效后入场的银行系/代币化存款。
- **验真链条业内少见地短**：链上负债可数、储备基金每日披露、10-K/A 附基金独立审计——报表造假空间小，**主风险天生在表外**（挤兑/利率/竞争）。
- **一次性项密集体质**：IPO 型 SBC、可转债/权证公允价值、代币预售确认、税项一次性——看趋势必须用 `季度经营.csv` 拆一次性后再比。

## 🅱 风险雷达（挤兑-利差-渠道三主轴）

- 🔴 **脱锚/挤兑**（头号·表外）：二级市场 USDC 价格偏离 1 美元、单日大额净赎回、储备银行对手方出险（SVB 型）。报表完全照不出来，出事在小时级。
- 🔴 **利率下行**：储备收益率随 Fed 降息直落；公司自测 ±100bp 的量级见 `财务数据/利率敏感性.csv`（**每年刷新 10-K Item 7A 时必须换成最新基准那张表**——10-K 同节并排放当期与上年两张，基准收益率与流通量基数都不同，**混用会把量级低估近一半**，2026-09-12 已实证踩过）。流通量增速若同时熄火 = 双杀。
  - **读表纪律**：公司表的第二列是「分销与交易成本变动」**不是净利影响**；真正的经营口径增量 = 第一列 − 第二列（= RLDC 变动，本库已派生）。且该表**假设流通量恒定**，不含"加息抬高持币机会成本→流通量承压"这一反向链条。
- 🔴 **GENIUS 生效后的竞争洪水**：银行/大机构发币、代币化存款、TMMF（含自家 USYC）分流「要收益的资金」；生效时点 = 2027-01-18 或最终细则后 120 天孰早——**细则出台节奏本身是事件级信号**。
- 🟡 **渠道自留率恶化**：USDC on-platform 占比抬升、新分销协议一次性预付/激励费——RLDC 率是照妖镜。
- 🟡 **Arc/ARC 代币执行与监管定性**：主网上线节奏、PoS 转型 deadline（2028-05-08 未转须退预售款）、代币的证券法定性风险；预售收入确认的一次性美化。
- 🟡 **软件资本化率**：资本化（含资本化 SBC）持续大于摊销 = 利润温和美化。
- 🟡 **内部人减持节奏**：双层股权 + 创始人投票权近三成 + Form 4/144 常态流水，减持骤然放量是信号。**判读纪律**：先看 10b5-1 预设计划标注比例——高比例意味着卖出时点与管理层当时判断脱钩，不可读成「知情卖出」；真正的信号是**新设/改设计划**与**非计划内的临时卖出**（序列见 `财务数据/内部人交易.csv`）。
- 🟡 **用股票买资产的连续动作 + 不摊销软资产堆积**：已披露对价结构的收购全部以股份为主；**Centre 那组无形资产被定为「无限寿命」不摊销**，与商誉一样只做年度减值测试——**平时不进利润表、暴露时是一次性砸坑**。每笔新并购都同时抬高摊薄与这块软资产（`财务数据/并购与对价.csv`）。

## 本公司独有红旗 / 易暴雷点

- **储备侧任何「创新」**：储备里出现非白名单资产、收益率异常跑赢基准、储备鉴证延迟——对全储备承诺的任何松动都是 🔴（对照造假模式库 B 类「现金验真」逻辑的稳定币版）。
- **赎回摩擦**：暂停/延迟赎回、Mint 客户门槛突然收紧——挤兑前兆。
- **代币预售会计**：ARC 预售确认进「其他收入」，若被用于抹平储备收入下滑的叙事（不单列、不提示一次性），按「非经常性撑利润」🟡→🔴 处理。
- **与 Coinbase 关系突变**：协议重签/仲裁/Coinbase 自发稳定币动作——分销结构是利润表上头号单一合同暴露（金额见 `财务数据/分销成本.csv`）。
- **并购叙事替代经营叙事**：若某季 RLDC/流通量走弱、而业绩稿把重心换成「新收购带来的 TPV/合作方数量」等**标的方口径、未经审计、且不进本公司收入**的指标，按「用故事盖住引擎失速」🟡 处理；判据=同期 `季度经营.csv` 的 RLDC 与 `USDC运营.csv` 的流通量是否同向。
- **监管两面性**：既受益于 GENIUS，也可能被细则卡（资本/流动性附加、活动限制——10-K 自述将因信托银行与 GENIUS 新增资本要求）。

- **日常（daily-news 哨兵）**：脱锚/大额赎回/储备银行出险/监管细则/Coinbase-Tether 动作——事件触发即入编年。
- **季度（10-Q + 业绩稿）**：六个核心跟踪变量全查，`季度经营.csv`/`中期-*.csv` 增量入库；**内部人 Form 4 按季全量重跑**（管线：`data.sec.gov/submissions/CIK0001876042.json` 取 form=4 → 逐份解析 `nonDerivativeTransaction` 的 code/shares/price + 脚注 10b5-1 标注 → 按**交易日**归季）→ `财务数据/内部人交易.csv`；同一管线取 `SCHEDULE 13*` 刷新 `财务数据/主要股东.csv`（**跌破 5% 后停报，空格=不可观测≠清零**）。
- **年度（10-K）**：储备构成与敏感性表刷新、分销协议条款变化、商誉减值测试、GENIUS 细则进展；刷新 `分析.md` 时旧定性一律回源重验。
- **事件触发**：Arc 主网（2026-09-16 定档）、GENIUS 最终细则、CRF/贝莱德协议变动、渠道协议重签、**CLARITY Act 立法节点（2026-09-15 参议院程序性投票→若过则看两院版本调和后的最终「稳定币奖励」措辞）**、**Tazapay 交割进程**。
  - **Tazapay 待验节点（按发生顺序盯）**：① 新加坡 MAS 等监管批准是否取得；② ≥75% 指定员工留任条件是否满足；③ 交割日前 20 交易日 VWAP → 实际发行股数（**股价越低发股越多**）；④ 交割后 PPA：多少进商誉、多少进无限寿命无形；⑤ 外部截止日 **9 个月（监管未清可延至 15 个月）**到期时是否交割——**无分手费意味着终止的直接财务代价接近零，沉没成本只是时间与管理层注意力**。
  - ⚠️ **该交易的经营侧无法用公司报表验证到交割之后**：标的无经审计财报进本库，公司披露的标的指标（年化支付额/合作方数/稳定币占比）是**新闻稿口径、未经审计**，不得当作已入表收入读（`财务数据/并购与对价.csv` 末段单列该块并已标注口径）。
  - ⚠️ **该项监控源必须在公司外部**：公司自身申报从未提及 CLARITY Act、无任何官方量化 → 盯国会程序与条文措辞，**不要等公司报表**。且 `.gov` 站点可能对自动化取数返回 403，**取不到 ≠ 不存在**（同 memory `unavailable-means-one-path-tried`）。
