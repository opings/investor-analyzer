# circle (Circle Internet Group / CRCL) 财报关注要点

> 持续监控规格（盯什么·频率·警戒线·触线动作）+ 排雷红旗。生意模式完整论述归 `分析.md`；指标时间序列一律落 `财务数据/<csv>`，本文件不嵌数字。
> 行业块：**稳定币 / 浮存金**（无现成模板块——按「银行/金融」的挤兑-利差雷达 + 「互联网平台」的 SBC/渠道雷达自建；本块可供未来 Tether 类/交易所类公司复用）。

- **生意一句话**：发行 1:1 全储备美元稳定币 USDC，独享储备利息（法定不付给持币人）、与分销渠道分成——「链上货币基金浮存生意」。
- **生意类型**：不确定生意（叠加强周期属性：利润 = 流通量 × 利率 − 渠道分成，前两个乘数外生）。

## 🅰 生意模式 / 收入结构 / 护城河本质（读财报前先记住）

- **收入 ≈ 短端利率的函数**：储备限「银行现金 + 贝莱德 Circle Reserve Fund（政府货基·USDXX·持仓每日公开）」，储备收益率贴着 SOFR/3M 美债走——**看营收先看 Fed，别把利率红利读成经营 alpha**（序列见 `财务数据/USDC运营.csv` 季度收益率块）。
- **分销成本是「渠道税」不是可变营销费**：Coinbase 按其平台上 USDC 余额拿走对应储备收入 + 平台外分成一半（Collaboration Agreement + Stablecoin Ecosystem Agreement），Binance 等新渠道再叠加——**USDC 往交易所平台集中 = Circle 自留率被动下降**。真实盈利线看 **RLDC（收入减分销成本）**，不看毛收入（`财务数据/季度经营.csv`）。
- **护城河 = 合规执照集 + 储备透明度**（OCC 联邦信托银行 + 州牌照 + MiCA + GENIUS PPSI 路径），防小玩家有效；**防不了两头**——离岸 Tether（监管/税负套利）与 GENIUS 生效后入场的银行系/代币化存款。
- **验真链条业内少见地短**：链上负债可数、储备基金每日披露、10-K/A 附基金独立审计——报表造假空间小，**主风险天生在表外**（挤兑/利率/竞争）。
- **一次性项密集体质**：IPO 型 SBC、可转债/权证公允价值、代币预售确认、税项一次性——看趋势必须用 `季度经营.csv` 拆一次性后再比。

## 🅱 风险雷达（挤兑-利差-渠道三主轴）

- 🔴 **脱锚/挤兑**（头号·表外）：二级市场 USDC 价格偏离 1 美元、单日大额净赎回、储备银行对手方出险（SVB 型）。报表完全照不出来，出事在小时级。
- 🔴 **利率下行**：储备收益率随 Fed 降息直落；公司自测 ±100bp ≈ 储备收入 ±4 亿美元量级/年（10-K 敏感性表）。流通量增速若同时熄火 = 双杀。
- 🔴 **GENIUS 生效后的竞争洪水**：银行/大机构发币、代币化存款、TMMF（含自家 USYC）分流「要收益的资金」；生效时点 = 2027-01-18 或最终细则后 120 天孰早——**细则出台节奏本身是事件级信号**。
- 🟡 **渠道自留率恶化**：USDC on-platform 占比抬升、新分销协议一次性预付/激励费——RLDC 率是照妖镜。
- 🟡 **Arc/ARC 代币执行与监管定性**：主网上线节奏、PoS 转型 deadline（2028-05-08 未转须退预售款）、代币的证券法定性风险；预售收入确认的一次性美化。
- 🟡 **软件资本化率**：资本化（含资本化 SBC）持续大于摊销 = 利润温和美化。
- 🟡 **内部人减持节奏**：双层股权 + 创始人投票权近三成 + Form 4/144 常态流水，减持骤然放量是信号。

## 本公司独有红旗 / 易暴雷点

- **储备侧任何「创新」**：储备里出现非白名单资产、收益率异常跑赢基准、储备鉴证延迟——对全储备承诺的任何松动都是 🔴（对照造假模式库 B 类「现金验真」逻辑的稳定币版）。
- **赎回摩擦**：暂停/延迟赎回、Mint 客户门槛突然收紧——挤兑前兆。
- **代币预售会计**：ARC 预售确认进「其他收入」，若被用于抹平储备收入下滑的叙事（不单列、不提示一次性），按「非经常性撑利润」🟡→🔴 处理。
- **与 Coinbase 关系突变**：协议重签/仲裁/Coinbase 自发稳定币动作——分销结构是利润表上头号单一合同暴露（金额见 `财务数据/分销成本.csv`）。
- **监管两面性**：既受益于 GENIUS，也可能被细则卡（资本/流动性附加、活动限制——10-K 自述将因信托银行与 GENIUS 新增资本要求）。
