## 公司分析速览

> 截至 2026-07-02。只放对**公司**的判断;本项目不沉淀任何主观决策。

- **生意质量(护城河)**:**一般偏弱**——护城河 = 艺术家 IP 独家签约 + 全球零售网络 + 社群/内容运营,但**任一 IP 的生命周期 2-3 年,单 IP 集中度过高**,爆款终会老去(2022 净利 -43% 就是历史证据)。护城河能防新进入者,防不住 IP 老化本身。
- **三大前提**:利润为真 ✅ · 维持利润不需大量资本投入 ✅ · **利润可持续 ❌**(核心问题)
- **股东回报姿态**:**混合偏"再投资"** —— 累计分红 24 亿 vs IPO 净募资 50.7 亿(未含 2020 上市前分红 3.78 亿),分红率从 2020 年的 72% 一路降到 2025 年的 8.5%,保留利润高比例扩张海外+新 IP;有 2022/2023/2024 少量回购但未持续大额回购。
- **排雷结论**:三表勾稽 60 条全过 + 通用红旗零命中(存贷双高、审计标准无保留等) —— **报表本身很干净**。但潮玩/IP 特有红旗有 🔴/🟡 项(见五、);**干净的三表不代表这门生意可估值**。
- **核心逻辑是否变坏**:**是** —— 2026-06-25 LABUBU 新款破发 + 2026Q1 整体增速回落到 +75-80%(vs 2025Q1 +165-170%),爆款周期见顶信号已现;当前极端高的净利率/ROE(35%/57%)大概率是周期顶部,不可外推。
- **一句话画像**:**一家不断孵化 IP 爆款的 2C 潮玩零售公司** —— 干净的账、印钞机的现金流、周期极强的业绩节奏、单 IP 决定全公司生死;归入"不确定生意/太难"。

## 二、商业模式与生意质量(正面:这门生意多好)

### ① 靠什么挣钱

卖**艺术家 IP 具象化的潮玩商品**(盲盒/搪胶/毛绒/MEGA 大娃)。核心是**情绪价值 + 收藏溢价**:
- 单个产品定价 59-599 元,毛利率 2025 高达 72.1%(接近奢侈品档)
- 用户为**"喜欢这个形象/角色"**买单,不是为物理效用
- 隐藏款/联名款/限定款制造二级市场溢价,反哺一级市场热度

**客户为何选它**:艺术家 IP 独家签约 + 内容运营 + 全球门店 + 隐藏款玩法。但**"喜欢"是易变的**——用户可以从 MOLLY 移情到 SKULLPANDA 再到 LABUBU,也可能整体从潮玩移情到其他情绪商品(咖啡/手办/游戏)。

### ② 钱能不能回款

**极其健康,2C 零售的天然优势**:
- 应收/营收长期 3-5%,2025 降到 2.48%
- 收现比 ≈ 1.0(2C 现付)
- 经营现金流/净利 6 年区间 0.84-1.87,大多数年份 ≥ 1
- **2025 现金含量 0.84 是异常**——需追因:一是所得税已付跳升(6.9 亿 → 40.8 亿,追缴+当期);二是存货占用现金大增(15.2 亿 → 54.7 亿);三是非现金收益(FVTPL 调整、汇兑)

数字见 `财务数据/财务比率.csv`。

### ③ 行业链地位强不强

- **对上游(艺术家/授权方)**:独家签约模式绑定核心 IP,但**签约到期风险始终存在**——若 Kasing Lung(LABUBU 设计师)独立开发或转投同行,是重大冲击。
- **对下游(消费者)**:议价权强(定价能力),但**替代品充裕**——潮玩品牌多(52TOYS/寻找独角兽/万代/乐高等),转换成本几乎为零。
- **对渠道**:自营零售 + 机器人商店 + 线上直营,不依赖大经销商 = 没有白酒式渠道压货风险,但也没有白酒式渠道蓄水池(合约负债/营收 1-3%,远低于白酒 20%+)。
- **议价权体现**:2025 应付周转 65.5 天 + 收现快 = **净营运资本极健康**。但商业模式决定了它不能像白酒那样"用别人的钱做生意"。

### ④ 前瞻增长的事实面

**只摆事实,不做增速预测**:

- **IP 生命周期规律(9 年硬数据·招股书回填后的完整证据链)**:
  - 2017-2019(上市前): **MOLLY 89.4% → 62.9% → 32.9%**(3 年从近乎 100% 单 IP 依赖降到 1/3,PUCKY/DIMOO/The Monsters 快速起势填空)——**招股书自证的 IP 洗牌初次证据**
  - 2020-2021: MOLLY 14-16%(继续降),SKULLPANDA 起势
  - 2022-2023: SKULLPANDA 接棒(16-18%),MOLLY 下滑但仍稳
  - 2024-2025: THE MONSTERS/LABUBU 井喷(23% → 38%),前三大 IP 洗牌
  - **每 2-3 年换一次主力 IP** 规律从 2017 起就一直如此——公司孵化能力已 9 年验证,但每次换代过程都伴随业绩巨幅波动(2022 -44%);LABUBU 见顶后下个主力尚未清晰
- **海外扩张**:2025 海外占比 43.8%(vs 2024 31.8% vs 2023 <25%)、美洲 +748%、欧洲 +506%。**基数低起点**(2023 海外仅 10 亿+),2026Q1 美洲 +55-60% 已显著回落 —— 是否可持续待观察。
- **渠道结构**:2025 中国区线上 +207%(抖音+抽盒机+其他电商)显著快于线下 +113%,渠道数字化加速。
- **2026Q1 增速已回落**(编年 2026-05-12 公告):整体 +75-80%、中国 +100-105%、亚太 +25-30%、美洲 +55-60% —— **相比 2025Q1 全部区域大幅减速**;需继续观察 Q2/Q3 是否巩固减速斜率。
- **2026-06-25 破发信号**(编年):LABUBU「复古理发店」新款半小时跌破发售价、隐藏款溢价从 25 倍缩到 5 倍、"一票难求"终结 —— **热度峰值可能已过**。

## 三、三大前提验证(事实与证据)

### 1. 利润为真 ✅(但 2025 需关注)

- 经营现金流/净利 6 年区间 0.84-1.87,除 2025 外均 ≥0.91,历史整体健康
- 应收占营收长期 3-5%,2025 反降到 2.48%,健康
- 合约负债/营收 1-3%(2C 模式合约负债本就不是核心蓄水池)
- **2025 现金含量首次 <1(0.84)** 需追因:所得税已付跳升 6.9→40.8 亿(追缴+当期)+ 存货占用现金 +39.5 亿(海外备货) —— 定性可解释,但需要 2026 中报确认转回

**结论**:历史利润为真 ✅;**2025 现金含量下滑需持续跟踪**,不改变整体判断。

### 2. 维持利润不需要大量资本开支 ✅

- capex(PPE + 无形)/净利:2020 43% → 2025 9.0% (完全印钞机档)
- capex/经营现金流:2020 32% → 2025 11% (远低于经营现金流)
- 使用权资产虽然增(全球开店),但作为经营租赁不构成"重资产"结构
- 无重大在建工程

**结论**:**极其轻资产,印钞机特征鲜明** ✅

### 3. 利润可持续 ❌(核心问题)

- **护城河脆弱**:艺术家 IP 独家签约可复制、门店可扩张、但"用户喜欢什么"是不确定的
- **单 IP 集中度过高**:2025 LABUBU 一 IP 占 38.1%,前 5 大 IP 占 71%
- **历史证据反证不可持续**:2022 归母净利同比 -43%(MOLLY 老化+疫情)—— 单主力 IP 下滑时业绩会断崖
- **2026 拐点信号**:LABUBU 破发(6/25) + 2026Q1 增速大幅回落 → 爆款周期见顶信号已现
- **护城河能防新进入者,防不住 IP 老化本身**:泡泡玛特再优秀,也无法保证下一个 LABUBU 一定诞生、一定同等强度、一定同等生命周期

**结论**:**利润不可持续** ❌ —— 这是本公司最核心的问题,也是"归入不确定生意/太难"的直接依据。

### 5.2 股权架构与股东回报(管理层立场的照妖镜)

**股权架构**:

- 分红率(归母):2020 72% → 2021 24% → 2022 46% → 2023 11% → 2024 12% → 2025 8.5% —— **一路走低**
- 大股东行为:编年未见系统性减持/质押

**结论**:**"再投资"路线,不是给股东路线**——利润高速留存扩海外+新 IP。这在成长期是正常的,但**需要相信下一个爆款 IP 一定诞生 + 海外一定成功**才成立。命中"大比例融资 + 持续留存不分" ≠ 命中"套现"红旗,是**中性**的成长期姿态。

## 六、小结

**这是一家什么生意**:
一家从盲盒起家、通过独家签约 + 内部孵化不断做出爆款 IP 的 2C 潮玩零售公司。**账面质地极佳**——三表 60 条勾稽全过、印钞机现金流、无有息负债、无重大商誉、审计无保留。

**好在哪**:
- IP 孵化能力已被 6 年三换主力 IP 反复验证
- 2C 零售模式回款极快(几乎无应收)
- 极轻资产(capex 占净利个位数%)
- 全球扩张有天花板但短期空间还大

**可能怎么坏**:
- **IP 老化的必然性**(不可控)—— 2022 -43% 净利已证明
- **单 IP 集中度 38.1%**(2025 LABUBU)为历史最高值,风险积压
- **2026-06-25 破发信号 + 2026Q1 增速大幅回落** —— 爆款周期见顶信号已现
- **护城河能防新进入者,防不住 IP 老化本身** —— 这门生意的**结构性上限**

**核心逻辑变坏了吗**:
**部分变坏**:
- 三表账面(会计层)= 完全没坏,反而在 2025 达到史上最好
- 生意本质(经营层)= LABUBU 见顶信号已现,当前极端高的净利率/ROE 大概率是周期顶部
- 结构性风险(生意质量层)= 一直存在,只是被 LABUBU 爆红掩盖

**判定**（生意质量四问 + 三前提·两道闸门任一 ❌）:
- 生意质量四问 = 护城河能挣钱但不能持续(第一问红灯)
- 三大前提 = 利润为真 ✅ + 维持利润不需重资本 ✅ + **利润可持续 ❌**
- 任一不过 → **归"太难"·生意本身不可估**·不给合理估值·不给买卖点

**结论**:**归入不确定生意/太难,不给买卖点**。**不含任何主观决策**(我懂不懂 / 买不买 / 仓位 / 操作)——本项目只做公司客观分析。
