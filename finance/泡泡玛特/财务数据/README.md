### 上市前 3 年新洞察(招股书 2017-2019)

- **爆发式增长历史**:营收 3 年 10.6 倍(1.58→16.83 亿)、净利 3 年 288 倍(0.016→4.51 亿);增速极端,不可外推(是"不确定生意"客观属性的关键证据)
- **单 IP 集中度演进史**:MOLLY 2017 89.4% → 2018 62.9% → 2019 32.9% → 2020 14.2%;**每 2-3 年主力 IP 洗牌一次**的规律从上市前就已经在数据里
- **上市前 CF 特征**:2017/2018/2019 现金含量 9.88 / 1.76 / 1.11,极强现金创造能力(2017 净利极小 + CF 已经上百万,是 2020 后印钞机特征的雏形)
- **上市前 ROE**:2018 45.48% → 2019 76.10%,极高;跟 2024 29.26% / 2025 57.35% 属同档;**说明这门生意在爆发期能创造极高 ROE**,但可持续性仍受 IP 生命周期限制

## 为什么必须从一手财报解析

港股同型公司东财二手数据存在同样风险(参考农夫山泉记忆:「经营业务现金净额」把税前 256 亿误标成净额,真净额 211 亿)。一手年报的:

- **损益表** = 数字唯一真源,避免二手口径错位
- **资产负债表附注** = 唯一披露科目明细(如「其他应收款」内部结构、「合约负债」性质)
- **董事会报告 MD&A** = 独家披露分部/区域/渠道/IP 拆解 + 增速解释
- **附注 现金流量表调节** = 从净利到经营现金流的完整调节过程
- **招股书附录一会计师报告** = IPO 前 3 年经审计财务数据的**唯一一手真源**(上市前无年报,只有招股书)
