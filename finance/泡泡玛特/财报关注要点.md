## 🅰 生意模式 + 护城河本质(读财报排雷相关的知识)

- **销售模式 = 2C 零售为主**(不是先款后货):零售店 + 机器人商店 + 自有线上 + 第三方平台;批发占比小(`财务数据/分部营收-H1.csv` 各区域渠道块)→ **合约负债量小,不是蓄水池**,但它随线上预订热度同向变化,可作辅助温度计。
- **护城河**:
  - 艺术家 IP 独家签约 + 内部孵化(核心)——2025 年 6 个 IP 年收入超 20 亿(`财务数据/分部营收.csv` 2025 列);LABUBU 作者在招股书时为两年期独家授权【源·招股书独家 IP 艺术家表】
  - 自营门店与机器人商店网络(中)——门店数见 `财务数据/门店与会员.csv`
  - 社群 / 内容运营 + 二级市场热度(弱)——溢价一破,热度传导会反向(2026-06/07 已发生,见编年)
- **脆弱点**:单 IP 热度决定业绩节奏;替代品多、用户无转换成本;门店与人手扩张形成固定成本,收入下行时利润降幅大于收入降幅。

## 🅱 排雷雷达(潮玩 / IP 型公司必查)

> 🔴 = 触发即高警惕 / 🟡 = 追因后定级 / 🟢 = 无异常。**本期判定见 `分析.md` 五**,本表只列监控规格。

- 🔴 **单季收入同比转负**(季度业务更新):已触发(2026Q3)。连续两季为负 → 生意类型判断维持、`分析.md` 三.3 维持 ❌。落 `财务数据/季度业务更新.csv`。
- 🔴 **二级市场溢价破位**(非报表):隐藏款 / 联名款二手价跌破发售价 = 需求端降温。落事实编年。
- 🔴 **海外线上崩塌 / 海外整体转负**:海外线上与海外整体同比为负 → 🔴;海外线下也转负 → 升级为「海外扩张逻辑失效」。落 `财务数据/分部营收-H1.csv` 派生块与 `季度业务更新.csv`。
- 🟡 **存货与收入背离**:存货占总资产 >20% 或期末口径周转 >150 天且收入同比为负 → 🔴;看减值计提是否与收入降幅相称(计提很小而收入大降 = 减值滞后嫌疑)。落 `财务数据/财务比率-H1.csv` / `财务比率.csv` + `费用按性质-H1.csv`「存货减值」行。
- 🟡 **现金含量(两段式)**:先看税前现金含量(经营所得现金 ÷ 除税前溢利),再看现金含量(经营现金流 ÷ 净利)。现金含量 <1 而税前 ≥1 → 差额在税的时间差(看实付税 − 税费、即期所得税负债),维持 🟡;税前 <1 → 拆营运资金(年报附注「除税前溢利与经营活动现金对账」),差额堰塞在存货 → 🔴;年度税前 <1 连续两年(2025 年已 <1)→ 🔴。落 `财务数据/经营现金流拆解.csv`、`财务比率.csv`。
- 🟡 **固定成本刚性**:租赁相关费用、僱员福利开支增速 > 营收增速,且营收同比为负 → 🔴 经营杠杆反向。落 `财务数据/费用按性质-H1.csv` + `门店与会员.csv`。
- 🟡 **汇兑**:公司无外汇对冲【公司自述·编年 2026-08-20】;「其他收益/亏损」行单期绝对值 > 经营溢利 10% → 拆附注。落 `财务数据/利润表-H1.csv` / `利润表.csv`。
- 🟡 **非控股股东派息 > 其应占利润**(泰国子公司):持续 → 追子公司股权与派息安排。落 `财务数据/现金流量表-H1.csv`「已付非控股股东股息」+ `利润表-H1.csv`「非控股权益溢利」。
- 🟡 **递延所得税资产(集团间销售未变现溢利)**:这一项是海外子公司按集团内部价持有、尚未卖出的货在税上的影子(2024 年初为零,`财务数据/递延所得税资产构成.csv`),能否收回取决于海外子公司以后的应税利润。年报看三处:① 集团间那项——海外收入下降而它不降 → 🔴 海外压货;② 「超过 12 个月后收回」部分明显变大 → 公司自认回收变慢;③ 所得税对账表「未确认递延所得税资产的税项亏损」明显变大,或实际税率显著高于 25% → 追附注是否减记(`财务数据/所得税税率对账.csv`)。中报只披露净额,不拆项。
- 🟢 **存贷双高** = 无(无银行借款)。🟢 **审计意见** = 罗兵咸永道无保留(2025 年报)。🟢 **商誉 / 在建工程 / 关联方占款** = 无重大项。

## 🅳 独有红旗 / 易暴雷点(泡泡玛特特有)

- **单一外部艺术家依赖**:LABUBU 作者为外部艺术家,招股书时为两年期独家授权【源·招股书独家 IP 艺术家表】;之后的续约期限与条款本库未核 ⏳——跟踪年报授权费应付与关联方披露。
- **存货无残值**:潮玩过季后可变现净值低;收入转降时,前期为海外扩张备下的存货是以后期间利润下滑的主要来源(`财务数据/财务比率-H1.csv` 存货 / 总资产);海外那部分另连着集团间销售未变现溢利的递延所得税资产,打折到内部价以下或海外子公司持续亏损时,抵不回来的部分会变成税费(见 🅱)。
- **海外线上流量依赖**:海外线上收入依赖外部平台流量(TikTok、Shopee 等),公司已自陈流量红利消退【公司自述·编年 2026-08-20】;平台政策或关税变化直接影响海外线上。
- **汇率**:海外收入占比可观且无对冲,汇兑损益直接进经营溢利(`财务数据/利润表-H1.csv`「其他收益/亏损」)。
- **监管 / 地缘 / 山寨**:盲盒与未成年人消费监管、海外关税【疑·本库无一手条目】;山寨商品【源·编年 2026 多条】。
