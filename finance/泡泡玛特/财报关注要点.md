# 泡泡玛特 · 财报关注要点（泡泡玛特特有）

> 配合 `_模板/财报阅读规则.md` 通用 SOP 使用。本文件只列**泡泡玛特独有**的看点。
> 港股 9992.HK（人民币报表、港币交易）。**无季报**（半年报 + 年报）。IP 潮玩，爆款驱动。

---

## 一、估值取数（泡泡玛特特有·最关键）

- ⚠️ **无法估值（直接下结论）**：爆款 IP 驱动、一年净利数倍增、三年后净利不可靠预估 → 三大前提②过不了 → **不套公式、不给买卖点**，归"太难"/能力圈外。敏感性测算仅量化不确定性，非买点。
- **基数用经调整净利**，但**警惕峰值盈利**：2025 净利 130.84 亿大概率含 Labubu 爆款峰值成分，不能简单外推。估值应考虑「正常化盈利」（剔除爆款峰值）。
- **不宜高 PE**：爆款盈利不可持续，按 50PE 持有/估值很危险。此类业务应给**更低 PE + 更保守安全边际**。
- 无季报 → 半年报（约 8 月）确认降速幅度。

## 二、利润为真（泡泡玛特信号）

| 指标 | 看什么 | 正常态 |
|------|--------|--------|
| 经营现金流/净利 | 现金含量 | 2025=0.83（爆发期备货占用）；零售即时回款 |
| **存货** | 余额+周转 | ❗爆发期大幅备货（2025 存货 54.7 亿/+259%）；**退潮时滞销是最大预警** |
| 应收 | 占比 | 低（零售/电商即时） |
| 净现金 | 现金-借款 | 净现金 ~175 亿，无有息借款 |

## 三、经营质量（泡泡玛特独有结构）

- **IP 矩阵 + 集中度**（年报披露各 IP 收入）：
  - **Labubu（THE MONSTERS）占比**（2025=38%）—— 单 IP 依赖度，**最核心指标**。占比下降（新 IP 接力）= 健康；持续高度集中 = 风险。
  - 17 个 IP 破亿（SKULLPANDA/CRYBABY/MOLLY/DIMOO/星星人/HIRONO…）—— IP 矩阵厚度。
  - 新 IP 能否持续孵化出爆款（平台能力的核心验证）。
- **产品结构**：毛绒玩具占比（2025 首成第一品类 187 亿）；手办/盲盒/MEGA 等。
- **渠道**：线下门店 + 机器人商店（roboshops）+ 自研 APP/官网 + 电商（天猫/京东/TikTok/Amazon/Shopee）。
- **海外占比（增长引擎）**：中国 vs 亚太/美洲/欧洲。海外门店净增、海外收入占比提升 = 第二曲线。
- **会员**：注册会员数、会员销售占比（93.7%）、**复购率（55.7%）**—— 复购率反映 IP 黏性 vs 一次性狂热。
- POP LAND（乐园）、popop、POP BAKERY、IP 授权等新业务孵化。

## 四、泡泡玛特特有排雷 / 关注

- **❗❗ IP 生命周期 / 爆款退潮**：Labubu 热度能否延续？类似游戏爆款、时尚潮流，可能快速退潮。**这是决定性风险。**
- **单 IP 集中度**（38%）：过度依赖 Labubu。
- **存货滞销**：退潮时备货变库存减值。
- **盲盒监管**：盲盒/抽盒模式的监管政策（未成年人保护、概率公示等）。
- **海外**：地缘、汇率、合规、IP 文化适配。
- **峰值盈利幻觉**：勿按 2025 峰值 + 高 PE 锚定估值。
- 派息率约 **25%**（2025 末期股息每股 2.3817 元/共 31.94 亿；首版"~8%"系未读年报的笔误，已更正）；比率较 2024（34.7%）回落=爆发年加大留存再投；现价波动极大。

## 关键跟踪变量（每期财报/半年报后回答）

1. **Labubu 热度与生命周期** —— 是否退潮（最关键）？
2. **单 IP 集中度** —— Labubu 占比是否下降、新 IP 是否接力？
3. **海外收入占比与增速** —— 第二曲线？
4. **存货周转** —— 退潮预警。
5. **会员复购率** —— IP 黏性 vs 一次性狂热。
6. **经调整净利增速** —— 管理层「2026 降速」兑现幅度。
7. 半年报（约 8 月）—— 无季报，半年确认趋势。
8. **段永平持仓动向** —— 2026-05 段已举牌成第二大股东（6.04%，均价约 150 港元 ≈ 本库保守买点 145）；后续增减持及其公开阐述是重要旁证（**非抄作业理由**）。
