# 泡泡玛特(09992.HK) 财报关注要点

> **持续监控规格 + 排雷红旗**(不复述完整生意论述,那在 `分析.md`)。**指标不嵌数字**,时间序列全部在 `财务数据/<csv>`。

- **生意一句话**:靠"艺术家 IP × 盲盒/搪胶/毛绒潮玩 × 全球零售网络"卖情绪价值——本质是 **快消 IP 授权/自制商品**,单 IP 生命周期 2-3 年;IP 矩阵需要不断孵化下一个爆款。
- **生意类型**:**不确定生意**(客观属性)——爆款依赖 + IP 生命周期短 + 单 IP 集中度过高(2025 LABUBU 占 38.1%);历史证据 = 2022 归母净利同比 -43%(MOLLY 老化 + 疫情)。**归入"太难"**。
- **行业匹配**:`_模板/财报关注要点-行业模板.md` 的「**互联网/平台**」块最近(泡泡玛特被明示为"爆款/IP 集中度过高且生命周期不定 → 归入不确定生意"),但泡泡玛特 IP 消费品属性又类似消费/零售——本文件从两处融合起步。

## 🅰 生意模式 + 护城河本质(读财报排雷相关的知识)

- **销售模式 = 2C 零售**(不是白酒式先款后货):零售店 + 机器人商店 + 线上 + 抖音/天猫 → **合约负债非核心先行指标**(与白酒不同,泡泡玛特合约负债/营收长期 <5%,不做安全垫用途)。
- **护城河**:
  - **艺术家 IP 独家签约 + 内部孵化能力**(核心)——2025 年已有 6 个 IP 年收入破 20 亿(详见 `财务数据/分部营收.csv` 2025 列)
  - **全球线下门店网络**(壁垒中)——机器人商店 + 大城市黄金地段零售店
  - **社群/内容运营 + 二级市场热度**(壁垒弱)——盲盒隐藏款炒作驱动溢价,但溢价崩塌就失效(2026-06 已发生)
- **护城河脆弱点**:
  - 单 IP 生命周期决定业绩节奏,老化时收入断崖(2022 已见)
  - "情绪价值"依赖用户群"上头",替代品多(乐高/万代/其他潮玩品牌)
  - 二级溢价一破,主流玩家可能撤离

## 🅱 排雷雷达(潮玩/IP 型公司必查)

> 🔴 = 触发即高警惕 / 🟡 = 追因后定级 / 🟢 = 无异常。**判定见 `分析.md` 五、排雷与风险**,本表只列监控规格。

- 🔴 **龙头 IP 收入占比 > 35%**:LABUBU 2025 已 38.1%,继续升 → 集中度风险加剧;骤降 → 主力老化。落 `财务数据/分部营收.csv`「按 IP」块。
- 🔴 **龙头 IP 二级市场溢价率破位**:非年报口径,通过日常盯盘(得物/闲鱼/千岛)采集;隐藏款溢价从 20+ 倍缩水到 5 倍以下 = 需求端见顶信号(2026-06-25 已出现)。落 `../../knowledge/companies/泡泡玛特/YYYY-MM.md` 事实编年。
- 🔴 **单季度增速大幅回落**:比对最近 4 个季度增速斜率变化;2026Q1 增速已回落到 +75-80%(vs 2025Q1 +165-170%)—— 已有减速信号。落 `财务数据/<季度指标>.csv`(建议新建)。
- 🟡 **存货急升 + 毛利率同升**:存货周转天数 vs 毛利率同方向变化 —— 是造假模式库典型模式(存货周转↓ + 毛利率↑ =🔴)。2025 存货天数 128.5 → 192.9,毛利率 66.8% → 72.1%,双升 → **🟡 需长盯**(海外备货合理性 vs 需求见顶后堆积)。
- 🟡 **海外美洲增速**:2025 美洲 +748%、欧洲 +506% —— 基数低效应,判断是不是一次性铺货;2026 起看第 2 年同店/同店增速。
- 🟡 **递延所得税资产异常**:2025 从 1.47 亿飙到 17.5 亿(+1094%),需要看附注 19 是否是海外亏损结转 or 存货减值等暂时性差异。若持续膨胀 → 深挖。
- 🟡 **非控股权益规模跳升**:2024 少数股东权益 2 亿, 2025 3.7 亿;损益也在跳增。是海外子公司引入战投 or JV 常态,还是利润转移?追附注。
- 🟢 **存贷双高** = 无(几乎无有息负债,现金充裕)。
- 🟢 **审计意见** = 罗兵咸永道无保留。
- 🟢 **商誉/在建工程/关联方占款** = 无重大项。

## 🅳 独有红旗 / 易暴雷点(泡泡玛特特有)

- **单一艺术家/IP 归属方合作破裂风险**:LABUBU 的原始设计师 Kasing Lung(龙家昇)是独立艺术家,若签约到期未续/独立开发同类 IP,是重大风险。跟踪年报授权费应付明细(License fees payables)+ 关联方交易披露。
- **政策/监管风险**:盲盒对未成年人销售监管收紧(2023 起中国有规范); 未来若加强监管,直接影响国内 55%+ 收入。
- **地缘政治**:2025 美洲收入占 18.3% 且增速极高,若遇美中关税/贸易摩擦 或 特定 IP 被禁,冲击集中。
- **山寨/知识产权**:LABUBU 全球爆红后,山寨横行(编年 2026 有多起案例) —— 品牌溢价被稀释风险。
- **存货减值风险**:潮玩过时的商品无残值;存货已升至总资产 ~17%、周转天数创上市以来最高(2025,详见 `财务数据/财务比率.csv`),一旦爆款周期结束数十亿量级存货可能面临大额减值(未减值 = 未来利润雷)。

## 🅴 历史踩过的坑 / 管理层诚信记录

- **上市前 3 年 IP 洗牌史(招股书 2017-2019 硬数据)**:MOLLY 单 IP 占比从 2017 89.4% → 2019 32.9% → 2020 14.2%(4 年内主力 IP 从近九成降到 1/7);**IP 生命周期短 + 需要不断孵化下一款**从上市前就已经在数据里,不是 2022 后才出现的问题——这是**结构性属性,不是阶段性问题**。
- **2022 净利同比 -43%**:MOLLY 老化 + 疫情双击,证明单 IP 依赖 + 消费场景中断的双重脆弱。可对照:即便疫情放开,2023 恢复也只回到 +108%(相比 2021),完全爆发要等 LABUBU 起来。
- **分红两口径勿混读**(现金流「年内已付」有跨年时间差):已付口径分红率 8-46% 波动(`财务数据/财务比率.csv` 已付股息行);**宣派口径 2025 年度末期股息派息率 ~25%、2026-05-28 已派付 31.94 亿(编年 2026-05)——分红显著升档**,但约 3/4 利润仍留存扩张(海外/新 IP),留存为主的姿态未变。
