# 分众传媒 财报关注要点

> 行业块：周期/资源（分众在行业模板"周期"块明确在列：产品价格=广告刊例、产能利用率=点位刊挂率）。
> 数字一律在 `财务数据/<csv>`，本文件只写监控规格（指标/频率/警戒线/触线动作）。

- **生意一句话**：把电梯口场景批发为品牌广告位——点位租金是固定成本，广告收入随大盘摆动，利润=高经营杠杆放大后的广告周期。
- **生意类型**：**强周期**（单年净利不可外推；扣非峰谷比可达 4:1，见 `财务数据/利润表.csv`）。

## 🅰 生意模式 / 护城河本质（读财报排雷相关的最小集）

- **点位是租的不是自有的**：媒体资源成本（租金）占营业成本 2/3 以上（`财务数据/成本构成.csv`）——竞争加剧→上游物业涨租→毛利率被两头挤（2018-2019 新潮大战实证）。护城河=网络规模+场景卡位+头部客户关系，**不是资源占有**。
- **高经营杠杆**：成本近似固定 → 营收变动被放大为利润巨幅波动；毛利率是周期温度计（区间约 45%-73%，见 `财务数据/财务比率.csv`）。
- **赊销制**：对下游赊销（应收大）、对上游预付/短账期（应付小）——营运资本两头被占，和"先款后货"快消是反面。
- **利润表噪声源**：政府补助（每年数亿·计入其他收益）+ 投资类资产（联营/基金/权益工具）的公允变动与减值——**读利润先看扣非、再手剔投资类损益**（数禾 2025 减值留在扣非内的先例见 `财务数据/README.md` 备注 7）。

## 🅱 本公司独有红旗 / 易暴雷点

- 🟡 **"毛利率升 + 应收增 + 应付减"三连**：2025 年形式命中（各有独立解释）——每年年报按 C 类红旗纪律复扫一次，解释不成立即升级（`财务数据/财务比率.csv`+`资产负债表.csv`）。
- 🟡 **政府补助依赖**：政府补助/利润总额超过 15% 的年份，扣非与归母的差距失真度上升；补助骤停是政策风险（`财务数据/财务比率.csv` 定制行）。
- 🟡 **投资资产减值-处置跷跷板**：先大额减值、次期处置兑现收益（数禾 2025→2026H1 实证）——利润年度形状被投资节奏塑形，跨年拼接扣非+剔投资口径看主业。
- 🟡 **借壳/承诺史**：2015 借壳估值 457 亿、业绩承诺前两年完成率 103.8%/106.1%（贴线达标）；2011 年浑水曾做空质疑点位统计口径——**点位数披露口径变化（自营/加盟/参股分类调整）需逐年对表**（`财务数据/媒体点位数.csv` 已记口径断点）。
- 🔴（前瞻）**新潮并表后商誉**：对价 77.94 亿 vs 标的微利体质（2025 归母约 0.54 亿·隐含约 160 倍·营收下滑中，一手数见编年 2026-08-28 新潮审计报告）——若并表首年即改减值测试资产组口径或迟迟不减值，按造假模式库 B 类"该提未提"处理。

## 历史踩过的坑 / 管理层诚信记录

- 2011 浑水做空（NASDAQ 时期·屏幕数口径+关联收购减值质疑·无监管定论）→ 2013 私有化 → 2015 借壳回 A（估值差数倍）——中概回 A 套利路径，治理立场的历史注脚。
- 2018-2019：顺周期大扩张（点位翻倍+capex 峰值）撞上大盘下行+客户暴雷 → 2019 扣非缩 74% + 坏账 7.4 亿——**"顺周期扩产=见顶信号"在本公司有精确前科**。
- 数禾科技：持股 54.97% 以董事会 4/9 席不并表（合并范围靠治理安排）；累计确认数年权益法收益后 2025 一次减值 73.45%、2026-01 清仓退出。
- 阿里系"二股东+第一大客户"双重身份（2018 至今）；与阿里系共同投资基金多起——关联网络密集，公允性依赖治理。

## 持续监控节奏

- **季报**：营收 yoy（周期位置）+ 应收变动。
- **半年报/年报**：五个核心跟踪变量全查 + 三表勾稽 6 条 + 造假模式库全清单复扫 + 点位口径对表。
- **事件触发**：新潮交易三关节点（深交所审核/证监会注册/反垄断）、大股东与阿里系增减持/质押、关联交易额度变更、大额投资资产减值或处置公告。
- **年度**（年报后）：刷新 `财务数据/` 各 csv（跑 `_build_from_pdf.py` 补年份）→ 刷新 `分析.md` → 复核本文件警戒线。
