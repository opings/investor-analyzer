## 🔴 第一件必须知道的事：期间轴不是一条年度序列

361度**改过财政年度结算日**。据 2011 年报附註 1「更改財政年度結算日」：依公司 2011-08-23 公告，财政年度结算日由 **6 月 30 日改为 12 月 31 日**，中间夹一个**六个月过渡期（2011-07-01 ~ 2011-12-31）**。

因此本库的列是**三段**：

| 段 | 列名 | 期间长度 | 口径 |
|---|---|---|---|
| ① | `FY2006/6` … `FY2011/6` | 12 个月 | 止 **6 月 30 日**的财政年度 |
| ② | `2011H2` | **6 个月** | 2011-07-01 ~ 2011-12-31 过渡期 |
| ③ | `2012` … `2025` | 12 个月 | 止 **12 月 31 日**的财政年度 |

> **`2011H2` 是半年数**。把它当成一个"年度"接进序列，会凭空造出一次腰斩再翻倍；
> 所有同比 / 复合增速 / ROE / 周转天数在该列都必须先排除或年化。CSV 表头注释里也写了这一条。
>
> 另有一个**陷阱**：2011 年报**前部**（管理层讨论之前）还印了一套「截至二零一零年及二零一一年十二月三十一日止年度」的**未经审核 12 个月日历年对比**（营业额 5,568.7 百万），与后面**经审核的 6 个月正表**（营业额 2,382.8 百万）差 2.3 倍。本库取的是**经审核正表**。

## 勾稽自洽校验

由 `_build_from_pdf.py` 生成，**校验不通过则不写出 CSV**。当前状态：**261 条恒等式全部通过**；跨源交叉核 **1,182 格**，差异 11 处**全部已判读且有算术佐证**（见下），未判读差异 **0**。

| 类别 | 条目 |
|---|---|
| 损益 | 营收 − \|成本\| = 毛利；除税前 − \|税\| = 本期溢利；股东应占 + 非控股 = 本期溢利 |
| 资产负债 | 流动资产 − 流动负债 = 流动资产净值；非流动资产 + 流动资产净值 = 总资产减流动负债；再 − 非流动负债 = 资产净值；股本 + 储备 = 股东应占权益；+ 非控股 = 权益总额 = 资产净值 |
| 现金流 | 经营 + 投资 + 融资 = 现金净变动；期初 + 净变动 + 汇率 = 期末 |
| 跨表 | 损益「除税前溢利」= 现金流量表起点；资产负债表现金 = 现金流量表期末现金 |
| 分部 | **每期分产品合计 = 利润表营业额（21/21 分毫吻合）**，由 `_build_segments.py` 强制 |
| 跨源交叉核 | 1,182 格：本期列 vs 另一份财报的比较列 |

### 已判读的口径断点（11 处·全部有算术佐证）

差异 ≠ 解析错，也可能是公司**真的重列**。以下均已回一手核实：

| 期间 | 断点 | 实质与佐证 |
|---|---|---|
| 2018 | 行政开支 | 2019 年报把「金融資產減值虧損」从行政开支拆出单列，2018 比较列同步重列。**543.5 + 1.2 = 544.7 ✓** |
| FY2011/6 | 应收账款 | 2011H2 起「應收賬款及應收票據」拆为两行。**1,558.6 + 23.1 = 1,581.7 ✓**（已分行存） |
| 2019 | 递延税项（4 行） | 2019 年报按**净额**列示（41.310），2020 年报改**总额**（资产 60.419 / 负债 19.109）。差额恒为 **19.109**，资产净值不变 ✓ |
| 2014 | 购建 PPE | 2015 年报把「非即期預付款項減少」并入购建 PPE 一行。**−135.046 + 20.475 = −114.571 ✓** |
| 2020 | 经营/投资（3 行） | 2021 年报把 **2.174**「就購買土地使用權支付的按金」由经营重分类到投资，两侧恰好抵消 ✓ |
| 2021 | 投资/融资（2 行） | 2022 年报把非控股权益往来（应收 6.290 / 应付 0.710）轧差为 **7.000** 并全部列入融资 ✓ |

> **口径断点的处理原则**：**分两行存，不合并成一条时间序列**（合并会凭空制造假跳水）。
> 需要连续序列时在 `_build_from_pdf.py` 里显式拼接并注明（见「应收合并口径」）。

### 恒等派生（11 处·非报表印出行）

361度 的报表体例有两处"本该有却不印"的行，按**同表内恒等关系**补，并在此登记：

- **无「資產總值」/「負債總值」行**：全表走「非流动 + 流动 − 流动负债 = 流动资产净值 → 总资产减流动负债 → − 非流动负债 = 资产净值」这条链。故 `资产总值 = 非流动资产合计 + 流动资产合计`、`负债总值 = 流动负债合计 + 非流动负债合计`。
- **FY2008/6 – 2011H2 无「非流动负债合计」小计行**（该区只有递延税项负债一项）→ 按分项求和。刻意**不**用「总资产减流动负债 − 资产净值」倒算，否则下游同名勾稽会变成恒真。
- **FY2006/6 – FY2009/6 无「應佔：」分配段**（当期无非控股权益）→ `股东应占溢利 = 本期溢利`。仅在**非控股权益整行不存在**时套用；FY2010 起出现非控股权益后立即停用、只取报表印出数。

### `财务比率.csv` 的 361度 定制层

| 指标 | 定义 |
|---|---|
| 经营溢利率 | 经营溢利 ÷ 营业额 |
| 财务成本/营收 | \|财务成本\| ÷ 营业额（2014-2020 发债期该比率显著抬升） |
| **经调整股东应占溢利（率）** | 股东应占溢利 − 可换股债券衍生工具公允值变动 − 购回可转债损益 − 购回优先票据损益。港股无「扣非」线，此项替代之；361度 的非经常大项就是 2012-2021 年那轮可转债/优先票据 |
| 有息负债 / 有息负债占总资产 | 银行贷款 + 其他贷款 + 计息借贷 + 可换股债券（流动 + 非流动） |
| 净现金 / 净现金占比 | 现金及现金等价物 + 银行存款 + 已抵押银行存款 − 有息负债 |

### 口径注意（引用前必读）

- **应收合并口径**：FY2006-FY2010 一行、FY2011 两行、2011H2 起三行。`财务比率.csv` 的应收相关指标已按「贸易应收 + 应收票据 + 按金预付款项及其他应收」合并成连续口径；与单看「贸易应收款项」不同。
- **分红率**：分母用「已付股息」（现金流量表·**期内实付**），与「本财政年度**宣派**」有跨年时间差；爆发年两者可差数倍。要看宣派口径须回年报董事会报告。
- **`2011H2` 六个月**：所有「流量 ÷ 存量」指标（ROE / 周转天数 / 现金含量）在该列天然只有半年强度。
- **derived 未匹配科目**：`扣非归母`（港股无此线，已由定制层「经调整股东应占溢利」替代）、`预付`（361度 的预付款并在「按金、预付款项及其他应收款项」内，已计入应收合并口径，故「(应收)/总资产」行名已自动降级、未虚标"应收+预付"）。

## 为什么从年报解析、不用东财二手

东财二手 CSV 会错、与一手打架（本库农夫山泉实证：现金流量表「经营业务现金净额」把税前 256 亿误标成净额，真净额 211 亿）。从年报解析则与一手同源，根除此类科目错位。**且 361度 的三段期间轴、过渡期 6 个月、前部未经审核 12 个月对比表这三件事，二手源一律不会标注**——用二手必错。
