## 分析流程总纲（拿到一家公司，从 0 到结论）

> 本节是**总纲/路由**，每步委派给对应 skill，不在此重复公式。两条铁律贯穿全程：
> **① 先提数据再下结论（不跳过提取、不编造）；② 估值方法由用户拍板，Claude 只给"建议+依据"。**

| 步骤 | 做什么 | 用哪个 skill / 规则 |
|------|--------|--------------------|
| **0 提数据** | 从年报/季报逐项提取硬数据（扣非/经调整净利、营收增速、毛利率、经营现金流、合同负债、应收、资本开支、分红、分部/地区），缺的标 `待补` | `caibao-analysis` + `_模板/财报阅读规则.md` |
| **1 过三大前提** | ①利润为真 ②利润可持续 ③维持盈利不需大量资本投入。任一不过（爆款/技术剧变/能力圈外）→ 不套公式 | 见下「选股三大前提」 |
| **2 分类 + 给方法建议** | 三道判断题填硬信号（能不能估／强周期？／方法一 vs 二）→ 输出"建议方法 X + 依据"，**请用户拍板** | `valuation-method` |
| **3 套选定方法算买卖点** | 成长=老唐简化DCF／绝对值=完整DCF／强周期=CAPE席勒／**不确定生意=不估值，直接下「无法估值」结论** | `valuation-method` |
| **4 现价对照 + 风险预警** | 现价落在买/卖区间何处；两层分级排雷（通用红旗 + 公司特有，🔴/🟡/🟢） | `_模板/财报阅读规则.md` Step 3 + `_模板/财报关注要点-行业模板.md` |
| **5（可选）大V视角 + 沉淀入库** | 老唐/段永平等怎么看；写入 `分析.md`+`.xlsx`、更新本 README | `guru-view`、`tangchao`/`duanyongping` |
| **★ 一键综合** | 把 0-5 合成一份《综合投资参考》（财报+风险+估值+多位大V视角+现价） | **`invest-report`**（编排 caibao+valuation-method+guru-view+行情）|

> 一句话：`提数据 → 过三大前提 → 分类给建议(用户拍板) → 套方法算买卖点 → 现价对照+风险预警 → 大V视角 → 沉淀入库`。
> 想直接要成品报告："**出一份 XX 的综合投资参考**" → `invest-report` 自动把上面整条流水线串起来。

## 分析框架（唐朝体系）

### 选股三大前提（一关不过即淘汰）

1. **利润为真** —— 净利润有没有真金白银？看经营现金流 / 净利润比率、应收账款增速 vs 营收增速。
2. **维持当前盈利不需要大量资本投入** —— 资本开支占净利润比例，是不是「印钞机」还是「碎钞机」。
3. **利润可持续** —— 商业模式是否刚需、有无提价权 / 护城河、能否抗通胀。

### 估值法

> 完整公式 / 变量拆解 / 使用前提 / 分类判据，见 **`valuation-method` skill**（单一真相）。下表为速查。

| 估值法（专业名） | 适用 | 公式速查 |
|--------|------|------|
| **老唐估值法 = 简化（两阶段）DCF / 收益资本化（成长股）** | 成长稳定的好生意（茅台/腾讯/古井贡/农夫/安踏） | 三年后净利 = 当年净利 ×(1+增速)³；合理市值 = 三年后净利 × 合理PE(=1/无风险利率≈25~27.5)；**买点 = 合理市值 ×50%**；卖点 = 当年净利 ×50/55/60PE |
| **完整 DCF / 所有者收益折现** | 要内在价值绝对值 / 重资产现金流稳定 / 增长分多段 / 交叉验证 | ΣFCFₜ/(1+r)ᵗ + 永续价值/(1+r)ⁿ；永续价值=FCF/(r−g)；算完打安全边际折扣 |
| **CAPE 席勒市盈率（周期调整 PE，强周期股）** | 强周期 / 利润大起大落（陕煤/中海油/分众/胜狮） | 买点 = 十年正常化盈利均值 ×PE下限(25)×0.7；卖点 = 均值 ×PE上限(30)×1.5（曾亏损者再加层净利折扣） |
| **无法估值（不确定生意·直接下结论）** | 爆款/技术剧变/能力圈外，三年后净利无法预估（泡泡玛特） | 不套公式、不给买卖点；归"太难"/能力圈外，可定性说明原因+列跟踪变量 |

> **老唐估值法本质是「单段 + 终值」的极简化 DCF**：只锚定「三年后」一个净利润 × 合理 PE，再打五折买入，不逐年折现、不分高增长/过渡/永续多段。出处 #89《投资的底层逻辑》(2021-08-18)。
> 合理 PE 取「无风险收益率的倒数」：无风险利率 4% → PE 25，3.6% → PE 27.5。
> 演化：2018「五折买/150%卖」→ 2019「15-25-50 三区」→ 2021「净利×25-30 + 五折」定稿。
> 「模糊的正确胜过精确的错误」——增速、折扣按保守原则取值。

## 标准 xlsx 三表

每家公司的 xlsx 统一为以下 sheet（按数据可得性，部分公司缺季度/营收表）：

1. **估值** —— 左侧「年份 | 扣非净利润 | 增速」十年历史；右侧估值参数块（成长法 / 席勒法）+ 买卖点历史。
2. **季度** —— 分部收入 / 毛利 / 毛利率，按季跟踪当年经营。
3. **营收 / 分部** —— 收入结构拆解（按业务线 / 产品 / 主营非主营）。

## 维护指南（新财报来了怎么补）

**标准流程：先按规则提取关键数据 → 再得出总结。不跳过提取直接下结论。**

0. **读规则**：先看 `_模板/财报阅读规则.md`（通用 SOP）+ 对应公司目录下的 `财报关注要点.md`（公司特有看点），按清单逐项提取。
1. **更新 xlsx**：
   - 估值表：新增一行「年份 | 扣非净利润 | 增速」，更新「当年净利润」基数。
   - 季度 / 营收表：填入最新季度分部数据。
2. **重算估值参数**（预估增速、合理 PE 随无风险利率变动），更新买点 / 卖点；在「买卖点历史」追加一行带日期的快照。
3. **更新 `分析.md`**：按规则 Step 4——三大前提是否仍成立、把 `⏳待补` 替换成实数、风险排查、跟踪变量、最新买卖点、文末数据截止。
4. 新增公司：从 `_模板/` 复制骨架到新目录，按 schema 填数；并新建该公司的 `财报关注要点.md`。
5. 同步 `组合/持仓.xlsx` 的仓位，以及本 README 状态表的「数据截止」。

> 让 Claude 补数据时，直接说「<公司> 出了 <期> 财报，扣非净利 X 亿 / 营收 Y 亿……补进去」即可——Claude 会自动套用上述规则提取、更新、总结。
