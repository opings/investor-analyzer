# 福耀玻璃 财报关注要点

> 行业块：制造/重资产（自 `_模板/财报关注要点-行业模板.md` 起步，按公司定制）。
> 本文件只写监控规格（指标/频率/警戒线/触线动作），**不嵌数字**——时间序列一律在 `财务数据/<csv>`。

- **生意一句话**：垂直一体化的全球汽车玻璃供应商——浮法原片自供压成本、全球基地贴近车厂交付、玻璃智能化升级抬单价，向全球整车厂(OEM)与售后市场(ARG)卖汽车安全玻璃及配套铝饰件。
- **生意类型**：成长稳定（周期敏感型）——利润中枢长期上移，但单年随汽车景气/汇率大幅波动（客观属性，勿用单年利润外推）。

## 🅰 生意模式 / 成本结构 / 护城河本质（读财报前先懂在哪赚钱）

- **收入 = 销量 × 单价**双轮：销量跟全球汽车产量+份额；单价靠高附加值产品渗透（天幕/HUD/调光/镀膜）。两个轮子的数据都在 `财务数据/产销量.csv`（销量、派生均价）与年报 MD&A「高附加值占比提升 pct」。
- **成本大头**：原辅材料（纯碱/PVB 膜等）+ 能源（浮法环节能源占成本三分之一强，年报成本分析表）+ 人工。浮法原片自供是毛利率稳定器——**看浮法毛利率与汽玻毛利率的剪刀差**（`分部营收.csv`）。
- **护城河本质**【判】：规模经济 + 一体化成本 + 全球就近交付网络 + 车规认证/快速响应的转换成本。验证口径：毛利率带是否守住、单价是否继续爬坡、行业逆风年（产销下滑）营收是否跑赢行业。
- **报表结构特性**：重资产（capex 常年占净利六成以上）→ 自由现金流比净利更真；财务费用常年为负（利息净收入+汇兑），**汇兑损益是单年利润的头号摆动项**（2026H1 实证：摆动 ±14 亿级 vs 利润总额 46 亿级【源：2026 中报归因】）——读利润表先剔汇兑再谈经营。

### 公司独有红旗 / 易暴雷点

- **汇兑损益摆动**：国外收入近半+美元资产敞口，单年汇兑可 ±两位数亿级冲击利润总额——**每期先算"剔汇兑利润增速"再下经营结论**（中报/年报 MD&A 披露汇兑数）。公司用远期外汇/货币掉期对冲【源：年报外汇风险节】，衍生金融资产/负债科目随之波动（`资产负债表.csv`）。
- **美国政策/地缘**：关税、劳工合规（2024-07 联邦搜查事件·非调查目标）、中美摩擦升级对美国双基地与出口的影响——事件触发式跟踪（`knowledge/companies/福耀玻璃/` 编年）。
- **收现比结构性下滑**：银票（应收款项融资）占比上升压低收现比——收现比连续低于 0.95 或 (应收+票据+融资)/营收 突破历史带上沿时追因（`财务比率.csv`）。
- **家族治理集中**：董事长（创始人长子）+ 总经理（女婿）等亲属任职网络——盯关联交易金额/占比（年报附注）、非经营性资金占用专项审计意见、股权质押/减持公告。历史记录干净（高分红+无占用），但治理集中本身放大关键人风险。
- **折旧政策沿革**：折旧年限是否放宽（利润质量信号，参照 Alphabet 服务器年限沿革教训）——年报附注固定资产折旧政策逐年对照 ⏳首次基线待建。
- **浮法库存异动**：浮法库存量大增曾是行业下行前兆（如 2018 年 +63% 后 2019 利润下滑）——盯 `产销量.csv` 浮法库存行。
- **2026Q1 经营现金流异常低**（-82%）未见专项解释，H1 已修复——下一期季报核对是否重现（季节性 or 一次性）。

### 历史踩过的坑 / 管理层诚信记录

- FY2006-FY2025 全部 20 份年报审计意见=标准无保留【源：逐份年报机械核验 2026-08-30】；建库窗口未见监管处罚记录；2024 年换审计师系普华永道行业性客户迁移（前任无异议）。
