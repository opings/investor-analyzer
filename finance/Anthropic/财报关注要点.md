# Anthropic 财报关注要点

> 本文件 = 持续监控规格（盯什么 · 频率 · 警戒线 · 触线动作 + 公司特有红旗）。**不嵌数字**——时间序列在 `财务数据/<csv>`；生意模式与护城河的完整论述在 `分析.md`。
> 首建 2026-10-27（依据 S-1 初步招股书）。公司尚未上市：上市前的跟踪对象是 S-1/A 修订与 424B4；上市后切换为 10-Q / 10-K / 8-K。
> ⚠️ 本文件由 Anthropic 训练的模型起草，监控规格刻意偏向「找反证」——公司自述的优势不进跟踪变量，只进待验证清单。

- **生意一句话**：按 token 用量与订阅，向企业、开发者与个人出售前沿大模型（Claude）的能力；算力主要向云服务商与芯片 / 数据中心伙伴长期租用。
- **生意类型**：**不确定生意**（公司客观属性）——盈利只有一个季度、收入高度依赖持续推出前沿模型、算力承诺规模远超现有收入（`分析.md` 速览）。

## 行业块：前沿 AI 模型 / 算力密集型软件（本库新建·模板里无现成块）

> 现有行业模板没有完全匹配的块。本块由「互联网 / 平台」（递延收入、股权激励、获客）+「制造 / 重资产」（资本强度、客户集中）+ 通用骨架拼成，按「这门生意靠什么赚钱、容易在哪里暴雷」逐项问出来。若日后本库再建同类公司（如其他模型公司），可上移到 `_模板/财报关注要点-行业模板.md`。

### 🅰 读这类公司财报前必须知道的（只保留与排雷相关的部分）

1. **算力是一个共用池**：训练、研发、服务客户、内部使用共用同一批算力，「营业成本」与「研发」的划分是管理层分摊（S-1 MD&A 原文 "on a total basis rather than by individual workload"——**译**：按总量而非按单项负载）。⇒ 毛利率是方向性指标；**看总的「算力与基础设施 ÷ 营收」比看毛利率更硬**。
2. **算力先承诺、后上线、再变费用**：通常提前 12-18 个月签约，上线时才计费用（S-1 MD&A）。⇒ 利润率随「新增算力上线」呈台阶式波动，单季利润率不可外推。
3. **资本强度藏在费用和表外**：租云算力记费用、租设备记租赁、未起租的租约与采购承诺只在附注。⇒ **capex 行几乎看不出资本强度**，要看费用率 + 承诺表 + 租约起租节奏。
4. **供应商、投资人、渠道、竞争者常是同一家**：云服务商代收款、用票据或股权换算力、按算力里程碑放款。⇒ 现金流的三段（经营 / 投资 / 融资）会被这种安排重新分布，需要把非现金支付加回去看。
5. **净利润被公允价值会计主导**：上市前的可转债、票据购买协议、认股权利都按公允价值计量。⇒ 上市后可转债转股即消失，但新的按市值计量工具（票据额度、认股安排）仍可能出现。

### 🅱 风险雷达（行业通用部分）

| 雷 | 级别 | 怎么看 |
|---|---|---|
| 前沿位置被追平 → 收入保质期变短 | 🔴 | 近六个月新模型贡献收入占比、价格下调幅度 vs 用量增长、客户迁移到新模型的速度 |
| 新增算力上线快于收入增长 | 🟡 | 单季「算力与基础设施 ÷ 营收」回升；公司 MD&A 是否归因于新增容量 |
| 以非现金方式支付算力（票据 / 股票 / 抵销） | 🔴 | 补充现金流披露的「非现金」项；票据购买协议动用额 |
| 渠道集中在少数云服务商 | 🟡 | 经云服务商市场的收入与应收占比；代收款逾期或抵销 |
| 版权 / 训练数据诉讼 | 🟡 | 或有事项附注是否开始计提或给出损失区间 |
| 出口管制与政府采购限制 | 🟡 | 风险因素与期后事项中的模型停用、政府客户流失 |
