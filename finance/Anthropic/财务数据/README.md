## 🚨 读任何一张表之前必须先接受的四件事

1. **这是一份「初步招股书」，不是年报。** S-1 于 2026-10-26 公开递交（accession 0001628280-26-067168，受理时间 2026-10-26 09:00:11 美东），发行股数、价格区间、2026Q3 季度金额、合同义务总表都**留空待修订**（S-1/A）。公司**尚未上市**，上市至今 10-K 份数 = 0、10-Q 份数 = 0——**不是缺件，是实证不可得**（SEC EDGAR CIK 0002130357 全量申报清单 2026-10-27 复核：DRS ×1 + DRS/A ×5 + S-1 ×1，别无他件）。
2. **净利润基本不反映经营。** 公司对 Amazon / Google 的可转换票据选用公允价值法（ASC 825），**公司估值越高、账面亏损越大**，且全部是非现金：2025 年净亏损约 420 亿美元中约 343 亿来自这一项，2026H1 净亏损约 807 亿中约 724 亿来自这一项、另有约 94 亿来自 Google/Amazon 2026 票据购买协议的公允价值确认与变动（`利润表.csv`、`中期财务-2026.csv`）。**看经营用「经营利润」，或公司自定义的「调整后经营利润」（加回股权激励、非现金捐赠、Bartz 和解）——后者是非 GAAP，口径由公司定**。累计亏损约 1,329 亿中约 1,132 亿是可转债与衍生负债公允价值变动（MD&A 原文）。
3. **利润表没有「营业成本 / 毛利」行。** 公司 2025 年把费用列报由职能法（营业成本/研发/销售/管理）改为**性质法**（算力与基础设施 / 人员 / 销售营销与合作伙伴 / Bartz 和解 / 其他运营与行政），并追溯重分类（F-14 附注 1）。职能口径只在**附注 8 补充披露**（`费用按职能.csv`），毛利率只能由它派生；两种切法合计相等（脚本逐期核对）。
4. **资产负债表看起来「资不抵债」是结构性的，不是经营性的。** 股东权益为负 = 优先股按「夹层」列在负债与权益之间 + 可转债公允价值累计亏损冲减了累计亏损。2026-06-30 剔除可转债后的负债率只有个位数（`中期比率-2026.csv`）。可转债账面（公允价值）远大于本金：2026-06-30 账面约 1,086 亿美元，对应本金仅约 62 亿（全部为 Amazon 不计息展期票据，IPO 时按 $2.0928 / $5.0478 转 N 类股，`可转债与公允价值.csv`）。

## 勾稽自洽校验

由 `_build_from_sec.py` 固化，**默认容差 0，校验不通过不写出 CSV**。当前 **执行 580 条、因空值跳过 0 条，全部通过**。

**闸门对照组（变异测试，2026-10-27）**：`python _build_from_sec.py --mutate` 把每个数值格逐一 +1（小于 20 的小数 +0.01）后重跑全部勾稽——**1,449 个数值格中 1,201 个（82.9%）一改就报错**；其余 248 个为单一来源、无可交叉的补充披露（广告费、税务结转、各系列原始发行价、MD&A 经营指标、具名合同金额等），`--mutate --list` 可逐格列出。

**显式放宽的容差（均为源表本身的差异或公司约数，非转录误差）**
| 条目 | 容差 | 原因 |
|---|---|---|
| 2026H1 合同负债：资产负债表变动 1,381 vs 现金流量表 1,380 | 1 | 资产负债表与附注 2 滚动表（269 − 196 + 1,577 = 1,650）自洽；差额应是收购带入或汇率，S-1 未拆 |
| 2025 应收账款：资产负债表变动 vs 现金流量表 | 20 | 差额 = 当年坏账准备计提 20（附注 1） |
| 「≥10 万美元客户收入占比」 | 1.5pp | 公司写「approximately」 |
| 公益基金注入股数 = 完全稀释股本 × 5% | 1 千股 | 股数取整到千股 |
| 公司口径累计融资 1,411 亿 vs 现金流逐年加总 | 50 | 公司取一位小数（加总 = 141,091） |
| G-2 / H-2 募资额（「approximately」）vs 股数 × 价格 | 50 | 公司约数 |
| Broadcom 托管存款 25 亿 vs 受限现金增量 | 20 | 受限现金另含少量租赁押金 |

**核对清单（摘要）**
- 利润表链条（年度 3 期 + 半年 2 期 + 单季 6 期）：五项费用 = 费用合计 → 经营利润 → 其他收支 → 税前 → 净利；综合收益；EPS = 净利 ÷ 加权股数（四舍五入到分）
- **单季 → 年度 / 半年**：每个利润表科目四季之和 = 2025 年、两季之和 = 2025H1 / 2026H1（含股权激励、非现金捐赠、非 GAAP 两行）
- 非 GAAP 调节（年度、半年、单季）：调整后经营利润 = 经营利润 + 股权激励 + 非现金捐赠 + Bartz；调整后净利润另加回可转债与其他按市值计量工具的公允价值变动
- 职能口径（附注 8）合计 = 性质口径合计；收入、Bartz 两表一致
- 资产负债表：流动资产、资产总计、流动负债、负债合计、股东权益、负债 + 优先股 + 权益 = 资产；附注 8（预付、其他非流动、应付应计四项拆分）、附注 6（物业设备原值 − 累计折旧 = 净额）逐项加总；公允价值层级（附注 4）资产、负债合计；投资到期结构 = 现金等价物 + 短投摊余成本
- 现金流量表：经营 / 投资 / 融资分项加总；三段 + 汇率 = 净变动；期初 + 净变动 = 期末 = 资产负债表（货币资金 + 受限现金）；年度与半年期初衔接；净利、公允价值变动、股权激励与利润表 / 权益变动表一致；合同负债变动与资产负债表一致
- 权益变动表：优先股账面 / 股数、A 类股数、资本公积、累计亏损逐期滚动；期末与资产负债表一致；优先股现金部分 = 现金流量表收现（2026H1 差额 11,810 = 票据购买协议结算转入，与附注 4、补充现金流三处一致）
- Level 3 公允价值滚动（附注 4）：可转换票据、衍生负债、SAFE、认股权利、票据购买协议、捐赠匹配负债、收购尾款七类逐期滚动与期初衔接；利润表「可转债等公允价值变动」= 票据 + SAFE + 衍生负债三项；2024 发债收现 6,050 = 票据新增 5,900 + 衍生负债新增 150
- 优先股明细（附注 10）：20 个系列的股数 / 账面 / 清算优先权合计 = 资产负债表；原始发行价 ↔ 融资轮次每股价格；E-1 / F-1 / G-1 / H-1 募资额 = 股数 × 价格
- 稀释：反稀释证券合计（2025、2026H1）；期权 / RSU 滚动；**公益基金注入股数 846,840,960 = 2026-06-30 完全稀释股本 × 5%**（反推完全稀释股本 = A 类 + N 类 + 优先股折合 + Amazon 票据折合 + 期权 + RSU + 捐赠匹配预留 + 股权计划可授予 ≈ 169.4 亿股，与公司表述吻合到千股）
- 排期：采购承诺、经营 / 融资租赁到期表加总 = 合计，现值 = 资产负债表租赁负债
- 或有：Bartz 已付 300 + 流动 750 + 非流动 450 = 1,500 = 利润表 = 2025Q3 单季计提

**申报人自身前后不一（照录、不抹平）**
- 收购尾款负债 2026H1 公允价值变动：附注 4 Level 3 滚动表 30 vs 附注 8 其他收支 39（差 9 百万，不重大，S-1 未解释）【疑】
