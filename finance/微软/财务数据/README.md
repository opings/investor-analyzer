# 微软（Microsoft Corporation·NASDAQ: MSFT·CIK 789019）财务数据（从一手申报解析）

> 本目录 = 微软的**一手财务数据库**：从一手申报解析的所有客观数字（三表 + 比率 + 分部 + 公司特有指标 + 分析派生指标）统一落点。
> 公司分析 → `../分析.md`；监控规格 → `../财报关注要点.md`；事件 → `knowledge/companies/微软/`（事实编年，分层不混）。

> **数据血缘**：所有 CSV 数字 = 从 `report/微软/`（**1986 年招股书 + FY1986–FY1993 年报扫描件 + FY1994–FY2026 共 33 份 10-K**）**逐行解析** + 勾稽自洽校验。
> **单位 / 符号**：金额一律 **百万美元（US$ mn）**；EPS 为美元/股、股数为百万股；利润表费用为正、现金流量表流出为负；空 = 该期财报无此科目（**不是零**）。
> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## ⚠️ 读这个库之前必须先知道的八件事

1. **财年截至 6 月 30 日**。FY2026 = 2025-07-01 ~ 2026-06-30。**"2026 年"在本库一律指财年**，与日历年差半年。
2. **EPS / 股数不可跨年直接相除**。可考期内拆股 **9 次、累计 ×288**（1987–2003），各年申报印的每股数据都按**该次申报时点**的股本基准。跨年比每股口径只用 `财务比率.csv` 的 **🔴【复权】行**。
3. **增速不要用相邻两年 as-reported 相除**。FY1999、FY2004、FY2018 三份 10-K 都对上年做过追溯（见下「口径断点」），as-reported 序列跨断点不可比。`财务比率.csv` 的增速行一律 = **本年自家 10-K 的本年列 ÷ 同一份 10-K 的上年比较列**；分部 / 产品线增速见 `同口径增速.csv`。
4. **FY2024 起报告净利被 OpenAI 权益法损益污染**：FY2024、FY2025 是损失，FY2026 是资本重组带来的稀释收益（`OpenAI敞口.csv`）。看经营增速用**营业利润**或公司剔除 OpenAI 的调整后净利，不要用报告净利。
5. **FY1996–FY2003 的 as-reported 净利不含期权费用**（APB 25 内在价值法）。FY2004 10-K 按 SFAS 123 只追溯了 FY2002–2003，更早年份只自陈了「若重述」的数（`附注自陈数.csv`）——**那个年代的净利率、ROE 与今天不是同一把尺**。
6. **FY1982–FY1992 的数来自千美元报表**（保留 3 位小数的百万美元），FY1993 起为百万美元原印。
7. **FY1987 之前没有现金流量表**（SFAS 95 之前印的是营运资本来源与运用表 SCFP），FY1983–1988 单列在 `营运资本变动表FY1983-1988.csv`；FY1987–1988 的现金流量表取自 FY1989 年报按 SFAS 95 重编的比较列。
8. **美股无「扣非」法定口径**，本库不造扣非行。一次性项目（商誉减值、重组、TCJA 一次性税、会计变更累积影响、OpenAI 稀释收益）各自单列或在下表标注，需要时自行剔除。

## 勾稽自洽校验（不过则不写出 CSV）

**三表**（`_build_from_filings.py`，最近一次运行**执行勾稽 856 次、全过**，并对执行次数设覆盖闸：利润表核心勾稽覆盖 FY1982–2026 全 45 年、资产负债表 FY1984–2026 全 43 年、现金流量表 FY1987–2026 全 40 年）：
- **必填项（C0）**：有数据的年份，营收 / 营业利润 / 税前 / 所得税 / 净利、总资产 / 流动资产 / 流动负债 / 权益、经营 / 投资 / 融资 / 期末现金就必须有值——防「锚科目丢了、整张表静默全过」。
- **利润表**：营收 − 成本 = 毛利；毛利 − 各项费用 = 营业利润（「营业费用合计」含不含营业成本按**当年数字**判定，不按标签：FY1997–2010 含、其余年份不含）；营业利润 + 营业外 = 税前；税前 − 所得税 = 净利（FY2000–2002 版式先到「会计变更前利润」再加累积影响）；产品 + 服务 = 营收、产品 + 服务成本 = 营业成本；（净利 − 优先股股息）÷ 股数 ≈ EPS（3% 容差·单位与拆股基准的守门人）。
- **资产负债表**：现金 + 短期投资 = 合计；流动资产 / 资产 / 流动负债 / 负债 / 权益各自分项和 = 合计；负债 + 权益 = 总资产；两侧合计相等。
- **现金流量表**：经营 / 投资 / 融资各段明细和 = 该段净额；经营 + 投资 + 融资 + 汇率 = 净变动；期初 + 净变动 = 期末；CF 净利 = IS 净利；期末现金 = BS 现金（FY1989–2008 资产负债表只印「现金及短期投资」合并行，拆分取现金流量表期末现金）。
- **营运资本表（SCFP）**：净利 + 折旧 + 其他 = 经营提供；来源 / 运用分项和 = 合计；来源 − 运用 = 营运资本增加 = 各要素变动和。
- **申报印刷错误订正 1 处**：FY2002 10-K 现金流量表把「Maturities of investments 8,654」印成「8.654」——投资段明细加总与印刷合计相等、FY2003 10-K 比较列印 8,654，**双证**后订正（`重述与口径变更.csv` 末尾留痕）。

**跨源**：
- **跨申报同值确认**：同一财年在其他申报（比较列 / 五年摘要）里印出同值的格数——利润表 1,118 格、资产负债表 1,001 格、现金流量表 1,956 格；不同值的 365 处全部进 `重述与口径变更.csv`（重述 / 重分类 / 准则追溯 / 拆股基准）。
- **XBRL 独立核**（`_xcheck_xbrl.py`，SEC companyfacts API，与 R 文件不同的数据通道）：FY2010–2026 12 个核心科目**一致 204 格、不一致 0 格**；缺一边 12 格 = FY2009（无 XBRL）。

**附注层**（`_build_notes.py`，全过）：分部（或组）+ 调节项 = 合并营收与营业利润（自家申报年份 = 利润表）；每份申报的重述列也必须自洽；产品线和 / 地区和 = 营收；递延收入分部和 = 资产负债表短期 + 长期递延收入；固定资产分项和 = 原值、原值 − 累计折旧 = 资产负债表净额；营业外分项和 = 合计 = 利润表；商誉分部和 = 资产负债表商誉；美国 + 境外税前 = 税前；当期 + 递延 = 所得税费用 = 利润表；递延所得税资产净额 + 负债 = 净额；**已签未起租租赁的 XBRL 值 = 10-K 正文句子金额**（FY2018–2026 逐年）；MUST 探针（必需格清单）缺格即失败。

**OpenAI 表**（`_build_openai.py`）：报告值 + OpenAI 调整 = 调整后值（营业外 / 净利 / EPS 三行 × 三年）；税前调整 + 税 = 税后调整；报告净利 = 利润表、报告营业外 = 营业外明细。

**经营指标、附注自陈数与合同义务**（`_build_kpi.py`）：云收入 XBRL 值 = 正文金额；正文增速 = 同一份 10-K 计算值（±1pp）；云毛利率「增减 N 点」隐含的上年水平 = 上一份 10-K 自陈；FY1999 改列收入自陈额 = 重述表差额；受限投资分项和 = 合计；代扣个税回购各份 10-K 互相一致；合同义务表每份申报每列分项和 = 合计。

**比率层**（`_build_ratios.py`）：通用底别名必须全部匹配；MUST 探针；**拆股链与公司自陈逐次对账**（下节）；每股股息每个值都要有另一份申报印同值。

## 拆股复权因子怎么来的（不是抄的）

`_build_ratios.py` 拿**相邻两份申报里同一个财年的股本口径**相除（有股数行用股数；没有就用「净利 ÷ EPS」的隐含股数，能抵消净利重述；SFAS 128 过渡年允许 primary ↔ diluted 跨口径比、容差放宽到 5%），比值落在 1 / 1.5 / 2 / 3 附近即判定倍数。推出的链条再与公司自陈逐次对账——**多一次、少一次都失败**：

| 在哪两份申报之间 | 推得倍数 | 公司自陈 |
|---|---|---|
| FY1986 年报 → FY1987 年报 | ×2 | 1987-09 一拆二（扫描件股数翻倍自证） |
| FY1989 年报 → FY1990 年报 | ×2 | 1990-04 一拆二（扫描件股数翻倍自证） |
| FY1990 年报 → FY1991 年报 | ×1.5 | 1991-06 三拆二（FY1995 10-K 附件「three-for-two stock splits in 1991 and 1992」） |
| FY1991 年报 → FY1992 年报 | ×1.5 | 1992-06 三拆二（同上） |
| FY1993 年报 → FY1994 10-K | ×2 | 1994-05 一拆二（FY1994 10-K 附件） |
| FY1996 10-K → FY1997 10-K | ×2 | 1996-12 一拆二（FY1997 10-K 附件写 November 1996、FY2000 10-K 写 December 1996） |
| FY1997 10-K → FY1998 10-K | ×2 | 1998-02 一拆二（FY1998 10-K 附注 STOCK SPLIT） |
| FY1998 10-K → FY1999 10-K | ×2 | 1999-03 一拆二（FY1999 10-K 附注 Stock split） |
| FY2002 10-K → FY2003 10-K | ×2 | 2003-02 一拆二（FY2003 10-K Note 2） |

由此得到相对 FY2026 股本基准的复权倍数：FY1982–1986 = ×288、FY1987–1989 = ×144、FY1990 = ×72、FY1991 = ×48、FY1992–1993 = ×32、FY1994–1996 = ×16、FY1997 = ×8、FY1998 = ×4、FY1999–2002 = ×2、FY2003 起 = ×1。
