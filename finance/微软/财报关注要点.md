## 🅰 行业块：企业软件 / 云基础设施（新建·可类推到其他「订阅软件 + 自建云」公司）

### 生意模式 + 成本结构 + 护城河本质（只保留读财报、排雷相关的部分）

**靠什么赚钱**：两种经济模型叠在一张报表里——
- **订阅软件**：边际成本近零、客户预付、按期分摊确认 → 高毛利、负营运资本、递延收入是先行指标。
- **云基础设施（IaaS/PaaS/AI 算力）**：按用量计费，成本是**服务器折旧 + 数据中心租赁 + 电力**，本质是重资产的规模生意 → 毛利率低于订阅软件，且**由折旧年限这个会计估计决定一大块**。
- 两者的混合比例一变，合并毛利率与资本密度就跟着变——**跨期比毛利率之前先看收入结构有没有在向云/AI 迁移**。

**护城河本质（排雷视角）**：企业客户的**转换成本 + 产品捆绑**。这同时是监管攻击的目标（英国 CMA 战略市场地位调查、欧盟 DMA 守门人认定）——**护城河与监管风险是同一个东西的两面**。

### 风险雷达（本行业结构性风险 = 资本密度与表外承诺）

- 🔴 **资本开支 + 融资租赁 + 代采购垫款**三者合计相对经营现金流的比例：只看现金流量表「资本开支」一行会低估——融资租赁取得的资产是非现金取得、代采购组件垫款走「其他投资活动」、未付现的资本开支挂在应付账款里。
- 🔴 **表外承诺**：已签未起租租赁、采购承诺（照付不议）——**不在资产负债表、但已经锁定了未来的现金流出**。
- 🟡 **折旧年限**：延长年限 = 当期利润上升、未来减值风险上升。必须**按历年沿革**与同业横比，不看当年快照（方法见本库记忆 depreciation-life-benchmark-drift）。
- 🟡 **云毛利率与折旧/营收**：新增算力的单位经济性。
- 🟡 **RPO 的期限结构与客户集中度**：RPO 越来越长、越来越集中，「锁定的收入」就越依赖少数客户的履约能力。
- 🟡 **股权激励 + 代扣个税回购**：真实的员工成本 = 利润表股权激励费用 + 为归属代扣个税回购的现金。
- 🟡 **公司自定义指标的定义变更**：云收入、分部、产品线、投资者指标都改过——**每次 10-K 先看定义段**。

## 🅱 核心跟踪变量（5 个·按优先级）

### 1. 🔴 资本密度与 FCF：投入有没有换来相应的收入

- **数据落点**：`财务数据/财务比率.csv`（「资本开支+新增融资租赁」及其占营收、占经营现金流；FCF；FCF/净利；资本开支/折旧）· `财务数据/附注自陈数.csv`（代采购组件应收、受限投资）· `财务数据/固定资产明细.csv`（仍挂应付账款的资本开支）
- **频率**：每季（10-Q 现金流量表 + 租赁附注）+ 每年（10-K）
- **警戒线**：①「资本开支 + 新增融资租赁」**超过经营现金流**（FCF 扣租赁后转负）；或 ② **连续两年 FCF 绝对额下降而营收在增长**；或 ③ 资本开支增速连续两年**高于 Microsoft Cloud 收入增速 2 倍以上**
- **触线动作**：
  1. 把三笔「不在资本开支行里」的投入（融资租赁取得资产、应付账款里的资本开支、代采购组件垫款）加回，重算真实投入；
  2. 拆增量：新增营业利润 ÷ 新增「固定资产净额 + 使用权资产」，看边际回报是否在下降；
  3. 查 MD&A 是否出现「产能利用率 / 交付延迟 / 需求超过供给」措辞的方向变化（只记原文，不推测）。
- **为什么排第一**：三大前提里**已经翻成 ❌ 的就是这一条**（另两条仍为 ✅），也是 `分析.md` 5.2 排在第一位的风险源【判】。

### 2. 🔴 云毛利率 + 折旧/营收：新增长的单位经济性

- **数据落点**：`财务数据/经营指标(公司口径).csv`（云毛利率、Azure 增速、折旧年限变更表）· `财务数据/财务比率.csv`（折旧/营收、毛利率、营业利润率、分部利润率）
- **频率**：每季（MD&A 自陈云毛利率）+ 每年（折旧费用在 10-K 固定资产附注）
- **警戒线**：① 云毛利率**连续第三年下降**；或 ② 折旧/营收**单年上升超过 2 个百分点**；或 ③ **任何一次折旧年限再延长**（已在 6 年，与 Alphabet 同步）
- **触线动作**：
  1. 年限再延长 → 立刻把「年限变更对营业利润的自陈影响」从当年利润里剔除再算增速（`经营指标(公司口径).csv` 折旧年限表追加一行）；同时对照 Alphabet / Amazon 同期是否同向（同业分化 = 🔴）；
  2. 云毛利率下降 → 读 MD&A 归因，区分「AI 基础设施投入」与「定价/竞争」两类原因（只记公司原话）；
  3. 年限若**缩短** → 是加速折旧信号，当期利润下降但盈利质量提高，记录不排雷。

### 3. 🔴 表外承诺：已签未起租租赁 + 采购承诺

- **数据落点**：`财务数据/租赁与承诺.csv`（已签未起租租赁、起租年份区间、表内租赁负债）· `财务数据/合同义务.csv`（租赁含利息、采购承诺、建造承诺、合计与一年内到期）
- **频率**：每年（10-K 附注 Leases + MD&A Contractual Obligations）；10-Q 租赁附注每季也给未起租额
- **警戒线**：① 合同义务合计**超过当年经营现金流 5 倍**；或 ② 已签未起租租赁**单年再翻倍**；或 ③ 10-K 新增「以合同条件达成为前提」类表述的范围扩大
- **触线动作**：
  1. 用「一年内到期」那一行对比下一财年的经营现金流，看**刚性流出占比**；
  2. 未起租租赁起租后会同时抬高资产与负债（融资租赁进固定资产）——**跨年比资产负债率时先剔租赁**（`财务比率.csv` 含/不含租赁两行净现金）；
  3. 查是否出现**取消、延期或转让租约**的披露（只认 10-K/10-Q/8-K 原文）。

### 4. 🟡 OpenAI 敞口：关联方收入 + 权益法损益 + 合同条款

- **数据落点**：`财务数据/OpenAI敞口.csv`（调节表、关联方收入、应收、出资承诺）· `财务数据/营业外收支明细.csv`（OpenAI 行）· `knowledge/companies/微软/`（协议修订）
- **频率**：每季（10-Q Note 1 / 营业外附注）+ 事件触发（协议修订公告）
- **警戒线**：① 来自 OpenAI 的收入**占营收超过 10%**；或 ② 应收 OpenAI 的周转天数**明显长于公司整体 DSO**；或 ③ 权益法损益**单年绝对额超过营业利润的 10%**；或 ④ 协议条款出现收入分成**提前触及总额上限**的披露
- **触线动作**：
  1. 净利增速一律用**两期同时剔除** OpenAI 的口径（`分析.md`「四」表；财报阅读规则硬规则 5）；
  2. 关联方收入与应收单独列示，DSO 计算时另算一版「剔除关联方」的；
  3. 关注 2026-04 修订后的三件事：许可**非独家**、OpenAI **可多云**、收入分成**设上限至 2030 年**——每次 10-Q 看这三条的措辞有无再变。

### 5. 🟡 股东回报的真实性：回购拆分 + 股数

- **数据落点**：`财务数据/财务比率.csv`（回购拆分三行、复权股数及同比、股息 + 回购 / 净利、分红率）· `财务数据/附注自陈数.csv`（代扣个税回购）· `财务数据/现金流量表.csv`
- **频率**：每季（10-Q Item 2 回购明细）+ 每年（10-K 股东权益附注）
- **警戒线**：① 复权股数**连续两年同比上升**（回购已盖不住股权激励稀释）；或 ② 代扣个税回购**占回购总额超过一半**；或 ③ 股息 + 回购 / 净利**连续三年下降且同期资本开支占营收上升**（资本开支挤占股东回报的趋势确认）
- **触线动作**：
  1. **「回购授权」≠「已执行」**——授权剩余额度只是上限，实际金额只看现金流量表与 10-Q Item 2；
  2. 分红率变化先分辨分子（股息）还是分母（净利，含 OpenAI 损益）在动；
  3. 用「股权激励费用 + 代扣个税回购」作员工成本口径，与营收比（`财务比率.csv` 已有该行）。
