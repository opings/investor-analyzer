> **本目录是公司数字的唯一真源**——`分析.md` / `财报关注要点.md` 引用本目录，不复制数字。

## 勾稽自洽校验（由 `_build_from_pdf.py` 固化，**校验不过不写出 CSV**）

每年验证：

- **资产负债表**：资产总计 = 负债和所有者权益总计；流动 + 非流动 = 合计（资产/负债两侧）；负债 + 权益 = 总计
- **利润表**：营业利润 + 营业外收支 = 利润总额；利润总额 − 所得税 = 净利润
- **现金流量表**：经营 + 投资 + 筹资 + 汇率 = 现金净增加额；期初 + 净增加 = 期末；各活动流入 − 流出 = 该活动净额
- **跨表**：期末现金 ≤ 货币资金
- **跨年**：上年期末现金 = 本年期初现金（2016→2025 逐年衔接）
- **跨报告**：2026 中报的「上年度末」列 = 2025 年报年末（资产总计/归母权益/货币资金/存货/应收账款 5 项）
- **分部四重勾稽**：分产品收入和 = 分地区收入和 = 主营业务收入（年报自述）；成本同理三路 —— 2019–2025 **7 年全过**
- **扣非归母两路对撞**：路径①「归母净利 − 非经常性损益合计」 vs 路径②「主要会计数据表披露值」，2019–2025 **7 年全部一致**；2016–2018 由招股书非经常性损益明细表算出，与招股书「合并利润表主要数据」的万元表逐年吻合

**多源交叉核**：同一年份在不同申报中重复出现（当年年报当年列 / 次年年报上年列 / 招股书），全部采集后逐格比对。**现存 18 处差异，已逐条回源查实，全部是公司自己披露的追溯重述，零解析错**（见 `重述与口径变更.csv`）。

## 解析器踩过的坑（改脚本前先读，都是实证）

1. **列位逐页漂移 + 孤值行**：`pdftotext -layout` 的列位每页重算（同一张表里 2025 列右端可能是 53 也可能是 73）。而「本年空 / 上年有值」的孤值行很常见（2025 年报「在建工程」「短期借款」）。按出现顺序分列 = 整格错一年。
   → 解法：**满列行按顺序填**；**缺列行取行号上最近的那条满列行的列位**判归属。
   ⚠️ 不要改成「整页聚类 + 取样本最多的 N 簇」：同一页并存两套列宽（利润表尾部每股收益 0.46/0.14 在 46/53，主表在 48/64），这么做会把每股收益吸到错列（实测把 2025 的 0.44 写成上年的 0.27）。
2. **招股书表头日期被当数字**：表头 `2019.6.30 / 2018.12.31` 会被数字正则抠出 `6.30 / 2018.12` 四个假数字，**恰好等于列数**、被当成满列行。实证：2016/2017「负债和所有者权益总计」一度被读成 2,016.12 / 2,018.12。→ 取数前用**等长空格**涂掉日期（列位不能变）。
3. **标签换行位置逐年不同，且断点可能在数字行之前**：2022 年报是「销售商品、提供劳务收到的 <数字>」/ 换行「现金」；2025 年报是「销售商品、提供劳务收到的现金 <数字>」；2022 年报连「量净额」都断行（「经营活动产生的现金流」）。→ 别名一律用**前缀**匹配，不用全等。
4. **附注号带括号子号**：`七、76（1）` 不剥干净就会剩下它当标签，整行漏读（实证：2019 年报「收到其他与经营活动有关的现金」）。
5. **「扣非」判据必须是完整标签的连续子串**：只查「扣除非经」会误中**归母净利那一行**——它后面紧跟的正是扣非行的开头碎片（2019 实证，误差恰为当年非经常性损益 8,562,827.07）。
6. **不许跨源混取同一 (表, 年)**：某科目在优先源缺失而从别源兜底，会把本版数与重述版数混进同一年、资产负债表当场不平（2022 实证：负债合计取 2022 年报、所有者权益合计兜底到 2023 年报重述值，差 349,964.14）。→ 兜底必须逐条报出。

## 为什么从年报解析、不用东财二手

东财二手 CSV 会错、与一手打架（农夫实证：「经营业务现金净额」把税前数当净额，256 亿 vs 真值 211 亿）。本库三表 + 衍生比率唯一来源 = 一手财报解析。
