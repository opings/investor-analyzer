# 主观分析 workflow · canonical

> 本文是**主观分析 workflow 的方法论真源**。skill `judgment-flow` 引用本文执行,数据落 `judgments/<公司>/`。
> 和 `研究新公司-分析流程.md` 平级:那份是客观层(模块一)canonical,本文是主观层(模块三)canonical。

## 定位

- **模块三 · 主观分析**:估值 / 能力圈 / 仓位 / 买卖点
- **三轴正交**:评级(公司好不好·客观·属模块一) × 估值(便宜不便宜) × 能力圈(我懂不懂·定仓位上限)
- **落盘规则**(呼应 [[subjective-layer-judgments]] memory):
  - 数据落 `judgments/<公司>/{估值.md, 能力圈.md, 观点变更.md}`
  - `finance/<公司>/` 只放**客观**,禁署单一大V名,不掺主观(呼应 [[analysis-framework-is-users-own]])
  - 大V视角审视(如"老唐会怎么看")= 走 `guru-query` **现问现答**,产出直接改写 `judgments/`,**不新建**「大V点评.md」
  - 不做大V回测/胜率复盘(呼应 [[no-guru-backtest]])
  - **结论产出禁用相对时间词**(2026-08-17 用户指示):当年/当月/本轮/上轮/今年/年内/去年/三年后/当前/当时…一律写**明确年月**(如 2026 年、2026-08、2027-2029、上轮=2026-07-08 轮);公式术语涉年的括注具体年份(如 P₁ 标 2026E、P₃ 标 2029)——judgments 是跨年回读的档案,相对时间词会随阅读时点漂移

## 六步骨架

```
Step 0  前置检查                → finance/<公司>/ 存在?否则引导 company-analysis
Step 1  读客观底座 + fresh 快检 → 分析.md 头部核对至字段·滞后 30 天阻塞
Step 2  双闸门                  → 三前提 + 生意四问(引用分析.md 已有结论)
Step 3  问你 · 选估值法         → 菜单(默认 A 成长股;E 归"太难")
Step 4  应用公式算买卖点        → 估值.md 台账 append 一行 + 估值记录/日期/{推导.md, 业务数据.html}
Step 5  能力圈 → 仓位上限       → 落 能力圈.md
Step 6  综合结论                → 观点变更.md 追加一行(append-only)
```

## Step 0 · 前置检查(硬 gate)

`ls finance/<公司>/分析.md` 存在?
- ❌ 不存在 → 🔴 **阻塞** · 引导:「这家公司还没有客观分析底座.先跑 `company-analysis` 建 `finance/<公司>/{财务数据/, 分析.md, 财报关注要点.md}` 三件套,完成后再回来.」
- ✅ 存在 → Step 1

## Step 1 · 读客观底座 + fresh 快检(硬 gate)

**① 读**
- `finance/<公司>/分析.md`(客观样貌 · 生意质量评级 · 三前提复核 · 排雷结论)
- `finance/<公司>/财报关注要点.md`(核心跟踪变量 · 触发线)
- 快扫 `finance/<公司>/财务数据/` 关键 CSV(核对最新一期数据)

**② fresh 快检**
- diff:`分析.md` 头部「事实编年核对至:YYYY-MM-DD」 vs `knowledge/companies/<公司>/` 最新事件日期
- **差 >30 天 或 最新事件命中「核心跟踪变量」** → 🔴 **阻塞** · 先跑 `company-analysis` 刷新
- <30 天 且 无核心事件命中 → 通过

**③ 复述**
- 一段话:生意类型 · 生意质量评级 · 三前提复核结果 · 关键排雷结论
- 用户确认理解一致 → Step 2

## Step 2 · 双闸门(硬 gate)

**读 `finance/<公司>/分析.md`** 里已有结论(**不重新算**):
- 三、三大前提验证(每条 ✅/⚠️/❌)
- 二、商业模式与生意质量(生意四问的答案)

### 三前提
1. **利润为真吗?** (vs 收现比 / 应收 / 存货)
2. **利润可持续吗?** (vs 业务性质 / 竞争 / 政策)
3. **维持当前盈利需要大量资本投入吗?** (vs 资本开支 / ROIC)

### 生意四问
1. **靠什么获利?**
2. **客户为何采购?**
3. **资本逐利,为何他人没提供更高性价比的替代?**
4. **同行挟巨资涌入,能否抢走份额?**

**判**:
- 三前提**全 ✅** + 四问答得上 → Step 3
- 任一 ❌ or 四问答不上 → 归**"太难"** → 跳到 Step 6(结论 = 太难)
- 用户 override(要求继续)→ 记录 override 原因,继续

## Step 3 · 选估值法(交互)

菜单(问用户):

| 编号 | 估值法 | 适用 | 状态 |
|---|---|---|---|
| A ⭐ | **成长股估值法** | 好生意成长型 | ✅ canonical 已定(见下) |
| B | **周期股席勒法** | 强周期好生意(扣非序列覆盖完整周期·陕煤/分众类) | ✅ canonical 已定(2026-08-27·见下) |
| E | **归"太难"** | 算不清就明说,不勉强套公式 | ✅ |
| C | 银行股 PB × ROE | 银行/保险 | ⏳ backlog |
| D | DCF 折现 | 复杂现金流案例 | ⏳ backlog |

- 用户选 **A** → Step 4-A
- 用户选 **B** → Step 4-B
- 用户选 **E** → 跳到 Step 6(结论 = 太难)

## Step 4 · 应用公式算买卖点

### 4-A · 成长股估值法(canonical)

**输入**(三个变量):

| 符号 | 定义 | 来源 |
|---|---|---|
| **P₀** | 最近一个完整年度的扣非归母净利(元) | 读 `finance/<公司>/财务数据/利润表.csv` |
| **P₁** | 当年预计扣非归母(**当下这个财年**的预估值,面向未来 · 非最近年报值) | 用户输入 or 我基于 P₀ + 增速建议 |
| **P₃** | 三年后预计扣非归母 = **P₁ × (1+g)³**(外推基数 = 当年预估 P₁ · 三年后 = 当年+3;2026-08-16 全库统一,勿用 P₀ 作基数) | g 我基于近 3-5 年 CAGR 建议 · 用户 override |

**参数**:
- **r = 你能锁定的最低无风险利率**(默认 3.6%)
  - 定义:你**当下能锁定的最保守无风险回报** —— 大额存单/货基/逆回购等可得档中的**最低**那档
  - **排除**:非保本理财 / 信托 / 城投等**带隐藏信用风险**的高利率产品

**当轮快照(算「当前估值状态」与台账每股价必取,取数记进观点变更)**:
- **现价**:`scripts/quote.py <代码> <起> <止>`(新浪·一手行情)
- **总股本**:一手来源(港股 FF301 月报表 / A股定期报告 / 最新回购注销后数)
- **汇率**(非人民币计价股):优先用一手隐含值(如公告股息双币换算),注明出处

**公式**:
```
合理 PE = 1 / r                          (当前 r = 3.6% → PE = 27.5·上下沿 25 / 30)

P₃ = P₁ × (1+g)³                         (外推基数 = 当年预估 P₁ · 三年后 = 当年+3)

合理估值 = P₃ × 合理 PE                  (三年后市值锚)
买点     = 合理估值 × 50%                (五折买点)

当年卖点三档(基于 P₁):
  第一档 (卖 1/3) = P₁ × 50
  第二档 (卖 2/3) = P₁ × 55
  第三档 (清仓)   = P₁ × 60

当前估值状态:
  · 当前市值 < 买点       → 便宜(可加)
  · 买点 ≤ 市值 < 第一档   → 合理(不动)
  · 市值 ≥ 第一档          → 贵(到档减仓)
```

**输出**:`judgments/<公司>/估值.md` —— **纯定稿台账**(只增不改·每轮 append 一行):列 = **估值时间 / P₀(已知) / P₁(预估) / g / P₃ / r(合理PE·格式 `3.6%·27.5`) / 总股本(亿股) / 买点(亿·每股) / 卖点一二三(亿·每股)**,除此之外**不放任何描述**。**每轮同时必建 `judgments/<公司>/估值记录/YYYY-MM-DD/`(以估值时间命名的子目录)**,内含两件:①`推导.md`(单轮完整推导文档·骨架见 `_模板/估值记录.md`:结论速览+**本估值的核心含义(必读·用一段话明说这套假设意味着什么样的世界,如"AI 投入持续且吃掉三年利润增长")**/触发背景/双闸门与 override/各输入完整推导含备选情景/当轮快照出处/公式代入/状态与敏感性/能力圈/结论与作废条件/同轮修订历史/下次复核点);②`业务数据.html`(**估值基石业务数据图**·自包含 SVG 无外链离线可开:收入与利润序列/分部/季度节奏/蓄水池/毛利率/capex 与 FCF/敏感性阶梯等,每图标注"支撑哪条结论"与数据出处,图目按当轮论证链取舍)——**台账行与记录目录按估值时间一一对应**;`观点变更.md` 记决策流水。公式不重抄(以本 canonical 为准)。**每轮必取当时总股本**(一手来源:FF301 月报表/年报/最新回购注销后数),股价 = 市值÷总股本(非人民币计价股按当轮汇率换算)。当前有效买卖点 = 台账**末行**

### 4-B · 周期股席勒法(canonical·2026-08-27 定)

> **适用**:生意质量=好但**强周期**(单年利润不可外推·Step 2 前提③常为 ⚠️,须用户 override 留痕后进入);要求扣非序列**覆盖至少一整轮周期**(两峰两谷更佳)。
> 定位:A 法赌"三年后的成长",B 法赌"未来 N 年的平均盈利与过去 N 年相似"——**不做任何单年/成长外推**。

**输入**(两个变量):

| 符号 | 定义 | 来源 |
|---|---|---|
| **P̄** | 近 N 年扣非归母**算术平均**(正常化利润·丰年灾年互抵·**按披露值不做主观调整**——历年投资收益与偶发减值在长窗口内大致对冲,只剔不利项不剔有利项是不对称的) | 读 `finance/<公司>/财务数据/利润表.csv` |
| **N** | 平均窗口·默认 **10 年**;口径不可比年份(如借壳前模拟合并期)可整段排除,理由记入 推导.md | 用户确认 |

**参数**:**r** 同 4-A(你能锁定的最低无风险利率·默认 3.6%)。**当轮快照**要求同 4-A(现价/总股本/汇率·出处进观点变更)。

**公式**:
```
合理 PE  = 1 / r                     (r = 3.6% → 27.5·与 A 法同源)
合理估值 = P̄ × 合理 PE              (当下锚·无三年外推)
买点     = 合理估值 × 50%            (与 A 法统一五折安全边际·2026-08-27 用户定案)
卖点     = P̄ × 45(单档清仓)         (≈合理上沿 30 倍 × 1.5;周期顶尖而短,不分三档)

当前估值状态:
  · 市值 < 买点        → 便宜(可加)
  · 买点 ≤ 市值 < 卖点 → 合理(不动)
  · 市值 ≥ 卖点        → 贵(清仓)
```

**与 A 法的两点差异**(设计依据):①锚 = 当下均值利润,非三年后利润——贯彻"周期股单年不可外推";②卖点单档非三档——周期顶部常尖而短,分档递卖易卖不完。买点折扣与 A 法**同为五折**。
> ⚠️ 与同构先例的有意分歧:陕煤 2021"十年扣非均值×25×**70%**=买点"、分众 2023"十年正常利润 41.2 亿×25~30=合理 1130±10%·买点<790(≈×70%)·卖点 1850"(gurus 来源层)均用七折;本框架 2026-08-27 定案**统一五折**——更苛刻,周期股触发买点的概率显著更低,取"宁可错过、不冒中枢下移之险"的立场。

**输出**:同 4-A(台账 append + `估值记录/YYYY-MM-DD/{推导.md,业务数据.html}` + 观点变更)。**台账 11 列复用规则**:P₀ 列填 `P̄=xx(席勒·N年窗)`、P₁/g/P₃ 列填 `—`、买点列照常、**卖点一列填单档卖点、卖点二/三列填 `—`**。推导.md 的「核心含义」段必须写明:①P̄ 隐含"未来周期形态与过去 N 年相似"的世界;②作废条件(均值中枢下移的结构性证据/股本或利润基数突变事件)。

### 4-E · 归"太难"

直接跳到 Step 6,结论 = 太难,原因说明写进 `观点变更.md`。

## Step 5 · 能力圈 → 仓位上限

**能力圈档位映射**(canonical):

| 档位 | 定义(自问三问) | 建议仓位上限 |
|---|---|---|
| 深懂 · 核心 | 三年以上跟踪 · 关键变量能一句话答 · 三前提能量化 | **≤ 40%** |
| 懂 · 圈内 | 商业模式讲得清 · 财报速读能出结论 | **≤ 20%** |
| 半懂 · 边缘 | 大致理解但关键假设无法量化 | **≤ 10%** |
| 试仓 · 学习 | 刚开始跟踪 | **≤ 5%** |
| 不懂 | 讲不清楚商业模式 | **0**(不开仓) |

**流程**:
1. 我给档位建议(基于 `finance/<公司>/分析.md` 生意质量 + 用户此前沉淀)
2. **用户拍板**具体档位(可 override)
3. 输出 `judgments/<公司>/能力圈.md`(**覆盖式**)

## Step 6 · 综合结论(结论矩阵)

| 生意质量(客观·模块①) | 估值(Step 4) | 能力圈(Step 5) | 结论 |
|---|---|---|---|
| 好 | 便宜(<买点) | 懂 / 深懂 | **买** |
| 好 | 合理 | 懂 / 深懂 | **观察** |
| 好 | 贵(≥第一档卖点) | 任意 | **观察 · 到卖点分档卖** |
| 好 | 任意 | 半懂 / 试仓 / 不懂 | **观察 · 不动**(能力圈不足) |
| 平庸 / 差 | 任意 | 任意 | **避** |
| 双闸门没过 or 估不了 | — | — | **太难** |

**输出**:`judgments/<公司>/观点变更.md`(**只增不改** · append 一行):

```markdown
| YYYY-MM-DD | 结论 | 估值基准(P₀/P₁/g/P₃/买点/卖点3档 + 快照:现价/总股本/汇率及出处) | 仓位上限 | 关键假设 · 变更原因 |
```

同轮多次修订 → 每次修订各 append 一行(过程留痕),**末行日期后标「定稿」**;收尾把该轮定稿 append 到 **`估值.md` 台账**(每轮一行·纯数字·过程行不登)。分工:`估值.md` = 定稿台账(末行即现值);`估值记录/` = 单轮完整推导档(怎么得出的·一轮一档);`观点变更.md` = 日志(跨轮决策流水·变了什么为什么变);胜率回算只取定稿行。
