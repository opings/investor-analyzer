# 财务造假案例库

> 用真实造假案例**喂养**风险预警系统：录入案例 → 蒸馏特征 → 风险预警清单自己长大。
> 和大V侧同构：`ingest-guru → knowledge/gurus/<人>/style+playbook → guru-view` ｜ 这里 `ingest-fraud-case → 造假模式库 → caibao/invest-report 风险预警`。

## 结构（两层）

```
knowledge/造假案例库/
├── README.md            本文件
├── _案例模板.md          单案例归档模板
├── _下载档案清单.md       原始档案（处罚决定书/调查报告）下载台账
├── 造假模式库.md         ★ 蒸馏层（跨案例模式·风险预警第一层 canonical 源·活清单）
└── <公司>/              每家造假公司一个目录
    ├── <公司>-<年>.md    单案例归档（怎么造的 + 财报上的信号 + 蒸馏贡献）
    └── 处罚决定书/调查报告  证监会/SEC/第三者委员会等原始档案（HTML/PDF）
```

- **案例层**（`<公司>/<公司>-<年>.md`）：单个造假案的事后复盘，重点是"**事发前财报里就看得到的信号**"；同目录放该公司的处罚决定书/调查报告原始档案。
- **蒸馏层**（`造假模式库.md`）：把各案例的信号归纳成可复用的红旗清单（按虚增收入/虚增资产/隐藏负债/现金流/治理五类），分 🔴/🟡，带来源案例。

## 怎么用

- **录入新案例**：走 `ingest-fraud-case` skill（贴处罚决定书/做空报告/年报数据 + 公司名）→ 自动归档 + 增量更新 `造假模式库.md`。
- **分析公司时**：`caibao-analysis` / `invest-report` 的风险预警**对照 `造假模式库.md` 逐项扫描**，命中即按级别预警、带数据依据。
- **关系**：`造假模式库.md` 是风险预警**第一层（通用红旗，全公司适用）**；公司/行业特有指标在 `finance/_模板/财报关注要点-行业模板.md` → `<公司>/财报关注要点.md`（第二层）。

## 纪律
- 案例归档只记**当时公开可见**的财报信号，不记事后内幕（目的是训练"提前识别"）。
- 不编造具体公司数字；来源以处罚决定书/做空报告/审计意见为准。
- 蒸馏强调"**可操作的排除动作**"，不是事后诸葛。
