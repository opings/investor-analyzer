# 唐书房 2020 年合集 · 整理笔记 (完整一年 / 疫情元年)

> **一句话定调**: 2020 是老唐"**葛优瘫躺赢**"的一年 —— 疫情元年 + 全球股灾 (3 月美股四次熔断) 之下, 老唐**全年除新股外没卖过一股 (零印花税)**, 靠企业成长 + 分红/新增资金加仓, 收获 **+66%** (净值法 +69%), 七年累计净值 100→755 / 年化 33.5%。这一年也是**《巴芒演义》(3 月) 和《手把手教你读财报: 新准则升级版》(12 月) 两本新书面世**、老唐**首次认真考虑卖出茅台 (#55)**、**唐九条 (#79) 与老唐估值法答疑系列 (#102/106/108) 定稿**的一年。

## 四、年度核心 SOP (playbook 增量来源)

### 1. ★★★★★ PEG 史诗 (#2/#3, 2020-01-08) — "跨过这道坎只剩赚和躺赚"
- 老唐用 PEG 框架论证: 一旦真正理解"股票是特殊的债券 + 合理估值 = 无风险收益率倒数", 投资就只剩"赚"和"躺赚"两种结果
- 反 PEG 机械套用 (PEG=1 买入是格栅思维)

### 2. ★★★★★ 老唐估值法范本 + 答疑系列 (#33/#102/#106/#107) — 估值法定稿之年
- **#33 茅台估值/买点/卖点计算演示**: 完整展示老唐估值法实操 (三年后净利 × 25-30 → 合理估值 → 50% 买点 / 150% 或卖点)
- **#106/#107 估值法答疑之再续**: 史诗级权威续作 + **估值更新 SOP (估值固化: 年初 + 年中各一次常规调整, 重大新信息单独调整)**
- 此后老唐估值表"正式固化"为标准披露格式

### 3. ★★★★★ 唐九条 = 1500 字概括投资体系 (#79, 2020-10-13)
- 国宝级浓缩: 把老唐整个投资体系理念核心压缩成 1500 字九条 (后续多次被引用为体系总纲)

### 4. ★★★★★ 茅台首次认真考虑卖点 (#55, 2020-07-04) — 卖出哲学经典
- 老唐**首次认真讨论茅台触及卖点后的后续计划** (此前从未卖过茅台)
- 为 2021 春节前真正卖出茅台埋下伏笔
- 卖出本质 = 收益率比较, 不是"逃顶"

### 5. ★★★★★ 从负油价奇迹谈确定性与仓位管理 (#31, 2020-04-21)
- 借 2020/4 WTI 原油负价格奇迹, 讲**确定性 + 仓位管理原则** (按确定性安排仓位 / 适度分散 / 个股上限)

### 6. ★★★★★ 财富的两个要点 / 财富三轮车 (#7/#28)
- **财富 = 本金 × (复利 / 时间)**; 阅读的价值 = 提升认知 → 提升本金回报率
- 10% 年化 vs 20% 年化复利对照表 (奋斗目标)

### 7. ★★★★★ 福寿园 6 集 = "如何从零开始研究一家企业" (#82-96, 2020-10/11)
- 完整研究方法论范本: 财报特征 → 需求 4 角度 → 政策+竞争 ("真正的对手只有它自己") → 6 假风险 + 3 真风险 → 股权激励真相 → 结论
- 墓园 vs 房地产 5 区别
