# 造假案例：康美药业 600518（300 亿"造假王"·虚构现金标杆）

> ⚠️ 事后复盘。本案与 [[康得新-2019]] 并称，是**货币资金造假/虚构现金**最具代表性的当代案例，证监会定性"**有预谋、有组织，长期、系统**实施财务造假"。饶钢《财报真相》以代称"康某药业·财务黑洞"收录。

## 1. 怎么造的（手法）
康美药业 2016-2018 年**三张报表协同造假**：
- **虚增货币资金（核心）**：用**伪造的银行单据**虚增银行存款，年报披露的货币资金严重不实——2016 年报虚增 225.8 亿、2017 年报虚增 299.4 亿、2018 半年报虚增 361.9 亿，**累计虚增货币资金 887 亿元**。
- **虚增收入利润**：通过**伪造、变造增值税发票及业务凭证**虚增营业收入约 275 亿、虚增利润约 39 亿。
- **隐瞒关联方资金占用 + 炒自家股票**：部分资金转入关联方账户买卖康美自身股票，隐瞒控股股东非经营性资金占用。
- 2019-04-29 以"会计差错更正"名义"自曝"货币资金多计 299.44 亿——典型"挖坑自己跳"。

## 2. 财报上的信号（★最关键）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **存贷双高**：巨额货币资金 + 大额有息负债 | 账上数百亿现金还大量借债/发债 | 资产负债表 | ✅ 🔴 一票排除项 |
| 货币资金**利息收入率异常低** | 数百亿"存款"却几乎无相应利息收入 | 利润表(利息收入)÷货币资金 | ✅ 简单一算即露馅 |
| 经营现金流与巨额账面现金/利润背离 | 钱多却仍缺钱、靠融资 | 现金流量表 | ✅ |
| 大额其他应收款/关联资金占用 | 资金被关联方占用、炒自家股 | 其他应收款·关联方 | 🟡 |
| 频繁大额融资/发债 vs 账面不缺钱 | "不缺钱"却拼命借钱=鬼在这里 | 筹资现金流/负债 | ✅ |

## 3. 事发经过
2018 年底起市场质疑其"存贷双高、货币资金虚高"。2019-04-29 康美发布会计差错更正公告，承认货币资金多计 299.44 亿。2019-05 证监会调查坐实系统性造假。证监会认定累计虚增货币资金 887 亿、虚增收入 275 亿。因适用旧《证券法》仅罚款 60 万元引发"罚酒三杯"争议，但成为**全国首例证券特别代表人诉讼**，一审判赔投资者约 24.59 亿元，实控人马兴田被追刑责。后经重整"复活"摘帽。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 与 [[康得新-2019]] 并列坐实 **B. 虚增资产/虚构现金**：「**存贷双高**」「货币资金巨大却**利息收入率异常低**/仍借高息债」「**伪造银行单据虚增存款**」——货币资金可以是假的，必须验真。
- 强化 **A**：「伪造增值税发票/业务凭证虚增收入」。
- 强化 **E**：「关联方资金占用 + 用占用资金买卖自家股票」。
- 跨案口诀实证："**钱多还借债=鬼在这里**""三张表协同造假，但**现金最该被验真**"。

## 5. 教训 / 识别方法
- **存贷双高直接 pass**：数百亿现金 + 大额有息负债并存，单这一条就该高度警惕。
- **利息收入率验真现金**：利息收入 ÷ 平均货币资金远低于活期利率 → 现金可能是假的。
- "不缺钱却拼命融资/发债"、频繁会计差错更正 = 强危险信号。
