# 造假案例：宏达新材 002211（专网通信系 · 隋田力代持 + 商誉违规）

> ⚠️ 事后复盘。专网通信案中**隋田力直接代持成为实控人**的样本，兼有商誉减值违规。来源以证监会决定书为准。

## 1. 怎么造的（手法）
- **实控人代持隐瞒**：隋田力与上海鸿孜法定代表人杨鑫约定，由上海鸿孜**代隋田力持有宏达新材股权**，隋田力实为实控人，但宏达新材**未按规定真实披露实控人**。
- **专网通信虚增**：2019 年虚增收入 2.47 亿/利润 0.30 亿；2020 年虚增收入 4.89 亿/利润 1.03 亿。
- **商誉减值违规**：2020 年末商誉减值测试时，认定的资产组与商誉初始确认时**不一致**，导致**未计提商誉减值，虚增利润 7580 万元**。

## 2. 财报上的信号（★最关键）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **实控人披露存疑/代持** | 名义控股方代隋田力持股 | 股权结构/公告 | 🟡 股权穿透难，但代持迹象可疑 |
| 与主业（有机硅）无关的**专网通信收入** | 不相关业务贡献收入 | 利润表/分部 | ✅ |
| **商誉减值"该提未提"**（资产组口径变动规避减值）| 测试资产组与初始不一致、不计提 | 商誉/资产减值附注 | ✅ 资产组口径变动=规避减值信号 |
| 增收不增现金 | 营收 vs 经营现金流 | 现金流量表 | ✅ |

## 3. 事发经过
2023-04-10 收到处罚字〔2023〕24号：公司罚 300 万，**隋田力（实控人）罚 1000 万**，杨鑫 200 万，乐美彧 50 万。深交所亦对隋田力等公开谴责。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 强化 **A 类「专网通信式自循环」**（同 [[凯乐科技-2023]] 等）。
- 新增 **E 类**红旗：「**实控人代持/披露不真实**」——隐藏真实控制人。
- 新增 **C/B 类**红旗：「**商誉减值'该提未提'：变动资产组认定口径规避减值、虚增利润**」（与 [[奥林巴斯-2011]] 商誉洗亏呼应，但本案是"规避计提"）。

## 5. 教训 / 识别方法
- **商誉减值测试的资产组口径若与初始确认不一致** → 警惕借口径变动规避减值、虚增利润（看附注资产组划分）。
- 实控人/代持披露含糊、名义股东与实际控制脱节 → 治理红旗。
- 与主业无关的专网通信/贸易收入 → 空转嫌疑。
