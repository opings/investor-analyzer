# 造假案例：金亚科技 300028（IPO 欺诈发行 + 两套账）

> ⚠️ 事后复盘。创业板早期"带病上市 + 上市后继续造假"的典型。来源以证监会处罚决定书/法院判决为准。
> 与本库归档关系：黄世忠等《财务舞弊识别与审计失败防范》研究涉及此类案例；**是否为该书 featured 案例待原书确认**，故来源以监管/司法为一手。

## 1. 怎么造的（手法）
- **IPO 欺诈发行（带病上市）**：2008-2009.7，实控人周旭辉授意财务总监、销售经理，**虚增、夸大 2006-2008 及 2009 上半年的营收与盈利能力**，用造假数据通过证监会审核，2009-10 创业板挂牌、募资净额 3.92 亿。
- **上市后继续造假（2014）**：通过**虚构客户、虚构业务、伪造合同、虚构回款**等方式虚增收入利润——2014 年**虚增利润总额 8049.55 万元**；同时**虚增银行存款 2.17 亿、虚增预付工程款 3.1 亿**（虚构现金+把窟窿挂在预付款）。
- **两套账**：设 003 账套（内部真实管理）+ 006 账套（对外披露的假数据）——典型的内外两本账。

## 2. 财报上的信号（★最关键）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **IPO 报告期利润恰好达标、上市即变脸** | 申报期虚增撑上市，挂牌后业绩下滑 | 利润表 | ✅ 报告期精准达标警惕 |
| **虚增货币资金**（虚构银行存款） | 2014 虚增银行存款 2.17 亿 | 资产负债表·货币资金 | ✅ 用利息收入率/银行函证验真 |
| **预付工程款异常虚高**（窟窿出口） | 2014 虚增预付工程款 3.1 亿 | 资产负债表·预付账款 | ✅ 大额预付款查对手方/进度 |
| 虚构客户/合同/回款 | 客户、合同、回款均伪造 | 收入、应收、附注 | 🟡 需穿透核验 |
| 利润 vs 经营现金流背离 | 账面利润 vs 真实造血 | 现金流量表 vs 利润表 | ✅ |

## 3. 事发经过
2015 年证监会立案，历经两年半调查。2018 年披露 IPO 欺诈发行 + 2014 年系统造假（两套账）。证监会处罚公司 60 万、周旭辉 90 万 + 终身市场禁入。周旭辉数罪并罚获刑 3 年缓 5 年。因 2016-2018 连续三年净利为负，2019-05 暂停上市后退市。实控人曾扬言"对标乐视"。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 强化 **A 类**：「IPO 报告期造假/带病上市」（与绿大地/新大地/紫晶存储同族）、「虚构客户合同回款」。
- 强化 **B 类**：「虚增货币资金（虚构银行存款）」（与康得新/康美呼应）、「**预付款异常虚高=窟窿出口**」（与广汇/紫晶呼应）。
- 新增 **E 类**视角：「**内外两套账**」——一旦坐实即铁案级造假。
- 典型的**黄世忠所谓"交易造假型"**：伪造真实交易（客户/合同/回款）而非单纯改分录。

## 5. 教训 / 识别方法
- 次新股/创业板：IPO 报告期精准达标 + 上市即变脸 = 高危。
- 货币资金用**银行函证/利息收入率**验真；**大额预付工程款**当窟窿出口查（对手方、工程进度真实性）。
- "对标乐视"式高调扩张叙事 + 业绩反常 → 提高警惕。
