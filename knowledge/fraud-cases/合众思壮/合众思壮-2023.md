# 造假案例：合众思壮 002383（专网通信系 · 多业务线虚构）

> ⚠️ 事后复盘。专网通信骗局涉案公司之一，特点是**多条业务线同时造假 + 财务费用跨期调节**。来源以证监会决定书为准。

## 1. 怎么造的（手法）
2017-2020 年，合众思壮（北斗导航龙头）通过**多条线**虚增收入利润：
- **虚构雷达业务（空转循环贸易）**：向虞某实际控制的公司**采购、再销售给虞某指定的通道公司**——自己买进再卖给对方安排的下家，形成空转循环。虚增 2017-2019 收入 6.09 亿、成本 5.48 亿。
- **专网通信垫资**：以"为北斗导航及子公司提供加工服务"为名加入专网通信链条，**实际不承担加工、不提供任何有附加值技术，只作出资方垫资**。虚增 2017-2020 收入 9.39 亿、成本 5.12 亿、利润 4.27 亿。
- **虚构软件销售和技术服务费收入**。
- **跨期确认票据贴现费用**：把财务费用跨期挪，**虚减财务费用 1.18 亿**做高利润。
- 合计虚增收入 15.81 亿、利润 5.21 亿。

## 2. 财报上的信号（★最关键——哪里能发现异常）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **多条新业务线（雷达/专网/软件）突然贡献大额收入** | 与主业协同弱的业务集中放量 | 利润表/分部 | ✅ 多条不相关业务齐放量=可疑 |
| **空转循环贸易**（向 X 采购再卖给 X 指定通道公司）| 供应商与下家由同一方安排 | 关联/客户供应商交叉 | ✅ 对手方穿透 |
| **垫资出资方角色**（不承担实质、只出钱）| 名为加工实为垫资 | 业务实质/毛利率 | 🟡 需穿透商业实质 |
| **财务费用异常偏低/跨期**（虚减 1.18 亿）| 票据贴现费用跨期确认压低财务费用 | 利润表·财务费用 | ✅ 财务费用与有息负债/票据规模背离 |
| 增收不增现金、垫资占用资金 | 营收增 vs 经营现金流 | 现金流量表 | ✅ |

## 3. 事发经过
专网通信骗局暴露后被牵出，2022 年立案，2023-05 处罚（合计 1250 万）。创始人郭信平（曾牵手姚明代言）等被罚。公司后续持续亏损、面临股民索赔。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 强化 **A 类「专网通信式自循环/虚构贸易」**（与 [[凯乐科技-2023]]、[[江苏舜天-2024]] 同族）；本案补：
  - **多业务线齐造假**：雷达+专网+软件三线同时虚构。
  - **垫资出资方**模式（不承担实质、只提供资金）。
- 新增 **C 类**红旗：「**跨期确认费用（如票据贴现费）虚减财务费用**做高利润」——财务费用与有息负债/票据规模背离可察。

## 5. 教训 / 识别方法
- 多条**互不相关的新业务线同时放量**贡献收入 → 警惕批量虚构。
- 看公司在交易链中**是否承担真实角色/风险**：只出钱垫资、不提供附加值 = 通道/空转。
- **财务费用异常低**（与有息负债、票据贴现规模不匹配）→ 查是否跨期调节。
- 供应商与客户由同一方指定/安排 = 循环。
