# 造假案例：上海普天 600680（2014 虚假贸易扭亏 · 非专网通信）

> ⚠️ 事后复盘。**更正说明**：本案是 2014 年独立的虚假贸易造假，**不属于隋田力"专网通信案"**（backlog 初版曾误归类，经决定书核实更正）。来源以证监会决定书/法院判决为准。
> ✅ 处罚决定书已存档（公司公告逐字转载上海证监局2018决定书；普华永道审计师另案 c7506621）。

## 1. 怎么造的（手法）
2014 年，时任副董事长、总经理郑某某为完成年度利润指标、实现盈利，授意总会计师陆某、能源公司总经理沈某某等，采用**与其他公司开展无实物交割、资金闭环的虚假贸易**，并**违规延期结转成本费用**，虚增主营业务收入 1.23 亿、虚增利润 1810.35 万元——**虚增利润占当期披露利润总额 133.61%，把亏损披露成盈利**。

## 2. 财报上的信号（★最关键）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **年末突击虚假贸易冲业绩**（无实物交割/资金闭环）| 2014 突击交易扭亏 | 利润表/分部、第四季度收入 | ✅ 临界扭亏+突击贸易=可疑 |
| **违规延期结转成本费用**（少结转成本做高利润）| 成本费用跨期 | 利润表·营业成本 | ✅ 毛利异常、成本与收入不配比 |
| **虚增利润占比畸高、恰好扭亏为盈** | 占披露利润 133.61% | 利润表 | ✅ 利润恰好转正=粉饰嫌疑 |
| 增收不增现金 | 营收 vs 经营现金流 | 现金流量表 | ✅ |

## 3. 事发经过
2018-03 证监会处罚（2014 年报虚假记载）。2020 年法院判决（虚增主营收入 1.23 亿"曾震惊 A 股"）。老牌央企上海普天后因亏损/转型主动退市。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 强化 **A 类「虚构贸易/资金闭环」**（与专网通信系同理，但本案 2014、独立主导）；
- 强化 **C 类「违规延期结转成本费用」**（与 [[合众思壮-2023]] 跨期调费用、成本跨期同族）；
- 新增判据：**临界点突击虚假贸易扭亏为盈**（利润恰好转正、占比畸高）。

## 5. 教训 / 识别方法
- 公司在**盈亏临界点**靠年末突击"贸易"扭亏 → 高度警惕（看第四季度收入集中度 + 是否无实物）。
- 成本费用**跨期/延期结转** → 毛利与成本配比异常。
- 虚增利润占披露利润比畸高、恰好把亏损做成微利 = 典型粉饰。
