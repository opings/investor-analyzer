# 造假案例：Valeant 威朗制药（隐秘专卖药店 + 渠道塞货）

> ⚠️ 事后复盘。被称"制药界的安然"，《财务诡计》第4版作为**当代**案例收录。来源以 SEC/做空报告为准。

## 1. 怎么造的（手法）
Valeant 靠**连环高杠杆收购 + 激进提价**做出"高速有机增长"叙事，并用一家**隐秘关联的专卖药店 Philidor** 粉饰收入：
- **隐秘控制的渠道 + 渠道塞货**：Valeant 出资设立/补贴 Philidor（付 1 亿美元买下"1 美元收购期权"），却长期不披露这层关系；向 Philidor **提前确认/塞货**确认收入。2014 年因此**虚增、需调减收入约 5800 万美元**（提前确认）。
- **"幻影"有机增长**：**连续 5 个季度**宣称两位数"同店有机增长"（一个非 GAAP 指标），其中很大部分实来自对 Philidor 的销售。
- **激进提价撑收入**：靠收购来的药大幅提价——**Nitropress 提价 525%、Isuprel 提价 212%**（两种心脏病急救药），把价格上涨收入错误归集到众多产品。
- 本质：用关联渠道 + 收购 + 提价制造的增长不可持续，被做空者点破。

## 2. 财报上的信号（★最关键）
| 信号 | 当时表现 | 哪张表/科目 | 事后能否识别 |
|------|---------|-----------|------------|
| **靠连环收购堆增长**、有机增长存疑 | 收购驱动、"有机增长"虚高 | 分部/收购披露 | ✅ 拆解增长来源 |
| **隐秘关联渠道**（专卖药店）贡献大量收入 | 与 Philidor 关系长期不披露 | 关联交易/渠道集中度 | 🟡 做空报告揭出 |
| 渠道塞货/提前确认 | 向 Philidor 提前确认 5800 万 | 收入确认、应收/渠道库存 | ✅ |
| **激进提价**撑收入 | Nitropress +525%、Isuprel +212% 等收购药大幅提价 | 收入结构 | ✅ 提价幅度离谱 |
| **非 GAAP"同店有机增长"连续多季亮眼** | 连续 5 季两位数同店有机增长、实赖 Philidor | 非GAAP指标 vs GAAP | ✅ 拆非GAAP口径 |
| 高杠杆 + 商誉/无形资产巨大 | 收购累积巨额商誉债务 | 资产负债表 | ✅ |

## 3. 事发经过
2015-10 做空机构（Citron 等）揭露 Valeant 与 Philidor 的隐秘关系、指其渠道塞货 → 股价从约 260 美元一路崩塌，2015-08 至 2016-02 跌逾 60%（后续跌至个位数）。公司重述 2014 收入。2016-04 CEO Pearson 被免。2020 年 SEC 和解：公司付 4500 万美元，Pearson、CFO Schiller、财务总监 Carro 分别付罚。公司更名 Bausch Health。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 新增 **A/E 类**红旗：「**隐秘关联渠道/专卖店贡献大量收入**（不披露关系 + 渠道塞货）」「**激进提价/一次性涨价撑收入**」。
- 新增视角：「**靠连环收购堆增长、有机增长存疑**」——拆增长来源（收购 vs 真实内生）。
- 与 [[瑞幸咖啡-2020]]（虚构交易+做空揭穿）、[[Sunbeam-1998]]（渠道塞货）呼应：**渠道+做空报告**是当代识别利器。

## 5. 教训 / 识别方法
- 拆**增长来源**：收购堆出来的"增长"和激进提价不可持续；问"剔除收购与提价后内生增长还剩多少"。
- 警惕**收入高度依赖单一/关联/不透明渠道**——尤其关系披露含糊的"专卖店/经销商"。
- 高杠杆连环收购 + 巨额商誉 + 做空质疑，三者叠加要高度警惕。
