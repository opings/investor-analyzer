# 造假案例：华讯方舟 000687（专网通信系 · 自组网空转）

> ⚠️ 事后复盘。隋田力"专网通信"自循环案涉案公司之一，造假占营收比一度达 83%。来源以证监会决定书为准。

## 1. 怎么造的（手法）
2015-2020 年，华讯方舟通过**虚构自组网业务**虚增营收利润：硬件产品业务是**以隋田力为核心的空转自循环**——整个业务链条上的公司均由隋田力**控制或指定**，**销售回款资金来自隋田力控制的"北京新一代"**，资金走一圈形成**闭环**。虚增收入占各年披露营收比例逐年攀升至 **83.14%（2018）**——即绝大部分营收是假的。

## 2. 财报上的信号（★最关键）
| 信号 | 当时数据表现 | 哪张表/科目 | 事后能否识别 |
|------|------------|-----------|------------|
| **单一业务（自组网/硬件）占营收比畸高且暴涨** | 虚增占营收比升至 83% | 利润表/分部 | ✅ |
| **回款资金来自同一关联方**（北京新一代）| 销售回款全来自隋田力控制的公司 | 现金流/客户回款穿透 | ✅ 回款来源集中=资金闭环 |
| **空转自循环·链条公司同一方控制** | 上下游均隋田力控制/指定 | 关联/客户供应商穿透 | 🟡 穿透对手方 |
| 营收暴增但经营现金流/回款质量存疑 | 增收靠闭环资金 | 现金流量表 | ✅ |

## 3. 事发经过
2021-07 收到证监会处罚决定书（载明 2016-2018 半年报/年报虚假记载）。2022-06-17 深交所终止上市，转两网/退市板块。

## 4. 蒸馏贡献（→ 造假模式库.md）
- 强化 **A 类「专网通信式自循环」**（与 [[凯乐科技-2023]]、[[江苏舜天-2024]]、[[合众思壮-2023]] 同族）。
- 突出判据：**销售回款资金来自同一关联方** = 资金闭环的直接证据（查回款来源集中度）。

## 5. 教训 / 识别方法
- 单一业务占营收比逐年飙升至七八成 → 高度警惕。
- **查销售回款的资金来源**：若集中来自一两个关联/指定方 → 资金闭环自循环。
- 对手方（供应商+客户+回款方）由同一方控制/指定 = 空转。
