# 研究新公司 · 分析流程

> **这是什么**：拿到任何一家公司后，把它**研究清楚**的主流程——我自己的价值投资分析框架（蒸馏自多位大V，子工具的原文出处见各处指针；**本框架不署单一大V名**）。
> **核心边界**：本流程**只回答「这家公司是什么样」（关于公司·客观）**，不回答「我懂不懂、它值多少、买不买」——那是关于**我**、关于**价格**的下游决策，见文末「流程之外」。
> **无任何事前预判**：不设能力圈闸门、不做「看不懂就跳过」的粗筛、不按品类一刀切。**来到桌上的公司，一律走同一套分析**。能力圈是靠分析 + 长期追踪「养」出来的，不是事前「筛」出来的——设任何前置闸门，新公司都永远进不来。

## 第一层 · 事实底座（硬前置·三样缺一就先补再分析）

| 底座 | 落点 | 怎么补 |
|---|---|---|
| ① 上市至今三表+比率（**从 ③ 一手财报 PDF 解析**·唯一真源） | `finance/<公司>/财务数据/*.csv` | 起点 = 招股书补齐的上市前 3 年，终点 = 最新一份定期报告；逐行解析 ③ 财报 + 勾稽自洽校验 + 比率派生（`_build_from_pdf.py`）；**不用东财二手**；季度粒度另存 `*-季度.csv` |
| ② 近 3 年事实编年 | `knowledge/companies/<公司>/YYYY-MM.md` | 一手公告核验后写入（只记事实·零判断） |
| ③ 一手财报 PDF 全集 | `report/<公司>/` | **招股书 + 上市至今全部年报 + 中报 + 季报**（一份都不能少）。命名：`招股说明书.pdf` / `YYYY.pdf`（年报）/ `YYYY-H1.pdf`（中报）/ `YYYY-Q1.pdf`·`YYYY-Q3.pdf`（季报）。`notices.py` 探 announcementId → 直链 `static.cninfo.com.cn/finalpage/{日期}/{id}.PDF` curl 下；file + 大小 + 首页三验 |

> 底座不全 = 地基没打就盖楼。**三样缺一就停下来补，绝不在残缺数据上出分析结论。**关键期（最近年报 / 会计差错更正期）双源交叉验证 + 三表自洽；**脚本按列名提数，不手抄**。
> **③ 为何必备**：CSV 是东财**二手**、会错（农夫 256→211 现金流坑实证），一手财报 PDF 是**二手数据的仲裁源** + 独家含董事会报告/附注；**招股书**独家含上市前 3 年经审计数据（上市早期年份唯一真源），**中报/季报**是最新经营动向的唯一一手来源（年报有 3–6 个月滞后，只用年报 = 用过期底座估当下）。
> 📐 完整规则见 `finance/_模板/财报阅读规则.md` **Step −1**。读三表的目的，就是为了看懂下面第二层的 ①②③。

## 第二层 · 分析漏斗（只认识公司·两块）

### 正面 · 商业模式 / 生意质量——这门生意多好

「商业故事」和「资产负债表」是一体两面，一起看：

| 三连问 | 在问什么 | 财报上的影子 |
|---|---|---|
| ① 靠什么挣钱 | 卖什么 · 被需要吗 · 客户为何选它 · 难替代吗 | 毛利率 / 营业利润率 |
| ② **钱能不能回款** | 收现比（销售收现÷营收）、应收占比、合同负债（预收=强）、经营现金流÷净利 ≥1 | **收不回的利润 = 纸面富贵，直接降档** |
| ③ **行业链地位强不强** | 能否无息占用上下游资金、议价权、护城河、竞争格局（真正的对手是不是只有它自己） | 应付↑ / 应收↓ / 合同负债↑ = 强势占款 |

> 📐 核心 4 问 + 护城河 5 来源的 canonical 源已删除·待重新设计；回款类数据口径见 `财报阅读规则.md` **Step 2①**。

### 反面 · 排雷与风险——这门生意会怎么坏 / 是不是真的

一个维度的三个侧面，统摄一句：**抛开「生意好」的故事，这家公司有没有可能是假的 / 烂的 / 扛不住的？**

| 侧面 | 在查什么 | canonical / 工具 |
|---|---|---|
| **财务证伪** | 三表勾稽找断点 + 红旗清单查实（事反必妖、存贷双高、毛利升应收升、现金流肖像…） | `财报阅读规则.md` **Step 3.0 + Step 3**；红旗 canonical 在 `造假案例库/造假模式库.md`（随案例增长） |
| **管理层诚信** | 董事会报告（连读几年+同行对比，最大宝藏）、股权激励是否与股东一致、大股东行为、关联交易、附注 | —— |
| **前瞻风险** | 不预测方向，而是**假设走到最坏极端，量化对净利的冲击，再问能不能承受**；6 维度：行业/区域→价格→需求→政策→管理层→黑天鹅 | 假风险 vs 真风险；变坏→斩仓 / 变贵→持有 |

> 「财报是用来排除企业的」——排掉 ①竞争力低下 ②数据可疑 ③不诚信管理层。**有疑就杀**，不必证明造假。命中 🔴 优先直接排除。

## 产出 · 对公司的客观认识

走完两块，得到：**生意画像 + 风险清单 + 生意质量定性（好 / 平庸 / 差 / 回避）**。

- 「生意质量定性」是对**公司**的结论——留在流程内。
- 「我懂不懂」（能力圈）是对**我自己**的结论、「它值多少」（估值）是对**价格**的结论——**都在流程之外**（下游）。

## 流程之外 · 下游决策（看懂公司之后，本文只给指针）

| 下游 | 干什么 | 去哪 |
|---|---|---|
| **估值** | 另起一步：先过三前提闸门 → 选估值法 → 算合理估值/买卖点 | 待重新设计（原 `valuation-method` skill 已删除）|
| **能力圈** | 我的**主观**判断，靠极致分析 + 长期追踪「养」深；深度（浅/中/深）决定**敢下多重仓**（仓位上限），不决定让不让我研究 | 主观层·落点待重建（**不落 `finance/`**）|
| **综合落点** | 生意质量 × 价格 × 能力圈深度（三轴正交，都高才下重注）→ 买 / 观察 / 避 + 仓位 | 主观层·落点待重建（**不落 `finance/`**）|

> 三轴正交：**评级**说公司好不好（与我无关）· **估值**说便宜不便宜 · **能力圈**说我懂不懂（决定我敢押多少）。

## 红线 / 心法

- **先建真实底座再推理**——不凭印象、不靠训练记忆下结论；现价 / 大V视角永远殿后。
- **先买对、再买贵** · **财报是用来排除企业的** · **宁错过，不做错**（亏 40% 要赚 67% 才打平）。
- **能力圈靠养不靠筛**：没有事前测试，只有研究 + 长期追踪挣来的深度；够不着的，研究完老实归「太难」——是结论，不是拒之门外。
- **事实与判断分层**：`companies/` 只记发生了什么（零判断）；`finance/<公司>/` 记公司当前客观长什么样（财报来了会重刷）；主观判断的变更史 `观点变更.md` 只增不改、留着算自己胜率（属主观层·落点待重建）。
