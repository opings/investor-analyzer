# 泸州老窖（000568.SZ）一手财报库索引

> 数据源：巨潮资讯（cninfo）· 深交所披露。全量下载自 `scripts/notices.py` 探明 announcementId + curl 直链。
> A 股上市日：1994-05-09（深交所主板）· 数据覆盖：年报 2006-2025（20 年）+ 2016 起中报/季报 + 2026-Q1。

## ⚠️ 前置说明（读财报前必看）

**泸州老窖 2025 年营收/利润下滑是真实经营下滑**（营收 -17.5%、归母 -19.6%），**不是**五粮液式的 sell-in→sell-through 会计差错更正——审计口径连续、无追溯重述。

三表建库（`finance/泸州老窖/财务数据/`）为保证 2006-2025 可比，对两处历史口径变化采用「重述口径」：
- **2006**：《企业会计制度》(老准则) 末年 → 采用 2007 年报追溯重述的 CAS2006 口径
- **2016**：全面营改增（2016-05）→ 采用 2017 年报按新口径重述的值

详见 `finance/泸州老窖/财务数据/README.md`。

## 数据可信度

1. **一手来源**：全部 PDF 从巨潮 cninfo `static.cninfo.com.cn/finalpage/` 直链下载，未经二手转手。
2. **完整性**：下载后 `file` + 大小（MB 级）+ 抽读首页三验；2006-2015 年报为补充下载（`/tmp/fetch_lzlj_annual.py` 探 id + urllib 下载）。
3. **命名规范**：`YYYY.pdf`=年报 · `YYYY-H1.pdf`=半年报 · `YYYY-Q1.pdf`=一季报 · `YYYY-Q3.pdf`=三季报。
