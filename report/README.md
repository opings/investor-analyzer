# report/ — 一手财报源档柜（本地维护 · 源档不入 git）

> 本目录放**一手财报源档**：招股说明书 / 年报 / 中报 / 季报 PDF（及公告、10-K 等）。
> **源档体积大（全量 ~1.7GB），不入 git** —— git 里只保留本 README + 蒸馏后的文本知识库（`finance/` 分析、`财务数据/*.csv`、`knowledge/`）。
> 你 clone 本项目后，**自己下载的年报按下面约定放进来**即可在本地跑分析（`finance/<公司>/财务数据/*.csv` 全部从这里的 PDF 逐行解析 + 勾稽校验）。

---

## 放档约定

每家公司一个子目录，**目录名与 `knowledge/companies/INDEX.md` 的「公司名」列一字不差**（跨目录引用才不断）：

```
report/<公司名>/
├── 招股说明书.pdf              # IPO 发行文件（独家含上市前 3 年经审计数据；补充版 → 招股说明书-YYYY-MM补充.pdf）
├── YYYY.pdf                    # 年报，每年一份（如 2024.pdf）
├── YYYY-H1.pdf                 # 中报（半年报）
├── YYYY-Q1.pdf / YYYY-Q3.pdf   # 季报（A 股必备；港股按披露，无则实证不可得）
```

- 完整「底座盘点表」+ 命名规范见 `finance/_模板/财报阅读规则.md` Step −1。
- **一手财报是唯一真源**：不用东财二手 CSV（会错——农夫实证「经营现金净额」256 亿实为税前、真 211 亿）。

## 怎么下载（A 股 / 港股均走巨潮 cninfo）

1. **探公告 announcementId**：`python3 scripts/notices.py <发布窗口起> <止> <代码>`
   （招股书=上市当年发行文件；年报次年 3-4 月；一季报 4 月底；中报 8 月；三季报 10 月）
2. **直链下载**：`curl -fsSL http://static.cninfo.com.cn/finalpage/{公告日期}/{id}.PDF -o report/<公司>/YYYY.pdf`
3. **三重验**：`file` 为 PDF + 大小 MB 级（错误页是几 KB 的 HTML）+ 抽读首页确认公司/年份/期间无串号

> 临时/探索性下载先走 `/tmp/`，验完再挪进 `report/<公司>/`（别在项目目录攒孤儿 PDF）。

## 为什么源档不入 git

- **体积**：全量 ~1.7GB 二进制，入 git 会让每次 clone 暴涨、历史永久膨胀（二进制不 diff）；
- **定位**：git 维护的是**可复用的逻辑与蒸馏知识**（脚本 / CSV / 分析 / 规则），源档是**本地档柜**；
- **版权**：一手财报是公开披露文件，各自按需下载即可，不随仓库再分发。
