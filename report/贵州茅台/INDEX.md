## 数据可信度

1. **一手来源**：全部 PDF 直接从巨潮 cninfo `static.cninfo.com.cn/finalpage/` 直链下载，未经二手转手。
2. **完整性**：全部 PDF 经 pypdf 首页抽读验证，无短篇/说明会公告/摘要误抓（2011/2012 年报最初误抓的说明会公告已重下并替换）。
3. **命名规范**：`YYYY.pdf` = 年报 · `YYYY-H1.pdf` = 半年报 · `YYYY-Q1.pdf` = 一季报 · `YYYY-Q3.pdf` = 三季报 · `YYYY-招股说明书.pdf` = IPO 材料。
4. **重跑复现**：`/tmp/download_moutai_history.py` 用 akshare cninfo API 探明 + curl 拼直链下载，重跑即复现全部结果。
