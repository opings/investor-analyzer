# analyses/

> ⚠️ 早期设计的占位目录，当前未启用。生成的报告现在主要落在 `report/`（如每日日报 `report/daily/`），
> 综合投研报告由 `invest-report` skill 编排输出。本目录暂作保留，如需归档独立分析报告可启用以下约定。

存放生成的分析报告（`guru-view` / `invest-report` / `backtest-call` 的输出）。

## 命名约定

- `YYYY-MM-DD-guru-<大V>-<标的>.md`
- `YYYY-MM-DD-compare-<主题>.md`
- `YYYY-MM-DD-backtest-<大V>-<时间窗>.md`

## 用途

- 给用户看
- 后续可以拿来做"分析准不准"的元复盘（我们的工具自己也会出错）
